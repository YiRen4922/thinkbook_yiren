现代C++学习资源汇总（C++11~C++23，中文为主，附带优质英文）
 
现代C++核心：移动语义、智能指针、lambda、auto、模板进阶、Concept、模块、协程，不推荐老C++98书籍。按【书籍、网站/博客、视频课程、实战项目、权威英文资料】分类，标注适用阶段。
 
📚 书籍（中文译本/中文原创）
 
入门→现代C++基础（有C基础，想系统学C++11起）
 
1. 《C++ Primer 第5版》（中文版）
✅ 国内最推荐入门，全书基于C++11；讲容器、智能指针、lambda。缺点：没有C++17/20新特性。
2. 《现代C++教程》欧长坤（开源在线书，中文）
https://changkun.de/modern-cpp/zh-cn/
🔥 强烈推荐！免费在线，覆盖C++11~C++26，中文，通俗讲解move、concept、module、协程，可在线阅读，适合现代特性专项学习。
3. 《C++程序设计原理与实践（第3版）》Bjarne Stroustrup（C++之父，中译，C++20）
适合建立正确编程思维，不适合快速刷题。
 
进阶必看（学完基础，掌握现代C++最佳实践）
 
1. 《Effective Modern C++》中文版 Scott Meyers｜42条C++11/14实战准则
✅ 现代C++圣经，move、forward、智能指针、auto、lambda全部重点，面试高频来源。
2. 《C++并发编程实战（第2版）》中文版 Anthony Williams
现代C++多线程， std::thread 、 std::async 、原子量、无锁编程，国内唯一系统讲C++并发的书。
3. 《C++模板：完全指南（第2版）》中译本
模板、模板元编程、CRTP，Concept，写库必备。
4. 《C++ Core Guidelines 解读》（《C++核心准则精讲》）
Stroustrup & Sutter 官方编码规范，吴咏炜译本；工业界现代C++编码风格。
 
高阶（库设计、泛型）
 
- 《C++ Software Design》（有中译版），现代C++软件设计、依赖管理、泛型范式
 
🌐 网站 & 博客
 
中文网站
 
1. 欧长坤 modern-cpp （上面那本在线书） https://changkun.de/modern-cpp/zh-cn/
2. CppCon 中文笔记：B站/掘金大量大佬翻译CppCon大会PPT（C++标准前沿）
3. 掘金、InfoQ C++专栏：吴咏炜、陈皓(左耳朵耗子)、潘庆霖，大量现代C++文章
4. Boolan 博客（侯捷老师） https://www.boolan.com/
侯捷文章：STL、内存、C++11新标准解析，经典。
 
权威参考（中英双语查阅）
 
1. cppreference https://en.cppreference.com 【最重要！】
标准参考手册，C++11~23全部特性、标准库，代码示例；有简体中文页面。写代码查标准必备。
2. LearnCpp.com（英文，优质免费教程）https://www.learncpp.com
从基础到C++20，例子极简，非常适合自学现代C++。
 
🎬 视频课程
 
中文精品

- 《C++11/14 新标准》《STL标准库与泛型编程》《面向对象高级编程》

英文精品（推荐）
 
1. The Cherno（YouTube）C++系列，现代C++，适合看底层思维，B站搬运很多。
2. CppCon 大会演讲（YouTube/B站搬运）：每年C++顶级会议，看C++20/23新特性，标准委员会大佬分享。
 
🧩 GitHub 实战项目（练现代C++，C++11及以上）
 
看书不动手=白学，优先阅读源码，仿写小模块
 
1. muduo（陈硕） https://github.com/chenshuo/muduo
C++11 高性能Linux网络库，国内现代C++工程典范，学习RAII、智能指针、线程模型。
2. yhirose/cpp-httplib 头文件-only HTTP库，C++17，短小精悍，适合阅读。
3. progschj/ThreadPool C++11线程池，几百行，入门并发练习。
4. fffaraz/awesome-cpp：⭐70k+，C++资源大全清单，库、项目、文档汇总
5. 个人练手：自己用现代C++写：容器包装、线程池、简易协程、cmake工程，禁用裸new/delete，全程用RAII/智能指针
 
✍️ 练习平台
 
1. LeetCode：用现代C++写法做题（ auto 、 std::vector 、 std::algorithm 、lambda），不要C风格写法
2. Compiler Explorer（godbolt.org）在线看汇编！超级重要
✅ 学习move、拷贝消除、模板实例化、constexpr，一行代码看底层汇编，现代C++神器
 
📜 英文经典书籍（有能力再读）
 
1. The C++ Programming Language 4th Bjarne Stroustrup，C++之父，词典式参考书，不适合通读
2. Exceptional C++ Herb Sutter，标准委员会，C++谜题，内存、异常、资源管理
3. Modern C++ Design Andrei Alexandrescu，模板元编程开山之作（偏老，但思想经典）
 
 
 
🗺️ 推荐学习路线（适配你考研+工程背景）
 
1. 基础：C++ Primer 5th → 掌握C++11基础语法、STL容器
2. 现代特性专项：欧长坤在线书，系统学习move语义、lambda、auto、constexpr
3. 最佳实践：Effective Modern C++
4. 工程实践：muduo源码 + 自己写小项目，全程CMake，使用C++17标准
5. 进阶：并发、模板、CppCon视频，C++20 concept/module/coroutine
 
避坑提醒：不要看《C++ Primer Plus》、不要大量啃C++98老旧资料，现代C++核心思维是RAII，尽量避免手动内存管理。
