# 树 Tree

## 一、树的基本概念

### 1. 树的定义

树是一种**非线性数据结构**，由 $n$ 个节点和 $n-1$ 条边组成，并满足：

- 有且仅有一个根节点
    
- 除根节点外，每个节点都有且仅有一个父节点
    
- 任意两个节点之间存在且仅存在一条简单路径
    
- 不存在环
    

当 $n=0$ 时称为空树。

---

### 2. 基本术语

- **节点（Node）**
    
- **根节点（Root）**
    
- **父节点（Parent）**
    
- **子节点（Child）**
    
- **兄弟节点（Sibling）**
    
- **祖先节点（Ancestor）**
    
- **后代节点（Descendant）**
    
- **叶节点（Leaf）**：没有孩子的节点
    
- **分支节点 / 内部节点**：至少有一个孩子的节点
    
- **子树（Subtree）**
    

---

### 3. 节点的度

节点的度：

degree(v)=节点 v 的孩子数量degree(v)=\text{节点 }v\text{ 的孩子数量}

树的度：

degree(T)=max⁡degree(v)degree(T)=\max degree(v)

---

### 4. 节点的深度

根节点深度通常定义为：

depth(root)=0depth(root)=0

其他节点：

depth(v)=depth(parent(v))+1depth(v)=depth(parent(v))+1

即：

> 从根节点到该节点经过的边数。

---

### 5. 节点的高度

叶节点高度：

height(v)=0height(v)=0

一般：

height(v)=1+max⁡(height(child))height(v)=1+\max(height(child))

树的高度：

height(T)=height(root)height(T)=height(root)

---

## 二、树的性质

### 1. 边数

具有 $n$ 个节点的树一定有：

E=n−1E=n-1

这是树最重要的基本性质之一。

---

### 2. 任意两个节点之间只有一条路径

如果两个节点之间存在两条不同路径，就一定形成环，因此不再是树。

---

### 3. 删除任意一条边

树会变成两个连通分量。

---

### 4. 添加任意一条新边

树会形成一个环。

因此：

> **树 = 连通且无环的图。**

---

# 三、树的遍历

这是算法中最核心的部分之一。

## 1. 深度优先搜索 DFS

从一个节点不断向深处搜索。

树上的 DFS 通常使用：

- 递归
    
- 栈
    

核心思想：

```text
访问当前节点
↓
递归访问子树
```

---

## 2. 广度优先搜索 BFS

按照距离根节点的层次逐层访问。

使用：

```text
Queue
```

例如：

```text
        A
      / | \
     B  C  D
    / \
   E   F
```

BFS：

```text
A
B C D
E F
```

---

# 四、二叉树

二叉树是：

> 每个节点最多有两个孩子的树。

分别称为：

```text
Left Child
Right Child
```

---

## 1. 二叉树的递归定义

二叉树可以是：

- 空树
    
- 一个根节点 + 左子树 + 右子树
    

其中左、右子树本身也是二叉树。

因此二叉树天然适合递归算法。

---

# 五、二叉树的特殊类型

## 1. 满二叉树

每个非叶节点都有两个孩子。

高度为 $h$：

n=2h+1−1n=2^{h+1}-1

第 $i$ 层节点数：

2i2^i

---

## 2. 完全二叉树

除最后一层外全部填满，最后一层从左向右连续排列。

这是**堆**的基础。

---

## 3. 平衡二叉树

树的左右子树高度不会相差太多。

常见的严格定义之一：

∣height(left)−height(right)∣≤1|height(left)-height(right)|\le1

注意：

> “平衡二叉树”是一个性质，并不等于某一种具体数据结构。

---

## 4. 退化二叉树

例如：

```text
A
 \
  B
   \
    C
     \
      D
```

本质上已经接近链表。

高度：

h=O(n)h=O(n)

# 九、二叉搜索树 BST

Binary Search Tree。

对于任意节点：

```text
左子树 < 当前节点 < 右子树
```

因此：

```text
        8
       / \
      3   10
     / \
    1   6
```

中序遍历：

```text
1 3 6 8 10
```

得到有序序列。

---

# 十、BST 的基本操作

## 1. 查找

根据大小关系决定：

```text
x < root → 左边
x > root → 右边
x = root → 找到
```

---

## 2. 插入

按照 BST 规则向下寻找合适的空位置。

---

## 3. 删除

分三种情况。

### 情况一：叶节点

直接删除。

### 情况二：只有一个孩子

让孩子接替自己。

### 情况三：有两个孩子

使用：

- 中序前驱
    
- 中序后继
    

替代当前节点。

然后删除那个前驱/后继节点。

---

# 十一、BST 的复杂度

如果树高度为 $h$：

查找：

O(h)O(h)

插入：

O(h)O(h)

删除：

O(h)O(h)

如果平衡：

h=O(log⁡n)h=O(\log n)

所以：

O(log⁡n)O(\log n)

如果退化：

h=O(n)h=O(n)

所以：

O(n)O(n)

# 十四、红黑树

红黑树也是一种平衡 BST。

每个节点具有颜色：

```text
Red
Black
```

通过颜色规则限制树的高度。

核心性质包括：

1. 每个节点是红色或黑色
    
2. 根节点为黑色
    
3. NIL 节点视为黑色
    
4. 红节点不能有红色孩子
    
5. 从节点到其所有后代 NIL 节点的路径具有相同黑节点数
    

最终保证：

h=O(log⁡n)h=O(\log n)

因此：

```text
查找 O(log n)
插入 O(log n)
删除 O(log n)
```

# 十五、堆 Heap

堆是一种特殊的**完全二叉树**。

## 最大堆

满足：

parent≥childparent\ge child

因此根节点最大。

## 最小堆

满足：

parent≤childparent\le child

因此根节点最小。

---

# 十六、堆的核心操作

### 插入

将元素放到最后：

```text
最后一个位置
↓
不断与父节点比较
↓
向上调整
```

称为：

> Sift Up / Percolate Up

复杂度：

O(log⁡n)O(\log n)

---

### 删除堆顶

删除根节点，然后：

```text
最后一个元素补到根
↓
向下调整
```

称为：

> Sift Down

复杂度：

O(log⁡n)O(\log n)

---

### 建堆

给定一个无序数组建立堆。

使用自底向上的 Heapify：

O(n)O(n)

注意：

> 建堆不是 $O(n\log n)$，而是 **$O(n)$**。

# 二十三、树上的 DFS

树上 DFS 是非常重要的算法模型。

例如求子树大小：

size(v)=1+∑size(child)size(v)=1+\sum size(child)

代码思想：

```text
DFS(v)
    size[v] = 1

    for child:
        DFS(child)
        size[v] += size[child]
```

这类思想可以解决：

- 子树大小
    
- 子树和
    
- 树高
    
- 节点深度
    
- 路径问题
    
- 树形 DP

# 二十四、树形 DP

Tree DP 是树算法的重要高级部分。

核心：

> **把一个大问题拆成若干子树问题。**

例如：

```text
             A
           /   \
          B     C
         / \
        D   E
```

先求：

```text
D
E
↓
B
↓
C
↓
A
```

也就是：

> **后序 DFS + 动态规划。**

# 二十五、树的直径

树中任意两个节点之间距离的最大值。

称为：

> **Tree Diameter**

例如：

```text
A
|
B
|
C
|
D
|
E
```

直径：

dist(A,E)=4dist(A,E)=4

经典求法：

```text
任意节点 s
↓
找到距离 s 最远的节点 u
↓
从 u 再 DFS/BFS
↓
找到距离 u 最远的节点 v
↓
dist(u,v) = 树的直径
```

# 二十六、最近公共祖先 LCA

Lowest Common Ancestor。

给定两个节点 $u,v$：

> 找到同时是 $u,v$ 祖先，并且深度最大的节点。

例如：

```text
          A
        /   \
       B     C
      / \   / \
     D   E F   G
```

那么：

LCA(D,E)=BLCA(D,E)=B LCA(D,G)=ALCA(D,G)=A

# 二十九、树的重心

树的重心：

> 删除该节点后，使剩余连通分量中最大连通分量最小的节点。

可以通过子树大小求。

设总节点数：

nn

节点 $v$ 的最大分量大小：

max(n−size[v],size[c1],size[c2],...)max\left( n-size[v], size[c_1], size[c_2], ... \right)

取使其最小的节点，即树的重心。
