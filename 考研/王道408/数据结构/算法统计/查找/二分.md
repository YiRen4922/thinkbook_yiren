# 二分查找（折半查找）

> 前提：**有序的顺序表**（随机存取）。每次与中间元素比较，将查找范围折半。**链表无法折半**——找 mid 需要 $O(n)$。408 高频考点：判定树、ASL 计算、边界条件。

## 算法思想

**核心思想**：每次与中间元素 $A[mid]$ 比较：

1. `key == A[mid]` → **命中**，返回下标
2. `key < A[mid]` → 查**左半**区间 `[low, mid-1]`
3. `key > A[mid]` → 查**右半**区间 `[mid+1, high]`

每次比较都把搜索范围**缩小一半** → $O(\log_2 n)$ 次比较。

## 代码实现

### 标准二分（升序数组）

```c
int BinarySearch(int A[], int n, int key) {
    int low = 0, high = n - 1, mid;
    while (low <= high) {
        mid = low + (high - low) / 2;   // 防溢出写法
        if (A[mid] == key) return mid;
        else if (key < A[mid]) high = mid - 1;
        else low = mid + 1;
    }
    return -1;                          // 查找失败
}
```

### 变式：求第一个 ≥ key 的位置（lower_bound）

```c
int lowerBound(int A[], int n, int key) {
    int low = 0, high = n;              // 注意 high 初始为 n（开区间）
    while (low < high) {
        int mid = low + (high - low) / 2;
        if (A[mid] >= key) high = mid;
        else low = mid + 1;
    }
    return low;                         // 第一个 >= key 的下标
}
```

> `low <= high` 和 `low < high` 两种写法对应不同的边界处理（闭区间 vs 左闭右开），408 手算时以 `low <= high` 最常用。

## 判定树与 ASL

- 比较过程构成一棵**平衡二叉排序树**（判定树），树高 $\lceil \log_2(n+1) \rceil$
- 查找成功：$ASL_{\text{成功}} = \log_2(n+1) - 1$（$n$ 较大时近似）
- 查找失败：比较次数不超过树高 + 1

## 时间复杂度

- 时间：$O(\log_2 n)$（最好 $O(1)$，即首比较即命中）
- 空间：$O(1)$（迭代版）；递归版 $O(\log n)$ 栈空间

## 易错点

> [!warning] 易错点
> - `mid` 用 `low + (high-low)/2` 防**整数溢出**
> - 边界更新：`low = mid + 1` 或 `high = mid - 1`（已排除 mid），写错会死循环
> - 循环条件 `low <= high`：等于时还要比较一次（mid 可能正好等于 low）
> - **前提是有序表**；无序必须先排序（排序成本 $O(n\log n)$）
> - **顺序存储才可折半**：链表找中间元素需 $O(n)$，失去折半意义

## 相关知识（考研408）

> [!note] 408 常考结论
> - 判定树是**平衡树但不是完全二叉树**：$mid$ 向下取整时，右子树结点数 ≤ 左子树（向上取整相反）
> - 比较次数 = 该结点在判定树中的**层数**
> - 失败比较次数 ≤ 树高；判定树**外结点**（失败结点）数 = $n+1$
> - 与顺序查找、分块查找的 ASL 对比是选择题常客
