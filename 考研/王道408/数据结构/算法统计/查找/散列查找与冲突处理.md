# 散列查找与冲突处理

> 用哈希函数 $H(key)$ 直接定位，期望 $O(1)$ 查找；**冲突不可避免**，用冲突处理方法解决。408 高频考点：手算散列表构造、ASL 成功/失败统计、线性探测堆积。

## 算法思想

**散列查找（哈希查找）**：通过哈希函数 $H(key)$ 把关键字映射为存储地址，查找时直接计算地址即可，理想情况下 $O(1)$。

**核心矛盾**：不同的关键字可能映射到同一地址——**冲突**不可避免（散列表长有限、关键字空间无限）。冲突处理 + 装填因子控制是散列查找的关键。

## 哈希函数

- **除留余数法**（最常用）：$H(key) = key \bmod p$，$p$ 取**不大于表长的最大质数**（减少冲突）
- 直接定址法：$H(key) = a \cdot key + b$
- 数字分析法、平方取中法、折叠法：用于关键字分布已知的场景

## 冲突处理

| 方法 | 思路 | 特点 |
|---|---|---|
| **拉链法** | 同义词挂成链表 | 装填因子可 > 1，删除方便，有指针开销 |
| **线性探测** | $H_i = (H(key) + i) \bmod m$ | 顺次探测，**堆积（聚集）**严重 |
| **平方探测** | $H_i = (H(key) \pm i^2) \bmod m$ | 避免堆积，表长须为 $4k+3$ 型质数 |
| **再散列** | 换一个哈希函数 | 增加计算量 |

## 代码实现（拉链法）

```c
typedef struct Node {
    int key;
    struct Node *next;
} Node;

// 插入：头插到对应桶
void insert(Node *H[], int m, int key) {
    int idx = key % p;                  // p 为不大于 m 的最大质数
    Node *s = (Node*)malloc(sizeof(Node));
    s->key = key; s->next = H[idx]; H[idx] = s;
}

// 查找：桶内链表顺序找
Node *search(Node *H[], int m, int key) {
    for (Node *p = H[key % p]; p; p = p->next)
        if (p->key == key) return p;
    return NULL;
}
```

## 时间复杂度

- 平均查找：$O(1)$（装填因子合适时，如 $\alpha \le 0.5$）
- 最坏：$O(n)$（所有关键字映射到同一桶——冲突极度集中）
- 查找成功/失败的 ASL 与**装填因子** $\alpha = \frac{\text{记录数 } n}{\text{表长 } m}$ 正相关

## 易错点

> [!warning] 易错点
> - **装载因子** $\alpha = n / m$：$\alpha$ 越大冲突越多，查找越慢
> - 开放定址法删除需**惰性删除**（打删除标记），直接删会断探测链
> - **线性探测的堆积**（聚集）：冲突元素聚成一片，后续冲突概率更大；**拉链法不产生堆积**
> - 查找失败 ASL：按**空位/哨兵边界**统计探测次数
> - 表长取质数（除留余数法）能显著减少冲突，但**不能消除**
