# 链表高频操作

> 线性表算法设计题常客（S/A 级），带头结点与不带头结点两种写法都要会。核心思想始终围绕**指针的重新指向**：要么用**头插法**实现逆序，要么用**快慢指针**定位位置，要么用**尾插法**保持有序性。

## 算法思想

链表操作本质是**调整结点指针的指向**，不涉及元素搬移。高频套路可归纳为三类：

1. **头插法**：把结点逐个插到头结点之后 → 链表逆序（逆置问题）
2. **尾插法**：把较小/符合条件的结点依次接到链表尾部（合并、去重问题）
3. **快慢指针**：slow 走 1 步、fast 走 2 步（找中点、判环、找倒数第 k 个）

> 题目常要求 $O(n)$ 时间、$O(1)$ 空间 → 禁止开新数组/新链表，只能**原地**调整指针。

## 代码实现

### 1. 单链表逆置（三指针，原地）

```c
LNode *Reverse(LNode *L) {              // 不带头结点，O(n)、O(1)
    LNode *prev = NULL, *cur = L, *next;
    while (cur) {
        next = cur->next;               // 先保存后继，防止断链
        cur->next = prev;               // 反转指针
        prev = cur; cur = next;         // 三指针整体后移
    }
    return prev;
}
```

带头结点版：摘下头结点，其余结点依次**头插**回链表。

### 2. 合并两个递增有序链表

两指针分别走，较小的结点尾插到新链表（带头结点），一表空则剩余直接接上。

```c
LNode *Merge(LNode *A, LNode *B) {      // A、B 带头结点
    LNode *C = (LNode*)malloc(sizeof(LNode));
    LNode *pa = A->next, *pb = B->next, *pc = C;
    while (pa && pb) {
        if (pa->data <= pb->data) { pc->next = pa; pa = pa->next; }
        else                      { pc->next = pb; pb = pb->next; }
        pc = pc->next;
    }
    pc->next = pa ? pa : pb;            // 剩余直接拼接
    return C;
}
```

### 3. 找中间结点（快慢指针）

```c
LNode *FindMid(LNode *L) {
    LNode *slow = L, *fast = L;         // 不带头结点
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
    }
    return slow;
}
```

### 4. 删除倒数第 k 个结点

快指针先走 $k$ 步，然后快慢同步走，快指针到尾时慢指针指向倒数第 $k$ 个。

```c
int DeleteKthFromEnd(LNode *L, int k) { // L 带头结点，成功返回 1
    LNode *fast = L->next, *slow = L;   // slow 停在待删结点前驱
    for (int i = 0; i < k && fast; i++) fast = fast->next;
    if (!fast) return 0;                // k 超长
    while (fast) { slow = slow->next; fast = fast->next; }
    LNode *q = slow->next;
    slow->next = q->next;
    free(q);
    return 1;
}
```

## 时间复杂度

| 操作 | 时间 | 空间 | 关键点 |
|---|---|---|---|
| 逆置（三指针/头插） | $O(n)$ | $O(1)$ | 头插法：带头结点时从头结点后插 |
| 合并有序链表 | $O(m+n)$ | $O(1)$ | 尾插保持有序 |
| 找中间结点 | $O(n)$ | $O(1)$ | 快 2 慢 1 |
| 删除倒数第 k 个 | $O(n)$ | $O(1)$ | 快指针先走 k 步 |

## 易错点

> [!warning] 易错点
> - **丢指针**：改 `cur->next` 前必须先保存 `next`，否则断链无法继续
> - **带头 vs 不带头**：不带头结点逆置返回新头；带头结点逆置用头插法仍在原头结点上操作
> - **边界条件**：链表为空、k 超过链表长度（返回失败）、只有一个结点
> - 找中间结点时若结点数为偶数，slow 停在后半段第一个（fast 走法决定），题目要按题意调整
