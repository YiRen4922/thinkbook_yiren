# 三次反转实现数组循环移位

> 数组循环移位的最优解：三次 `reverse` 操作，时间 $O(n)$、空间 $O(1)$，原地完成。是考研 408 顺序表高频考法（2010 年真题原题/变式）。本质：反转操作的复合实现元素的循环搬移。

## 算法思想

**数学本质**：设数组为 $AB$（$A$ 为前 $k$ 个，$B$ 为后 $n-k$ 个），则：

- **循环左移 $k$ 位**：$AB \to BA$，只需先反转 $A$ 再反转 $B$ 再整体反转 → `(BA)`
- **循环右移 $k$ 位**：$BA \to AB$，先整体反转再反转前 $k$ 位再反转后 $n-k$ 位

> **前提**：$k$ 必须先 $k = k \bmod n$，否则 $k > n$ 时下标越界。

## 代码实现

### 逆序辅助函数

```c
void reverse(int a[], int l, int r) {
    while (l < r) { int tmp = a[l]; a[l] = a[r]; a[r] = tmp; l++; r--; }
}
```

### 循环右移 k 位

```c
void rotateRight(int a[], int n, int k) {
    k %= n;
    reverse(a, 0, n - 1);    // 整体反转
    reverse(a, 0, k - 1);    // 反转前 k 个
    reverse(a, k, n - 1);    // 反转后 n-k 个
}
// 右移口诀：全 → 前k → 后n-k
```

### 循环左移 k 位

```c
void rotateLeft(int a[], int n, int k) {
    k %= n;
    reverse(a, 0, k - 1);    // 反转前 k 个
    reverse(a, k, n - 1);    // 反转后 n-k 个
    reverse(a, 0, n - 1);    // 整体反转
}
// 左移口诀：前k → 后n-k → 全
```

### 推演示例

`[1,2,3,4,5]`，$n=5$，右移 $k=2$：

1. 整体反转 → `[5,4,3,2,1]`
2. 反转前 2 位 → `[4,5,3,2,1]`
3. 反转后 3 位 → `[4,5,1,2,3]` ✔

## 时间复杂度

- 时间：$O(n)$，每个元素最多被反转 2 次（常数次遍历）
- 空间：$O(1)$，原地操作，无需辅助数组

## 易错点

> [!warning] 易错点
> - `k %= n` **必不可少**，$k > n$ 时会越界
> - 右移、左移的三步顺序**不能记混**——可以手动验证：
>   - 右移 $k$ 位：整体 → 前k → 后n-k
>   - 左移 $k$ 位：前k → 后n-k → 整体
> - `reverse(a, l, r)` 是**闭区间** `[l, r]`，不是左闭右开
> - 本算法**不稳定**，元素相对位置发生改变
