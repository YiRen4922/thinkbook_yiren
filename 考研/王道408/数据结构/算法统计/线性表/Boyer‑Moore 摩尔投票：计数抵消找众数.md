# Boyer‑Moore 摩尔投票法

> 找数组中**出现次数大于 $n/2$ 的众数（主元素）**，时间 $O(n)$、空间 $O(1)$。可以扩展到找大于 $n/3$ 的最多两个候选。**前提**：如果存在主元素，算法能找出；但算法输出的候选**不一定**是答案，必须再校验一遍。

## 算法思想

**核心观察**：不同元素可以**成对抵消**。如果存在一个数出现次数超过 $n/2$，它不会被完全抵消掉，最终剩下的一定是它（或它的候选）。

**流程（找 $>n/2$ 众数）**：

1. 初始化 `candidate`（候选值）和 `count = 0`
2. 遍历每个元素 `num`：
   - `count == 0` → 更新 `candidate = num`，`count = 1`
   - `num == candidate` → `count++`
   - `num != candidate` → `count--`（抵消）
3. 遍历结束得到 `candidate`
4. **必须再次遍历统计 `candidate` 真实出现次数**，判断是否 $> n/2$

> **为什么需要校验**：数组 `[1,2,3]` 无众数，算法仍会输出一个数（该数出现次数 ≤ n/2），因此校验必不可少。

## 代码实现

### 找众数（主元素）

```c
int majorityElement(int nums[], int n) {
    // 阶段一：摩尔投票
    int candidate = nums[0], count = 0;
    for (int i = 0; i < n; i++) {
        if (count == 0)
            candidate = nums[i];
        count += (nums[i] == candidate) ? 1 : -1;
    }
    // 阶段二：校验（必需！）
    int real_cnt = 0;
    for (int i = 0; i < n; i++)
        if (nums[i] == candidate) real_cnt++;
    return (real_cnt > n / 2) ? candidate : -1;  // -1 表示不存在主元素
}
```

### 扩展：找大于 $n/3$ 的元素（最多 2 个）

最多只能有 2 个元素满足 $> n/3$，维护两个候选 `c1`、`c2` 及对应计数器：

```c
int count1 = 0, count2 = 0, c1 = 0, c2 = 0;
for (int i = 0; i < n; i++) {
    if      (count1 == 0 && nums[i] != c2) { c1 = nums[i]; count1 = 1; }
    else if (count2 == 0 && nums[i] != c1) { c2 = nums[i]; count2 = 1; }
    else if (nums[i] == c1) count1++;
    else if (nums[i] == c2) count2++;
    else { count1--; count2--; }          // 三个不同值同时抵消
}
// 同样必须二次校验 c1、c2 的真实频次
```

## 推演示例

数组：`[2,2,1,1,1,2,2]`，$n=7$，需 $>3$ 次：

| 步骤 | num | candidate | count | 操作 |
|---|---|---|---|---|
| 1 | 2 | — | 0→1 | count=0 → candidate=2, count=1 |
| 2 | 2 | 2 | 1→2 | 相同，count++ |
| 3 | 1 | 2 | 2→1 | 不同，count-- |
| 4 | 1 | 2 | 1→0 | 不同，count-- |
| 5 | 1 | 1 | 0→1 | count=0 → candidate=1, count=1 |
| 6 | 2 | 1 | 1→0 | 不同，count-- |
| 7 | 2 | 2 | 0→1 | count=0 → candidate=2, count=1 |

候选 = 2；再统计：2 出现 4 次，$4 > 3$，是主元素。

## 时间复杂度

- 时间：$O(n)$，两轮遍历（投票 + 校验）
- 空间：$O(1)$，只用常数变量，原地算法

## 易错点

> [!warning] 易错点
> - **最大误区**：摩尔投票返回的候选一定是众数 ✘ —— 只是潜在候选，**必须二次校验**
> - 适用条件：$> n/2$ 时只需 1 个候选；$> n/3$ 时最多 2 个候选；$> n/k$ 时最多 $k-1$ 个候选
> - 不相等时两个计数器**同时减 1**，不是只减一个
> - 摩尔投票只适用于**找众数（出现次数 > n/k）**，不是通用频率统计
