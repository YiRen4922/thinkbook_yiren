# 双指针 & 数组压缩法

> 用两个下标在**原数组**上操作，不开新数组，空间 $O(1)$。核心三种形态：**快慢指针（压缩去重）、左右指针（对称操作）、滑动窗口（区间维护）**。考研 408 顺序表算法题的首选技巧。

## 算法思想

双指针的本质是**将二重循环降为一重**，或在原数组上**原地覆盖**以实现"删除"效果。三种经典子类：

1. **快慢指针（压缩法）**：`fast` 遍历探测，`slow` 记录下一个可写入位置；合法元素 `nums[slow] = nums[fast]; slow++`；fast 每次 `++`
2. **左右指针**：`left=0, right=n-1`，向中间靠拢 → 反转数组、有序数组两数之和、回文判断
3. **滑动窗口**：`right` 扩张、`left` 收缩，维护满足条件的最短/最长区间

## 代码实现

### 1. 移除元素（压缩法核心模板）

```c
int removeElement(int nums[], int n, int val) {
    int slow = 0;
    for (int fast = 0; fast < n; fast++) {
        if (nums[fast] != val) {
            nums[slow] = nums[fast];
            slow++;
        }
    }
    return slow;  // slow = 压缩后有效长度
}
```

### 2. 有序数组去重（LeetCode 26）

```c
int removeDuplicates(int nums[], int n) {
    if (n == 0) return 0;
    int slow = 1;
    for (int fast = 1; fast < n; fast++) {
        if (nums[fast] != nums[slow - 1]) {
            nums[slow] = nums[fast];
            slow++;
        }
    }
    return slow;
}
```

## 三种双指针对比

| 类型 | 变量 | 行为 | 典型题目 |
|---|---|---|---|
| 快慢指针压缩法 | `slow` / `fast` | fast 探测，slow 写结果，原地覆盖 | 移除元素、有序去重 |
| 左右指针 | `left` / `right` | 两头向中间收拢 | 有序数组两数之和、反转数组 |
| 滑动窗口 | `left` / `right` | 右扩左缩，维护区间 | 最小子数组、子串问题 |

## 时间复杂度

- 时间：$O(n)$，fast 遍历一遍
- 空间：$O(1)$，原地算法，不开辟辅助数组——压缩法最大优势

## 易错点

> [!warning] 易错点
> - 压缩法属于**快慢双指针**，不是左右指针（左右指针是两头向中）
> - 只是覆盖前面位置，**不会真正删除内存**，依靠返回的长度限定有效区间
> - 有序去重的判断条件是 `nums[fast] != nums[slow-1]`，不是 `!= nums[slow]`（slow-1 是上一个保留元素）
> - 压缩法和快慢指针（链表判环）是**同一思想的两种应用**：写 vs 读
