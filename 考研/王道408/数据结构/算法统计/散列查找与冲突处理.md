# 散列查找与冲突处理

> 用哈希函数 $H(key)$ 直接定位，期望 $O(1)$ 查找；冲突不可避免，用冲突处理方法解决。

## 常见哈希函数

- 除留余数法：$H(key) = key \bmod p$（$p$ 取不大于表长的最大质数）
- 直接定址法、数字分析法、平方取中法、折叠法

## 冲突处理（拉链法 vs 开放定址法）

| 方法 | 思路 | 特点 |
|---|---|---|
| 拉链法 | 同义词挂成链表 | 装填因子可 >1，删除方便，指针开销 |
| 线性探测 | 顺次探测下一个空位 $H_i=(H(key)+i)\bmod m$ | **堆积（聚集）**现象严重 |
| 平方探测 | $H_i=(H(key)\pm i^2)\bmod m$ | 避免堆积，表长须为质数 $4k+3$ 型 |
| 再散列 | 换一个哈希函数 | 增加计算量 |

## 关键指标

- **装填因子** $\alpha = \frac{\text{记录数 } n}{\text{表长 } m}$：$\alpha$ 越大冲突越多
- 拉链法查找成功 $ASL$ 与 $\alpha$ 有关；开放定址法删除需**惰性删除**（标记）

## 408 考点

> [!warning] 常考结论
> - 手算：构造散列表、求 ASL 成功/失败
> - 查找失败的 ASL：按**空位/哨兵边界**统计探测次数
> - 线性探测的堆积是高频易错点；拉链法不产生堆积
