# 堆排序

> 完全二叉树的数组表示（下标从 1 开始）。**升序用大根堆**：每轮把堆顶与末尾交换，再调整剩余部分。

## 核心操作：向下调整 Sift

从结点 $k$ 开始下滤：若孩子中较大者 > 自己，与较大孩子交换，继续向下。建堆从最后一个非叶结点 $\lfloor n/2 \rfloor$ 起**向前**逐个调整。

```c
void Sift(int A[], int k, int n) {       // 对 A[1..n] 中结点 k 向下调整（大根堆）
    int x = A[k];
    for (int i = 2 * k; i <= n; i *= 2) {
        if (i < n && A[i] < A[i + 1]) i++;     // 选较大的孩子
        if (x >= A[i]) break;
        A[k] = A[i]; k = i;
    }
    A[k] = x;
}
void HeapSort(int A[], int n) {
    for (int i = n / 2; i >= 1; i--) Sift(A, i, n);   // 建堆 O(n)
    for (int i = n; i > 1; i--) {
        swap(A[1], A[i]);                // 堆顶（最大）放到末尾
        Sift(A, 1, i - 1);               // 调整剩余 i-1 个
    }
}
```

## 复杂度与性质

- 时间稳定 $O(n\log n)$（建堆 $O(n)$ + $n$ 次调整各 $O(\log n)$）；空间 $O(1)$
- **不稳定**；适合 n 很大且要求原地排序（top-k、优先队列）

## 408 考点

> [!warning] 常考结论
> - 建堆：从 $\lfloor n/2 \rfloor$ 向前逐个下滤
> - 插入：末尾加入后**向上调整**；删除堆顶：末元素顶上再向下调整
> - 判断给定数组是否为大根堆；一次插入/删除后的堆形态
> - 堆的调整次数与元素位置变化是手算常客
