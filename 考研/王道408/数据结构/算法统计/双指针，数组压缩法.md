# 双指针 & 数组压缩法（刷题/数据结构高频）

> 双指针：用两个下标，不额外开数组，原地遍历； 压缩法（原地压缩，也叫移除元素、覆盖法）属于**快慢双指针的经典子类**。

## 1、双指针大类

分为三类：快慢指针、左右指针、滑动窗口指针

### ①快慢指针（fast、slow）

- slow：**待写入位置**（新数组的下标）
- fast：**遍历探测指针**，挨个扫原始数组
    
    > 典型就是数组原地压缩，不开新数组，用后面合法元素覆盖前面。
    

### ②左右指针（left、right）

一个在头部，一个在尾部，向中间靠拢。 适用：有序数组两数之和、反转数组、回文判断。

### ③滑动窗口（left、right）

right扩张窗口，left收缩窗口，求子数组区间。

---

## 2、压缩法（原地压缩，快慢双指针）

> 题目原型：LeetCode27 移除元素：给数组，删除等于val的元素，原地修改，返回新长度。 本质：把**符合条件的元素保留，向前覆盖，把有效数据“压缩”到数组前面**。

### 核心逻辑

- slow：记录下一个**合法元素要放的位置**
- fast：从头到尾遍历全部元素

1. 如果 `nums[fast]` 是要保留的元素：`nums[slow] = nums[fast]; slow++;`
2. fast每次都 ++

最终 `slow` 的值就是压缩之后有效数组的长度。

C++示例

```cpp
// 删除所有值等于val，原地压缩
int removeElement(vector<int>& nums, int val) {
    int slow = 0;
    for(int fast = 0; fast < nums.size(); fast++){
        if(nums[fast] != val){
            nums[slow] = nums[fast];
            slow++;
        }
    }
    return slow; // slow就是压缩后有效长度
}
```

例子： `nums = [3,2,2,3], val=3`

- fast=0：是3跳过
- fast=1：是2，nums[0]=2，slow=1
- fast=2：是2，nums[1]=2，slow=2
- fast=3：是3跳过 返回 slow=2，数组前2位：`[2,2]` ✔

> ⚠注意：数组后面的元素不用管，逻辑上已经丢弃，只看`[0 ~ slow‑1]`区间。

### 同类变形考题

1. 删除有序数组重复项（Leet26）：只要和前一个不一样就保留，快慢指针压缩

```cpp
int removeDuplicates(vector<int>& nums) {
    if(nums.empty()) return 0;
    int slow = 1;
    for(int fast = 1; fast < nums.size(); fast++){
        if(nums[fast] != nums[slow‑1]){
            nums[slow] = nums[fast];
            slow++;
        }
    }
    return slow;
}
```

## 复杂度

- 时间 $(O(n))$，fast遍历一遍
- 空间 $(O(1))$，**原地算法，没有开辟辅助数组**，这就是压缩法最大优势。

## 考试易错点

1. 压缩法属于**快慢双指针**，不是左右指针。
2. 只是覆盖前面位置，**不会真正删除内存**，依靠返回的长度限定有效区间。
3. 有序去重、移除指定值、把0移到数组末尾，全部是这套快慢压缩模板。

## 区分三种双指针对比表

|类型|变量|行为|典型题目|
|---|---|---|---|
|快慢指针压缩法|slow/fast|fast探测，slow写结果，原地覆盖|移除元素、有序去重|
|左右指针|left/right|两头向中间收拢|两数之和（有序）、反转数组|
|滑动窗口|left/right|右扩左缩，维护区间|最小子数组、子串问题|

## 记忆口诀

> 快慢压缩：fast到处跑，slow只管存；合格就往前盖，slow记录新长度。

### 拓展小对比

- 摩尔投票：$(O(n)),(O(1))$，抵消计数；
- 双指针压缩：$(O(n)),(O(1))$，原地覆盖保留合法元素。
