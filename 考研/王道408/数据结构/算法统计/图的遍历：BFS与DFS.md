# 图的遍历：BFS 与 DFS

## BFS（广度优先，队列）

类似二叉树层序遍历：访问一个顶点 → 其**所有未被访问**的邻接点入队，队头出队重复。
- 辅助：`visited[]` + 队列
- 连通图得到**广度优先生成树**；非连通图得到生成森林

## DFS（深度优先，栈/递归）

类似树的先序遍历：访问顶点 → 递归访问其第一个未访问邻接点，走到底再回溯。

```c
void DFS(Graph G, int v) {            // 邻接表存储
    visited[v] = true; visit(v);
    for (p = G.adjlist[v].first; p; p = p->next)
        if (!visited[p->adjvex]) DFS(G, p->adjvex);
}
```

## 复杂度（取决于存储结构）

| 存储 | BFS | DFS |
|---|---|---|
| 邻接矩阵 | $O(V^2)$ | $O(V^2)$ |
| 邻接表 | $O(V+E)$ | $O(V+E)$ |

## 408 考点

> [!warning] 常考结论
> - 遍历序列**不唯一**：由存储结构（邻接矩阵/邻接表）与起始顶点决定
> - 调用 BFS/DFS 的次数 = **连通分量数**
> - BFS 可用于无权图最短路径（按层扩展）、判断连通性
> - DFS 可用于有向图判环、拓扑排序、求强连通分量
