# 二分查找（折半查找）

> 前提：**有序的顺序表**（随机存取）。链表无法折半——找 mid 需要 $O(n)$。

## 核心逻辑

每次与中间元素 $A[mid]$ 比较：相等 → 命中；$key < A[mid]$ → 查左半；否则查右半。

```c
// 升序数组，返回下标（-1 表示失败）
int BinarySearch(int A[], int n, int key) {
    int low = 0, high = n - 1, mid;
    while (low <= high) {
        mid = (low + high) / 2;          // low + (high-low)/2 防溢出
        if (A[mid] == key) return mid;
        else if (key < A[mid]) high = mid - 1;
        else low = mid + 1;
    }
    return -1;
}
```

## 判定树与 ASL

- 比较过程构成一棵**平衡二叉排序树**（判定树），树高 $\lceil \log_2(n+1) \rceil$
- 查找成功 $ASL = \log_2(n+1) - 1$（n 较大时近似）
- 时间 $O(\log_2 n)$，空间 $O(1)$

## 408 考点

> [!warning] 常考结论
> - 判定树是平衡树但不是**完全**二叉树
> - mid 向下取整时，判定树右子树结点数 ≤ 左子树（向上取整则相反）
> - 比较次数 = 结点在判定树中的层数；失败比较次数 ≤ 树高
> - 与顺序查找、分块查找的 ASL 对比是选择题常客
