# 卡特兰数-出栈序列（例题）

> 408 经典出栈序列计数问题，考查卡特兰数 $C_n$ 的直接应用与分段计数思想。

## 题目

已知进栈序列为 $1,2,3,4,5$：

1. 出栈序列共有多少种可能？
2. 第一个出栈元素为 3 的出栈序列有多少种？

## 解题思路

**卡特兰数直接应用**：$n$ 个不同元素进栈的出栈序列总数 = $C_n$。

**分段计数**：若第一个出栈的是元素 $k$，则：
- $1,2,\ldots,k-1$ 已进栈但未出栈 → 其出栈序列数 = $C_{k-1}$
- $k+1,k+2,\ldots,n$ 尚未进栈 → 其出栈序列数 = $C_{n-k}$
- 两者独立，总数 = $C_{k-1} \times C_{n-k}$

## 详细解答

### (1) 出栈序列总数

$$C_5 = \frac{1}{6}\binom{10}{5} = \frac{252}{6} = \boxed{42}$$

### (2) 第一个出栈元素为 3

- 3 第一个出栈 → 1、2 已进栈但未出栈，3 进栈后立即出栈
- 前半段（1、2 的进出栈序列）：$C_2 = 2$ 种
- 后半段（4、5 的进出栈序列）：$C_2 = 2$ 种
- 两者独立 → 总数 = $C_2 \times C_2 = 2 \times 2 = \boxed{4}$

## 408 易错点

> [!warning] 易错点
> - 第一个出栈元素为 $k$ 时，$k-1$ 个元素是"已进未出"，$n-k$ 个元素是"未进"，两者**独立计数**
> - 卡特兰数 $C_0 = 1$（空序列也是一种情况），不是 $C_0 = 0$
> - 408 高频变式：问"某个特定序列是否合法"（判断题），不是计数
