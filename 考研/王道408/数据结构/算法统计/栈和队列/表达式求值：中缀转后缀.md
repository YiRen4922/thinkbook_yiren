# 表达式求值：中缀转后缀

> 栈的经典应用（A 级）。机器求值用**后缀（逆波兰）表达式**最方便：一个栈即可算完，无需括号和优先级。考研 408 高频考点：手算中缀 → 后缀、后缀求值过程、栈的变化。

## 算法思想

**为什么需要后缀表达式**：中缀表达式需要考虑运算符优先级和括号嵌套；后缀表达式**消除了括号和优先级**，从左到右扫描时，遇操作数就压栈，遇运算符就弹栈计算——完全符合机器的处理逻辑。

**中缀转后缀规则**（从左到右扫描）：

1. **操作数**：直接输出
2. **左括号 `(`**：入栈
3. **右括号 `)`**：弹出栈顶直到 `(`，`(` 出栈但不输出
4. **运算符**：弹出栈中**优先级 ≥ 它**的运算符后入栈（同级按左结合）
5. **扫描结束**：弹出栈中剩余所有运算符

优先级：`* /` > `+ -` > `(`

## 代码实现

### 后缀表达式求值

```c
int evalPostfix(char *expr) {
    int stack[100], top = -1;
    for (int i = 0; expr[i]; i++) {
        if (isdigit(expr[i])) {
            stack[++top] = expr[i] - '0';
        } else {
            int b = stack[top--];        // 注意：先弹出的是右操作数
            int a = stack[top--];        // 后弹出的是左操作数
            switch (expr[i]) {
                case '+': stack[++top] = a + b; break;
                case '-': stack[++top] = a - b; break;
                case '*': stack[++top] = a * b; break;
                case '/': stack[++top] = a / b; break;
            }
        }
    }
    return stack[top];
}
```

### 转换过程跟踪（手动模拟用）

用一个**运算符栈**，按上述规则扫描中缀串，依次输出后缀串。

## 转换示例

| 中缀表达式 | 后缀表达式（波兰式） |
|---|---|
| $a+b$ | $ab+$ |
| $(a+b) \times c$ | $ab+c\times$ |
| $a+b \times c$ | $abc\times+$ |
| $a \times b + c$ | $ab\times c+$ |

## 时间复杂度

- 时间：$O(n)$，扫描一遍输入串，每个元素最多入栈、出栈各一次
- 空间：$O(n)$（运算符栈深度）

## 易错点

> [!warning] 易错点
> - 弹栈顺序：$a - b$ 中，**先弹出**的是右操作数 $b$，**后弹出**的是左操作数 $a$
> - `(` 的优先级最低（进栈时不弹出任何东西），不是"无优先级"
> - 左括号入栈后，右括号到来时把栈顶运算符弹出直到左括号，**左括号出栈但不输出**
> - 后缀求值栈的**最大深度** = 操作数个数 = 操作数在后缀串中的连续出现段长度
