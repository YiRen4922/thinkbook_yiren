# 出栈序列合法性判断

> 给定入栈序列，判断一个出栈序列是否合法。408 选择题高频技巧题：**栈模拟**最稳妥；计数规律（卡特兰数约束）可用于快速排除。与 [[卡特兰数]] 互补：后者计**数量**，本笔记判**合法性**。

## 算法思想

**核心规则**：出栈序列合法 ⇔ 任意时刻出栈的元素都不可能是"被后面入栈的元素压在栈底还没出来的"。

**栈模拟法**（最可靠）：

1. 依次把入栈序列的元素压栈
2. 每次压入后，**循环**：若栈顶 == 当前要出栈的元素，则出栈并推进出栈序列
3. 全部入栈元素处理完后，若栈空 → 合法；否则 → 非法（栈顶卡住了无法出栈的元素）

**计数技巧**（快速判断选择题）：对任意前缀，出栈次数 ≤ 入栈次数（等价于"进栈记为 +1、出栈记为 -1，任意前缀和 ≥ 0"）。这既是卡特兰数的推导基础，也是合法性的充要条件。

## 代码实现

```c
#include <stdio.h>
int isValidPopSequence(int push[], int pop[], int n) {
    int stack[1000], top = -1;
    int i = 0, j = 0;                  // i 扫描入栈序列，j 扫描出栈序列
    while (i < n) {
        stack[++top] = push[i++];      // 模拟入栈
        while (top != -1 && stack[top] == pop[j]) {
            top--; j++;                // 栈顶匹配，出栈
        }
    }
    while (top != -1 && stack[top] == pop[j]) { top--; j++; }
    return (top == -1) ? 1 : 0;        // 栈空 = 全部出栈 = 合法
}
// 例：push=[1,2,3,4,5]，pop=[4,5,3,2,1] 合法；pop=[4,3,5,1,2] 非法
```

## 时间复杂度

- 时间：$O(n)$（每个元素至多入栈一次、出栈一次）
- 空间：$O(n)$（辅助栈）

## 易错点

> [!warning] 易错点
> - **不能只看"出栈顺序是入栈顺序的逆序"**：如入 `1,2,3`，出 `1,3,2` 合法（1 进即出，2、3 进，3 出，2 出），但不是逆序
> - 计数技巧：任意前缀"出栈数 ≤ 入栈数"，否则必非法
> - 元素全部进栈后仍需**连续出栈匹配**（代码的第二个 while 不能省）
> - 模拟法的关键是"栈顶才可出栈"——出栈序列的元素只能是当前栈顶

## 相关知识（考研408）

> [!note] 408 常考结论
> - 选择题：判断哪些出栈序列合法/非法——栈模拟 + 计数排除法
> - 合法出栈序列的**总数** = 卡特兰数 $C_n$（见 [[卡特兰数]]）
> - 第一个出栈元素为 $k$ 时：前面 $k-1$ 个已进未出，后面独立——分段计数
> - 栈容量有限制时：模拟过程还要检查是否超过栈容量（栈上溢）
