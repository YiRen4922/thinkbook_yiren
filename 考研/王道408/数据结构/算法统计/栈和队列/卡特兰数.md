# 卡特兰数（Catalan Number）

> 组合数学中最重要的计数数列之一，出现在**栈的出栈序列、括号匹配、二叉树形态、凸多边形三角剖分**等大量看似不同的问题中。408 中栈的出栈序列问题是卡特兰数最直接的应用。

## 算法思想

卡特兰数的递推关系 $C_{n+1} = \sum_{i=0}^{n} C_i \cdot C_{n-i}$ 描述了**"将大问题分解为两个子问题"**的组合结构。大量不同问题都符合这种结构：

- **出栈序列**：第一次出栈的元素把序列分成两段，各自独立
- **括号匹配**：第一次匹配的括号对把序列分成内部和外部两段
- **二叉树形态**：根结点把结点集分为左子树和右子树两部分

## 代码实现（递推求值）

```c
// 递推求卡特兰数 C[0..n]，时间 O(n^2)，空间 O(n)
long long catalan(int n) {
    long long C[n + 1];
    C[0] = 1;
    for (int i = 1; i <= n; i++) {
        C[i] = 0;
        for (int j = 0; j < i; j++)
            C[i] += C[j] * C[i - 1 - j];
    }
    return C[n];
}
```

## 定义与公式

$$\boxed{C_n = \frac{1}{n+1}\binom{2n}{n} = \frac{(2n)!}{(n+1)!\, n!}}$$

**递推关系**：

$$C_{n+1} = \sum_{i=0}^{n} C_i \cdot C_{n-i}, \quad C_0 = 1$$

**前几项（必背）**：

| $n$ | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| $C_n$ | 1 | 1 | 2 | 5 | 14 | 42 | 132 |

## 常见等价计数问题

| 问题 | 计数结果 |
|---|---|
| $n$ 个元素入栈的出栈序列数 | $C_n$ |
| $n$ 对括号的合法匹配数 | $C_n$ |
| $n$ 个结点的不同二叉树形态数 | $C_n$ |
| $n+1$ 个叶子的满二叉树个数 | $C_n$ |
| $n+2$ 边形的三角剖分数 | $C_n$ |
| 从 $(0,0)$ 到 $(n,n)$ 不越过 $y=x$ 的路径数 | $C_n$ |

## 时间复杂度

- 递推法：$O(n^2)$ 时间，$O(n)$ 空间
- 公式法：$O(n)$ 时间（预处理阶乘），$O(1)$ 查询
- 递推关系在 408 中更常用，公式在选择题中快速估算

## 易错点

> [!warning] 易错点
> - $C_0 = 1$（0 个元素的出栈序列只有"空序列"一种），不是 $C_0 = 0$
> - $n$ 个结点的二叉树形态数是 $C_n$，不是 $C_{n-1}$
> - 卡特兰数用于**计数**，不是求解具体序列
> - 出栈序列总数 $C_n$ 是**全部合法序列**，不是某个特定序列
