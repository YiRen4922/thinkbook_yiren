# 快速排序

> 分治：选枢轴 **pivot**，一趟划分把序列分成「左 < pivot < 右」两段，再递归排序两段。平均 $O(n\log n)$，最坏 $O(n^2)$，**不稳定**。408 高频考点：划分过程手算、枢轴落位、第 k 小元素。

## 算法思想

**三步分治**：

1. **划分（Partition）**：选一个枢轴 pivot，一趟下来 pivot 左边全 ≤ pivot、右边全 ≥ pivot，pivot 到达**最终位置**
2. **递归左半**：对左段快速排序
3. **递归右半**：对右段快速排序

**挖坑法划分细节**（pivot 暂存首元素）：

1. `high` 从右往左找 `< pivot` 的元素**填入** `low` 位置（挖坑填坑）
2. `low` 从左往右找 `> pivot` 的元素填入 `high` 位置
3. 相遇处放回 pivot——**pivot 到达最终位置**

## 代码实现

```c
int Partition(int A[], int low, int high) {
    int pivot = A[low];                 // 挖坑：暂存枢轴
    while (low < high) {
        while (low < high && A[high] >= pivot) high--;  // 找小填左
        A[low] = A[high];
        while (low < high && A[low] <= pivot) low++;    // 找大填右
        A[high] = A[low];
    }
    A[low] = pivot;                     // 枢轴落位，返回最终位置
    return low;
}

void QuickSort(int A[], int low, int high) {
    if (low < high) {
        int p = Partition(A, low, high);
        QuickSort(A, low, p - 1);
        QuickSort(A, p + 1, high);
    }
}
```

## 时间复杂度

| 情况 | 时间 | 条件 |
|---|---|---|
| 平均 | $O(n\log n)$ | 划分较均匀 |
| 最好 | $O(n\log n)$ | 每次划分恰好对半 |
| 最坏 | $O(n^2)$ | 序列**基本有序/逆序**且每趟选首元素为枢轴，划分极度不平衡 |

- 空间：递归栈 $O(\log n)$ 平均，最坏 $O(n)$
- **不稳定**：如 $[3, 3']$ 中，枢轴交换后 $3'$ 可能跑到前面

## 易错点

> [!warning] 易错点
> - 每趟划分后**枢轴到达最终位置**：左 ≤ pivot ≤ 右
> - 基本有序的序列对快排**最不利**（选首元素为枢轴时）——实际应用中随机选枢轴
> - 划分时**= pivot 的元素**既可能跳过也可能停下，写法不同结果序列不同但都正确
> - 非递归实现需借助**栈**保存待处理区间（408 选择/判断题）
> - 一趟划分不等于"第一趟快排"，一趟排完只确定**一个**元素位置

## 相关知识（考研408）

> [!note] 408 常考结论
> - 手算：给出一趟/两趟划分后的序列状态（高频选择题）
> - **找第 k 小元素**：利用划分每次确定枢轴位置，平均 $O(n)$（408 算法题）
> - 快排是所有 $O(n\log n)$ 排序中**平均最快**的，但最坏退化 $O(n^2)$
> - 快排不适合链表（枢轴选择需要随机存取）
