# 基数排序

> **不比较关键字大小**的排序：按位"分配-收集"，从最低位（LSD）逐位进行。**稳定**，时间 $O(d(n+r))$。408 高频：一趟分配收集后的序列、基数与稳定性的关系。

## 算法思想

**核心思想**：把排序拆成按关键字**各位**的多次"分配 + 收集"：

1. **分配**：按当前位的取值（0~r-1）把所有元素放入 **r 个队列**（桶）
2. **收集**：按位值从小到大的顺序依次把桶中元素**串回**原序列

从**最低位**（个位）开始到最高位（LSD 法），每趟按一位排序；使用**先进先出的队列**保证同一桶内相对顺序不变 → **稳定**。

> 例：对三位十进制数排序，需要 3 趟；每趟 10 个桶（r=10）。

## 代码实现

```c
// 关键字为 d 位十进制数，r=10 个桶（用队列/链表实现分配收集）
void RadixSort(int A[], int n, int d) {
    int bucket[10][MAXN];              // 简单实现：10 个桶
    int cnt[10] = {0};
    int factor = 1;
    for (int k = 0; k < d; k++) {      // d 趟，按位从低到高
        for (int i = 0; i < n; i++) {  // 分配
            int digit = (A[i] / factor) % 10;
            bucket[digit][cnt[digit]++] = A[i];
        }
        int idx = 0;
        for (int b = 0; b < 10; b++) { // 收集（顺序保留桶内次序 → 稳定）
            for (int j = 0; j < cnt[b]; j++)
                A[idx++] = bucket[b][j];
            cnt[b] = 0;
        }
        factor *= 10;
    }
}
```

## 时间复杂度

- 时间：$O(d \times (n + r))$——$d$ 为关键字位数，$r$ 为基数（桶数）
- 空间：$O(r + n)$（桶）
- **稳定**：因为同一桶内用队列保持原顺序

## 易错点

> [!warning] 易错点
> - 基数排序**不比较关键字**——与所有比较排序区分开
> - **LSD（低位优先）**最常用：先从个位开始；MSD（高位优先）少见
> - 同一个桶内元素顺序**必须保持**（队列/链表尾插）
> - 时间 $O(d(n+r))$，不是 $O(n)$——$d$、$r$ 决定效率
> - 适合：$d$ 小、$r$ 小（如整数、短字符串）、**需要稳定**的场景
> - 每一趟分配收集后：所有元素按"已处理的最低位组"有序
