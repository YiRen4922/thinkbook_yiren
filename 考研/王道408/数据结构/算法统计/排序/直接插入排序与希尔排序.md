# 直接插入排序与希尔排序

> 插入类排序：把新元素**插入到已有序序列**的合适位置。直接插入**稳定**、序列基本有序时 $O(n)$；希尔是它的改进（分组插入），**不稳定**。408 高频：趟后序列手算、与初始序列的关系。

## 算法思想

**直接插入**：把序列看成「前 i 个已有序 + 待插元素」，每趟把待插元素在有序部分**从后往前**找到位置插入。

**希尔排序**：按增量 $d$ 分组，组内做直接插入，增量递减（$d_1 = \lfloor n/2 \rfloor, d_{k+1} = \lfloor d_k/2 \rfloor$），最后 $d=1$ 时整体一次插入——**先宏观有序，再微观有序**。

## 代码实现

```c
// 直接插入排序（稳定）
void InsertSort(int A[], int n) {
    for (int i = 1; i < n; i++) {        // 从第 2 个开始
        int x = A[i], j = i - 1;
        while (j >= 0 && A[j] > x) {     // 后移腾位（> 保证稳定；>= 会不稳定）
            A[j + 1] = A[j]; j--;
        }
        A[j + 1] = x;
    }
}

// 希尔排序（不稳定）
void ShellSort(int A[], int n) {
    for (int d = n / 2; d >= 1; d /= 2) {   // 增量序列
        for (int i = d; i < n; i++) {       // 对每个分组做插入
            int x = A[i], j = i - d;
            while (j >= 0 && A[j] > x) {
                A[j + d] = A[j]; j -= d;
            }
            A[j + d] = x;
        }
    }
}
```

## 时间复杂度

| 算法 | 平均 | 最好 | 最坏 | 空间 | 稳定性 |
|---|---|---|---|---|---|
| 直接插入 | $O(n^2)$ | $O(n)$（基本有序） | $O(n^2)$（逆序） | $O(1)$ | **稳定** |
| 希尔排序 | $O(n^{1.3})$（经验） | — | $O(n^2)$ | $O(1)$ | **不稳定** |

## 易错点

> [!warning] 易错点
> - 直接插入**稳定**的写法：`while (A[j] > x)`（严格大于才后移）；写成 `>=` 就不稳定
> - 直接插入的比较/移动次数**与初始序列有关**（最好 $O(n)$，最坏 $O(n^2)$）
> - 希尔排序**不稳定**：相同关键字可能分到不同组被交换
> - 希尔增量序列最后**必须为 1**，否则不能保证完全有序
> - 基本有序序列：插排/冒泡最快——408 常考结论
