# 冒泡排序与简单选择排序

> 两类 $O(n^2)$ 基础排序：**冒泡（稳定，相邻交换）**与**简单选择（不稳定，跨距离交换）**。408 高频：一趟后的序列、每趟确定最终位置的特征。

## 算法思想

**冒泡排序**：相邻元素两两比较，逆序则交换。每趟把**最大值（升序）冒泡到末尾**——**每趟确定一个最终位置**（末尾最大元素）。可优化：某趟无交换即已有序。

**简单选择排序**：每趟在无序区选**最小（升序）**元素与无序区**第一个**位置交换——**每趟确定一个最终位置**（头部最小元素）。

## 代码实现

```c
// 冒泡排序（稳定）
void BubbleSort(int A[], int n) {
    for (int i = n - 1; i > 0; i--) {
        bool flag = false;
        for (int j = 0; j < i; j++)
            if (A[j] > A[j + 1]) {     // 严格大于才交换 → 稳定
                int t = A[j]; A[j] = A[j + 1]; A[j + 1] = t;
                flag = true;
            }
        if (!flag) break;              // 优化：本趟无交换已有序
    }
}

// 简单选择排序（不稳定）
void SelectSort(int A[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int min = i;
        for (int j = i + 1; j < n; j++)
            if (A[j] < A[min]) min = j;
        if (min != i) { int t = A[i]; A[i] = A[min]; A[min] = t; }  // 跨距离交换
    }
}
```

## 时间复杂度

| 算法 | 平均 | 最好 | 最坏 | 空间 | 稳定性 | 比较次数 |
|---|---|---|---|---|---|---|
| 冒泡 | $O(n^2)$ | $O(n)$（已有序+优化） | $O(n^2)$ | $O(1)$ | **稳定** | 与初始序列有关 |
| 简单选择 | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | **不稳定** | 恒为 $n(n-1)/2$，**与初始序列无关** |

## 易错点

> [!warning] 易错点
> - **冒泡稳定**（相邻交换，相等不换）；**选择不稳定**（跨距离交换，可能跳过相等元素）
> - 选择排序的比较次数**固定** $n(n-1)/2$，与初始序列**无关**（移动次数才有关）
> - 冒泡优化：某趟无交换直接结束——最好情况 $O(n)$
> - 两者**每趟都确定一个元素的最终位置**：冒泡确定末尾最大，选择确定头部最小
> - 冒泡适合链表（相邻元素），选择也适合链表（交换 data 或改指针）
