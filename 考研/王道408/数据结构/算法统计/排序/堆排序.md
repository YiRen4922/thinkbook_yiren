# 堆排序

> 基于**完全二叉树的数组表示**（下标从 1 开始）。**升序用大根堆**：每轮把堆顶与末尾交换，再调整剩余部分。时间**稳定** $O(n\log n)$，空间 $O(1)$，**不稳定**。408 高频考点：建堆过程、插入/删除堆顶后的调整。

## 算法思想

**堆**：完全二叉树，且任一结点 ≥（大根堆）/ ≤（小根堆）其所有后代。

**堆排序两步**：

1. **建堆**：从最后一个非叶结点 $\lfloor n/2 \rfloor$ 起**向前**逐个向下调整（Sift），得到大根堆
2. **排序**：每轮 `swap(A[1], A[i])` 把堆顶（最大）放到末尾，再对 `[1, i-1]` 向下调整

**向下调整 Sift**：从结点 $k$ 开始，若孩子中较大者 > 自己，与较大孩子交换，继续向下。

**插入**：新元素加到末尾，**向上调整**（与双亲比较交换）。
**删除堆顶**：末元素顶上，再**向下调整**。

## 代码实现

```c
void Sift(int A[], int k, int n) {       // 对 A[1..n] 中结点 k 向下调整（大根堆）
    int x = A[k];                        // 暂存待调整值
    for (int i = 2 * k; i <= n; i *= 2) {
        if (i < n && A[i] < A[i + 1]) i++;   // 选较大的孩子
        if (x >= A[i]) break;            // 无需继续下移
        A[k] = A[i];
        k = i;
    }
    A[k] = x;                            // 落入最终位置
}

void HeapSort(int A[], int n) {
    for (int i = n / 2; i >= 1; i--)     // 建堆：从最后一个非叶结点向前
        Sift(A, i, n);
    for (int i = n; i > 1; i--) {
        int tmp = A[1]; A[1] = A[i]; A[i] = tmp;  // 堆顶放到末尾
        Sift(A, 1, i - 1);               // 调整剩余 i-1 个
    }
}
```

### 插入与删除

```c
// 插入：末尾入堆后向上调整
void insert(int A[], int &n, int key) {
    A[++n] = key;
    for (int k = n; k > 1 && A[k] > A[k / 2]; k /= 2) {
        int t = A[k]; A[k] = A[k / 2]; A[k / 2] = t;
    }
}
// 删除堆顶：末元素顶上后向下调整
void deleteTop(int A[], int &n) {
    A[1] = A[n--];
    Sift(A, 1, n);
}
```

## 时间复杂度

- 建堆：$O(n)$（从 $\lfloor n/2 \rfloor$ 往前，总调整次数 $O(n)$）
- 每趟调整：$O(\log n)$，共 $n-1$ 趟
- 总时间：**$O(n\log n)$，与初始序列无关**（最坏也不退化）
- 空间：$O(1)$，原地排序

## 易错点

> [!warning] 易错点
> - **建堆从 $\lfloor n/2 \rfloor$ 向前**，不是从 1 向后
> - Sift 循环中要**选择较大的孩子**：`if (i < n && A[i] < A[i+1]) i++`
> - **升序用大根堆**、降序用小根堆（别记反）
> - **不稳定**排序（例如 `[1, 5, 5']` 建堆交换后 $5'$ 可能跑到 $5$ 前面）
> - 数组下标**从 1 开始**（0 号位空置或存哨兵）
> - 堆顶是最值，但**堆不是有序的**（兄弟之间无约束）
