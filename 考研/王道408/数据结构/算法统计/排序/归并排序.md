# 归并排序

> 分治：把序列对半分成两段递归排好，再**二路归并**成一个有序段。时间 $O(n\log n)$ **与初始序列无关**，空间 $O(n)$，**稳定**。408 高频考点：一趟归并后的序列、归并趟数、外部排序基础。

## 算法思想

**分治三步**：

1. **分解**：把区间 `[low, high]` 对半分为 `[low, mid]` 和 `[mid+1, high]`
2. **递归排序**：两段分别归并排序
3. **合并**：二路归并——两个有序段借助辅助数组 B，每次取较小者写入

> $n$ 个元素归并 $\lceil \log_2 n \rceil$ 趟；每趟 $O(n)$，总 $O(n\log n)$。

## 代码实现

```c
void Merge(int A[], int low, int mid, int high) {
    int B[MAXN];                          // 辅助数组
    for (int k = low; k <= high; k++) B[k] = A[k];   // 复制到辅助数组
    int i = low, j = mid + 1, k = low;
    while (i <= mid && j <= high)         // 取较小者写入
        A[k++] = (B[i] <= B[j]) ? B[i++] : B[j++];
    while (i <= mid) A[k++] = B[i++];     // 左段剩余
    while (j <= high) A[k++] = B[j++];    // 右段剩余
}

void MergeSort(int A[], int low, int high) {
    if (low < high) {
        int mid = (low + high) / 2;
        MergeSort(A, low, mid);
        MergeSort(A, mid + 1, high);
        Merge(A, low, mid, high);
    }
}
```

## 时间复杂度

- 时间：$O(n\log n)$——每趟 $O(n)$，共 $\lceil \log_2 n \rceil$ 趟，**与初始序列无关**（最坏也是 $O(n\log n)$）
- 空间：$O(n)$（辅助数组 B），递归栈 $O(\log n)$ 可忽略
- **稳定**：合并时 `B[i] <= B[j]` 取左段，相等元素保持前序

## 易错点

> [!warning] 易错点
> - 合并必须**借助辅助数组**并复制回原数组，直接原地合并会破坏有序性
> - 二路归并（每趟两个两个合并）；$n$ 个记录归并趟数 $=\lceil \log_2 n \rceil$
> - 一趟归并 ≠ 一趟排序：一趟归并后序列由若干**长度为 2 的有序段**组成
> - **稳定**（与快排、堆排不同）
> - 空间 $O(n)$ 是它与原地排序的**关键区别**

## 相关知识（考研408）

> [!note] 408 常考结论
> - 手算：给出一趟归并后的序列状态
> - 归并是**外部排序的基础**（多路归并 + 败者树 + 置换选择）
> - 适合**链表**（无需随机存取，链表归并只需改指针）
> - 适合 n 很大、不能全部装入内存的数据（外排）
