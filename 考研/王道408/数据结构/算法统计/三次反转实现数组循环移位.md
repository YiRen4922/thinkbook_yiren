# 三次反转实现数组循环移位

> 前提：数组长度 $n$，移位 $k$，务必执行 $k=k\%n$，消除 $k\ge n$ 的情况。reverse(a,l,r)： 反转闭区间  $([l,r])$

## ✅循环右移 k 位

步骤：

1. 反转整个数组 $[0,n-1]$
2. 反转前 $k$ 个 $[0,k-1]$
3. 反转剩余 $n-k$ 个 $[k,n-1]$

示例：`[1,2,3,4,5]`，n=5，右移k=2

1. 整体反转 → `5 4 3 2 1`
2. 反转前2位 → `4 5 3 2 1`
3. 反转后3位 → `4 5 1 2 3`

```
void reverse(vector<int>& a,int l,int r){
    while(l<r) swap(a[l++],a[r--]);
}
void rotateRight(vector<int>& nums,int k){
    int n=nums.size();
    k%=n;
    reverse(nums,0,n-1);
    reverse(nums,0,k-1);
    reverse(nums,k,n-1);
}
```

## ✅循环左移 k 位

步骤：

1. 反转前 $k$ 个 $[0,k-1]$
2. 反转后 $n-k$ 个 $[k,n-1]$
3. 反转整个数组 $[0,n-1]$

示例：`[1,2,3,4,5]`，n=5，左移k=2

1. 反转前2位 → `2 1 3 4 5`
2. 反转后3位 → `2 1 5 4 3`
3. 整体反转 → `3 4 5 1 2`

```
void rotateLeft(vector<int>& nums,int k){
    int n=nums.size();
    k%=n;
    reverse(nums,0,k-1);
    reverse(nums,k,n-1);
    reverse(nums,0,n-1);
}
```

## 复杂度

- 时间：$(O(n))$，每个元素最多被反转2次
- 空间：$(O(1))$，原地操作

## 考试要点

1. `k%=n`必不可少，否则k大于数组长度会下标越界
2. 右移、左移的三步顺序**不能记混**
3. reverse是闭区间`\([l,r]\)`

### 极简记忆

- **右移：全 → 前k → 后n‑k**
- **左移：前k → 后n‑k → 全**
