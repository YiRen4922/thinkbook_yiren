# 快速排序

> 分治：选枢轴 pivot，一趟划分把序列分成"左 < pivot < 右"两段，递归排序两段。

## 一趟划分（挖坑法）

pivot 暂存首元素，low/high 从两端交替找"坑"：
1. high 从右往左找 `< pivot` 的元素填入 low 位置
2. low 从左往右找 `> pivot` 的元素填入 high 位置
3. 相遇处放回 pivot——**pivot 到达最终位置**

```c
int Partition(int A[], int low, int high) {
    int pivot = A[low];
    while (low < high) {
        while (low < high && A[high] >= pivot) high--;
        A[low] = A[high];
        while (low < high && A[low] <= pivot) low++;
        A[high] = A[low];
    }
    A[low] = pivot;
    return low;
}
void QuickSort(int A[], int low, int high) {
    if (low < high) {
        int p = Partition(A, low, high);
        QuickSort(A, low, p - 1);
        QuickSort(A, p + 1, high);
    }
}
```

## 复杂度与性质

- 平均：时间 $O(n\log n)$，空间（递归栈）$O(\log n)$
- 最坏 $O(n^2)$：序列**基本有序/逆序**且每次选首元素为枢轴时划分极不平衡
- **不稳定**（如 $[3, 3']$，枢轴交换后 $3'$ 可能跑到前面）

## 408 考点

> [!warning] 常考结论
> - 每趟划分后**枢轴到达最终位置**，且左侧全部 ≤ 枢轴、右侧全部 ≥ 枢轴（可用于找第 k 小元素）
> - 手算：给出一趟/两趟划分后的序列状态
> - 非递归实现需借助**栈**保存待处理区间
