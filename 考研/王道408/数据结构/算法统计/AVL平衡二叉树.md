# AVL 平衡二叉树

> 任一结点左右子树高度差 ≤ 1：平衡因子 $BF = H_{\text{左}} - H_{\text{右}} \in \{-1, 0, 1\}$。

## 插入失衡的四类调整（旋转）

| 类型 | 失衡原因 | 调整 |
|---|---|---|
| LL | 插到左孩子的**左**子树 | **右**单旋 |
| RR | 插到右孩子的**右**子树 | **左**单旋 |
| LR | 插到左孩子的**右**子树 | 先左旋后右旋 |
| RL | 插到右孩子的**左**子树 | 先右旋后左旋 |

旋转后子树高度与插入前相同 → 只需处理**第一个**失衡结点，无需向上连锁（删除除外）。

## 最少结点数

$$N(h) = N(h-1) + N(h-2) + 1, \quad N(0)=0,\ N(1)=1$$

- $N(h)$ 近似斐波那契 → $n$ 个结点的 AVL 高度 ≈ $O(\log n)$
- 查找/插入/删除均 $O(\log n)$，但插入删除常数较大 → 适合读多写少

## 408 考点

> [!warning] 常考结论
> - 判断是否为平衡二叉树；插入后依次旋转，手画最终形态
> - 删除也可能失衡，且可能需**多次**调整回溯到根
> - 从 $BF = 2$ 的结点开始做旋转，注意 LL/LR/RR/RL 的判别
