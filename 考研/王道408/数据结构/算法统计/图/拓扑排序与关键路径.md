# 拓扑排序与关键路径

> **拓扑排序（AOV 网）**：将有向无环图的顶点排成线性序列，使每条边的起点在终点之前。**关键路径（AOE 网）**：从源点到汇点的**最长路径**，长度 = 工程最短工期，是 408 图论大题必考点。

## 算法思想

### 拓扑排序

1. 从 AOV 网中选择一个**入度为 0** 的顶点输出
2. 删除该顶点及其所有**出边**
3. 重复 1-2，直到无可输出顶点
4. 若输出顶点数 $< n$ → 图**有环**

> 基于入度表 + 队列实现：$O(V+E)$。结果**可能不唯一**。

### 关键路径

在 AOE 网（有向带权图，边 = 活动，顶点 = 事件）上：

1. **$ve(v)$**：事件最早发生时间——**正向拓扑序**，$\max$（所有入边）
2. **$vl(v)$**：事件最迟发生时间——**逆拓扑序**，$\min$（所有出边）
3. 活动 $a_k = \langle u, v \rangle$：最早 $e_k = ve(u)$，最迟 $l_k = vl(v) - w$
4. **$e_k = l_k$ 的活动是关键活动**，关键活动构成**关键路径**

## 代码实现

### 拓扑排序（BFS/Kahn 算法）

```c
void TopologicalSort(Graph G) {
    int indegree[MAXV] = {0};
    for (int i = 0; i < G.vexnum; i++)
        for (ArcNode *p = G.adjlist[i].first; p; p = p->next)
            indegree[p->adjvex]++;
    Queue Q; InitQueue(&Q);
    for (int i = 0; i < G.vexnum; i++)
        if (indegree[i] == 0) EnQueue(&Q, i);
    int count = 0;
    while (!QueueEmpty(&Q)) {
        int u; DeQueue(&Q, &u);
        printf("%d ", u); count++;
        for (ArcNode *p = G.adjlist[u].first; p; p = p->next) {
            indegree[p->adjvex]--;
            if (indegree[p->adjvex] == 0)
                EnQueue(&Q, p->adjvex);
        }
    }
    if (count < G.vexnum) printf("图中有环！\n");
}
```

## 时间复杂度

- 拓扑排序：$O(V+E)$（邻接表 + 队列）
- 关键路径：$O(V+E)$（两次拓扑遍历）

## 易错点

> [!warning] 易错点
> - 拓扑排序**结果不唯一**——多个入度为 0 的顶点可任选
> - 若输出顶点数 $< n$，图**有环**（可用于判环）
> - 关键路径计算 $vl(v)$ 时必须**逆拓扑序**，不能随意顺序
> - 关键路径**可能不唯一**——缩短工期必须同时加速**所有**关键路径上的关键活动
> - $e = l$ 的活动是关键活动，$e < l$ 的活动**不是**关键活动
