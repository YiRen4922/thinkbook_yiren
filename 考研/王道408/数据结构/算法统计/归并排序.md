# 归并排序

> 分治：把序列对半分成两段，递归排好，再**二路归并**成一个有序段。

## 核心操作：二路归并 Merge

两个有序段 $[low..mid]$、$[mid+1..high]$ 借助辅助数组 B，每次取较小者写入。

```c
void Merge(int A[], int low, int mid, int high) {
    int B[MAXN];
    for (int k = low; k <= high; k++) B[k] = A[k];
    int i = low, j = mid + 1, k = low;
    while (i <= mid && j <= high)
        A[k++] = (B[i] <= B[j]) ? B[i++] : B[j++];
    while (i <= mid) A[k++] = B[i++];
    while (j <= high) A[k++] = B[j++];
}
void MergeSort(int A[], int low, int high) {
    if (low < high) {
        int mid = (low + high) / 2;
        MergeSort(A, low, mid);
        MergeSort(A, mid + 1, high);
        Merge(A, low, mid, high);
    }
}
```

## 复杂度与性质

- 每趟归并 $O(n)$，共 $\lceil \log_2 n \rceil$ 趟 → 时间 $O(n\log n)$（**与初始序列无关**）
- 空间 $O(n)$（辅助数组）
- **稳定**；适合链表（无需随机存取）；外部排序以归并为基础

## 408 考点

> [!warning] 常考结论
> - 一趟归并后的序列手算
> - $n$ 个记录归并趟数 $=\lceil \log_2 n \rceil$
> - 稳定性与空间开销是选择题高频；归并是**外部排序**的基础
