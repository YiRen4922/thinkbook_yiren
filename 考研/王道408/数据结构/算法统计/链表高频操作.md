# 链表高频操作

> 线性表算法设计题常客（S/A 级），带头结点与不带头结点两种都要会写。

## 1. 单链表逆置（三指针，原地）

```c
LNode *Reverse(LNode *L) {              // 不带头结点，O(n)、O(1)
    LNode *prev = NULL, *cur = L, *next;
    while (cur) {
        next = cur->next;
        cur->next = prev;
        prev = cur; cur = next;
    }
    return prev;
}
```
带头结点版：摘下头结点，其余结点依次**头插**回链表。

## 2. 合并两个递增有序链表

两指针分别走，较小的结点尾插到新链表（带头结点），一表空则剩余直接接上 → $O(m+n)$。

## 3. 找中间结点（快慢指针）

slow 每次 1 步、fast 每次 2 步，fast 到尾时 slow 在中间。

## 4. 删除倒数第 k 个结点

快指针先走 $k$ 步，然后快慢同步走，快指针到尾时慢指针指向倒数第 $k$ 个。

## 5. 其他高频变体

- 判断回文：快慢找中点 + 逆置后半段逐一比较
- 有序链表去重：一趟扫描，重复结点跳过
- 判环 / 环入口：[[Floyd 判圈算法（快慢指针，龟兔算法 Tortoise and Hare）]]

## 408 考点

> [!warning] 常考结论
> - 找中点 / 倒数第 k 个 / 判环 → 统一联想**快慢指针**
> - 逆置 → 统一联想**头插法**或三指针
> - 题目常要求 $O(n)$ 时间、$O(1)$ 空间
