# 哈夫曼树

> 带权路径长度（WPL）**最小**的二叉树——贪心：每次合并权值**最小的两棵**子树。408 高频考点：哈夫曼树构造、WPL 计算、哈夫曼编码（前缀码）。

## 算法思想

**WPL（带权路径长度）**：所有叶子结点的（权值 × 到根的路径长度）之和。目标：构造 WPL 最小的二叉树。

**构造算法（贪心）**：

1. 将 $n$ 个权值看成 $n$ 棵只有根结点的二叉树（森林）
2. 每次取**权值最小的两棵**合并成一个新根（权值 = 两者之和），加入森林
3. 重复直到森林只剩一棵树

**性质**：

- 叶子结点数 $n_0 = n$，度为 2 的结点数 $n_2 = n-1$，总结点数 $2n-1$
- 哈夫曼树中**没有度为 1 的结点**（由构造过程保证）
- 形态**不唯一**（权值相等时可互换），但 **WPL 唯一最小**

**哈夫曼编码**：左 0 右 1，从根到叶子的路径即该字符的编码——**前缀编码**（任一编码不是其他编码的前缀），可用于数据压缩。

## 代码实现

```c
// 结构：树结点（叶子存权值）+ 小顶堆辅助
typedef struct HTNode {
    int weight;
    int parent, lchild, rchild;      // 静态链表实现（王道版）
} HTNode, *HuffmanTree;

// 每次从森林中选两个最小权值且无双亲的结点（O(n) 扫描，408 手算即可）
int selectMin(HuffmanTree HT, int n, int *s2) {
    int s1 = -1, s2 = -1;
    for (int i = 1; i <= n; i++)
        if (HT[i].parent == 0 && (s1 == -1 || HT[i].weight < HT[s1].weight)) s1 = i;
    for (int i = 1; i <= n; i++)
        if (i != s1 && HT[i].parent == 0 && (s2 == -1 || HT[i].weight < HT[s2].weight)) s2 = i;
    *s2 = s2; return s1;
}

void CreateHuffmanTree(HuffmanTree &HT, int w[], int n) {
    if (n <= 1) return;
    int m = 2 * n - 1;
    HT = (HTNode*)malloc((m + 1) * sizeof(HTNode));
    for (int i = 1; i <= n; i++)                 // 初始化 n 个叶子
        { HT[i].weight = w[i-1]; HT[i].parent = HT[i].lchild = HT[i].rchild = 0; }
    for (int i = n + 1; i <= m; i++)
        { HT[i].weight = 0; HT[i].parent = HT[i].lchild = HT[i].rchild = 0; }
    for (int i = n + 1; i <= m; i++) {           // 构造 n-1 个非叶结点
        int s2;
        int s1 = selectMin(HT, i - 1, &s2);
        HT[s1].parent = HT[s2].parent = i;
        HT[i].lchild = s1; HT[i].rchild = s2;
        HT[i].weight = HT[s1].weight + HT[s2].weight;
    }
}
```

## 时间复杂度

- 朴素实现：$O(n^2)$（每次扫描选最小两个）
- 堆优化：$O(n\log n)$
- 手算：$n$ 个权值需要 $n-1$ 次合并

## 易错点

> [!warning] 易错点
> - 哈夫曼树**没有度为 1 的结点**：总结点数恒为 $2n-1$
> - 形态**不唯一**（权值相同的兄弟可互换），但 **WPL 唯一**
> - 编码长度为路径长度；**编码总长度 = WPL**
> - WPL 计算：$\sum (w_i \times l_i)$，别漏算或误算层数（根算第 0 层）
> - 哈夫曼编码是**前缀编码**，解码时无歧义
