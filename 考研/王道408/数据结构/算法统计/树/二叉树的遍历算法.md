# 二叉树的遍历算法

> 前序、中序、后序（递归 + 非递归）与层序遍历，是树章节 S 级必会内容。408 算法设计题常考非递归实现与由遍历序列还原二叉树。

## 算法思想

**递归三序**：访问时机决定顺序——

- **先序**：根 → 左 → 右（先访问根）
- **中序**：左 → 根 → 右
- **后序**：左 → 右 → 根（最后访问根）

**非递归**：用**栈**模拟递归调用。先序/中序入栈时机不同，后序需要一个标志位或用"先序变体+逆序"实现。
**层序**：用**队列**，根入队 → 出队访问 → 左右孩子依次入队。

## 代码实现

```c
typedef struct BiTNode {
    int data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;

// 递归先序
void PreOrder(BiTree T) {
    if (T) { visit(T); PreOrder(T->lchild); PreOrder(T->rchild); }
}

// 非递归中序
void InOrder2(BiTree T) {
    BiTNode *stack[MAXSIZE]; int top = -1;
    BiTNode *p = T;
    while (p || top != -1) {
        if (p) { stack[++top] = p; p = p->lchild; }   // 一路向左入栈
        else { p = stack[top--]; visit(p); p = p->rchild; }
    }
}

// 层序遍历（队列）
void LevelOrder(BiTree T) {
    BiTNode *q[MAXSIZE]; int front = 0, rear = 0;
    if (T) q[rear++] = T;
    while (front != rear) {
        BiTNode *p = q[front++];
        visit(p);
        if (p->lchild) q[rear++] = p->lchild;
        if (p->rchild) q[rear++] = p->rchild;
    }
}
```

## 时间复杂度

- 时间：$O(n)$，每个结点恰好访问一次
- 空间：递归栈 $O(h)$（$h$ 为树高，最坏 $O(n)$）；层序队列 $O(w)$（$w$ 为最大宽度，最坏 $O(n)$）

## 易错点

> [!warning] 易错点
> - 三种遍历的**访问时机**：先序先访问根再递归，中序递归左后访问根，后序递归完再访问根
> - 非递归中序：**入栈时向左走，出栈时访问并向右转**
> - 层序必须用**队列**，不是栈
> - 由遍历序列还原二叉树：**先序+中序 / 后序+中序 / 层序+中序**才唯一；先序+后序不唯一
> - 后序非递归：可用"先序（根右左）的逆序"，或加标志位区分左右子树是否已访问
