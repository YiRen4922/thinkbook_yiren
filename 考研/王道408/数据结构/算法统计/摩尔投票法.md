# Boyer‑Moore 摩尔投票法

## 核心用途

**找数组中出现次数大于 n/2 的众数（主元素）**；也可以扩展找大于 n/3 的最多两个候选。 前提：**如果存在主元素，算法能找出；算法输出的候选不一定是答案，必须再校验一遍**。

> 题目例子：给定数组，找出出现次数超过数组长度一半的元素。

## 核心思想

> 不同元素互相抵消；相同元素计数+1，不同就-1。 如果有一个数占半数以上，抵消到最后剩下的一定是它。

### 流程（找＞n/2 众数）

1. 设置两个变量：`candidate`候选值，`count = 0`计数
2. 遍历每一个元素 `num`
    - 如果 `count == 0`：把 `candidate = num`
    - 如果 `num == candidate`：`count++`
    - 否则：`count--`
3. 遍历结束得到 `candidate`
4. ✅**必须再遍历一次数组统计 candidate 真实出现次数，判断是否真的大于 n/2**
    
    > 重要：数组不存在众数时，算法依然会吐出一个候选，这个候选是无效的，**校验必不可少**。
    

### C++极简示例

```
// 摩尔投票阶段
int candidate, cnt = 0;
for(auto x : nums){
    if(cnt == 0){
        candidate = x;
    }
    cnt += (x == candidate) ? 1 : -1;
}
// --------必须校验---------
int real_cnt = 0;
for(auto x:nums) if(x==candidate) real_cnt++;
if(real_cnt > nums.size()/2) return candidate;
else return -1; // 不存在主元素
```

## 复杂度

- 时间：$(O(n))$，两轮遍历
- 空间：$(O(1))$，只使用常数变量，**原地算法**

## 扩展：找大于 n/3 的元素（最多2个）

原理：最多只能有2个元素同时满足出现次数 > n/3。维护两个候选、两个计数器。 遇到：

- 和候选A相等 →A计数+1
- 和候选B相等 →B计数+1
- 某个计数器为0，则替换该位置候选
- 都不相等，两个计数器同时减1
    
    > 结束后，同样**必须二次校验两个候选真实频次**。
    

## 考试易错点

1. ❌误区：摩尔投票返回的候选一定是众数。 ✅错！**只是潜在候选，一定要校验**。数组 `[1,2,3]`，没有众数，算法依旧会输出一个数。
2. 适用条件：大于 n/2、大于 n/3；推广：大于 n/k，最多 k‑1 个候选。
3. 优势：不需要哈希表统计频次，空间 (O(1))。

## 举例推演

数组：`[2,2,1,1,1,2,2]`，n=7，需要次数>3

1. 2:cnt=0 →candidate=2，cnt=1
2. 2:等于候选，cnt=2
3. 1:不等，cnt=1
4. 1:不等，cnt=0
5. 1:cnt=0 →candidate=1，cnt=1
6. 2:不等，cnt=0
7. 2:cnt=0 →candidate=2，cnt=1

得到候选=2；再统计：2出现4次，4>3，是主元素。
