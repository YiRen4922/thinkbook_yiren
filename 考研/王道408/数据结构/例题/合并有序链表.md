**将两个递增有序单链表合并为一个递增有序链表**（经典题）

### 题目描述
已知两个单链表，它们的节点值都是**递增有序**的，请将这两个链表合并成一个新的**递增有序**单链表。

要求：
- 合并后仍然保持递增有序
- 尽量使用原有节点，不新建节点（空间高效）

---

### 思路（推荐：双指针 + 哑节点）

1. 创建一个**哑节点**（dummy），作为新链表的头节点的前一个节点，方便操作。
2. 用一个指针 `tail` 指向新链表的当前最后一个节点。
3. 用两个指针 `p1`、`p2` 分别遍历两个原链表。
4. 比较 `p1` 和 `p2` 的值：
   - 谁小就把谁接在 `tail` 后面
   - 然后对应指针后移
5. 当其中一个链表走完后，把另一个链表剩余部分直接接上。
6. 返回 `dummy->next` 即可。

时间复杂度：\(O(m + n)\)  
空间复杂度：\(O(1)\)（只使用了几个指针）

---

### C++ 完整代码（迭代版，推荐）

```cpp
#include <iostream>
using namespace std;

// 链表节点定义
struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};

// 合并两个有序链表
ListNode* mergeTwoLists(ListNode* l1, ListNode* l2) {
    // 哑节点（哨兵）
    ListNode dummy(0);
    ListNode* tail = &dummy;   // tail 指向新链表的最后一个节点

    while (l1 != nullptr && l2 != nullptr) {
        if (l1->val <= l2->val) {
            tail->next = l1;
            l1 = l1->next;
        } else {
            tail->next = l2;
            l2 = l2->next;
        }
        tail = tail->next;     // tail 后移
    }

    // 把剩余部分接上
    if (l1 != nullptr) tail->next = l1;
    if (l2 != nullptr) tail->next = l2;

    return dummy.next;
}
```

---

### 递归版（更简洁，但空间是 O(m+n)）

```cpp
ListNode* mergeTwoLists(ListNode* l1, ListNode* l2) {
    if (l1 == nullptr) return l2;
    if (l2 == nullptr) return l1;

    if (l1->val <= l2->val) {
        l1->next = mergeTwoLists(l1->next, l2);
        return l1;
    } else {
        l2->next = mergeTwoLists(l1, l2->next);
        return l2;
    }
}
```

### 测试代码

```cpp
// 辅助函数：创建链表
ListNode* createList(initializer_list<int> vals) {
    ListNode dummy(0);
    ListNode* tail = &dummy;
    for (int v : vals) {
        tail->next = new ListNode(v);
        tail = tail->next;
    }
    return dummy.next;
}

// 辅助函数：打印链表
void printList(ListNode* head) {
    while (head) {
        cout << head->val;
        if (head->next) cout << " -> ";
        head = head->next;
    }
    cout << endl;
}

int main() {
    ListNode* l1 = createList({1, 3, 5, 7});
    ListNode* l2 = createList({2, 4, 6, 8, 10});

    cout << "链表1: "; printList(l1);
    cout << "链表2: "; printList(l2);

    ListNode* merged = mergeTwoLists(l1, l2);
    cout << "合并后: "; printList(merged);

    return 0;
}
```

**输出结果：**
```
链表1: 1 -> 3 -> 5 -> 7
链表2: 2 -> 4 -> 6 -> 8 -> 10
合并后: 1 -> 2 -> 3 -> 4 -> 5 -> 6 -> 7 -> 8 -> 10
```

### 考研常考提醒

1. 必须考虑其中一个（或两个）链表为空的情况。
2. 推荐使用**哑节点**，可以避免很多空指针判断。
3. 迭代版空间是 \(O(1)\)，递归版是 \(O(m+n)\)（函数调用栈），一般更推荐迭代版。
4. 如果题目要求“不能修改原链表，必须新建节点”，则每次都 `new` 新节点即可。
