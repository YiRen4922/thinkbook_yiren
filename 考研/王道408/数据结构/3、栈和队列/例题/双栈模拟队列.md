## 双栈模拟队列 · 考研408核心笔记

> 用两个栈模拟队列是**栈和队列**章节的经典考题，考察对两种数据结构**操作特性**的深刻理解——栈LIFO与队列FIFO的对立统一。在408中，此类题目常出现在选择题或算法设计题中；在数一中，可类比**递推与逆推**的转换思想；在英语一中，`stack`、`queue`、`simulate` 等词为科技类阅读高频词。


### 1. 问题描述

已知栈的4个基本操作：
- `Push(S, x)`：元素x入栈S
- `Pop(S, x)`：S出栈，并将出栈值赋给x
- `StackEmpty(S)`：判断栈S是否为空
- `StackOverflow(S)`：判断栈S是否已满（栈有容量限制）

利用上述栈操作，设计算法实现队列的3个操作：
- `Enqueue(x)`：元素x入队
- `Dequeue(x)`：出队，并将出队元素存储在x中
- `QueueEmpty()`：判断队列是否为空


### 2. 算法设计思想

**核心思路**：用两个栈——**输入栈（S1）** 和**输出栈（S2）**。

- **入队**：新元素直接压入S1（输入栈）
- **出队**：
  1. 若S2非空，直接从S2弹出栈顶元素（即最早入队的元素）
  2. 若S2为空，则将S1中所有元素依次弹出并压入S2（此过程反转顺序），然后从S2弹出栈顶元素
- **判空**：S1和S2均为空时队列为空

> 经典比喻：S1是“进水管”，S2是“出水管”。入队只管往S1里倒；出队时若S2没水，就把S1的水全部倒入S2，然后从S2倒出。


### 3. 数据结构定义

```cpp
#define MAX_SIZE 100

typedef struct {
    int data[MAX_SIZE];
    int top;
} Stack;

typedef struct {
    Stack S1;   // 输入栈
    Stack S2;   // 输出栈
} QueueByTwoStacks;
```


### 4. 操作实现（含栈满处理）

#### 4.1 入队操作 Enqueue(x)

```cpp
bool Enqueue(QueueByTwoStacks &Q, int x) {
    // 若S1未满，直接入栈
    if (!StackOverflow(Q.S1)) {
        Push(Q.S1, x);
        return true;
    }

    // S1已满，尝试腾挪空间
    // 只有S2为空时才能转移（否则S2中已有元素，无法保证顺序）
    if (StackEmpty(Q.S2)) {
        // 将S1中所有元素转移到S2
        int temp;
        while (!StackEmpty(Q.S1)) {
            Pop(Q.S1, temp);
            Push(Q.S2, temp);
        }
        // 现在S1已空，可以入队新元素
        Push(Q.S1, x);
        return true;
    }

    // S1满且S2非空 → 队列已满（无法入队）
    return false;
}
```

#### 4.2 出队操作 Dequeue(x)

```cpp
bool Dequeue(QueueByTwoStacks &Q, int &x) {
    // 若S2非空，直接从S2弹出
    if (!StackEmpty(Q.S2)) {
        Pop(Q.S2, x);
        return true;
    }

    // S2为空，将S1所有元素转移到S2
    if (!StackEmpty(Q.S1)) {
        int temp;
        while (!StackEmpty(Q.S1)) {
            Pop(Q.S1, temp);
            Push(Q.S2, temp);
        }
        // 从S2弹出队头
        Pop(Q.S2, x);
        return true;
    }

    // S1和S2均为空 → 队列空
    return false;
}
```

#### 4.3 判空操作 QueueEmpty()

```cpp
bool QueueEmpty(QueueByTwoStacks &Q) {
    return StackEmpty(Q.S1) && StackEmpty(Q.S2);
}
```


### 5. 复杂度分析

| 操作 | 时间复杂度 | 说明 |
|------|------------|------|
| **入队** | 均摊 $O(1)$ | 最坏情况 $O(n)$（当S1满且需转移时），但每个元素最多被转移一次 |
| **出队** | 均摊 $O(1)$ | 最坏情况 $O(n)$（当S2空时需转移S1全部元素），但每个元素最多被转移一次 |
| **判空** | $O(1)$ | 直接判断两个栈是否为空 |
| **空间复杂度** | $O(n)$ | 两个栈总共容纳的元素数不超过 $2 \times MAX\_SIZE$ |

> [!important] 均摊分析
> 每个元素入队时压入S1（$O(1)$），出队时如果S2为空，则需将S1中所有元素弹出并压入S2（每个元素 $O(1)$ 操作）。**每个元素在整个生命周期中只被转移一次**，因此总转移次数为 $n$，均摊到每次操作为 $O(1)$。


### 6. 执行示例

假设空队列，依次执行：`Enqueue(1)`, `Enqueue(2)`, `Enqueue(3)`, `Dequeue()`, `Enqueue(4)`, `Dequeue()`

| 步骤 | 操作 | S1（栈顶→底） | S2（栈顶→底） | 结果 |
|------|------|---------------|---------------|------|
| 0 | 初始 | 空 | 空 | — |
| 1 | Enqueue(1) | `[1]` | 空 | — |
| 2 | Enqueue(2) | `[2,1]` | 空 | — |
| 3 | Enqueue(3) | `[3,2,1]` | 空 | — |
| 4 | Dequeue() | S2空 → 转移S1至S2 | 空 | 转移后S1空，S2 `[1,2,3]`（栈顶为1） |
| 4 | 继续 | 空 | `[1,2,3]` | Pop(S2)得到1 |
| 5 | Enqueue(4) | `[4]` | `[2,3]`（栈顶2） | — |
| 6 | Dequeue() | S2非空 → 直接Pop | `[4]` | `[3]`（栈顶3） |


### 7. 注意事项

| 要点 | 说明 |
|------|------|
| **转移条件** | 仅在S2为空时才将S1元素转移到S2，否则会破坏FIFO顺序 |
| **栈满处理** | 入队时若S1满且S2非空，队列满；若S2空，可先转移再入队 |
| **均摊常数** | 尽管单次转移操作是 $O(n)$，但算法整体的均摊复杂度为 $O(1)$ |
| **C++ STL实现** | 直接用 `std::stack<int>` 即可，无需自己实现栈；但考场上需按题目给出栈操作编写 |
