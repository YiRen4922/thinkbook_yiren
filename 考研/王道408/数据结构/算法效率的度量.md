## 算法效率的度量 · 考研专题

> 算法效率的度量是408每年必考的内容，通常以选择题形式出现，偶尔在算法大题的第一问要求分析时间复杂度。

### 时间复杂度（大O记号）

**定义**：算法中**基本操作**的执行次数随问题规模 $n$ 增长的趋势。

> [!tip] 大O记号的核心含义
> 大O表示**上界**，即算法在最坏情况下的时间增长趋势。它忽略常数因子和低阶项，只保留最高阶项。

#### 常见时间复杂度排 序（由快到慢）

$$
O(1) < O(\log n) < O(n) < O(n\log n) < O(n^2) < O(n^3) < O(2^n) < O(n!)
$$

> [!warning] 考研高频考点
> - 递归算法的时间复杂度往往涉及**递推方程**的求解（主定理、迭代法）
> - 嵌套循环的时间复杂度需要分析**内外层循环变量的变化关系**

### [[空间复杂度 · 栈帧分析|空间复杂度]]（大O记号）

**定义**：算法运行过程中**临时占用的额外存储空间**随问题规模 $n$ 增长的趋势。

> [!note] 空间复杂度分类
> - **原地工作**：$O(1)$，算法所需额外空间为常数级
> - **递归算法**：空间复杂度通常等于递归调用的**最大深度**

### 经典例题

---

#### 例题1 · 基本循环结构

**题目**：分析以下代码段的时间复杂度。

```cpp
int func(int n) {
    int sum = 0;
    for (int i = 1; i <= n; i *= 2) {
        for (int j = 1; j <= i; j++) {
            sum++;
        }
    }
    return sum;
}
```

**思路**：外层循环变量 `i` 以**指数方式增长**（每次乘以2），内层循环的执行次数依赖于外层当前的 `i` 值。

**解答**：

外层循环中，$i$ 的取值为 $1, 2, 4, 8, \dots, 2^k$，其中 $2^k \le n$，所以外层循环次数为 $\lfloor \log_2 n \rfloor + 1$。

内层循环总共执行的次数为：
$$
1 + 2 + 4 + 8 + \dots + 2^k = 2^{k+1} - 1
$$

其中 $k = \lfloor \log_2 n \rfloor$，所以总执行次数约为 $2 \times 2^k - 1 \le 2n - 1$。

sum++运行的次数，这是一个公比为 2 的[[数列基础|等比数列求和]]，首项 a1=1a1​=1，末项为 $2^{\lfloor \log_2 n \rfloor}$

$$
\boxed{T(n) = O(n)}
$$

> [!check] 易错点
> 外层是指数增长，**不是** $O(n \log n)$。关键在于内层和外层的循环次数是同一个序列求和，整体为 $O(n)$。

#### 例题2 · 递归算法

**题目**：已知某递归算法的时间复杂度满足递推关系式：
$$
T(n) = 2T\left(\frac{n}{2}\right) + O(n)
$$
求该算法的时间复杂度。

**思路**：这是典型的**分治法**递推式，可以用**主定理（Master Theorem）** 求解。

**解答**：

主定理标准形式：
$$
T(n) = aT\left(\frac{n}{b}\right) + f(n), \quad a \ge 1, \; b > 1
$$

本题中，$a = 2,\; b = 2,\; f(n) = O(n)$。

计算 $n^{\log_b a} = n^{\log_2 2} = n^1 = n$。

因为 $f(n) = O(n)$ 与 $n^{\log_b a}$ 同阶，属于主定理的**情况二**（两者同阶）。

根据主定理情况二：
$$
T(n) = O(n^{\log_b a} \log n) = O(n \log n)
$$

$$
\boxed{T(n) = O(n \log n)}
$$

> [!info] 主定理补充（数一/数二也可用）
> - **情况一**：$f(n) = O(n^{\log_b a - \varepsilon})$，则 $T(n) = \Theta(n^{\log_b a})$
> - **情况二**：$f(n) = \Theta(n^{\log_b a})$，则 $T(n) = \Theta(n^{\log_b a} \log n)$
> - **情况三**：$f(n) = \Omega(n^{\log_b a + \varepsilon})$，且 $af(n/b) \le cf(n)$，则 $T(n) = \Theta(f(n))$

#### 例题3 · 空间复杂度与递归

**题目**（408真题改编）：考虑以下递归算法：

```cpp
int f(int n) {
    if (n <= 1) return 1;
    return f(n - 1) + f(n - 2);
}
```

**问**：
1. 该算法的时间复杂度为？（用大O表示）
2. 该算法的空间复杂度为？（用大O表示）

**思路**：这是斐波那契数列的递归实现，画出递归调用树分析。

**解答**：

**（1）时间复杂度**

递归调用树是一棵**满二叉树**，深度约为 $n$，每个节点调用自身两次。

$$T(n) = T(n-1) + T(n-2) + O(1)$$

这等价于斐波那契数列的增长，通项公式为 $T(n) = O(\phi^n)$，其中 $\phi = \frac{1+\sqrt{5}}{2} \approx 1.618$。

因此：
$$
T(n) = O(2^n)
$$

> 在考研中，如果不需要特别精确，直接写 $O(2^n)$ 即可得分。

**（2）空间复杂度**

递归的空间复杂度取决于**递归调用的最大深度**（栈的深度）。

对于 `f(n)`，递归调用的最大深度为 $n$（例如一直走 `f(n-1)` 这一条路径）。

空间复杂度为：
$$
S(n) = O(n)
$$

> [!important] 口诀记忆
> - **时间复杂度看节点数**：递归树节点总数为 $O(2^n)$
> - **空间复杂度看深度**：递归栈深度为 $O(n)$

### 补充 · 考研常见递推式速查表

| 递推式                       | 时间复杂度        | 典型算法      |
| ------------------------- | ------------ | --------- |
| $T(n) = T(n-1) + O(1)$    | $O(n)$       | 单次递归线性处理  |
| $T(n) = T(n-1) + O(n)$    | $O(n^2)$     | 选择排序、插入排序 |
| $T(n) = 2T(n/2) + O(1)$   | $O(n)$       | 简单二分遍历    |
| $T(n) = 2T(n/2) + O(n)$   | $O(n\log n)$ | 归并排序      |
| $T(n) = 2T(n/2) + O(n^2)$ | $O(n^2)$     | 某些分治矩阵乘法  |
| $T(n) = T(n/2) + O(1)$    | $O(\log n)$  | 二分查找      |
| $T(n) = T(n/2) + O(n)$    | $O(n)$       | 快速选择（平均）  |

> [!summary] 度量算法效率的三步法
> 1. **找基本操作**：哪条语句执行次数最多？
> 2. **建立求和式或递推式**：写出执行次数与 $n$ 的关系
> 3. **化简为大O**：保留最高阶，忽略常数因子
