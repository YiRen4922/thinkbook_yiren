## 串 · 考研408核心笔记（一）定义和基本操作

> 串（String）是由零个或多个字符组成的**有限序列**，是数据元素**限定为单个字符**的线性表。408 中串是**模式匹配（朴素匹配 → KMP）的载体：定义与基本操作本身考察频率中等，但它们是理解 next 数组、nextval 数组的前提。C++ 中 `std::string` 就是串的标准实现。


### 1. 串的定义

**串（String）**：由零个或多个字符组成的有限序列，一般记为

$$
S = 'a_1\,a_2\,a_3\,\cdots\,a_n' \quad (n \ge 0)
$$

- $S$ 为**串名**；单引号括起来的字符序列是串的**值**
- $n$ 称为串的**长度**；$n = 0$ 时称为**空串**，记作 $\emptyset$ 或 `''`
- 字符在串中的**位置**从 **1** 开始编号（408 默认约定，也是 KMP 求 next 的下标基础）

**基本术语**：

| 术语 | 定义 |
| --- | --- |
| 子串（Substring） | 串中**任意个连续字符**组成的子序列 |
| 主串 | 包含子串的串 |
| 字符位置 | 字符在串中的序号（从 1 开始） |
| 子串的位置 | 子串第一个字符在主串中的位置 |
| 空格串 | 由一个或多个**空格**组成的串，如 `' '`、`'  '` |
| 串相等 | 两个串**长度相等**且**对应位置字符都相同** |

> [!warning] 高频易错
> **空格串 ≠ 空串**。空格串长度 $\ge 1$（有几个空格长度就是几），空串长度恒为 $0$。真题常以判断题/选择题形式考察这一点。


### 2. 串与线性表的关系

串是**数据元素受限的线性表**：

- **逻辑结构**：串就是线性表——元素（字符）之间是线性的一对一关系
- **区别**：普通线性表以"单个元素"为操作对象（插入/删除某个元素）；串常以"**串整体 / 子串**"为操作对象（查找子串、连接、替换）

> [!note] 一句话总结
> "串是内容受限的线性表" —— 数据元素只能是字符；反之，线性表不要求元素是字符。


### 3. 串的基本操作（ADT 定义）

```text
ADT String {
    数据对象：D = {a_i | a_i ∈ 字符集, i = 1,2,...,n, n ≥ 0}
    数据关系：R = {<a_{i-1}, a_i> | a_{i-1}, a_i ∈ D, i = 2,...,n}
    基本操作：
        StrAssign(&T, chars)           // 生成一个其值等于 chars 的串 T
        StrCopy(&T, S)                 // 串复制：由串 S 复制得串 T
        StrEmpty(S)                    // 判空：为空返回 true
        StrCompare(S, T)               // 比较：S<T 返回负值；S=T 返回 0；S>T 返回正值
        StrLength(S)                   // 返回串长
        SubString(&Sub, S, pos, len)   // 求子串：返回 S 中第 pos 个字符起 len 个字符的子串
        Concat(&T, S1, S2)             // 串联接：T = S1 + S2
        Index(S, T)                    // 定位：若 T 是 S 的子串，返回其首次出现的位置，否则 0
        Replace(&S, T, V)              // 串替换：用 V 替换 S 中所有与 T 相等的子串
        ClearString(&S)                // 清空串（长度置 0）
        DestroyString(&S)              // 销毁串（释放存储空间）
}
```

> [!tip] 记法
> `Index`（定位/模式匹配）是本章主线，考研 80% 的串考题都围绕它展开——朴素匹配、KMP、next、nextval 全部服务于 `Index` 这个操作。


### 4. 串的比较

比较规则（相当于字典序）：

1. 从第一个字符起，依次比较两串对应字符的**编码（ASCII/Unicode）**
2. 遇到第一对不同字符时，**编码小者的串小**
3. 若前 $n$ 个字符全部相等，则**长度长者大**；长度也相等才是相等

$$
S = 'apple',\quad T = 'apply' \Rightarrow S < T \quad(\text{'e'} < \text{'y'})
$$


### 5. 子串个数公式（408 常考）

**长度为 $n$ 的串（假设无重复子串问题，按"位置"计数）：**

- 含空串的子串个数：$\dfrac{n(n+1)}{2} + 1$
- 非空子串个数：$\dfrac{n(n+1)}{2}$

> [!example] 真题方向
> 例：长度为 4 的串 `abcd`，它的子串总数（含空串）为
> $$
> \frac{4 \times 5}{2} + 1 = 11
> $$
> 若题目要求**互不相同**的子串（如 `aaaa` 的情况），需去重，审题要仔细。


### 6. 408 常考点

| 考点 | 说明 |
| --- | --- |
| 空串 vs 空格串 | 空格串长度 ≥ 1，空串长度 = 0 |
| 子串个数 | $n(n+1)/2 + 1$（含空串） |
| 串的相等 | 长度相等 + 对应字符都相等 |
| 串比较规则 | 逐字符比编码 → 全同则比长度 |
| 串与线性表 | 串是"数据元素为字符、面向子串操作"的线性表 |
| `Index` 定位 | 朴素匹配 / KMP 的目标，本章主线 |
