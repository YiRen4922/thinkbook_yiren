## 二叉树的性质

> 二叉树性质是 408 高频公式考点：每层最多结点数、最大结点数、叶子与度为 2 结点的关系、完全二叉树的编号性质。

### 第 $i$ 层最多结点数

二叉树第 $i$ 层最多有：

$$
\boxed{2^{i-1}}
$$

个结点。

### 高度为 $h$ 的二叉树最多结点数

高度为 $h$ 的二叉树最多有：

$$
\boxed{2^h - 1}
$$

个结点（即满二叉树）。

### 叶子结点数与度为 2 的结点数关系

对任意二叉树，若叶子结点数为 $n_0$，度为 $2$ 的结点数为 $n_2$，则：

$$
\boxed{n_0 = n_2 + 1}
$$

**推导**：
- 结点总数 $n = n_0 + n_1 + n_2$
- 边数 $e = n - 1 = n_1 + 2n_2$
- 联立得 $n_0 = n_2 + 1$

### 完全二叉树的性质

设完全二叉树有 $n$ 个结点，按层序从 $1$ 开始编号：

| 性质            | 公式                                                         |
| ------------- | ---------------------------------------------------------- |
| 高度            | $\lceil \log_2(n+1) \rceil$ 或 $\lfloor \log_2 n \rfloor + 1$ |
| 结点 $i$ 的双亲    | $\lfloor i/2 \rfloor$（$i > 1$）                             |
| 结点 $i$ 的左孩子   | $2i$（若 $2i \le n$）                                         |
| 结点 $i$ 的右孩子   | $2i+1$（若 $2i+1 \le n$）                                     |
| 结点 $i$ 所在层次   | $\lfloor \log_2 i \rfloor + 1$                             |
| 结点 $i$ 为分支或叶子 | $i≤\lfloor n/2 \rfloor$为分支结点，$i> \lfloor n/2 \rfloor$为叶子结点 |

**由结点数 $n$ 推 $n_0,\ n_1,\ n_2$**：完全二叉树**最多只有一个度为 $1$ 的结点**（$n_1$ 只可能为 $0$ 或 $1$），结合 $n_0 = n_2 + 1$ 可全部推出：

| $n$ 的奇偶 | $n_1$ | $n_0$（叶子数）       | $n_2$              |
| ------- | ----- | ---------------- | ------------------ |
| $n$ 为奇数 | $0$   | $\dfrac{n+1}{2}$ | $\dfrac{n-1}{2}$   |
| $n$ 为偶数 | $1$   | $\dfrac{n}{2}$   | $\dfrac{n}{2} - 1$ |

即叶子结点数恒为 $n_0 = \lceil n/2 \rceil$。

**推导**：$n = n_0 + n_1 + n_2$ 且 $n_2 = n_0 - 1$，得 $n - n_1 = 2n_0 - 1$ 恒为奇数 $\Rightarrow$ $n$ 与 $n_1$ 奇偶性相反。

> 这是"给完全二叉树结点数 $n$，求叶子/度为 1/度为 2 结点数"类选择题的**通杀公式**，真题出现频率很高。

> 这些编号性质是**堆**（优先队列）实现的基础，408 中常与完全二叉树结合考查。

### 二叉排序树（BST）

**定义**：二叉排序树（Binary Sort Tree, BST）或为一棵空树，或满足以下性质的二叉树：
- 左子树非空时，左子树上所有结点的值**均小于**根结点的值
- 右子树非空时，右子树上所有结点的值**均大于**根结点的值
- 左、右子树本身也各是一棵二叉排序树

**核心性质**：

$$
\boxed{\text{BST 的中序遍历序列} \Rightarrow \text{递增有序序列}}
$$

BST 的中序遍历得到递增有序序列，因此它本质上是"**动态的折半查找表**"，也是将树用于排序（树排序）的基础。

**查找**：从根结点出发，将给定值与当前结点比较——相等则查找成功；小于则进入左子树，大于则进入右子树；走到空结点则查找失败。

| 情形 | BST 形态 | 比较次数 / ASL |
| ---- | -------- | ---- |
| 最好 | 形态接近完全二叉树 | $O(\log_2 n)$ |
| 最坏 | 按有序序列插入，退化为单支树 | $O(n)$，ASL 接近 $\dfrac{n+1}{2}$ |

**插入**：新结点**必作为叶子结点**插入——查找失败的位置即插入位置。

**删除**（三种情况）：
1. **叶子结点**：直接删除
2. **只有一棵子树**：用该子树顶替被删结点
3. **有两棵子树**：用**前驱**（左子树中最大结点）或**后继**（右子树中最小结点）替换被删结点，再删除该前驱/后继

> BST 的构造就是依次插入：**插入顺序不同，BST 形态不同**；而同一序列按相同顺序插入，结果唯一。为避免最坏情况退化，引入**平衡二叉树（AVL）**——任意结点左右子树高度差不超过 $1$。

### 平衡二叉树（AVL）

**定义**：平衡二叉树（Balanced Binary Tree，AVL 树）或为一棵空树，或满足以下性质的二叉树：
- 任意结点的左、右子树高度差的绝对值**不超过 $1$**
- 左、右子树也分别是一棵平衡二叉树

**平衡因子**：

$$
\boxed{BF = h_L - h_R \in \{-1,\ 0,\ 1\}}
$$

**失衡调整**：插入新结点后，从插入位置向上找到**最小不平衡子树**，按失衡类型做旋转：

| 失衡类型 | 插入位置 | 调整方法 |
| ------- | ------- | ------- |
| LL | 失衡结点**左孩子的左**子树 | **右单旋转** |
| RR | 失衡结点**右孩子的右**子树 | **左单旋转** |
| LR | 失衡结点**左孩子的右**子树 | 先左后右（**双旋转**） |
| RL | 失衡结点**右孩子的左**子树 | 先右后左（**双旋转**） |

> 记忆口诀：LL 看"左左"转右，RR 看"右右"转左，LR/RL 名字里先写的方向先转（"先左后右"即是 LR）。

**最少结点数**：高度为 $h$ 的 AVL 树最少结点数满足：

$$
\boxed{n_h = n_{h-1} + n_{h-2} + 1 \quad (n_0 = 0,\ n_1 = 1)}
$$

与斐波那契数列同构。

**复杂度**：含 $n$ 个结点的 AVL 树高度为 $O(\log_2 n)$（最坏约 $1.44\log_2(n+2)$），查找、插入、删除的平均和最坏时间复杂度均为 $O(\log_2 n)$——以插入/删除时的旋转开销换取了稳定的查找效率。

> 408 常考：给定插入序列判断失衡类型与所需旋转；或给出"平衡因子全为 $-1/0/1$"的二叉树判定其是否为 AVL。AVL 是**严格的平衡**，而红黑树的平衡要求更宽松（后续章节对比）。

### 总结表

| 性质 | 公式 |
|------|------|
| 二叉树第 $i$ 层最多结点 | $2^{i-1}$ |
| 高度 $h$ 的二叉树最多结点 | $2^h - 1$ |
| 叶子与度为 2 结点关系 | $n_0 = n_2 + 1$ |
| 完全二叉树高度 | $\lceil \log_2(n+1) \rceil = \lfloor \log_2 n \rfloor + 1$ |
| 结点 $i$ 的双亲 | $\lfloor i/2 \rfloor$ |
| 结点 $i$ 的左孩子 | $2i$ |
| 结点 $i$ 的右孩子 | $2i+1$ |
| 完全二叉树由 $n$ 推 $n_0, n_1, n_2$ | $n$ 奇数时 $n_1 = 0$，偶数时 $n_1 = 1$；$n_0 = \lceil n/2 \rceil$ |
| BST 中序遍历 | 递增有序序列 |
| BST 查找 | 最好 $O(\log_2 n)$，最坏 $O(n)$ |
| AVL 平衡因子 | $BF = h_L - h_R \in \{-1, 0, 1\}$ |
| AVL 高度 | $O(\log_2 n)$ |



### 408 常考点

| 考点 | 说明 |
|------|------|
| 二叉树叶子与度 2 结点关系 | $n_0 = n_2 + 1$ |
| 完全二叉树编号性质 | 双亲、左孩子、右孩子 |
| 完全二叉树高度 | $\lceil \log_2(n+1) \rceil$ 或 $\lfloor \log_2 n \rfloor + 1$ |
| 完全二叉树由 $n$ 求 $n_0, n_1, n_2$ | $n_1$ 至多 $1$（$n$ 奇偶定 $n_1$），$n_0 = \lceil n/2 \rceil$ |
| BST 中序序列 | 递增有序，可由此判断 BST 合法性 |
| BST 删除 | 两棵子树时用前驱/后继替换 |
| AVL 四种旋转 | LL 右旋 / RR 左旋 / LR、RL 双旋 |
| AVL 判定 | 平衡因子全为 $-1, 0, 1$ |
