> 题目：设一棵二叉树的结点结构为 `(LLINK, INFO, RLINK)`，`ROOT` 为指向该二叉树根结点的指针，`p` 和 `q` 分别为指向该二叉树中任意两个结点的指针，试编写算法 `ANCESTOR(ROOT, p, q, r)`，找到 `p` 和 `q` 的最近公共祖先结点 `r`。

### 一、结点定义

```c
typedef struct BiTNode {
    int INFO;
    struct BiTNode *LLINK, *RLINK;
} BiTNode, *BiTree;
```

### 二、算法思想

采用**递归后序遍历**的思想。对于当前结点 `ROOT`：

1. 若 `ROOT` 为空，返回 `false`。
2. 若 `ROOT` 就是 `p` 或 `q`，则 `r` 暂时指向 `ROOT`，并返回 `true`（表示在该子树中找到了 `p` 或 `q` 中的一个）。
3. 递归在左子树中查找，再递归在右子树中查找。
4. 若左右子树都返回 `true`，说明 `p` 和 `q` 分别位于当前结点的两侧，当前结点即为**最近公共祖先**，令 `r = ROOT`，返回 `true`。
5. 否则，返回左右子树查找结果的逻辑或（只要有一侧找到，就向上传递 `true`）。

> 核心：利用后序遍历“先处理左右子树，再处理根”的特性，自底向上寻找第一个同时包含 `p` 和 `q` 的结点。

### 三、代码实现（C++）

```cpp
bool ANCESTOR(BiTree ROOT, BiTNode *p, BiTNode *q, BiTNode *&r) {
    if (ROOT == NULL) return false;          // 空树
    if (ROOT == p || ROOT == q) {            // 当前结点就是 p 或 q
        r = ROOT;
        return true;
    }
    
    bool left = ANCESTOR(ROOT->LLINK, p, q, r);   // 在左子树中找
    bool right = ANCESTOR(ROOT->RLINK, p, q, r);  // 在右子树中找
    
    if (left && right) {                     // 左右子树各找到一个
        r = ROOT;                            // 当前结点即为最近公共祖先
        return true;
    }
    return left || right;                    // 否则向上传递是否找到
}
```

**调用方式**：

```cpp
BiTNode *r = NULL;
ANCESTOR(ROOT, p, q, r);
// 此时 r 指向最近公共祖先结点
```

### 四、时间复杂度与空间复杂度

| 指标 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| 时间复杂度 | $O(n)$ | 每个结点最多访问一次 |
| 空间复杂度 | $O(h)$ | 递归栈深度，$h$ 为树高，最坏 $O(n)$，平均 $O(\log n)$ |

### 五、易错点

| 易错点 | 正确理解 |
| :--- | :--- |
| 误认为需要保存路径 | 递归后序遍历可以自底向上直接找到 LCA，无需显式保存路径 |
| 忘记处理 `p` 或 `q` 本身是祖先的情况 | 若 `ROOT == p` 或 `ROOT == q`，直接令 `r = ROOT` 并返回 `true`，上层若再找到另一个，会自动更新为更高层的 LCA，逻辑正确 |
| 在左右子树均返回 `true` 时未更新 `r` | 此时 `ROOT` 才是 LCA，必须令 `r = ROOT` |
| 参数 `r` 未使用引用传递 | 在 C++ 中需用 `BiTNode *&r`，否则修改无法传出；在 C 中可用 `BiTNode **r` |

### 六、相关真题与预测

- **2010年408真题**：类似思想求最近公共祖先（但题目表述略有不同）。
- **预测题**：若要求用非递归方法（如保存路径到栈中），也可实现，但递归法更简洁，是考研首选。

### 七、拓展

- 若二叉树是**二叉排序树**，可利用结点值大小关系快速定位 LCA。
- 若结点结构中含有**双亲指针**，可转化为求两个链表（到根的路径）的公共结点。
