## 二叉树的线索化

> 线索化在中序/先序/后序**遍历过程中**完成：用 `pre` 指针记录上一个访问的结点，将空指针改为线索。

### 中序线索化（最常考）

**核心思路**：中序遍历过程中，用 `pre` 指针记录上一个访问的结点，将当前结点的空左指针指向 `pre`，将 `pre` 的空右指针指向当前结点。

```cpp
ThreadNode *pre = NULL;   // 全局变量，记录前驱

void InThread(ThreadTree &p) {
    if (p != NULL) {
        InThread(p->lchild);        // 递归左子树
        
        // 处理当前结点的前驱
        if (p->lchild == NULL) {
            p->lchild = pre;        // 左指针指向前驱
            p->ltag = 1;
        }
        
        // 处理前驱结点的后继
        if (pre != NULL && pre->rchild == NULL) {
            pre->rchild = p;        // 前驱的右指针指向当前结点
            pre->rtag = 1;
        }
        
        pre = p;                    // 更新 pre
        InThread(p->rchild);        // 递归右子树
    }
}

void CreateInThread(ThreadTree &T) {
    pre = NULL;
    if (T != NULL) {
        InThread(T);
        if (pre->rchild == NULL) {  // 处理最后一个结点
            pre->rtag = 1;
        }
    }
}
```

### 先序线索化

**注意**：先序线索化时，若先处理左孩子再处理右孩子，可能导致死循环（因为左指针可能已被改为前驱线索）。需要加 `ltag == 0` 判断。

```cpp
void PreThread(ThreadTree &p) {
    if (p != NULL) {
        // 处理前驱
        if (p->lchild == NULL) {
            p->lchild = pre;
            p->ltag = 1;
        }
        if (pre != NULL && pre->rchild == NULL) {
            pre->rchild = p;
            pre->rtag = 1;
        }
        pre = p;
        
        if (p->ltag == 0) PreThread(p->lchild);  // 只有左孩子才递归
        PreThread(p->rchild);
    }
}
```

### 后序线索化

```cpp
void PostThread(ThreadTree &p) {
    if (p != NULL) {
        PostThread(p->lchild);
        PostThread(p->rchild);
        
        if (p->lchild == NULL) {
            p->lchild = pre;
            p->ltag = 1;
        }
        if (pre != NULL && pre->rchild == NULL) {
            pre->rchild = p;
            pre->rtag = 1;
        }
        pre = p;
    }
}
```

> [!warning] 易错点
> - 先序线索化必须判断 `ltag == 0` 再递归左子树，否则可能死循环
> - 中序和后序不需要此判断（因为递归顺序自然避开了线索指针）
> - 线索化后，最后一个结点的右指针需要单独处理

### 408 常考点

| 考点 | 说明 |
|------|------|
| 中序线索化代码 | 全局 `pre` 指针，处理前驱后继 |
| 先序线索化死循环 | 必须判断 `ltag == 0` 再递归左子树 |
| 尾结点处理 | 最后一个结点的右指针单独处理 |

### 易错与易混点

| 易错判断 | 正确理解 |
|----------|----------|
| 中序线索化需要判断 `ltag` | ❌ 不需要；先序线索化才需要 |
