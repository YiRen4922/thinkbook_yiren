## 二叉树的线索化（修正版 · 完全对照王道408）

> 抱歉，我之前的笔记确实写反了。**王道408的标准写法是：第一个参数 `p` 传值，第二个参数 `pre` 传引用，且 `pre` 是 `CreateInThread` 内部的局部变量，不是全局变量。**

### 线索二叉树结点定义

```cpp
typedef struct ThreadNode {
    ElemType data;
    struct ThreadNode *lchild, *rchild;
    int ltag, rtag;
} ThreadNode, *ThreadTree;
```


### 中序线索化（王道标准 · 与截图完全一致）

```cpp
// 中序线索化
void InThread(ThreadTree p, ThreadTree &pre) {
    if (p != NULL) {
        InThread(p->lchild, pre);               // 递归，线索化左子树
        
        if (p->lchild == NULL) {                // 左子树为空，建立前驱线索
            p->lchild = pre;
            p->ltag = 1;
        }
        if (pre != NULL && pre->rchild == NULL) {
            pre->rchild = p;                    // 建立前驱结点的后继线索
            pre->rtag = 1;
        }
        
        pre = p;
        InThread(p->rchild, pre);               // 递归，线索化右子树
    }
}

// 中序线索化二叉树 T
void CreateInThread(ThreadTree T) {
    ThreadTree pre = NULL;                      // 局部变量 pre
    if (T != NULL) {
        InThread(T, pre);
        pre->rchild = NULL;                     // 处理遍历的最后一个结点
        pre->rtag = 1;
    }
}
```

> [!important] 截图里两个关键思考题（考研高频）
>
> **① 为什么 `pre` 参数是引用类型？**
> 因为 `pre` 在递归过程中需要**逐层被修改**。如果传值，每层递归只是修改自己的副本，无法把"上一个访问的结点"传递回来。用引用才能让所有递归层共享同一个 `pre`。
>
> **② 处理最后一个结点时，为什么没有判断 `rchild` 是否为 NULL？**
> 因为**中序遍历的最后一个结点，其右孩子指针必然为空**（否则中序还会继续访问它右子树）。所以可以放心直接 `pre->rchild = NULL; pre->rtag = 1;`。


### 先序线索化（王道标准）

```cpp
// 先序线索化
void PreThread(ThreadTree p, ThreadTree &pre) {
    if (p != NULL) {
        if (p->lchild == NULL) {                // 左子树为空，建立前驱线索
            p->lchild = pre;
            p->ltag = 1;
        }
        if (pre != NULL && pre->rchild == NULL) {
            pre->rchild = p;                    // 建立前驱结点的后继线索
            pre->rtag = 1;
        }
        pre = p;
        
        if (p->ltag == 0) {                     // 左指针不是线索才能递归
            PreThread(p->lchild, pre);
        }
        if (p->rtag == 0) {                     // 右指针不是线索才能递归
            PreThread(p->rchild, pre);
        }
    }
}

// 先序线索化二叉树 T
void CreatePreThread(ThreadTree T) {
    ThreadTree pre = NULL;
    if (T != NULL) {
        PreThread(T, pre);
        if (pre->rchild == NULL) {              // 处理遍历的最后一个结点
            pre->rtag = 1;
        }
    }
}
```

> [!warning] 先序必须判断标志位
> 先序中**先处理当前结点，再递归**。若当前结点的左指针被改成了前驱线索，不判断 `ltag` 就递归左子树，会沿线索走到前驱结点，**死循环**。


### 后序线索化（王道标准）

```cpp
// 后序线索化
void PostThread(ThreadTree p, ThreadTree &pre) {
    if (p != NULL) {
        PostThread(p->lchild, pre);             // 递归，线索化左子树
        PostThread(p->rchild, pre);             // 递归，线索化右子树
        
        if (p->lchild == NULL) {                // 左子树为空，建立前驱线索
            p->lchild = pre;
            p->ltag = 1;
        }
        if (pre != NULL && pre->rchild == NULL) {
            pre->rchild = p;                    // 建立前驱结点的后继线索
            pre->rtag = 1;
        }
        pre = p;
    }
}

// 后序线索化二叉树 T
void CreatePostThread(ThreadTree T) {
    ThreadTree pre = NULL;
    if (T != NULL) {
        PostThread(T, pre);
        if (pre->rchild == NULL) {              // 处理遍历的最后一个结点
            pre->rtag = 1;
        }
    }
}
```


### 三版代码对比速查（修正后）

| 版本 | 参数形式 | 是否判断标志位 | 尾结点处理 |
|------|:---:|:---:|:---:|
| **中序线索化** | `(ThreadTree p, ThreadTree &pre)` | ❌ 不需要 | `pre->rchild = NULL; pre->rtag = 1;` |
| **先序线索化** | `(ThreadTree p, ThreadTree &pre)` | ✅ 递归前判断 `ltag`/`rtag` | `pre->rtag = 1` |
| **后序线索化** | `(ThreadTree p, ThreadTree &pre)` | ❌ 不需要 | `pre->rtag = 1` |

> **统一规律**：三种线索化的函数签名完全一致，都是 `(ThreadTree p, ThreadTree &pre)`，`pre` 在 `CreateXXXThread` 中初始化为 `NULL` 局部变量。


### 408 常考点

| 考点 | 说明 |
|------|------|
| 中序线索化代码 | 王道标准：`pre` 为引用参数 |
| 先序线索化死循环 | 递归左/右子树前必须判断 `ltag == 0` 和 `rtag == 0` |
| 后序线索化 | 不需要判断标志位 |
| `pre` 传引用原因 | 跨递归层共享"上一个访问结点" |
| 尾结点处理 | 遍历结束后 `pre->rtag = 1` |


### 易错与易混点

| 易错判断 | 正确理解 |
|----------|----------|
| 王道用全局变量 `pre` | ❌ 错误。王道用**局部变量 + 引用参数** |
| 中序线索化需要判断 `ltag` | ❌ 不需要；先序才需要 |
| 先序线索化只需判断 `ltag` | ❌ 递归右子树前也要判断 `rtag == 0` |
| 后序线索化需要判断标志位 | ❌ 不需要 |
| 处理尾结点时判断 `rchild` | ❌ 中序尾结点的右孩子必为空，无需判断 |
