## 在线索二叉树中找前驱后继

> 线索化的目的是快速找前驱后继：标志位为 1 直接取，为 0 则按"子树最左/最右"规则查找。

### 中序线索二叉树找后继

**规则**：
- 若 `p->rtag == 1`，则 `p->rchild` 直接指向后继
- 若 `p->rtag == 0`，则后继为**右子树中最左下的结点**

```cpp
ThreadNode *InNext(ThreadNode *p) {
    if (p->rtag == 1) return p->rchild;   // 直接指向后继
    else {
        ThreadNode *q = p->rchild;
        while (q->ltag == 0) q = q->lchild;  // 右子树最左下
        return q;
    }
}
```

### 中序线索二叉树找前驱

**规则**：
- 若 `p->ltag == 1`，则 `p->lchild` 直接指向前驱
- 若 `p->ltag == 0`，则前驱为**左子树中最右下的结点**

```cpp
ThreadNode *InPrior(ThreadNode *p) {
    if (p->ltag == 1) return p->lchild;
    else {
        ThreadNode *q = p->lchild;
        while (q->rtag == 0) q = q->rchild;  // 左子树最右下
        return q;
    }
}
```

### 中序线索二叉树遍历（不用栈）

```cpp
void InOrderTraverse(ThreadTree T) {
    if (T == NULL) return;
    
    // 找到中序第一个结点（最左下）
    ThreadNode *p = T;
    while (p->ltag == 0) p = p->lchild;
    
    // 依次找后继
    while (p != NULL) {
        visit(p);
        p = InNext(p);
    }
}
```

> [!important] 线索二叉树的优势
> **不用递归、不用栈**即可完成遍历，空间复杂度从 $O(h)$ 降为 $O(1)$。

### 先序线索二叉树找后继

| 情况 | 后继 |
|------|------|
| `rtag == 1` | `rchild` 直接指向后继 |
| `rtag == 0` 且有左孩子 | 左孩子为后继 |
| `rtag == 0` 且无左孩子 | 右孩子为后继 |

### 后序线索二叉树找前驱

| 情况 | 前驱 |
|------|------|
| `ltag == 1` | `lchild` 直接指向前驱 |
| `ltag == 0` 且有右孩子 | 右孩子为前驱 |
| `ltag == 0` 且无右孩子 | 左孩子为前驱 |

### 408 常考点

| 考点 | 说明 |
|------|------|
| 找中序后继 | 右标志为 1 直接取；为 0 找右子树最左下 |
| 找中序前驱 | 左标志为 1 直接取；为 0 找左子树最右下 |
| 线索二叉树遍历 | 不用栈，空间 $O(1)$ |

### 易错与易混点

| 易错判断 | 正确理解 |
|----------|----------|
| 线索二叉树遍历必须用栈 | ❌ 不用栈，利用线索直接找后继 |
| 后序线索二叉树找前驱需要双亲指针 | ✅ 正确，这是后序线索化的特殊之处 |
