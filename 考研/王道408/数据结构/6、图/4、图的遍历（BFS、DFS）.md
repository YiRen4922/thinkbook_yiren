## 图的遍历 · 考研408核心笔记

> 图的遍历是从某一顶点出发，按照某种搜索方式访问图中所有顶点，且每个顶点仅访问一次。遍历是图算法的基础，BFS 和 DFS 是最核心的两种遍历方式，广泛应用于连通性判断、最短路径、生成树、拓扑排序等问题。代码严格遵循王道408教材写法。
>

### 一、广度优先遍历（BFS）

#### 1. 基本思想

从起始顶点 $v$ 出发：
1. 访问 $v$；
2. 依次访问 $v$ 的所有邻接点 $w_1, w_2, \dots$；
3. 再依次访问 $w_1, w_2, \dots$ 的所有未被访问的邻接点；
4. 以此类推，直到所有顶点都被访问。

> 本质是**按层次由近及远**访问，类似于树的层次遍历，需要借助**队列**。

![图1：BFS 遍历过程示意图]()

#### 2. 代码实现（邻接表版）

```c
bool visited[MaxVertexNum];    // 访问标记数组

void BFS(ALGraph G, int v) {
    visit(v);                  // 访问初始顶点 v
    visited[v] = true;         // 标记已访问
    Queue Q;
    InitQueue(Q);
    EnQueue(Q, v);             // 顶点 v 入队
    
    while (!QueueEmpty(Q)) {
        int u;
        DeQueue(Q, u);         // 队头顶点出队
        // 遍历 u 的所有邻接点
        for (int w = FirstNeighbor(G, u); w >= 0; w = NextNeighbor(G, u, w)) {
            if (!visited[w]) {
                visit(w);      // 访问顶点 w
                visited[w] = true;
                EnQueue(Q, w); // 顶点 w 入队
            }
        }
    }
}
```

#### 3. 遍历非连通图

一次 BFS 只能遍历一个连通分量。要遍历整个非连通图，需对所有顶点依次检查：

```c
void BFSTraverse(ALGraph G) {
    for (int i = 0; i < G.vexnum; i++) {
        visited[i] = false;    // 初始化访问标记
    }
    InitQueue(Q);              // 全局或传入队列
    for (int i = 0; i < G.vexnum; i++) {
        if (!visited[i]) {
            BFS(G, i);         // 对每个未访问的连通分量进行 BFS
        }
    }
}
```

![图2：非连通图的 BFS 遍历示意图]()

#### 4. 复杂度分析

| 存储结构 | 时间复杂度    | 空间复杂度                   |
| :--- | :------- | :---------------------- |
| 邻接矩阵 | $O(n^2)$ | $O(n)$（队列 + visited 数组） |
| 邻接表  | $O(n+e)$ | $O(n)$                  |

#### 5. BFS 应用

- 求**无权图单源最短路径**（边数最少）
- 判断图的连通性
- 求连通分量个数
- 求 BFS 生成树（或生成森林）

**BFS 求单源最短路径**：

```c
void BFS_MIN_Distance(ALGraph G, int u) {
    int d[MaxVertexNum];       // 记录从 u 到各顶点的最短距离
    for (int i = 0; i < G.vexnum; i++) {
        d[i] = INFINITY;       // 初始化为无穷大
        visited[i] = false;
    }
    d[u] = 0;
    visited[u] = true;
    Queue Q;
    InitQueue(Q);
    EnQueue(Q, u);
    
    while (!QueueEmpty(Q)) {
        int x;
        DeQueue(Q, x);
        for (int w = FirstNeighbor(G, x); w >= 0; w = NextNeighbor(G, x, w)) {
            if (!visited[w]) {
                d[w] = d[x] + 1;   // 距离加 1
                visited[w] = true;
                EnQueue(Q, w);
            }
        }
    }
}
```

### 二、深度优先遍历（DFS）

#### 1. 基本思想

从起始顶点 $v$ 出发：
1. 访问 $v$；
2. 从 $v$ 的未访问邻接点中选择一个 $w$，继续 DFS；
3. 当 $w$ 的所有邻接点都被访问过后，回溯到 $v$；
4. 重复直到所有顶点被访问。

> 本质是**一条路走到黑，再回溯**，类似于树的先序遍历，可借助 **栈（递归或显式栈）** 实现。

![图4：DFS 遍历过程示意图]()

#### 2. 代码实现（邻接表版，递归）

```c
bool visited[MaxVertexNum];

void DFS(ALGraph G, int v) {
    visit(v);                  // 访问顶点 v
    visited[v] = true;         // 标记已访问
    for (int w = FirstNeighbor(G, v); w >= 0; w = NextNeighbor(G, v, w)) {
        if (!visited[w]) {
            DFS(G, w);         // 递归访问
        }
    }
}
```

#### 3. 遍历非连通图

```c
void DFSTraverse(ALGraph G) {
    for (int i = 0; i < G.vexnum; i++) {
        visited[i] = false;
    }
    for (int i = 0; i < G.vexnum; i++) {
        if (!visited[i]) {
            DFS(G, i);         // 对每个未访问的连通分量进行 DFS
        }
    }
}
```

![图5：非连通图的 DFS 遍历示意图]()

#### 4. 复杂度分析

| 存储结构 | 时间复杂度 | 空间复杂度 |
| :--- | :--- | :--- |
| 邻接矩阵 | $O(n^2)$ | $O(n)$（递归栈） |
| 邻接表 | $O(n+e)$ | $O(n)$ |

#### 5. DFS 应用

- 判断图的连通性
- 求连通分量个数
- 求 DFS 生成树（或生成森林）
- 判断图中是否有环
- 拓扑排序（逆后序）

### 三、BFS 与 DFS 对比

| 对比项 | BFS | DFS |
| :--- | :--- | :--- |
| 辅助结构 | 队列 | 栈（递归或显式） |
| 搜索方式 | 按层次由近及远 | 一条路走到黑 |
| 典型类比 | 树的层次遍历 | 树的先序遍历 |
| 时间复杂度（邻接表） | $O(n+e)$ | $O(n+e)$ |
| 时间复杂度（邻接矩阵） | $O(n^2)$ | $O(n^2)$ |
| 空间复杂度 | $O(n)$ | $O(n)$ |
| 应用 | 最短路径（无权图）、层次分析 | 连通性、环检测、拓扑排序 |

### 四、遍历与生成树

- **BFS 生成树**：BFS 遍历过程中，每个顶点首次被访问时的边构成的树。
- **DFS 生成树**：DFS 遍历过程中，每个顶点首次被访问时的边构成的树。
- **非连通图**：得到生成森林（多个连通分量各对应一棵生成树）。
- **连通图**：遍历一次即可，得到一棵生成树。

> 遍历序列与生成树的关系：**给定图的邻接矩阵或邻接表，遍历序列唯一确定**；但若改变存储结构或起始顶点，遍历序列可能不同。

### 五、考点与易错点

| 考点 | 说明 |
| :--- | :--- |
| BFS 用队列 | 先进先出，按层次访问 |
| DFS 用栈 | 后进先出，递归实现 |
| 邻接矩阵遍历 | 时间复杂度 $O(n^2)$ |
| 邻接表遍历 | 时间复杂度 $O(n+e)$ |
| BFS 求最短路径 | 仅适用于**无权图**（或边权相同） |
| 遍历序列不唯一 | 邻接点访问顺序不同 → 序列不同 |
| 连通分量个数 | 遍历次数 = 连通分量个数 |
| 非连通图遍历 | 需检查所有顶点是否被访问 |

**BFS 序列**：按层次访问。
**DFS 序列**：按邻接点顺序递归访问。

> 具体序列取决于图的存储结构（邻接矩阵 vs 邻接表）以及邻接点的排列顺序。
