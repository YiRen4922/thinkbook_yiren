## 拓扑排序 · 考研408核心笔记

> 拓扑排序是针对有向无环图（DAG）的一种线性排序，使图中所有顶点排成一个序列，且对任意有向边 $\langle u,v \rangle$，$u$ 在序列中都出现在 $v$ 之前。它是判断有向图是否存在环、安排任务执行顺序的核心算法。代码严格遵循王道408教材写法。

### 一、AOV 网

**AOV 网**（Activity On Vertex Network）：
- 用**顶点**表示活动，用**有向边**表示活动之间的优先关系。
- AOV 网中不能存在环，否则活动间会出现循环依赖，无法确定执行顺序。
- 拓扑排序正是判断 AOV 网是否存在环的方法。

![图1：一个AOV网示例（活动依赖关系）]()

### 二、拓扑排序的定义

**拓扑排序**：对有向无环图 $G$，将其所有顶点排成一个线性序列，使得对图中任意一条有向边 $\langle u,v \rangle$，$u$ 在序列中都排在 $v$ 之前。

- 拓扑排序序列**不一定唯一**。
- 若图中存在环，则不存在拓扑排序序列。

### 三、拓扑排序算法（Kahn 算法）

#### 1. 基本思想

1. 从图中选择一个**入度为 0** 的顶点并输出；
2. 删除该顶点及其所有出边；
3. 重复步骤 1、2，直到所有顶点均已输出；
4. 若图中还有顶点未输出，但已找不到入度为 0 的顶点，说明图中存在环。

> 本质是不断删除“没有前驱”的顶点。

#### 2. 王道代码（邻接表版）

```c
#define MaxVertexNum 100

typedef struct ArcNode {
    int adjvex;
    struct ArcNode *next;
} ArcNode;

typedef struct VNode {
    VertexType data;
    ArcNode *first;
} VNode, AdjList[MaxVertexNum];

typedef struct {
    AdjList vertices;
    int vexnum, arcnum;
} ALGraph;

// 拓扑排序
bool TopologicalSort(ALGraph G) {
    int indegree[MaxVertexNum];     // 入度数组
    int print[MaxVertexNum];        // 拓扑序列
    int cnt = 0;                    // 已输出顶点数
    Stack S;                        // 用栈保存入度为 0 的顶点
    InitStack(S);
    
    // 1. 初始化入度数组
    for (int i = 0; i < G.vexnum; i++) {
        indegree[i] = 0;
    }
    for (int i = 0; i < G.vexnum; i++) {
        ArcNode *p = G.vertices[i].first;
        while (p != NULL) {
            indegree[p->adjvex]++;
            p = p->next;
        }
    }
    
    // 2. 将所有入度为 0 的顶点入栈
    for (int i = 0; i < G.vexnum; i++) {
        if (indegree[i] == 0) {
            Push(S, i);
        }
    }
    
    // 3. 拓扑排序
    while (!StackEmpty(S)) {
        int v;
        Pop(S, v);                  // 出栈
        print[cnt++] = v;           // 输出顶点 v
        
        // 遍历 v 的所有邻接点，入度减 1
        for (ArcNode *p = G.vertices[v].first; p != NULL; p = p->next) {
            int w = p->adjvex;
            indegree[w]--;
            if (indegree[w] == 0) {
                Push(S, w);
            }
        }
    }
    
    // 4. 判断是否有环
    if (cnt < G.vexnum) {
        return false;               // 有环，拓扑排序失败
    }
    return true;
}
```

> 王道教材中常用**栈**保存入度为 0 的顶点；也可用**队列**，得到另一种拓扑序列。

#### 3. 复杂度

| 存储结构 | 时间复杂度 | 空间复杂度 |
| :--- | :--- | :--- |
| 邻接表 | $O(n+e)$ | $O(n)$ |
| 邻接矩阵 | $O(n^2)$ | $O(n)$ |

### 四、逆拓扑排序

**逆拓扑排序**：类似拓扑排序，但每次选择**出度为 0** 的顶点输出，并删除其所有入边。

- 也可用 DFS 实现：DFS 退栈时输出顶点，得到逆拓扑序列。
- 逆拓扑排序常用于关键路径算法中求事件的最晚发生时间。

### 五、用 DFS 实现拓扑排序

DFS 遍历图，在顶点退栈时将其加入序列，最后逆序输出，即得拓扑排序序列。

```c
bool visited[MaxVertexNum];
int topo[MaxVertexNum];
int idx = 0;

void DFS_Topo(ALGraph G, int v) {
    visited[v] = true;
    for (ArcNode *p = G.vertices[v].first; p != NULL; p = p->next) {
        if (!visited[p->adjvex]) {
            DFS_Topo(G, p->adjvex);
        }
    }
    topo[idx++] = v;        // 退栈时记录
}

void TopologicalSort_DFS(ALGraph G) {
    for (int i = 0; i < G.vexnum; i++) visited[i] = false;
    idx = 0;
    for (int i = 0; i < G.vexnum; i++) {
        if (!visited[i]) DFS_Topo(G, i);
    }
    // 逆序输出 topo 即为拓扑序列
    for (int i = idx - 1; i >= 0; i--) {
        visit(topo[i]);
    }
}
```

### 六、考点与易错点

| 考点 | 说明 |
| :--- | :--- |
| AOV 网定义 | 顶点表示活动，边表示优先关系 |
| 拓扑序列不唯一 | 存在多个入度为 0 的顶点时，顺序可不同 |
| 判断有向图是否有环 | 拓扑排序成功则无环，失败则有环 |
| Kahn 算法复杂度 | 邻接表 $O(n+e)$，邻接矩阵 $O(n^2)$ |
| 用栈还是队列 | 王道用栈，也可用队列 |
| 逆拓扑排序 | 每次选出度为 0 的顶点 |
| DFS 实现 | 退栈时记录，最后逆序 |
| 入度数组初始化 | 遍历所有边，统计每个顶点的入度 |
