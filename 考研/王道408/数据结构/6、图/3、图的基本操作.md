## 图的基本操作 · 考研408核心笔记

> 图的基本操作是遍历、最短路径等算法的基础。408中主要考查各操作在**邻接矩阵**和**邻接表**两种存储结构下的实现与时间复杂度。代码严格遵循王道408教材写法。

### 一、基本操作清单

| 操作 | 含义 |
| :--- | :--- |
| `Adjacent(G, x, y)` | 判断图 $G$ 中是否存在边 $(x,y)$ 或 $\langle x,y \rangle$ |
| `Neighbors(G, x)` | 列出图 $G$ 中与顶点 $x$ 邻接的所有边 |
| `InsertVertex(G, x)` | 在图 $G$ 中插入顶点 $x$ |
| `DeleteVertex(G, x)` | 从图 $G$ 中删除顶点 $x$ |
| `AddEdge(G, x, y)` | 若边不存在，则添加边 $(x,y)$ 或 $\langle x,y \rangle$ |
| `RemoveEdge(G, x, y)` | 若边存在，则删除该边 |
| `FirstNeighbor(G, x)` | 求顶点 $x$ 的第一个邻接点 |
| `NextNeighbor(G, x, y)` | 求 $x$ 的下一个邻接点（$y$ 是已知的邻接点） |
| `Get_edge_value(G, x, y)` | 获取边 $(x,y)$ 的权值 |
| `Set_edge_value(G, x, y, v)` | 设置边 $(x,y)$ 的权值为 $v$ |

### 二、邻接矩阵实现

#### 2.1 数据类型定义

```c
#define MaxVertexNum 100
#define INFINITY 0x3f3f3f3f

typedef char VertexType;
typedef int EdgeType;

typedef struct {
    VertexType Vex[MaxVertexNum];
    EdgeType Edge[MaxVertexNum][MaxVertexNum];
    int vexnum, arcnum;
} MGraph;
```

#### 2.2 Adjacent(G, x, y)

```c
bool Adjacent(MGraph G, int x, int y) {
    return G.Edge[x][y] != 0 && G.Edge[x][y] != INFINITY;
}
```

**时间复杂度**：$O(1)$

#### 2.3 Neighbors(G, x)

```c
void Neighbors(MGraph G, int x) {
    for (int i = 0; i < G.vexnum; i++) {
        if (G.Edge[x][i] != 0 && G.Edge[x][i] != INFINITY) {
            visit(i);
        }
    }
}
```

**时间复杂度**：$O(n)$

#### 2.4 InsertVertex(G, x)

```c
bool InsertVertex(MGraph &G, VertexType x) {
    if (G.vexnum >= MaxVertexNum) return false;
    G.Vex[G.vexnum++] = x;
    return true;
}
```

**时间复杂度**：$O(1)$

#### 2.5 DeleteVertex(G, x)

删除顶点 $x$：在顶点表中删除 $x$，并更新邻接矩阵（行和列都要删除，或末尾行/列填补）。

```c
bool DeleteVertex(MGraph &G, int x) {
    if (x < 0 || x >= G.vexnum) return false;
    // 将最后一行一列覆盖到 x 行 x 列
    for (int i = 0; i < G.vexnum; i++) {
        G.Edge[x][i] = G.Edge[G.vexnum-1][i];
        G.Edge[i][x] = G.Edge[i][G.vexnum-1];
    }
    G.vexnum--;
    return true;
}
```

**时间复杂度**：$O(n)$

#### 2.6 AddEdge(G, x, y)

```c
bool AddEdge(MGraph &G, int x, int y) {
    if (x < 0 || y < 0 || x >= G.vexnum || y >= G.vexnum) return false;
    if (G.Edge[x][y] == 0) {
        G.Edge[x][y] = 1;
        G.Edge[y][x] = 1;   // 无向图
        G.arcnum++;
    }
    return true;
}
```

**时间复杂度**：$O(1)$

#### 2.7 RemoveEdge(G, x, y)

```c
bool RemoveEdge(MGraph &G, int x, int y) {
    if (G.Edge[x][y] != 0 && G.Edge[x][y] != INFINITY) {
        G.Edge[x][y] = 0;
        G.Edge[y][x] = 0;   // 无向图
        G.arcnum--;
    }
    return true;
}
```

**时间复杂度**：$O(1)$

#### 2.8 FirstNeighbor / NextNeighbor

```c
int FirstNeighbor(MGraph G, int x) {
    for (int i = 0; i < G.vexnum; i++) {
        if (G.Edge[x][i] != 0 && G.Edge[x][i] != INFINITY) return i;
    }
    return -1;
}

int NextNeighbor(MGraph G, int x, int y) {
    for (int i = y + 1; i < G.vexnum; i++) {
        if (G.Edge[x][i] != 0 && G.Edge[x][i] != INFINITY) return i;
    }
    return -1;
}
```

**时间复杂度**：$O(n)$

### 三、邻接表实现

#### 3.1 数据类型定义

```c
#define MaxVertexNum 100

typedef struct ArcNode {
    int adjvex;
    struct ArcNode *next;
} ArcNode;

typedef struct VNode {
    VertexType data;
    ArcNode *first;
} VNode, AdjList[MaxVertexNum];

typedef struct {
    AdjList vertices;
    int vexnum, arcnum;
} ALGraph;
```

#### 3.2 Adjacent(G, x, y)

```c
bool Adjacent(ALGraph G, int x, int y) {
    ArcNode *p = G.vertices[x].first;
    while (p != NULL) {
        if (p->adjvex == y) return true;
        p = p->next;
    }
    return false;
}
```

**时间复杂度**：$O(deg(x))$

#### 3.3 Neighbors(G, x)

```c
void Neighbors(ALGraph G, int x) {
    ArcNode *p = G.vertices[x].first;
    while (p != NULL) {
        visit(p->adjvex);
        p = p->next;
    }
}
```

**时间复杂度**：$O(deg(x))$

#### 3.4 InsertVertex(G, x)

```c
bool InsertVertex(ALGraph &G, VertexType x) {
    if (G.vexnum >= MaxVertexNum) return false;
    G.vertices[G.vexnum].data = x;
    G.vertices[G.vexnum].first = NULL;
    G.vexnum++;
    return true;
}
```

**时间复杂度**：$O(1)$

#### 3.5 DeleteVertex(G, x)

删除顶点 $x$：删除该顶点的边链表，同时遍历所有其他顶点的链表，删除指向 $x$ 的边结点。

```c
bool DeleteVertex(ALGraph &G, int x) {
    if (x < 0 || x >= G.vexnum) return false;
    
    // 1. 删除 x 的边链表
    ArcNode *p = G.vertices[x].first;
    while (p != NULL) {
        ArcNode *tmp = p;
        p = p->next;
        free(tmp);
    }
    G.vertices[x].first = NULL;
    
    // 2. 遍历其他顶点，删除指向 x 的边结点
    for (int i = 0; i < G.vexnum; i++) {
        if (i == x) continue;
        ArcNode *pre = NULL, *cur = G.vertices[i].first;
        while (cur != NULL) {
            if (cur->adjvex == x) {
                if (pre == NULL) {
                    G.vertices[i].first = cur->next;
                } else {
                    pre->next = cur->next;
                }
                free(cur);
                break;
            }
            pre = cur;
            cur = cur->next;
        }
    }
    G.vexnum--;
    return true;
}
```

**时间复杂度**：$O(n+e)$

#### 3.6 AddEdge(G, x, y)

```c
bool AddEdge(ALGraph &G, int x, int y) {
    // 头插法插入到 x 的链表
    ArcNode *p = (ArcNode*)malloc(sizeof(ArcNode));
    p->adjvex = y;
    p->next = G.vertices[x].first;
    G.vertices[x].first = p;
    
    // 无向图：还要插入到 y 的链表
    ArcNode *q = (ArcNode*)malloc(sizeof(ArcNode));
    q->adjvex = x;
    q->next = G.vertices[y].first;
    G.vertices[y].first = q;
    
    G.arcnum++;
    return true;
}
```

**时间复杂度**：$O(1)$

#### 3.7 RemoveEdge(G, x, y)

```c
bool RemoveEdge(ALGraph &G, int x, int y) {
    // 删除 x 链表中 y 的边结点
    ArcNode *pre = NULL, *cur = G.vertices[x].first;
    while (cur != NULL && cur->adjvex != y) {
        pre = cur;
        cur = cur->next;
    }
    if (cur == NULL) return false;
    if (pre == NULL) G.vertices[x].first = cur->next;
    else pre->next = cur->next;
    free(cur);
    
    // 无向图：还要删除 y 链表中 x 的边结点
    pre = NULL; cur = G.vertices[y].first;
    while (cur != NULL && cur->adjvex != x) {
        pre = cur;
        cur = cur->next;
    }
    if (cur != NULL) {
        if (pre == NULL) G.vertices[y].first = cur->next;
        else pre->next = cur->next;
        free(cur);
    }
    
    G.arcnum--;
    return true;
}
```

**时间复杂度**：$O(deg(x) + deg(y))$

#### 3.8 FirstNeighbor / NextNeighbor

```c
int FirstNeighbor(ALGraph G, int x) {
    if (G.vertices[x].first == NULL) return -1;
    return G.vertices[x].first->adjvex;
}

int NextNeighbor(ALGraph G, int x, int y) {
    ArcNode *p = G.vertices[x].first;
    while (p != NULL && p->adjvex != y) {
        p = p->next;
    }
    if (p != NULL && p->next != NULL) return p->next->adjvex;
    return -1;
}
```

**时间复杂度**：`FirstNeighbor` 为 $O(1)$，`NextNeighbor` 为 $O(deg(x))$

### 四、两种存储结构下操作复杂度对比

| 操作 | 邻接矩阵 | 邻接表 |
| :--- | :--- | :--- |
| `Adjacent(G, x, y)` | $O(1)$ | $O(deg(x))$ |
| `Neighbors(G, x)` | $O(n)$ | $O(deg(x))$ |
| `InsertVertex(G, x)` | $O(1)$ | $O(1)$ |
| `DeleteVertex(G, x)` | $O(n)$ | $O(n+e)$ |
| `AddEdge(G, x, y)` | $O(1)$ | $O(1)$ |
| `RemoveEdge(G, x, y)` | $O(1)$ | $O(deg(x)+deg(y))$ |
| `FirstNeighbor(G, x)` | $O(n)$ | $O(1)$ |
| `NextNeighbor(G, x, y)` | $O(n)$ | $O(deg(x))$ |
| `Get_edge_value` | $O(1)$ | $O(deg(x))$ |
| `Set_edge_value` | $O(1)$ | $O(deg(x))$ |

### 五、考点与易错点

| 考点 | 说明 |
| :--- | :--- |
| `Adjacent` 邻接矩阵 $O(1)$ | 直接查二维数组 |
| `DeleteVertex` 邻接矩阵 | 删除行和列，$O(n)$ |
| `DeleteVertex` 邻接表 | 遍历所有顶点删除指向 x 的边，$O(n+e)$ |
| 邻接表 `AddEdge` | 头插法，$O(1)$ |
| 邻接表 `RemoveEdge` | 需查链表，$O(deg(x)+deg(y))$ |
| 邻接表 `FirstNeighbor` | 直接取第一个边结点，$O(1)$ |
| 邻接矩阵 `FirstNeighbor` | 需遍历整行，$O(n)$ |

### 六、简单发散

- **数一**：邻接矩阵的操作与线性代数运算紧密相关，如矩阵乘法对应路径计数。
- **英语一**：`adjacent`、`neighbor`、`degree`、`insert`、`delete` 等词是科技阅读高频词。
- **408**：本章操作是后续 BFS/DFS、最短路径、拓扑排序等算法的基础。
