## 最短路径问题 · 考研408核心笔记

> 最短路径问题是图论中的核心问题，分为**单源最短路径**（一个源点到其他所有顶点）和**各顶点间最短路径**。根据图的类型和边权特点，分别有 BFS、Dijkstra、Floyd 三种经典算法。代码严格遵循王道408教材写法。

### 一、最短路径问题分类

| 问题类型     | 适用图       | 算法       | 时间复杂度    |
| :------- | :-------- | :------- | :------- |
| 单源最短路径   | 无权图       | BFS      | $O(n+e)$ |
| 单源最短路径   | 带权图（非负权）  | Dijkstra | $O(n^2)$ |
| 各顶点间最短路径 | 带权图（可含负权） | Floyd    | $O(n^3)$ |

![图1：最短路径问题分类示意图]()

### 二、BFS 求单源最短路径（无权图）

#### 1. 基本思想

在无权图中，BFS 按层次遍历，**首次访问某顶点时的路径长度即为最短路径**（边数最少）。

#### 2. 王道代码（邻接表版）

```c
#define MaxVertexNum 100
#define INFINITY 0x3f3f3f3f

bool visited[MaxVertexNum];
int d[MaxVertexNum];            // 最短距离
int path[MaxVertexNum];         // 最短路径上的前驱

void BFS_MIN_Distance(ALGraph G, int u) {
    // 初始化
    for (int i = 0; i < G.vexnum; i++) {
        d[i] = INFINITY;
        path[i] = -1;
        visited[i] = false;
    }
    
    d[u] = 0;
    visited[u] = true;
    Queue Q;
    InitQueue(Q);
    EnQueue(Q, u);
    
    while (!QueueEmpty(Q)) {
        int x;
        DeQueue(Q, x);
        for (int w = FirstNeighbor(G, x); w >= 0; w = NextNeighbor(G, x, w)) {
            if (!visited[w]) {
                d[w] = d[x] + 1;
                path[w] = x;
                visited[w] = true;
                EnQueue(Q, w);
            }
        }
    }
}
```

#### 3. 复杂度

| 存储结构 | 时间复杂度 | 空间复杂度 |
| :--- | :--- | :--- |
| 邻接表 | $O(n+e)$ | $O(n)$ |
| 邻接矩阵 | $O(n^2)$ | $O(n)$ |

### 三、Dijkstra 算法（带权图，非负权）

#### 1. 基本思想

贪心策略，逐步确定源点到各顶点的最短路径：

1. 初始化：源点 $v_0$ 的 `dist[v0]=0`，其余为 $\infty$；
2. 每次从未确定最短路径的顶点中选 `dist` 最小者，将其标记为已确定；
3. 用该顶点更新其邻接点的 `dist`；
4. 重复直到所有顶点确定。

#### 2. 王道代码（邻接矩阵版）

```c
#define MaxVertexNum 100
#define INFINITY 0x3f3f3f3f

int dist[MaxVertexNum];        // 最短距离
int path[MaxVertexNum];        // 最短路径上的前驱
bool final[MaxVertexNum];      // 是否已确定最短路径

void Dijkstra(MGraph G, int v0) {
    // 初始化
    for (int i = 0; i < G.vexnum; i++) {
        dist[i] = G.Edge[v0][i];
        final[i] = false;
        if (G.Edge[v0][i] < INFINITY) path[i] = v0;
        else path[i] = -1;
    }
    dist[v0] = 0;
    final[v0] = true;
    
    // 循环 n-1 次
    for (int i = 1; i < G.vexnum; i++) {
        int min = INFINITY, v = -1;
        
        // 找未确定顶点中 dist 最小者
        for (int j = 0; j < G.vexnum; j++) {
            if (!final[j] && dist[j] < min) {
                min = dist[j];
                v = j;
            }
        }
        
        if (v == -1) return;    // 图不连通
        final[v] = true;
        
        // 更新邻接点的 dist
        for (int j = 0; j < G.vexnum; j++) {
            if (!final[j] && dist[v] + G.Edge[v][j] < dist[j]) {
                dist[j] = dist[v] + G.Edge[v][j];
                path[j] = v;
            }
        }
    }
}
```

#### 3. 复杂度

| 指标 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| 时间复杂度 | $O(n^2)$ | 可用堆优化至 $O(e\log n)$ |
| 空间复杂度 | $O(n)$ | `dist`、`path`、`final` |
| 适用条件 | 非负权图 | 负权边会导致错误 |

### 四、Floyd 算法（各顶点间最短路径）

#### 1. 基本思想

动态规划，逐步允许更多中间顶点：

- 初始化：`A[i][j]` 为直接边的权值，无边为 $\infty$；
- 对每个中间顶点 $k$，若 `A[i][k] + A[k][j] < A[i][j]`，则更新；
- 经过 $n$ 轮迭代后，`A[i][j]` 即为 $i$ 到 $j$ 的最短路径长度。

#### 2. 王道代码（邻接矩阵版）

```c
#define MaxVertexNum 100
#define INFINITY 0x3f3f3f3f

int A[MaxVertexNum][MaxVertexNum];      // 最短路径长度
int path[MaxVertexNum][MaxVertexNum];   // 中间顶点

void Floyd(MGraph G) {
    // 初始化
    for (int i = 0; i < G.vexnum; i++) {
        for (int j = 0; j < G.vexnum; j++) {
            A[i][j] = G.Edge[i][j];
            if (i != j && A[i][j] < INFINITY) path[i][j] = i;
            else path[i][j] = -1;
        }
    }
    
    // 三重循环
    for (int k = 0; k < G.vexnum; k++) {
        for (int i = 0; i < G.vexnum; i++) {
            for (int j = 0; j < G.vexnum; j++) {
                if (A[i][k] + A[k][j] < A[i][j]) {
                    A[i][j] = A[i][k] + A[k][j];
                    path[i][j] = path[k][j];
                }
            }
        }
    }
}
```

#### 3. 复杂度

| 指标 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| 时间复杂度 | $O(n^3)$ | 三重循环 |
| 空间复杂度 | $O(n^2)$ | 两个二维数组 |
| 适用条件 | 可含负权边，但不可有负权回路 |

### 五、三种算法对比

| 对比项 | BFS | Dijkstra | Floyd |
| :--- | :--- | :--- | :--- |
| 问题类型 | 单源 | 单源 | 各顶点间 |
| 适用图 | 无权图 | 非负权图 | 可含负权 |
| 核心思想 | 层次遍历 | 贪心 | 动态规划 |
| 辅助结构 | 队列 | `dist`/`final` | 二维矩阵 |
| 时间复杂度 | $O(n+e)$ 或 $O(n^2)$ | $O(n^2)$ | $O(n^3)$ |
| 空间复杂度 | $O(n)$ | $O(n)$ | $O(n^2)$ |
| 能否处理负权 | 不适用 | 不能 | 能（无负权回路） |

### 六、考点与易错点

| 考点 | 说明 |
| :--- | :--- |
| BFS 仅适用于无权图 | 边权必须相同（通常为1） |
| Dijkstra 不能处理负权 | 负权边可能导致贪心失效 |
| Floyd 三重循环顺序 | 中间顶点 $k$ 必须放最外层 |
| Dijkstra 每轮选最小 | 选最小后标记 `final` |
| 最短路径不唯一 | 存在多条等长路径时可能不唯一 |
| 负权回路 | Floyd 无法处理含负权回路的图 |
| 堆优化 Dijkstra | 时间复杂度 $O(e\log n)$，适合稀疏图 |
| BFS 求最短路径 | 得到的是边数最少的路径 |

### 七、简单发散

- **数一**：最短路径问题与图论、动态规划、矩阵乘法有交叉；Floyd 本质是动态规划。
- **英语一**：`shortest path`、`Dijkstra`、`Floyd`、`greedy`、`dynamic programming` 等术语常见于科技文献。
- **408**：最短路径是图章节高频考点，常考手算 Dijkstra、Floyd 过程，以及复杂度对比。
