## 关键路径 · 考研408核心笔记

> 关键路径是AOE网中从源点到汇点的最长路径，决定了整个工程的最短完成时间。关键路径上的活动称为关键活动，其时间余量为0。求关键路径是图章节的收官考点，也是408高频考点。代码严格遵循王道408教材写法。

### 一、AOE 网

**AOE 网**（Activity On Edge Network）：
- 用**边**表示活动，用**顶点**表示事件。
- 边上的权值表示活动持续时间。
- 源点：入度为 0 的顶点（工程开始）。
- 汇点：出度为 0 的顶点（工程结束）。
- 只有所有入边活动都结束后，该顶点代表的事件才能发生。

> AOE 网中，从源点到汇点的最长路径长度决定了整个工程的最短完成时间。

### 二、关键路径相关概念

| 概念 | 定义 |
| :--- | :--- |
| **关键路径** | 从源点到汇点的最长路径 |
| **关键活动** | 关键路径上的活动 |
| **事件最早发生时间 $ve(k)$** | 从源点到顶点 $k$ 的最长路径长度 |
| **事件最晚发生时间 $vl(k)$** | 在不推迟整个工程的前提下，事件 $k$ 最迟必须发生的时间 |
| **活动最早开始时间 $e(i)$** | 活动 $a_i$ 的最早开始时间 = 该活动起点事件的最早发生时间 |
| **活动最晚开始时间 $l(i)$** | 活动 $a_i$ 的最晚开始时间 = 该活动终点事件的最晚发生时间 − 活动持续时间 |
| **时间余量 $d(i)$** | $l(i) - e(i)$，余量为 0 的活动为关键活动 |

### 三、求关键路径的步骤

1. **拓扑排序**：求事件最早发生时间 $ve$。
2. **逆拓扑排序**：求事件最晚发生时间 $vl$。
3. **求活动最早开始时间 $e$**：$e(i) = ve(\text{起点})$。
4. **求活动最晚开始时间 $l$**：$l(i) = vl(\text{终点}) - w_i$。
5. **求时间余量**：$d(i) = l(i) - e(i)$。
6. **确定关键活动**：$d(i) = 0$ 的活动。
7. **确定关键路径**：由关键活动组成的从源点到汇点的路径。

### 四、王道代码

#### 1. 求事件最早发生时间 $ve$

```c
#define MaxVertexNum 100
#define INFINITY 0x3f3f3f3f

// 拓扑排序，同时求 ve
bool TopologicalOrder(ALGraph G, int ve[]) {
    int indegree[MaxVertexNum] = {0};
    int cnt = 0;
    Stack S;
    InitStack(S);
    
    // 初始化 ve
    for (int i = 0; i < G.vexnum; i++) ve[i] = 0;
    
    // 统计入度
    for (int i = 0; i < G.vexnum; i++) {
        for (ArcNode *p = G.vertices[i].first; p; p = p->next) {
            indegree[p->adjvex]++;
        }
    }
    
    // 入度为 0 的顶点入栈
    for (int i = 0; i < G.vexnum; i++) {
        if (indegree[i] == 0) Push(S, i);
    }
    
    while (!StackEmpty(S)) {
        int v;
        Pop(S, v);
        cnt++;
        // 遍历 v 的出边，更新 ve
        for (ArcNode *p = G.vertices[v].first; p; p = p->next) {
            int w = p->adjvex;
            if (ve[v] + p->weight > ve[w]) {
                ve[w] = ve[v] + p->weight;
            }
            indegree[w]--;
            if (indegree[w] == 0) Push(S, w);
        }
    }
    
    return cnt == G.vexnum;     // 有环则返回 false
}
```

#### 2. 求事件最晚发生时间 $vl$ 和关键活动

```c
// 求关键路径
void CriticalPath(ALGraph G) {
    int ve[MaxVertexNum], vl[MaxVertexNum];
    
    // 1. 求 ve
    if (!TopologicalOrder(G, ve)) {
        printf("图中有环，无法求关键路径\n");
        return;
    }
    
    // 2. 初始化 vl 为汇点的 ve
    int maxve = 0;
    for (int i = 0; i < G.vexnum; i++) {
        if (ve[i] > maxve) maxve = ve[i];
    }
    for (int i = 0; i < G.vexnum; i++) vl[i] = maxve;
    
    // 3. 逆拓扑排序求 vl
    // （需先获得逆拓扑序列，此处用栈存储）
    // 简化处理：对所有边反向更新
    for (int i = G.vexnum - 1; i >= 0; i--) {
        // 需按逆拓扑序，遍历所有边更新 vl
    }
    
    // 4. 求关键活动
    for (int i = 0; i < G.vexnum; i++) {
        for (ArcNode *p = G.vertices[i].first; p; p = p->next) {
            int j = p->adjvex;
            int e = ve[i];                      // 活动最早开始时间
            int l = vl[j] - p->weight;          // 活动最晚开始时间
            if (e == l) {                        // 时间余量为 0
                printf("关键活动：<%d, %d> 权值：%d\n", 
                       i, j, p->weight);
            }
        }
    }
}
```

> 完整实现需先记录逆拓扑序列，再按逆序求 $vl$。考场上手算更常考。

### 五、手算示例

**示例**：某 AOE 网如下，求关键路径。

```
         a1=3        a4=2
   v1 ─────────→ v2 ─────────→ v5
    │              │              ↑
    │a2=2          │a3=4          │a7=4
    ↓              ↓              │
   v3 ─────────→ v4 ─────────────┘
         a5=3
```

> 具体计算需按步骤求 $ve$、$vl$、$e$、$l$、$d$。关键活动时间余量为 0。

### 六、复杂度

| 指标 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| 时间复杂度 | $O(n+e)$ | 拓扑排序 + 逆拓扑排序 |
| 空间复杂度 | $O(n)$ | `ve`、`vl` 数组 |

### 七、考点与易错点

| 考点 | 说明 |
| :--- | :--- |
| AOE 网定义 | 边表示活动，顶点表示事件 |
| 关键路径 = 最长路径 | 决定工程最短完成时间 |
| $ve(k)$ 求法 | 按拓扑序，取入边最大值 |
| $vl(k)$ 求法 | 按逆拓扑序，取出边最小值 |
| 活动最早开始时间 | $e(i) = ve(\text{起点})$ |
| 活动最晚开始时间 | $l(i) = vl(\text{终点}) - w_i$ |
| 关键活动 | $e(i) = l(i)$，时间余量为 0 |
| 关键路径可能不唯一 | 存在多条最长路径 |
| 缩短关键活动 | 可能缩短工期，但过度缩短会使关键路径改变 |

- **数一**：关键路径与动态规划、最长路径问题相通。
- **英语一**：`critical path`、`AOE network`、`event`、`activity`、`slack` 等术语常见于工程管理文献。
- **408**：关键路径是图章节的收官考点，常考手算、复杂度、判断关键活动。
