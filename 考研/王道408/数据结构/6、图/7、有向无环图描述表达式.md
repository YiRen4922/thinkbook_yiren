## 有向无环图描述表达式 · 考研408核心笔记

> 有向无环图（DAG）是描述算术表达式的一种高效结构。通过共享相同的子表达式，DAG 可以显著减少存储空间和计算量。本章是图章节的收尾考点，常以选择题形式出现。

### 一、有向无环图（DAG）的定义

**有向无环图**：不存在环的有向图，简称 DAG（Directed Acyclic Graph）。

- 常用于描述表达式、任务依赖、程序流程等。
- 是拓扑排序和关键路径的基础。

### 二、用 DAG 描述算术表达式

#### 1. 表达式树

一个算术表达式可以唯一表示为一棵**二叉树**（表达式树）：
- 叶子结点：操作数（变量或常数）
- 内部结点：运算符

例如，表达式 $((a+b)*(a+b))*(c-d)$ 的表达式树中，$(a+b)$ 会出现两次。

#### 2. DAG 的合并思想

将表达式树中**相同的子表达式合并**为一个顶点，得到有向无环图。

- 顶点：操作数或运算符
- 有向边：表示运算的依赖关系
- 相同子表达式只保留一份

### 三、构建步骤

1. 将算术表达式转换为**表达式树**。
2. 从底向上扫描，找出相同的子表达式。
3. 将相同子表达式合并为同一个顶点。
4. 最终得到有向无环图。

### 四、示例

表达式：$((a+b)*(a+b))*(c-d)$

- 表达式树中有两个 $(a+b)$ 子树。
- 合并后，DAG 中 $(a+b)$ 只出现一次。
- 顶点：$a, b, c, d, +, *, -$ 等。
- 边：表示运算顺序。

### 五、优点

| 优点 | 说明 |
| :--- | :--- |
| 减少存储空间 | 相同子表达式只存一份 |
| 提高计算效率 | 相同子表达式只计算一次 |
| 便于优化 | 可进行公共子表达式消除 |

### 六、考点与易错点

| 考点 | 说明 |
| :--- | :--- |
| DAG 的定义 | 有向且无环 |
| 表达式树转 DAG | 合并相同子表达式 |
| 顶点与边的含义 | 顶点为操作数或运算符，边为运算关系 |
| 与二叉树的区别 | 二叉树中相同子表达式重复，DAG 中共享 |
| 顶点数计算 | 合并后顶点数减少 |
| 边数计算 | 每个运算符对应若干条入边 |

> 易错点：DAG 中**不允许出现环**；合并的是**完全相同的子表达式**，包括结构和操作数。

### 七、简单发散

- **数一**：DAG 与偏序关系、拓扑排序、动态规划有交叉。
- **英语一**：`directed acyclic graph`、`DAG`、`expression`、`subexpression` 等术语常见于科技文献。
- **408**：DAG 是拓扑排序和关键路径的基础，也是公共子表达式消除的经典应用。
