## 最小生成树 · 考研408核心笔记

> 最小生成树（Minimum Spanning Tree, MST）是带权连通无向图中边权之和最小的生成树。Prim 算法和 Kruskal 算法是两种经典求法，分别适合稠密图和稀疏图。代码严格遵循王道408教材写法。

### 一、最小生成树的定义

**生成树**：连通图的极小连通子图，含 $n$ 个顶点、$n-1$ 条边。

**最小生成树**：带权连通无向图中，边权之和最小的生成树。

$$
\text{MST 权值} = \min \left\{ \sum_{e \in T} w(e) \right\}
$$

### 二、最小生成树的性质

- $n$ 个顶点，$n-1$ 条边。
- 权值唯一时，MST 唯一；否则 MST 可能不唯一，但最小权值和唯一。
- MST 中不存在环。
- 任意一个割（将顶点集分成两部分）中，权值最小的边一定属于某棵 MST（切割性质）。
- 任意一个环中，权值最大的边一定不属于任何 MST（环性质）。

### 三、Prim 算法

#### 1. 基本思想

从某一顶点出发，逐步扩展生成树：

1. 任取一个顶点加入生成树集合 $U$；
2. 在连接 $U$ 与 $V-U$ 的所有边中，选择权值最小的边，将其另一端点加入 $U$；
3. 重复步骤 2，直到 $U=V$。

> 本质是**贪心**，每次选择连接已选集合与未选集合的最小边。

#### 2. 王道代码（邻接矩阵版）

```c
#define MaxVertexNum 100
#define INFINITY 0x3f3f3f3f

typedef struct {
    VertexType adjvex;      // 最小边在 U 中的顶点
    int lowcost;            // 最小边权值
} CloseEdge[MaxVertexNum];

// 从顶点 u 出发构造最小生成树
void Prim(MGraph G, int u) {
    CloseEdge closedge;
    
    // 初始化：将 u 加入 U
    for (int i = 0; i < G.vexnum; i++) {
        closedge[i].adjvex = u;
        closedge[i].lowcost = G.Edge[u][i];
    }
    closedge[u].lowcost = 0;    // 0 表示已加入 U
    
    // 选择剩余 n-1 个顶点
    for (int i = 1; i < G.vexnum; i++) {
        int k = -1, min = INFINITY;
        
        // 找连接 U 与 V-U 的最小边
        for (int j = 0; j < G.vexnum; j++) {
            if (closedge[j].lowcost != 0 && closedge[j].lowcost < min) {
                min = closedge[j].lowcost;
                k = j;
            }
        }
        
        if (k == -1) return;    // 图不连通
        printf("(%c, %c) %d\n", 
               G.Vex[closedge[k].adjvex], G.Vex[k], min);
        closedge[k].lowcost = 0;    // 将 k 加入 U
        
        // 更新 closedge
        for (int j = 0; j < G.vexnum; j++) {
            if (G.Edge[k][j] < closedge[j].lowcost) {
                closedge[j].adjvex = k;
                closedge[j].lowcost = G.Edge[k][j];
            }
        }
    }
}
```

#### 3. 复杂度

| 指标 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| 时间复杂度 | $O(n^2)$ | 与边数无关 |
| 空间复杂度 | $O(n)$ | `closedge` 数组 |
| 适用图 | 稠密图 | 边数多时优势明显 |

### 四、Kruskal 算法

#### 1. 基本思想

按边权从小到大排序，依次选择边：

1. 将图中所有边按权值从小到大排序；
2. 依次取出每条边，若加入后不构成环，则加入生成树；
3. 重复直到选够 $n-1$ 条边。

> 本质是**并查集判环** + 贪心选边。

#### 2. 王道代码（边集数组 + 并查集）

```c
#define MaxVertexNum 100
#define MaxEdgeNum 1000

typedef struct {
    int u, v;       // 边的两个端点
    int w;          // 边权
} Edge;

// 并查集
int father[MaxVertexNum];

void InitUFSet(int n) {
    for (int i = 0; i < n; i++) father[i] = -1;
}

int Find(int x) {
    while (father[x] >= 0) x = father[x];
    return x;
}

bool Union(int u, int v) {
    int rootu = Find(u), rootv = Find(v);
    if (rootu == rootv) return false;
    father[rootu] += father[rootv];
    father[rootv] = rootu;
    return true;
}

// 按边权排序（升序）
int cmp(const void *a, const void *b) {
    return ((Edge*)a)->w - ((Edge*)b)->w;
}

void Kruskal(Edge edges[], int n, int e) {
    InitUFSet(n);
    qsort(edges, e, sizeof(Edge), cmp);
    
    int cnt = 0;        // 已选边数
    int sum = 0;        // 总权值
    
    for (int i = 0; i < e && cnt < n - 1; i++) {
        if (Union(edges[i].u, edges[i].v)) {
            printf("(%d, %d) %d\n", edges[i].u, edges[i].v, edges[i].w);
            sum += edges[i].w;
            cnt++;
        }
    }
    
    if (cnt < n - 1) printf("图不连通\n");
    else printf("MST 总权值: %d\n", sum);
}
```

#### 3. 复杂度

| 指标 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| 时间复杂度 | $O(e\log e)$ | 排序为主 |
| 空间复杂度 | $O(n+e)$ | 边集 + 并查集 |
| 适用图 | 稀疏图 | 边数少时优势明显 |

### 五、Prim 与 Kruskal 对比

| 对比项 | Prim | Kruskal |
| :--- | :--- | :--- |
| 核心思想 | 从顶点扩展 | 从边选择 |
| 辅助结构 | `closedge` 数组 | 并查集 |
| 时间复杂度 | $O(n^2)$ | $O(e\log e)$ |
| 适用图 | 稠密图 | 稀疏图 |
| 是否依赖起始顶点 | 是 | 否 |
| 是否易处理非连通图 | 需额外判断 | 最后判断边数 |

### 六、考点与易错点

| 考点 | 说明 |
| :--- | :--- |
| MST 边数 | $n-1$ |
| MST 权值唯一性 | 权值唯一时 MST 唯一 |
| Prim 复杂度 | $O(n^2)$，适合稠密图 |
| Kruskal 复杂度 | $O(e\log e)$，适合稀疏图 |
| Prim 起始顶点 | 任意顶点均可，结果权值和相同 |
| Kruskal 判环 | 用并查集 |
| MST 不一定唯一 | 存在相同权值的边时可能不唯一 |
| 切割性质 | 割中最小的边一定在某 MST 中 |
| 环性质 | 环中最大的边一定不在 MST 中 |

### 七、简单发散

- **数一**：MST 与图论中的最优化问题、矩阵树定理有交叉。
- **英语一**：`minimum spanning tree`、`greedy`、`union-find` 等术语常见于科技文献。
- **408**：MST 是图章节的高频考点，常考手算 MST、Prim/Kruskal 过程、复杂度对比。
