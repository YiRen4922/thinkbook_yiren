## 顺序表（Sequential List）· 考研408核心笔记

> 顺序表是线性表的**顺序存储结构**，是数据结构中最基础、最常考的存储方式。它的核心特征是**逻辑相邻的元素在物理地址上也相邻**。在数一中，顺序表对应**向量**和**矩阵**的存储方式；在英语一中，`sequential`、`contiguous`、`index` 等词为高频科技词汇。

---

### 1. 顺序表的定义

**定义**：用一组**地址连续**的存储单元依次存储线性表的各个元素，使得逻辑上相邻的两个元素在物理位置上也相邻。

$$
L = (a_1, a_2, a_3, \dots, a_n)
$$

**存储结构（C++描述）**：

```cpp
#define MAXSIZE 100
typedef struct {
    ElemType data[MAXSIZE];  // 静态数组存储
    int length;              // 当前长度
} SqList;
```

> [!note] 动态分配版本（考研也常见）
> ```cpp
> typedef struct {
>     ElemType *data;        // 动态分配数组的指针
>     int length;            // 当前长度
>     int maxSize;           // 最大容量
> } SqList;
> ```

---

### 2. 顺序表的核心特征

| 特征              | 说明                             |
| --------------- | ------------------------------ |
| **随机存取**        | 可通过首地址和下标直接访问任意元素，时间复杂度 $O(1)$ |
| **逻辑相邻 = 物理相邻** | 元素之间无额外指针，存储密度高                |
| **插入/删除需移动元素**  | 平均需要移动约 $n/2$ 个元素，时间复杂度 $O(n)$ |
| **静态分配为主**      | 需要预先分配空间，扩容代价高                 |
| **存储密度高**       | 比链表空间利用率高                      |

> [!important] 408 核心结论
> **随机存取**是顺序表相对于链表最大的优势，也是考研选择题的高频考点。

---

### 3. 顺序表的基本操作

#### 3.1 初始化操作

初始化顺序表，构造一个空的顺序表。

**静态分配版本**：

```cpp
void InitList(SqList &L) {
    L.length = 0;            // 将表长置为 0，数据数组无需清空
}
```

**动态分配版本**（考研常考）：

```cpp
void InitList(SqList &L) {
    L.data = (ElemType*)malloc(MAXSIZE * sizeof(ElemType));  // 分配空间
    if (!L.data) exit(OVERFLOW);                             // 分配失败处理
    L.length = 0;                                            // 空表长度为 0
    L.maxSize = MAXSIZE;                                     // 记录最大容量
}
```

**时间复杂度**：$O(1)$

> [!warning] 易错点
> - 静态分配初始化时，只需将 `length` 设为 0，**不需要**将 `data` 数组清空。
> - 动态分配初始化时，必须先调用 `malloc` 或 `new` 分配存储空间，**再**设置 `length = 0`，顺序不能颠倒。
> - 动态分配版本在函数结束时不会自动释放堆内存，需由 `DestroyList` 负责释放。

**C++ 动态分配版（使用 new）**：

```cpp
void InitList(SqList &L) {
    L.data = new ElemType[MAXSIZE];  // 分配空间
    L.length = 0;
    L.maxSize = MAXSIZE;
}
```

#### 3.2 插入操作

在顺序表的第 $i$ 个位置插入新元素 $e$（$1 \le i \le n+1$）。

**实现步骤**：
1. 检查插入位置是否合法
2. 检查表是否已满
3. 将第 $i$ 到第 $n$ 个元素依次向后移动一位
4. 将新元素插入第 $i$ 个位置
5. 表长加 1

```cpp
bool ListInsert(SqList &L, int i, ElemType e) {
    if (i < 1 || i > L.length + 1) return false;  // 位置非法
    if (L.length >= MAXSIZE) return false;        // 表已满
    for (int j = L.length; j >= i; j--) {
        L.data[j] = L.data[j - 1];                // 后移
    }
    L.data[i - 1] = e;                            // 插入
    L.length++;
    return true;
}
```

**时间复杂度**：
- 最好情况：插入表尾，移动 0 次，$O(1)$
- 最坏情况：插入表头，移动 $n$ 次，$O(n)$
- 平均情况：移动 $n/2$ 次，$O(n)$

$$
\text{平均移动次数} = \frac{1}{n+1} \sum_{i=1}^{n+1} (n - i + 1) = \frac{n}{2}
$$

#### 3.3 删除操作

删除顺序表中第 $i$ 个位置的元素（$1 \le i \le n$）。

**实现步骤**：
1. 检查删除位置是否合法
2. 取出被删除元素（若需要）
3. 将第 $i+1$ 到第 $n$ 个元素依次向前移动一位
4. 表长减 1

```cpp
bool ListDelete(SqList &L, int i, ElemType &e) {
    if (i < 1 || i > L.length) return false;      // 位置非法
    e = L.data[i - 1];                            // 取出被删元素
    for (int j = i; j < L.length; j++) {
        L.data[j - 1] = L.data[j];                // 前移
    }
    L.length--;
    return true;
}
```

**时间复杂度**：
- 最好情况：删除表尾，移动 0 次，$O(1)$
- 最坏情况：删除表头，移动 $n-1$ 次，$O(n)$
- 平均情况：移动 $(n-1)/2$ 次，$O(n)$

$$
\text{平均移动次数} = \frac{1}{n} \sum_{i=1}^{n} (n - i) = \frac{n-1}{2}
$$

#### 3.4 按值查找（顺序查找）

在顺序表中查找第一个值为 $e$ 的元素，返回其位序。

```cpp
int LocateElem(SqList L, ElemType e) {
    for (int i = 0; i < L.length; i++) {
        if (L.data[i] == e) return i + 1;          // 返回位序
    }
    return 0;                                      // 查找失败
}
```

**时间复杂度**：$O(n)$（平均比较 $n/2$ 次）

#### 3.5 按位取值

取第 $i$ 个位置的值，是顺序表唯一 $O(1)$ 的查询操作。

```cpp
bool GetElem(SqList L, int i, ElemType &e) {
    if (i < 1 || i > L.length) return false;
    e = L.data[i - 1];
    return true;
}
```

### 5. 地址计算公式（数一关联）

假设每个元素占用 $c$ 个存储单元，顺序表首地址为 $\text{Loc}(a_1)$，则第 $i$ 个元素的地址为：

$$
\boxed{\text{Loc}(a_i) = \text{Loc}(a_1) + (i - 1) \times c}
$$

**二维数组的按行/按列存储**（数一线性代数与408的交汇点）：

| 存储方式 | 地址公式（$A[0][0]$ 为首地址） |
|----------|-------------------------------|
| 按行优先 | $\text{Loc}(A[i][j]) = \text{Loc}(A[0][0]) + (i \times n + j) \times c$ |
| 按列优先 | $\text{Loc}(A[i][j]) = \text{Loc}(A[0][0]) + (j \times m + i) \times c$ |

> [!note] 数一关联
> 数一线性代数中矩阵在计算机中的存储方式，本质就是顺序表的一维展开。上述公式在考研数一和408中均会涉及。

### 6. 顺序表 vs 链表（对比速查）

| 对比维度 | 顺序表 | 链表 |
|----------|--------|------|
| 存储空间 | 预先分配，连续 | 动态分配，不连续 |
| 随机存取 | ✅ $O(1)$ | ❌ $O(n)$ |
| 插入/删除 | ❌ $O(n)$ | ✅ $O(1)$（已知位置） |
| 存储密度 | 高（无需指针） | 低（需额外指针空间） |
| 扩容方式 | 静态分配，扩容困难 | 动态分配，灵活 |

> [!tip] 记忆口诀
> **“顺序查快改慢，链表改快查慢”**

### 8. STL 源码剖析：`vector` 的底层实现

> 本节基于侯捷《STL源码剖析》及 SGI STL 源码，深入分析 `vector` 的底层实现原理。

#### 8.1 数据结构：三个迭代器（核心）

`vector` 维护的是一块连续的线性空间，其数据结构非常简单——**三个迭代器（本质是三个原生指针）** 即可描述整个空间的状态：

```cpp
template <class T, class Alloc = alloc>
class vector {
protected:
    iterator start;           // 指向目前使用空间的头部
    iterator finish;          // 指向目前使用空间的尾部（最后一个元素的下一个位置）
    iterator end_of_storage;  // 指向目前可用空间的尾部
};
```

> [!important] 三个指针的含义
> - `start`：指向第一个元素
> - `finish`：指向最后一个有效元素的**下一个位置**（前闭后开区间 `[start, finish)`）
> - `end_of_storage`：指向已分配内存的末尾（含备用空间）

凭借这三个指针，`vector` 可以轻松提供大部分基础功能：

```cpp
iterator begin() { return start; }
iterator end() { return finish; }
size_type size() const { return size_type(end() - begin()); }
size_type capacity() const { return size_type(end_of_storage - begin()); }
bool empty() const { return begin() == end(); }
reference operator[](size_type n) { return *(begin() + n); }
reference front() { return *begin(); }
reference back() { return *(end() - 1); }
```

**内存布局示意图**：

```
  start                        finish                        end_of_storage
    ↓                            ↓                                   ↓
  ┌──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┬──────┐
  │  a1  │  a2  │  a3  │  a4  │      │      │      │      │      │      │
  └──────┴──────┴──────┴──────┴──────┴──────┴──────┴──────┴──────┴──────┘
  <──── 使用空间 (size = 4) ──><────── 备用空间 (capacity - size) ───────>
  <────────────────────── 已分配空间 (capacity) ────────────────────────>
```

#### 8.2 迭代器：原生指针

由于 `vector` 维护的是连续线性空间，**普通指针就可以作为 `vector` 的迭代器**，满足 Random Access Iterator 的所有必要条件。

```cpp
typedef value_type* iterator;        // 迭代器就是原生指针 T*
typedef const value_type* const_iterator;
```

这意味着 `vector` 的迭代器支持所有指针算术运算：`p+n`、`p-n`、`p[n]`、`p1-p2`、`p1<p2` 等。

> [!note] 考研补充
> 在 408 中，`vector` 的迭代器是**原生指针**这一特性，决定了它的迭代器在插入/删除时可能**全部失效**（因为扩容后指针指向的地址变了）。

#### 8.3 构造与内存管理

`vector` 的构造过程本质上是**先分配内存，再在内存上构造对象**。

```cpp
// 指定大小和初值的构造函数
vector(size_type n, const T& value) {
    fill_initialize(n, value);
}

void fill_initialize(size_type n, const T& value) {
    start = allocate_and_fill(n, value);
    finish = start + n;
    end_of_storage = finish;
}

iterator allocate_and_fill(size_type n, const T& x) {
    iterator result = data_allocator::allocate(n);   // 分配 n 个元素的空间
    uninitialized_fill_n(result, n, x);              // 在未初始化内存上构造对象
    return result;
}
```

> [!important] 内存分配与对象构造分离
> `vector` 将**内存分配**（`allocate`）和**对象构造**（`construct`）分离，这是 STL 空间配置器的核心思想。这样做的好处是：
> - 可以推迟对象构造到真正需要的时候
> - 可以批量分配内存，减少扩容次数
> - 析构时先销毁对象（`destroy`），再释放内存（`deallocate`）

#### 8.4 核心操作实现

**（1）`push_back` 与扩容**

当调用 `push_back` 插入新元素时，首先检查是否有备用空间：

```cpp
void push_back(const T& x) {
    if (finish != end_of_storage) {          // 有备用空间
        construct(finish, x);                // 在备用空间上构造元素
        ++finish;                            // 调整 finish
    } else {                                 // 无备用空间，需要扩容
        insert_aux(end(), x);
    }
}
```

**扩容机制（核心算法）**：当备用空间不足时，`vector` 会重新配置空间、移动数据、释放原空间。

```cpp
template <class T, class Alloc>
void vector<T, Alloc>::insert_aux(iterator position, const T& x) {
    if (finish != end_of_storage) {
        // 有备用空间：在 finish 处构造最后一个元素的副本，然后整体后移
        construct(finish, *(finish - 1));
        ++finish;
        T x_copy = x;
        copy_backward(position, finish - 2, finish - 1);
        *position = x_copy;
    } else {
        // ⭐ 无备用空间：扩容
        const size_type old_size = size();
        const size_type len = old_size != 0 ? 2 * old_size : 1;  // 2 倍扩容
        iterator new_start = data_allocator::allocate(len);      // 1. 分配新空间
        iterator new_finish = new_start;
        
        // 2. 将原数据拷贝到新空间
        new_finish = uninitialized_copy(start, position, new_start);
        construct(new_finish, x);                               // 插入新元素
        ++new_finish;
        new_finish = uninitialized_copy(position, finish, new_finish);
        
        // 3. 析构并释放原空间
        destroy(start, finish);
        deallocate();
        
        // 4. 调整迭代器指向新空间
        start = new_start;
        finish = new_finish;
        end_of_storage = new_start + len;
    }
}
```

> [!important] 扩容三步走
> 1. **配置新空间**：通常为原容量的 **2 倍**（GCC 实现）
> 2. **移动数据**：将旧空间的元素**拷贝**到新空间
> 3. **释放旧空间**：析构旧元素并释放内存
>
> 这个过程**工程浩大**，也是为什么 `vector` 的扩容操作时间复杂度为 $O(n)$，但均摊后为 $O(1)$。

虽然**某一次**扩容很慢（O(n)），但扩容**不是每次插入都会发生**。

vector 采用的是**成倍扩容**策略（容量变成原来的 2 倍）。我们来算一笔账：

假设从空 vector 开始，不断 push_back 到 n 个元素：

|扩容时机|当时元素个数|这次扩容的代价|
|---|---|---|
|第 1 次|1|1|
|第 2 次|2|2|
|第 3 次|4|4|
|第 4 次|8|8|
|...|...|...|
|最后一次|n/2|n/2|

把所有扩容的代价加起来：
$$
1 + 2 + 4 + 8 + \dots + \frac{n}{2} \approx n
$$

总共才花了大约 **O(n)** 的时间，却完成了 **n 次**插入。

所以：

- 平均每次插入分摊到的扩容成本 = $O(n)n=O(1)\dfrac{O(n)}{n} = O(1)nO(n)​=O(1)$

这就是**均摊时间复杂度（Amortized Time Complexity）为 O(1)** 的含义。


**扩容策略对比**：

| 编译器 | 扩容因子 | 说明 |
|--------|----------|------|
| GCC (libstdc++) | **2 倍** | `old_size != 0 ? 2 * old_size : 1` |
| MSVC | **1.5 倍** | 减少内存碎片 |

**（2）`pop_back` 删除尾元素**

```cpp
void pop_back() {
    --finish;        // 将尾端标记前移一个位置
    destroy(finish); // 析构被放弃的元素
}
```

> `pop_back` 只是将 `finish` 前移并析构对象，**不释放内存**，容量不变。

**（3）`erase` 删除指定位置元素**

`erase` 的核心逻辑是**将删除位置之后的所有元素向前移动**。

```cpp
iterator erase(iterator position) {
    if (position + 1 != end()) {
        copy(position + 1, finish, position);  // 后面前移
    }
    --finish;
    destroy(finish);
    return position;
}
```

**时间复杂度**：$O(n)$（需移动元素）

#### 8.5 迭代器失效问题（408 高频考点）

`vector` 的插入/删除操作可能导致迭代器失效：

| 操作                     | 失效情况           | 原因               |
| ---------------------- | -------------- | ---------------- |
| `push_back` / `insert` | **所有迭代器**都可能失效 | 扩容时重新分配内存，所有指针失效 |
| `erase`                | 被删除位置及之后的迭代器失效 | 元素前移，指针指向的位置改变   |
| `pop_back`             | 被删除元素的迭代器失效    | 该元素被析构           |

> [!warning] 考研常考
> ```cpp
> for (auto it = v.begin(); it != v.end(); ++it) {
>     if (*it == 0) v.erase(it);  // ❌ it 失效！
> }
> ```
> 正确做法：`it = v.erase(it);`（利用 `erase` 返回下一个有效迭代器）
> ```cpp
> for (auto it = v.begin(); it != v.end(); ) {  // 注意：这里不要写 ++it
>    if (*it == 0) {
> 	   it = v.erase(it);   // erase 返回下一个有效位置，直接接住
>    } else {
> 	   ++it;               // 只有不删除时才手动++
>    }
>}
> ```

#### 8.6 `vector` 的继承体系（SGI STL）

在 SGI STL 中，`vector` 继承自 `_Vector_base`，采用**保护继承**方式：

```cpp
template <typename _Tp, typename _Alloc = std::allocator<_Tp>>
class vector : protected _Vector_base<_Tp, _Alloc> {
    // ...
};
```

`_Vector_base` 内部定义了 `_Vector_impl` 结构体，包含三个指针：

```cpp
struct _Vector_impl : public _Tp_alloc_type {
    pointer _M_start;          // 容器开始位置
    pointer _M_finish;         // 容器结束位置
    pointer _M_end_of_storage; // 已申请内存的末尾
};
```

> [!note] 考研视角
> 理解 `vector` 的继承体系有助于回答“`vector` 的内存管理是如何实现的”这类深度问题。核心是 **`_Vector_base` 负责内存管理（分配/释放），`vector` 负责元素操作（构造/析构/移动）** 。

### 10. 易错与易混点

| 易错判断 | 正确理解 |
|----------|----------|
| “顺序表支持随机存取，所以插入也是 $O(1)$” | ❌ 错误。随机存取是**取值**操作 $O(1)$，插入需要**移动元素**，为 $O(n)$ |
| “顺序表插入平均移动 $n$ 次” | ❌ 错误。平均移动 $n/2$ 次，不是 $n$ 次 |
| “顺序表删除平均移动 $(n+1)/2$ 次” | ❌ 错误。删除平均移动 $(n-1)/2$ 次 |
| “`erase` 后迭代器仍然有效” | ❌ 错误。`erase` 会使被删除位置及之后所有迭代器失效 |
| “`vector` 的 `size()` 和 `capacity()` 总是相等” | ❌ 错误。`size <= capacity`，`size` 是实际元素数，`capacity` 是分配空间数 |
| “`vector` 扩容是在原地扩展” | ❌ 错误。`vector` **不能**在原地扩容，必须重新配置新空间、移动数据、释放旧空间 |
| “`vector` 的迭代器是封装过的类” | ❌ 错误。`vector` 的迭代器就是**原生指针** `T*` |

### 11. 核心公式速查卡

| 公式 | 说明 |
|------|------|
| $\text{Loc}(a_i) = \text{Loc}(a_1) + (i-1) \times c$ | 第 $i$ 个元素地址 |
| 插入平均移动次数 $= \dfrac{n}{2}$ | 时间复杂度 $O(n)$ |
| 删除平均移动次数 $= \dfrac{n-1}{2}$ | 时间复杂度 $O(n)$ |
| 按位取值 $O(1)$ | 随机存取 |
| 按值查找 $O(n)$ | 顺序查找 |
| `push_back` 均摊 $O(1)$ | 扩容机制保证了均摊常数时间 |
| `insert`/`erase` $O(n)$ | 需要移动元素 |
| 扩容因子（GCC） | $\text{new\_capacity} = \max(1, 2 \times \text{old\_capacity})$ |
