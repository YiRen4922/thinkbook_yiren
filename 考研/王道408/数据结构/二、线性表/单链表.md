## 单链表（Singly Linked List）· 考研408核心笔记

> 单链表是线性表的**链式存储结构**中最基本的形式，通过一组**任意的存储单元**存储数据元素，利用**指针**建立元素之间的线性关系。在数一中，单链表的遍历过程对应**递推与迭代**的思想；在英语一中，`pointer`、`node`、`successor` 等词为高频科技词汇。

---

### 1. 单链表的定义

**定义**：单链表通过**节点（Node）** 来存储数据，每个节点包含**数据域**和**指针域**，指针域指向下一个节点。

$$
\text{Node} = (\text{data}, \text{next})
$$

**存储结构（C++描述）**：

```cpp
typedef struct LNode {
    ElemType data;           // 数据域
    struct LNode *next;      // 指针域，指向后继结点
} LNode, *LinkList;          // LinkList 为指向头结点的指针类型
```

#### 1.1 头指针、头结点、首元结点

| 概念              | 定义                            | 作用              |
| --------------- | ----------------------------- | --------------- |
| **头指针LinkList** | 指向链表第一个结点的==指针==              | 链表的唯一标识         |
| **头结点**         | ==在首元结点之前附加的结点==（`data` 不存数据） | **统一空表与非空表的操作** |
| **首元结点**        | 链表中==存储第一个数据元素==的结点           | 存储实际数据          |

> [!important] 考研约定
> 408考试中**默认使用带头结点的单链表**。头结点使得插入、删除操作**无需区分首元素**，代码更简洁统一。

---

### 2. 单链表的核心特征

| 特征          | 说明                            |
| ----------- | ----------------------------- |
| **顺序存取**    | 访问第 $i$ 个元素需从头遍历，时间复杂度 $O(n)$ |
| **动态存储**    | 不需要预先分配连续空间，按需分配              |
| **插入/删除高效** | 只需修改指针，$O(1)$（已知前驱结点）         |
| **存储密度低**   | 每个结点需要额外指针空间                  |

> [!tip] 记忆口诀
> **“链表改快查慢，存储不连续，插入删除快”**

---

### 3. 单链表的基本操作（带头结点）

#### 3.1 初始化操作

构造一个带头结点的空单链表。

```cpp
bool InitList(LinkList &L) {
    L = (LNode*)malloc(sizeof(LNode));  // 分配头结点
    if (L == NULL) return false;        // 内存分配失败
    L->next = NULL;                     // 头结点指针域置空
    return true;
}
```

**时间复杂度**：$O(1)$

> [!warning] 易错点
> - 初始化必须将 `L->next = NULL`，否则 `L->next` 为**野指针**，后续操作会崩溃。
> - 必须检查 `malloc` 是否成功。

---

#### 3.2 按位插入

在第 $i$ 个位置插入新元素 $e$（$1 \le i \le n+1$）。

**实现步骤**：
1. 检查插入位置是否合法（$i \ge 1$）
2. 找到第 $i-1$ 个结点（前驱结点）
3. 申请新结点，赋值
4. 修改指针：新结点指向原第 $i$ 个结点，前驱结点指向新结点

```cpp
bool ListInsert(LinkList &L, int i, ElemType e) {
    if (i < 1) return false;
    LNode *p = L;          // p 指向头结点（第0个结点）
    int j = 0;             // j 表示 p 指向第几个结点
    while (p != NULL && j < i - 1) {  // 找到第 i-1 个结点
        p = p->next;
        j++;
    }
    if (p == NULL) return false;      // i 不合法（超过了表长+1）
    LNode *s = (LNode*)malloc(sizeof(LNode));
    s->data = e;
    s->next = p->next;                // 新结点指向原第 i 个结点
    p->next = s;                      // 前驱指向新结点
    return true;
}
```

**时间复杂度**：
- 最好情况：插入表头，$O(1)$
- 最坏情况：插入表尾，$O(n)$
- 平均情况：$O(n)$

> [!tip] 插入操作关键
> **必须先 `s->next = p->next`，再 `p->next = s`**。顺序颠倒会导致原链表丢失。

---

#### 3.3 按位删除

删除第 $i$ 个位置的元素，并用 $e$ 返回其值。

**实现步骤**：
1. 检查删除位置是否合法（$1 \le i \le n$）
2. 找到第 $i-1$ 个结点（前驱结点）
3. 用指针 $q$ 指向被删除结点
4. 修改指针：前驱结点指向被删除结点的后继
5. 取出被删除结点的数据，释放被删除结点

```cpp
bool ListDelete(LinkList &L, int i, ElemType &e) {
    if (i < 1) return false;
    LNode *p = L;
    int j = 0;
    while (p != NULL && j < i - 1) {  // 找到第 i-1 个结点
        p = p->next;
        j++;
    }
    if (p == NULL || p->next == NULL) return false;  // i 不合法
    LNode *q = p->next;               // q 指向被删除结点
    e = q->data;                      // 取出数据
    p->next = q->next;                // 前驱指向后继
    free(q);                          // 释放被删除结点
    return true;
}
```

**时间复杂度**：$O(n)$（需先查找前驱）

---

#### 3.4 按值查找（顺序查找）

查找第一个值为 $e$ 的结点，返回其位序。

```cpp
int LocateElem(LinkList L, ElemType e) {
    LNode *p = L->next;   // 从首元结点开始
    int i = 1;
    while (p != NULL && p->data != e) {
        p = p->next;
        i++;
    }
    if (p == NULL) return 0;  // 查找失败
    return i;                 // 返回位序
}
```

**时间复杂度**：$O(n)$（平均比较 $n/2$ 次）

---

#### 3.5 按位取值

取第 $i$ 个位置的值。

```cpp
bool GetElem(LinkList L, int i, ElemType &e) {
    if (i < 1) return false;
    LNode *p = L->next;   // 从首元结点开始
    int j = 1;
    while (p != NULL && j < i) {
        p = p->next;
        j++;
    }
    if (p == NULL) return false;  // i 不合法
    e = p->data;
    return true;
}
```

**时间复杂度**：$O(n)$

---

#### 3.6 头插法建立单链表

将新结点插入到头结点之后。

```cpp
void ListInsert_H(LinkList &L, int a[], int n) {
    InitList(L);                     // 初始化空表
    LNode *s;
    for (int i = 0; i < n; i++) {
        s = (LNode*)malloc(sizeof(LNode));
        s->data = a[i];
        s->next = L->next;           // 新结点指向原首元结点
        L->next = s;                 // 头结点指向新结点
    }
}
```

**时间复杂度**：$O(n)$

> [!tip] 头插法特点
> 头插法建立的单链表，**元素顺序与输入顺序相反**。可用于**链表逆置**。

---

#### 3.7 尾插法建立单链表

用指针 `rear` 始终指向表尾，将新结点插入到表尾。

```cpp
void ListInsert_R(LinkList &L, int a[], int n) {
    InitList(L);                     // 初始化空表
    LNode *s, *rear = L;             // rear 指向表尾
    for (int i = 0; i < n; i++) {
        s = (LNode*)malloc(sizeof(LNode));
        s->data = a[i];
        rear->next = s;              // 表尾指向新结点
        rear = s;                    // 更新 rear
    }
    rear->next = NULL;               // 表尾指针置空
}
```

**时间复杂度**：$O(n)$

> [!tip] 尾插法特点
> 尾插法建立的单链表，**元素顺序与输入顺序相同**。

#### 3.8 求表长

计算单链表中数据结点的个数（**不包含头结点**）。

**实现步骤**：
1. 从首元结点开始遍历
2. 每访问一个结点，计数器加 1
3. 遇到 `NULL` 时停止

```cpp
int ListLength(LinkList L) {
    int len = 0;
    LNode *p = L->next;          // 从首元结点开始，跳过头结点
    while (p != NULL) {
        len++;
        p = p->next;
    }
    return len;
}
```

**递归写法**（408 偶尔考察）：

```cpp
int ListLength_Recursive(LinkList L) {
    if (L->next == NULL) return 0;           // 递归基：空表
    return 1 + ListLength_Recursive(L->next); // 1 + 剩余部分长度
}
```

**时间复杂度**：
- 无论表长多少，都需要**遍历整个链表**
- $T(n) = O(n)$

**空间复杂度**：
- 迭代版本：$O(1)$（只需一个计数器变量）
- 递归版本：$O(n)$（递归调用栈深度为 $n$）

> [!tip] 与顺序表的对比
> | 存储结构 | 求表长实现 | 时间复杂度 |
> |----------|-----------|------------|
> | 顺序表 | 直接返回 `L.length` | $O(1)$ |
> | 单链表 | 遍历所有结点 | $O(n)$ |
>
> 这是顺序表在“查表长”操作上的优势——空间换时间，用额外的 `length` 字段换取 $O(1)$ 的查询效率。

> [!note] 数一关联：遍历计数与数列求和
> 求表长的过程本质是**有限数列的遍历计数**，与数一中“计算有限集合的元素个数”思想一致。考研中若遇到“统计链表中满足某条件的结点个数”这类变式题，其循环结构与求表长完全相同，只是增加了条件判断，时间复杂度仍为 $O(n)$。

> [!tip] 英语一写作句式
> - `The length of the list can be obtained by traversing all nodes.`
> - `The time complexity of computing the length is linear in the number of elements.`

**考研变式题**（“求表长”思想的迁移）：

| 变式              | 代码改动                           | 时间复杂度             |
| --------------- | ------------------------------ | ----------------- |
| 统计偶数结点个数        | `if (p->data % 2 == 0) len++;` | $O(n)$            |
| 统计值大于 $k$ 的结点个数 | `if (p->data > k) len++;`      | $O(n)$            |
| 求表长的**递归版本**    | 见上文递归写法                        | $O(n)$（空间 $O(n)$） |
| **循环链表**求表长     | 终止条件改为 `p != head`             | $O(n)$            |

### 4. 带头结点 vs 不带头结点

| 对比项 | 带头结点 | 不带头结点 |
|--------|----------|------------|
| 空表判断 | `L->next == NULL` | `L == NULL` |
| 插入/删除首元结点 | 统一操作，无需特殊处理 | 需单独处理 `i == 1` 的情况 |
| 代码复杂度 | 简单统一 | 复杂，需分情况讨论 |
| 考研默认 | ✅ 默认使用 | 少数情况考察 |

> [!important] 考研建议
> **默认使用带头结点的单链表**，除非题目明确说明“不带头结点”。

### 6. STL 源码剖析：`slist` 的底层实现

> SGI STL 提供了一个单向链表容器 `slist`（Single linked list），它不是 C++ 标准库的一部分，但它的实现深刻体现了单链表的底层设计思想。

#### 6.1 数据结构：节点设计

`slist` 的节点采用**继承**方式设计，将**指针**和**数据**分离：

```cpp
// 基类：只包含指向下一个节点的指针
struct _Slist_node_base {
    _Slist_node_base* _M_next;
};

// 派生类：继承指针，增加数据域
template <class _Tp>
struct _Slist_node : public _Slist_node_base {
    _Tp _M_data;
};
```

> [!note] 设计思想
> 将指针部分抽象为基类，使得**所有节点共有的指针操作**（如插入、删除、遍历）可以**独立于数据类型**实现，提高代码复用性。

`slist` 的数据结构非常简单——**只有一个头结点**（是实物，不是指针）：

```cpp
template <class T, class Alloc = alloc>
class slist {
private:
    list_node_base head;   // 头部，是实物不是指针
public:
    slist() { head.next = 0; }
    iterator begin() { return iterator((list_node*)head.next); }
    iterator end() { return iterator(0); }        // 空指针作为 end
    bool empty() const { return head.next == 0; } // 判空
};
```

**内存布局示意图**：

```
  head (实物)                           end() = 0
    ↓                                      ↓
  ┌──────────┐    ┌──────────┐    ┌──────────┐
  │ _M_next  │───→│  data    │───→│  data    │───→ 0
  └──────────┘    │  _M_next │    │  _M_next │
                  └──────────┘    └──────────┘
  <── 头结点 ──>   <── 首元结点 ──>   <── 后续结点 ──>
```

#### 6.2 核心内部函数

`slist` 提供了若干**内部全局函数**，不对外开放，仅供对外接口调用：

**（1）在指定节点后插入新节点**

```cpp
inline _Slist_node_base* 
__slist_make_link(_Slist_node_base* __prev_node, 
                  _Slist_node_base* __new_node) {
    __new_node->_M_next = __prev_node->_M_next;
    __prev_node->_M_next = __new_node;
    return __new_node;
}
```

**（2）查找指定节点的前驱**

```cpp
inline _Slist_node_base* 
__slist_previous(_Slist_node_base* __head, 
                 const _Slist_node_base* __node) {
    while (__head && __head->_M_next != __node) 
        __head = __head->_M_next;    // 从头遍历
    return __head;
}
```

> [!warning] 性能瓶颈
> 由于是单向链表，查找前驱必须**从头遍历**。在非起点位置使用 `insert` 或 `erase` **效率低下**，是不智之举。

#### 6.3 迭代器设计

`slist` 的迭代器属于**前向迭代器（Forward Iterator）** ，只支持 `++` 操作，不支持 `--`。

```cpp
// 迭代器基类
struct _Slist_iterator_base {
    typedef forward_iterator_tag iterator_category;  // 前向迭代器标记
    _Slist_node_base* _M_node;
    
    _Slist_iterator_base(_Slist_node_base* __x) : _M_node(__x) {}
    void _M_incr() { _M_node = _M_node->_M_next; }   // 前进
    bool operator==(const _Slist_iterator_base& __x) const {
        return _M_node == __x._M_node;                // 比较指针
    }
};

// 迭代器派生类
template <class _Tp, class _Ref, class _Ptr>
struct _Slist_iterator : public _Slist_iterator_base {
    // 重载 operator*、operator->、operator++ 等
};
```

> [!note] 迭代器本质
> `slist` 的迭代器本质上就是**封装了节点指针**，`begin()` 返回头结点后的第一个节点指针，`end()` 返回空指针。

#### 6.4 `insert` 与 `insert_after`

由于 `slist` 是单向链表，STL 标准的**“在指定位置之前插入”** 操作需要先查找前驱，效率低下。

**标准 `insert`（低效版本）** ：

```cpp
iterator insert(iterator __pos, const value_type& __x) {
    return iterator(
        _M_insert_after(
            __slist_previous(&this->_M_head, __pos._M_node),  // 从头找前驱
            __x
        )
    );
}
```

**高效版本 `insert_after`** （在指定节点**之后**插入）：

```cpp
// 在指定位置之后插入，O(1)
iterator insert_after(iterator __pos, const value_type& __x) {
    return iterator(
        _M_insert_after(__pos._M_node, __x)  // 无需查找前驱
    );
}
```

> [!important] 考研对比
> | 操作 | 时间复杂度 | 说明 |
> |------|-----------|------|
> | `insert_after` | $O(1)$ | 在已知节点后插入，高效 |
> | `insert`（标准） | $O(n)$ | 需从头找前驱，低效 |
> | `push_front` | $O(1)$ | 在头部插入 |

#### 6.5 `slist` 与 `list` 的对比

| 对比维度 | `slist`（单链表） | `list`（双向链表） |
|----------|------------------|-------------------|
| 迭代器类型 | Forward Iterator | Bidirectional Iterator |
| 遍历方向 | 只能向前 | 可向前可向后 |
| 空间占用 | 小（只有一个指针） | 大（有两个指针） |
| `push_back` | ❌ 不提供 | ✅ 提供 |
| `insert` 效率 | 非头部位置需 $O(n)$ | $O(1)$ |
| 迭代器失效 | 插入/删除不失效 | 插入/删除不失效 |

> [!note] C++11 标准
> C++11 标准库提供了 `std::forward_list`，正是以 SGI `slist` 为蓝本设计的单向链表容器。

### 8. 易错与易混点

| 易错判断 | 正确理解 |
|----------|----------|
| “单链表支持随机存取” | ❌ 错误。单链表只能**顺序存取**，访问第 $i$ 个元素需 $O(n)$ |
| “单链表插入操作总是 $O(1)$” | ❌ 错误。**已知前驱结点**时才是 $O(1)$；按位插入需先查找，为 $O(n)$ |
| “带头结点的单链表判空为 `L == NULL`” | ❌ 错误。带头结点时判空为 `L->next == NULL` |
| “头结点就是头指针” | ❌ 错误。头指针指向头结点，头结点是实际存在的结点 |
| “`malloc` 后不用检查返回值” | ❌ 错误。必须检查 `malloc` 是否成功，否则可能宕机 |
| “`slist` 是 C++ 标准库容器” | ❌ 错误。`slist` 是 SGI STL 特有的，不在标准规格内 |

### 9. 核心公式速查卡

| 操作 | 时间复杂度 | 说明 |
|------|-----------|------|
| 按位取值 `GetElem` | $O(n)$ | 需从头遍历 |
| 按值查找 `LocateElem` | $O(n)$ | 平均比较 $n/2$ 次 |
| 按位插入 `ListInsert` | $O(n)$ | 需先查找前驱 |
| 按位删除 `ListDelete` | $O(n)$ | 需先查找前驱 |
| 头插法建表 | $O(n)$ | 每个节点插入头部 |
| 尾插法建表 | $O(n)$ | 每个节点插入尾部 |
| 已知前驱插入 | $O(1)$ | **单链表最大的优势** |
| 已知前驱删除 | $O(1)$ | **单链表最大的优势** |
