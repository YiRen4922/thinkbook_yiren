## 两个递增有序链表求交集 · 考研408笔记（简化版）

> 本题是**二路归并**的典型应用，重点考察**原地修改链表指针**的能力。本文给出适合笔试/算法思维考察的**逻辑简化版**，不释放内存，仅通过指针操作实现交集存放于 A。

---

### 一、题目描述

已知两个链表 $A$ 和 $B$ 分别表示两个集合，其元素**递增排列**。编制函数，求 $A$ 与 $B$ 的**交集**，并存放于 $A$ 链表中。


### 二、算法思想

**核心思路**：一趟遍历 + 尾插法重构 A 链表。

由于 $A$ 和 $B$ 均递增有序，采用**双指针** $pa$ 和 $pb$ 分别遍历：

| 情况 | 操作 | 说明 |
|------|------|------|
| `pa->data < pb->data` | `pa = pa->next` | A 当前元素不在交集中，**逻辑删除**（跳过） |
| `pa->data > pb->data` | `pb = pb->next` | B 当前元素较小，B 指针后移 |
| `pa->data == pb->data` | 将 $pa$ 结点链接到结果表，两指针均后移 | 找到公共元素，**保留** |

遍历结束后，将结果链表尾指针置 `NULL` 即可。未被链接的 A 结点在逻辑上已被删除（不可达），B 链表保持不变。

> [!note] 笔试 vs 工程
> 本版本**不释放内存**（`free`），适合笔试答题侧重逻辑的场景。若要求工程落地，需在跳过结点时使用 `free(tmp)` 释放内存。

> [!tip] 关于 `pre->next = pa`
> 在匹配分支中，`pre->next = pa` 是**必须的**。因为 `pre` 与 `pa` 之间可能存在被跳过的结点，不重新链接会导致丢失保留结点或链接到错误位置。


### 三、代码实现（C++）

```cpp
void Intersection(LinkList &A, LinkList &B) {
    LNode *pa = A->next;          // A 的遍历指针
    LNode *pb = B->next;          // B 的遍历指针
    LNode *pre = A;               // 结果链表的尾指针

    while (pa != NULL && pb != NULL) {
        if (pa->data < pb->data) {
            pa = pa->next;        // A 当前结点不在交集中，跳过（逻辑删除）
        } else if (pa->data > pb->data) {
            pb = pb->next;        // B 当前结点较小，B 指针后移
        } else {
            pre->next = pa;       // 将 A 结点链接到结果链表
            pre = pa;             // 更新尾指针
            pa = pa->next;        // A 后移
            pb = pb->next;        // B 后移
        }
    }

    pre->next = NULL;             // 截断结果链表，后续结点逻辑上全部删除
    // B 链表不变（或根据要求整体释放）
}
```


### 四、时空复杂度

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| 时间复杂度 | **$O(m+n)$** | 两个指针各遍历一次 |
| 空间复杂度 | **$O(1)$** | 没有申请新结点，只用常数个辅助指针 |


### 五、执行过程示例

**输入**：
- $A$ = 头 → 1 → 3 → 5 → 7 → 9
- $B$ = 头 → 2 → 3 → 6 → 7 → 10

| 步骤 | pa | pb | 比较 | 操作 |
|------|----|----|------|------|
| 1 | 1 | 2 | 1 < 2 | `pa` 跳过 1 |
| 2 | 3 | 2 | 3 > 2 | `pb` 后移 |
| 3 | 3 | 3 | 3 == 3 | 保留 3，`pa` 后移，`pb` 后移 |
| 4 | 5 | 6 | 5 < 6 | `pa` 跳过 5 |
| 5 | 7 | 6 | 7 > 6 | `pb` 后移 |
| 6 | 7 | 7 | 7 == 7 | 保留 7，`pa` 后移，`pb` 后移 |
| 7 | 9 | 10 | 9 < 10 | `pa` 跳过 9 |
| 8 | NULL | 10 | 循环结束 | `pre->next = NULL` |

**输出**：$A$ = 头 → 3 → 7 → NULL ✅


### 六、关键细节与易错点

| 要点 | 说明 |
|------|------|
| **循环条件** | `while (pa && pb)`，一方为空后不可能再有交集，**必须用 `&&`** |
| **`pre->next = pa`** | 必须执行，因为 `pre` 与 `pa` 之间可能隔着被跳过的结点 |
| **尾指针置空** | 最后必须 `pre->next = NULL`，否则会保留多余的旧结点 |
| **不释放内存** | 笔试版本不 `free` 结点，逻辑删除即可；工程版本需补充 `free` |
| **B 链表处理** | 本版本不修改 B，若要求释放 B，需单独遍历释放 |
