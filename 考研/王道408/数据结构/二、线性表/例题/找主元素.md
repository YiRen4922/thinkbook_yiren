## 2013统考真题 · 找主元素（Boyer-Moore 投票法）


### 一、题目描述

已知一个整数序列 $A = (a_0, a_1, \dots, a_{n-1})$，其中 $0 \le a_i < n$（$0 \le i < n$）。若存在 $a_{p1} = a_{p2} = \dots = a_{pm} = x$ 且 $m > n/2$（$0 \le p_k < n$，$1 \le k \le m$），则称 $x$ 为 $A$ 的主元素。

**示例**：
- $A = (0, 5, 5, 3, 5, 7, 5, 5)$，则 $5$ 为主元素 ✅
- $A = (0, 5, 5, 3, 5, 1, 5, 7)$，则没有主元素 ❌

**要求**：假设 $A$ 中的 $n$ 个元素保存在一个一维数组中，请设计一个尽可能高效的算法，找出 $A$ 的主元素。若存在主元素，则输出该元素；否则输出 $-1$。


### 二、顺序表类型定义

```cpp
#define MaxSize 100

typedef struct {
    int data[MaxSize];   // 存储空间
    int length;          // 当前表长
} SqList;
```


### 三、算法基本设计思想

**核心思路**：利用 Boyer-Moore 投票法（多数投票算法）——主元素出现次数超过一半，正负相抵后必然剩下主元素。

**算法分两步**：

**第一步（候选阶段）**：遍历数组，确定主元素的候选值
1. 设置候选值 `candidate` 和计数器 `count`，初始 `count = 0`
2. 遍历每个元素：
   - 若 `count == 0`，将当前元素设为 `candidate`，`count = 1`
   - 若当前元素 == `candidate`，`count++`
   - 若当前元素 != `candidate`，`count--`

**第二步（验证阶段）**：遍历数组，统计候选值出现次数
- 若次数 > $n/2$，则该候选值为主元素
- 否则没有主元素，返回 $-1$

> [!example] 为什么可以这样找候选？
> 主元素出现次数超过 $n/2$，而非主元素最多只有 $n/2-1$ 次。每次遇到不同元素就抵消一对，最后剩下的候选值必然是出现次数最多的元素。如果存在主元素，它一定是最终剩下的候选值。


### 四、代码实现（C++）

```cpp
int FindMajority(SqList A) {
    int candidate = -1;
    int count = 0;

    // 第一步：找出候选主元素
    for (int i = 0; i < A.length; i++) {
        if (count == 0) {
            candidate = A.data[i];
            count = 1;
        } else if (A.data[i] == candidate) {
            count++;
        } else {
            count--;
        }
    }

    // 第二步：验证候选元素是否真的是主元素
    int times = 0;
    for (int i = 0; i < A.length; i++) {
        if (A.data[i] == candidate) {
            times++;
        }
    }

    if (times > A.length / 2) {
        return candidate;
    } else {
        return -1;
    }
}
```


### 五、执行过程示例

**例1**：$A = (0, 5, 5, 3, 5, 7, 5, 5)$，$n = 8$

| 轮次 | 当前元素 | count | 操作 | candidate |
|------|---------|-------|------|-----------|
| 初始 | — | 0 | — | -1 |
| 1 | 0 | 0 | `count == 0`，candidate = 0，count = 1 | 0 |
| 2 | 5 | 1 | 5 != 0，count-- → 0 | 0 |
| 3 | 5 | 0 | `count == 0`，candidate = 5，count = 1 | 5 |
| 4 | 3 | 1 | 3 != 5，count-- → 0 | 5 |
| 5 | 5 | 0 | `count == 0`，candidate = 5，count = 1 | 5 |
| 6 | 7 | 1 | 7 != 5，count-- → 0 | 5 |
| 7 | 5 | 0 | `count == 0`，candidate = 5，count = 1 | 5 |
| 8 | 5 | 1 | 5 == 5，count++ → 2 | 5 |

候选值：5。验证：5 出现 5 次，$5 > 8/2 = 4$ ✅ → 输出 **5**

**例2**：$A = (0, 5, 5, 3, 5, 1, 5, 7)$，$n = 8$

候选阶段后得到 `candidate = 5`。验证：5 出现 4 次，$4 > 8/2 = 4$ 不成立 ❌ → 输出 **-1**


### 六、时空复杂度

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| 时间复杂度 | **$O(n)$** | 遍历数组两次（候选 + 验证） |
| 空间复杂度 | **$O(1)$** | 仅使用两个辅助变量 |


### 七、注意事项

| 要点 | 说明 |
|------|------|
| **验证步骤必须做** | 候选元素不一定是主元素（如例2），必须二次遍历验证 |
| **`count == 0` 时的处理** | 将当前元素设为新候选，count = 1（不是 count++） |
| **边界情况** | $n=1$ 时，唯一元素即为主元素 |
| **题目约束** | $0 \le a_i < n$，但本算法不依赖此约束，可处理任意整数序列 |


### 八、与其他解的对比

| 方案 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| **Boyer-Moore 投票法（本解）** | $O(n)$ | $O(1)$ | **最优解**，利用主元素定义 |
| 哈希表统计 | $O(n)$ | $O(n)$ | 空间开销大，非“尽可能高效” |
| 排序后统计 | $O(n \log n)$ | $O(1)$ | 时间开销大 |
