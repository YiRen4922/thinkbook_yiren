## 两个递增有序单链表求公共元素 · 考研408笔记

> 本题是**有序表归并**思想的典型应用，考察如何**不破坏原链表**的前提下，利用**二路归并**提取公共元素。核心是**值相等才复制，不相等则移动较小指针**。


### 一、题目描述

设 $A$ 和 $B$ 是两个**带头结点**的单链表，其中元素**递增有序**。设计一个算法，从 $A$ 和 $B$ 中的**公共元素**产生单链表 $C$，要求**不破坏 $A$、$B$ 的结点**。


### 二、算法思想

**核心思路**：二路归并 + 尾插法构建新链表。

由于 $A$ 和 $B$ 均递增有序，公共元素必然在**相同值的结点**处出现。采用双指针 $pa$ 和 $pb$ 分别遍历 $A$ 和 $B$：

| 情况 | 操作 |
|------|------|
| `pa->data < pb->data` | $A$ 的元素小，$pa$ 后移 |
| `pa->data > pb->data` | $B$ 的元素小，$pb$ 后移 |
| `pa->data == pb->data` | 找到公共元素，**复制**到 $C$ 中，$pa$、$pb$ 均后移 |

**关键**：$C$ 中的结点是**新申请的结点**，与原链表无关，因此**不破坏** $A$、$B$。

> [!example] 为什么要“复制”而非“借用”？
> 若直接将 $A$ 的结点链接到 $C$，则破坏了 $A$ 的结构（一个结点同时属于两个链表）。本题要求不破坏原链表，因此必须 `new` 新结点并复制 `data`。


### 三、代码实现（C++）

```cpp
LinkList GetCommon(LinkList A, LinkList B) {
    // 创建带头结点的空链表 C
    LinkList C = (LNode*)malloc(sizeof(LNode));
    C->next = NULL;
    LNode *tail = C;          // 尾指针，用于尾插

    LNode *pa = A->next;      // A 的工作指针（跳过头结点）
    LNode *pb = B->next;      // B 的工作指针

    while (pa != NULL && pb != NULL) {
        if (pa->data < pb->data) {
            pa = pa->next;
        } else if (pa->data > pb->data) {
            pb = pb->next;
        } else {
            // 找到公共元素，复制到 C
            LNode *s = (LNode*)malloc(sizeof(LNode));
            s->data = pa->data;
            s->next = NULL;

            tail->next = s;
            tail = s;

            pa = pa->next;
            pb = pb->next;
        }
    }

    return C;
}
```


### 四、时空复杂度

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| 时间复杂度 | **$O(m+n)$** | 两个指针各遍历一次 |
| 空间复杂度 | **$O(k)$** | $k$ 为公共元素个数（新链表 $C$ 的大小） |


### 五、执行过程示例

**输入**：
- $A =$ 头 → 1 → 3 → 5 → 7 → 9
- $B =$ 头 → 2 → 3 → 6 → 7 → 10

| 步骤 | pa | pb | 比较 | 操作 |
|------|----|----|------|------|
| 1 | 1 | 2 | 1 < 2 | pa 后移 |
| 2 | 3 | 2 | 3 > 2 | pb 后移 |
| 3 | 3 | 3 | 3 == 3 | 复制 3，两指针均后移 |
| 4 | 5 | 6 | 5 < 6 | pa 后移 |
| 5 | 7 | 6 | 7 > 6 | pb 后移 |
| 6 | 7 | 7 | 7 == 7 | 复制 7，两指针均后移 |
| 7 | 9 | 10 | 9 < 10 | pa 后移 → NULL，结束 |

**输出**：$C =$ 头 → 3 → 7 → NULL ✅


### 六、注意事项

| 要点 | 说明 |
|------|------|
| **跳过头结点** | $pa = A \to next$，$pb = B \to next$，头结点不参与比较 |
| **尾插法** | 用 `tail` 指针始终指向 $C$ 的尾结点，$O(1)$ 插入 |
| **复制结点** | 必须 `malloc` 新结点，不能直接借用原链表结点 |
| **公共元素唯一** | 若 $A$ 和 $B$ 中有重复值，需根据题意决定是否去重（本题默认递增无重复） |


### 七、变式思考

| 变式 | 改动点 |
|------|--------|
| **求并集** | 将较小值也复制到 $C$，较大值指针不动 |
| **求差集（$A-B$）** | 只复制 $A$ 中有而 $B$ 中没有的元素 |
| **允许破坏原链表** | 可直接将 $A$ 中的结点链接到 $C$，无需 `malloc`，空间复杂度降为 $O(1)$ |
| **公共元素去重** | 若 $A$ 或 $B$ 中有重复值，需增加去重逻辑 |
