## 顺序表删除所有值为x的元素 · 考研408笔记


### 顺序表类型定义

```cpp
#define MaxSize 100

typedef struct {
    ElemType data[MaxSize];   // 存储空间
    int length;               // 当前表长
} SqList;
```


### 一、题目要求

对长度为 $n$ 的顺序表 `L`，编写一个时间复杂度为 $O(n)$、空间复杂度为 $O(1)$ 的算法，删除顺序表中**所有**值为 `x` 的数据元素。


### 二、算法思想（双指针 / 统计法）

**核心思路**：遍历顺序表，将**不等于 `x` 的元素**重新排列到表的前端。

==双指针覆写==

**具体操作**：
1. 设置指针 `k`，记录**不等于 `x` 的元素个数**（即新表的长度）
2. 遍历顺序表：
   - 若 `data[i] != x`，将其放入 `data[k]` 位置，`k++`
   - 若 `data[i] == x`，跳过
3. 遍历完成后，将表长更新为 `k`

> 本质：将所有 `!= x` 的元素“压缩”到表的前 `k` 个位置，等价于删除了所有 `x`。


### 三、代码实现

```cpp
void DeleteAllX(SqList &L, ElemType x) {
    int k = 0;   // 记录不等于 x 的元素个数
    
    for (int i = 0; i < L.length; i++) {
        if (L.data[i] != x) {
            L.data[k] = L.data[i];
            k++;
        }
    }
    
    L.length = k;   // 更新表长
}
```


### 四、时空复杂度

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| 时间复杂度 | **$O(n)$** | 遍历整个顺序表一次 |
| 空间复杂度 | **$O(1)$** | 仅用一个整型变量 `k` |


### 五、执行过程示例

**输入**：`L = [1, 2, 3, 2, 4, 2, 5]`，`x = 2`

| 轮次 | i | data[i] | k | 操作 | 数组状态 |
|------|---|---------|---|------|----------|
| 1 | 0 | 1 | 0 | `!= 2`，放入 `data[0]`，k=1 | `[1, 2, 3, 2, 4, 2, 5]` |
| 2 | 1 | 2 | 1 | `== 2`，跳过 | `[1, 2, 3, 2, 4, 2, 5]` |
| 3 | 2 | 3 | 1 | `!= 2`，放入 `data[1]`，k=2 | `[1, 3, 3, 2, 4, 2, 5]` |
| 4 | 3 | 2 | 2 | `== 2`，跳过 | `[1, 3, 3, 2, 4, 2, 5]` |
| 5 | 4 | 4 | 2 | `!= 2`，放入 `data[2]`，k=3 | `[1, 3, 4, 2, 4, 2, 5]` |
| 6 | 5 | 2 | 3 | `== 2`，跳过 | `[1, 3, 4, 2, 4, 2, 5]` |
| 7 | 6 | 5 | 3 | `!= 2`，放入 `data[3]`，k=4 | `[1, 3, 4, 5, 4, 2, 5]` |

最终：`L.length = 4`，有效数据为 `[1, 3, 4, 5]` ✅


### 六、与常规删除方式的对比

| 方案 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| **双指针法（本解）** | $O(n)$ | $O(1)$ | 一次遍历，前移覆盖 |
| 常规删除（每次删除后前移） | $O(n^2)$ | $O(1)$ | 每删一个元素就移动后续所有元素 |


### 七、注意事项

| 要点 | 说明 |
|------|------|
| **`k` 的含义** | 既是“不等于 `x` 的元素个数”，也是“新表的下一个插入位置” |
| **原地操作** | 直接在原数组上修改，不用辅助数组 |
| **覆盖安全** | `k <= i` 恒成立，所以用 `data[k] = data[i]` 不会丢失未处理的元素 |
| **表长更新** | 遍历完成后必须 `L.length = k` |


### 八、扩展应用

| 变式 | 改动点 | 代码变化 |
|------|--------|----------|
| 删除所有值在 `[min, max]` 之间的元素 | 修改 `if` 条件 | `if (L.data[i] < min \|\| L.data[i] > max)` |
| 删除所有奇数/偶数 | 修改判断条件 | `if (L.data[i] % 2 == 0)` |
| 删除所有重复元素（保留一个） | 需额外记录已出现元素 | 需增加辅助结构（空间换时间） |


### 总结

```
双指针压缩法的通用模板：
k = 0
for i = 0 to L.length - 1:
    if (L.data[i] 满足保留条件):
        L.data[k] = L.data[i]
        k++
L.length = k
```

**核心思想**：不关心被删除的元素，只关心**保留哪些元素**。将所有需要保留的元素重新排列到表的前端，一次遍历完成所有删除，是顺序表“批量删除”的标准最优解。
