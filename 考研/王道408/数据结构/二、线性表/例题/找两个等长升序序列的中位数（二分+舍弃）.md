## 2011统考真题 · 找两个等长升序序列的中位数


### 一、题目描述

一个长度为 $L$（$L \ge 1$）的升序序列 $S$，处在第 $\lceil L/2 \rceil$ 个位置的数称为 $S$ 的中位数。

例如：
- $S_1 = (11, 13, 15, 17, 19)$，中位数为 $15$
- $S_2 = (2, 4, 6, 8, 20)$，中位数为 $6$

两个序列的中位数是**含它们所有元素的升序序列的中位数**。

例如，$S_1$ 和 $S_2$ 的所有元素排序为：
$$
(2, 4, 6, 8, 11, 13, 15, 17, 19, 20)
$$
中位数为第 $\lceil 10/2 \rceil = 5$ 个数，即 $11$。

现给定两个**等长升序序列** $A$ 和 $B$，试设计一个**在时间和空间两方面都尽可能高效**的算法，找出两个序列 $A$ 和 $B$ 的中位数。


### 二、顺序表类型定义

```cpp
#define MaxSize 100

typedef struct {
    int data[MaxSize];   // 存储空间
    int length;          // 当前表长
} SqList;
```


### 三、算法基本设计思想

**核心思路**：利用升序序列的有序性，采用**二分 + 舍弃**的策略，逐步缩小查找范围，最终定位中位数。

**具体步骤**：
1. 分别取 $A$ 和 $B$ 的中位数 $a$ 和 $b$
2. 若 $a = b$，则 $a$ 即为全局中位数，直接返回
3. 若 $a < b$，则：
   - $A$ 中 $a$ 左侧的元素（小于等于 $a$ 的半数元素）**不可能**包含全局中位数，**舍弃**
   - $B$ 中 $b$ 右侧的元素（大于等于 $b$ 的半数元素）**不可能**包含全局中位数，**舍弃**
4. 若 $a > b$，则反之：舍弃 $A$ 的右半部分，舍弃 $B$ 的左半部分
5. 重复上述过程，直到两个序列中各剩 1 个元素，较小的即为全局中位数

> [!example] 为什么可以舍弃？
> 以 $a < b$ 为例：$A$ 中有 $\lceil n/2 \rceil$ 个元素 $\le a$，$B$ 中有 $\lceil n/2 \rceil$ 个元素 $\ge b$。由于 $a < b$，$A$ 的左半部分（包括 $a$）最多排在全球中位数的左侧，不可能成为中位数；$B$ 的右半部分（包括 $b$）同理。


### 四、代码实现（C++）

```cpp
int FindMedian(SqList A, SqList B) {
    int s1 = 0, e1 = A.length - 1;      // A 的查找范围 [s1, e1]
    int s2 = 0, e2 = B.length - 1;      // B 的查找范围 [s2, e2]
    int m1, m2;                         // A 和 B 的中位数下标

    while (s1 != e1 || s2 != e2) {
        m1 = (s1 + e1) / 2;
        m2 = (s2 + e2) / 2;

        if (A.data[m1] == B.data[m2]) {
            return A.data[m1];           // 相等，直接返回
        }

        if (A.data[m1] < B.data[m2]) {
            // 舍弃 A 的左半部分，舍弃 B 的右半部分
            // 注意处理奇偶性：保证舍弃后两序列长度相同
            if ((e1 - s1 + 1) % 2 == 0) {   // 长度为偶数时
                s1 = m1 + 1;                // A 舍弃左半（含中位数）
            } else {
                s1 = m1;                   // A 舍弃左半（不含中位数）
            }
            e2 = m2;                       // B 舍弃右半
        } else {
            // A.data[m1] > B.data[m2]
            // 舍弃 A 的右半部分，舍弃 B 的左半部分
            if ((e2 - s2 + 1) % 2 == 0) {
                s2 = m2 + 1;
            } else {
                s2 = m2;
            }
            e1 = m1;
        }
    }

    return (A.data[s1] < B.data[s2]) ? A.data[s1] : B.data[s2];
}
```


### 五、执行过程示例

**输入**：
- $A = (11, 13, 15, 17, 19)$，$n = 5$
- $B = (2, 4, 6, 8, 20)$，$n = 5$

| 轮次 | A 范围 | B 范围 | m1 | m2 | A[m1] | B[m2] | 比较 | 操作 |
|------|--------|--------|----|----|-------|-------|------|------|
| 1 | [0,4] | [0,4] | 2 | 2 | 15 | 6 | 15 > 6 | 舍弃 A 右半 (e1=2)，舍弃 B 左半 (s2=2) |
| 2 | [0,2] | [2,4] | 1 | 3 | 13 | 8 | 13 > 8 | 舍弃 A 右半 (e1=1)，舍弃 B 左半 (s2=3) |
| 3 | [0,1] | [3,4] | 0 | 3 | 11 | 8 | 11 > 8 | 舍弃 A 右半 (e1=0)，舍弃 B 左半 (s2=3) |
| 4 | [0,0] | [3,4] | 0 | 3 | 11 | 8 | 11 > 8 | 舍弃 A 右半，舍弃 B 左半，s2=4 |
| 5 | [0,0] | [4,4] | — | — | 11 | 20 | — | 取较小者：11 |

**输出**：$11$ ✅


### 六、时空复杂度

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| 时间复杂度 | **$O(\log n)$** | 每轮比较后，两个序列的范围缩小约一半 |
| 空间复杂度 | **$O(1)$** | 仅使用常数个辅助变量 |


### 七、算法正确性证明（简析）

**循环不变式**：
- 每次迭代后，全局中位数**仍在** $A[s_1..e_1]$ 和 $B[s_2..e_2]$ 的并集中
- 舍弃的部分**不可能**包含全局中位数

**证明要点**：
1. 若 $A[m1] < B[m2]$，则 $A$ 中 $\le A[m1]$ 的元素个数为 $m1+1$，$B$ 中 $\ge B[m2]$ 的元素个数为 $n-m2$，合计至少 $n+1$ 个元素。全局中位数的位置是 $n$，所以 $A$ 的左半部分和 $B$ 的右半部分都不可能是全局中位数。
2. 同理可证 $A[m1] > B[m2]$ 的情况。
3. 当 $A[m1] = B[m2]$ 时，该值就是全局中位数。

**终止性**：每轮迭代后，$e1-s1+1$ 和 $e2-s2+1$ 严格递减，最终各为 1，必然终止。


### 八、注意事项

| 要点 | 说明 |
|------|------|
| **奇偶性处理** | 序列长度为偶数时，中位数为第 $\lceil n/2 \rceil$ 个（即下标 $n/2$），舍弃左半时需跳过当前中位数 |
| **等长条件** | 本题要求 $A$ 和 $B$ 长度相等，算法依赖此条件 |
| **升序前提** | 若序列无序，需先排序（本题已保证） |
| **边界情况** | $n=1$ 时直接返回较小者 |


### 九、与其他解的对比

| 方案 | 时间复杂度 | 空间复杂度 | 说明 |
|------|-----------|-----------|------|
| **二分解法（本解）** | $O(\log n)$ | $O(1)$ | 最优解，利用中位数性质二分 |
| 归并法 | $O(n)$ | $O(n)$ | 合并后取中位数，常规解法 |
| 双指针法 | $O(n)$ | $O(1)$ | 归并到第 $n$ 个元素停止 |
