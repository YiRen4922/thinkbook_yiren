## 顺序表 · 408 大题考点全归纳


### 顺序表类型定义

```cpp
#define MaxSize 100

typedef struct {
    ElemType data[MaxSize];   // 存储空间
    int length;               // 当前表长
} SqList;
```

### 二、题型一：双指针/压缩法

**适用场景**：删除满足某条件的元素，保留其余元素，**不保持原序或保持原序均可**。

**通用模板**：

```cpp
void Compress(SqList &L) {
    int k = 0;   // k 指向保留元素的存放位置
    for (int i = 0; i < L.length; i++) {
        if (L.data[i] 满足保留条件) {
            L.data[k] = L.data[i];
            k++;
        }
    }
    L.length = k;
}
```

**常见变形**：

| 变形                              | 保留条件                                   | 代码变化     |
| ------------------------------- | -------------------------------------- | -------- |
| [[顺序表删除所有值为x的元素\|删除所有值为 x 的元素]] | `L.data[i] != x`                       | 仅改 if 条件 |
| 删除值在 `[min, max]` 之间的元素         | `L.data[i] < min \|\| L.data[i] > max` | 仅改 if 条件 |
| 删除所有偶数/奇数                       | `L.data[i] % 2 != 0`                   | 仅改 if 条件 |
| [[有序顺序表去重\|删除所有重复元素（保持顺序）]]     | 需用双指针 + 辅助判断                           | 见下题型四    |

> [!tip] 408 关联
> 双指针压缩法是 408 线性表大题的**最高频考点**，几乎每年都有。


### 三、题型二：逆置法

**适用场景**：将整个顺序表或某一部分逆置，常用于循环移位。

**通用模板**：

```cpp
void Reverse(SqList &L, int left, int right) {
    if (left >= right) return;
    for (int i = left, j = right; i < j; i++, j--) {
        swap(L.data[i], L.data[j]);
    }
}
```

**常见变形**：

| 变形         | 操作         | 实现                                                         |
| ---------- | ---------- | ---------------------------------------------------------- |
| 整体逆置       | 逆置整个表      | `Reverse(L, 0, L.length - 1)`                              |
| 逆置前 $k$ 个  | 只逆置前 $k$ 个 | `Reverse(L, 0, k - 1)`                                     |
| 循环左移 $k$ 位 | 三次逆置       | `Reverse(L,0,n-1); Reverse(L,0,n-k-1); Reverse(L,n-k,n-1)` |
| 循环右移 $k$ 位 | 三次逆置       | `Reverse(L,0,n-1); Reverse(L,0,k-1); Reverse(L,k,n-1)`     |

> [!example] 408 真题：循环左移
> 将顺序表 $L$ 循环左移 $k$ 位（$k < n$）。例如 `[1,2,3,4,5]` 左移 2 位 → `[3,4,5,1,2]`。
>
> ```cpp
> void LeftShift(SqList &L, int k) {
>     k = k % L.length;   // 防止 k > n
>     Reverse(L, 0, L.length - 1);
>     Reverse(L, 0, L.length - k - 1);
>     Reverse(L, L.length - k, L.length - 1);
> }
> ```


### 四、题型三：有序表归并

**适用场景**：两个有序顺序表合并为一个有序顺序表（不改变原表或原地合并）。

**通用模板（二路归并）**：

```cpp
void Merge(SqList A, SqList B, SqList &C) {
    int i = 0, j = 0, k = 0;
    while (i < A.length && j < B.length) {
        if (A.data[i] <= B.data[j]) {
            C.data[k++] = A.data[i++];
        } else {
            C.data[k++] = B.data[j++];
        }
    }
    while (i < A.length) C.data[k++] = A.data[i++];
    while (j < B.length) C.data[k++] = B.data[j++];
    C.length = k;
}
```

**常见变形**：

| 变形 | 修改点 | 时间复杂度 |
|------|--------|-----------|
| 合并到新表 | 新建 $C$，空间复杂度 $O(n)$ | $O(m+n)$ |
| 原地合并到 $A$（$A$ 有足够空间） | 从后往前归并 | $O(m+n)$ |
| 求有序表的交集/并集 | 归并过程中处理相同元素 | $O(m+n)$ |
| 求中位数 | 归并到第 $(m+n)/2$ 个停止 | $O(m+n)$ |

> [!note] 408 命题特点
> 有序表归并是 408 中性价比最高的考点——思路固定（二路归并），容易拿分。


### 五、题型四：有序表去重

**适用场景**：有序顺序表中删除所有重复元素，使每个值只保留一个。

**代码实现**：

```cpp
void RemoveDuplicates(SqList &L) {
    if (L.length <= 1) return;
    int k = 0;   // k 指向去重后新表的最后一个元素
    for (int i = 1; i < L.length; i++) {
        if (L.data[i] != L.data[k]) {
            L.data[++k] = L.data[i];
        }
    }
    L.length = k + 1;
}
```

**常见变形**：

| 变形 | 思路变化 |
|------|----------|
| 删除所有重复元素（一个不留） | 需额外判断相邻元素是否重复，记录重复值 |
| 统计每种元素出现次数 | 在去重过程中计数 |
| 有序链表去重 | 指针逻辑相同 |


### 六、题型五：查找 + 删除（末位填补）

**适用场景**：查找特定元素并删除，**删除后不要求保持原序**，用最后一个元素填补空位。

**代码框架**：

```cpp
bool DeleteByFill(SqList &L, ElemType &value) {
    if (L.length == 0) return false;
    // 1. 查找目标（如最小值）
    int pos = 0;
    for (int i = 1; i < L.length; i++) {
        if (L.data[i] < L.data[pos]) pos = i;
    }
    // 2. 删除：用最后一个元素填补
    value = L.data[pos];
    L.data[pos] = L.data[L.length - 1];
    L.length--;
    return true;
}
```

**常见变形**：

| 变形 | 查找逻辑 | 删除方式 |
|------|----------|----------|
| 删除最小值 | 找最小 | 末位填补 |
| 删除最大值 | 找最大 | 末位填补 |
| 删除第 $i$ 个元素（不保持顺序） | 直接定位 | 末位填补 |
| 删除第一个值为 $x$ 的元素 | 按值查找 | 末位填补 |


### 七、408 真题高频变形补充

| 题型                  | 核心思想                                      | 代码框架      | 复杂度      |
| ------------------- | ----------------------------------------- | --------- | -------- |
| **删除区间元素**          | 双指针压缩，条件改为 `data[i] < a \|\| data[i] > b` | 同题型一      | $O(n)$   |
| **拆分顺序表（奇偶分离）**     | 双指针从两端向中间交换                               | 同题型二      | $O(n)$   |
| **查找主元素（众数 > n/2）** | Boyer-Moore 投票法                           | 遍历计数 + 验证 | $O(n)$   |
| **两个有序表找公共元素**      | 二路归并取交集                                   | 同题型三      | $O(m+n)$ |
| **将两个顺序表位置互换**      | 三次逆置                                      | 同题型二      | $O(n)$   |

> [!tip] 应试技巧
> 顺序表大题几乎都能归入以上 5 种题型。考试时先**判断题型**，再套用对应框架，最后补充边界条件。
