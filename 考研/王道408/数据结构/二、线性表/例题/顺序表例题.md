## 数据结构 · 顺序表综合应用题（考研408核心笔记）

> 顺序表是 408 数据结构中**性价比最高**的内容——代码量适中、考点集中、容易拿分。本篇系统梳理顺序表的**六大题型**，涵盖 2011-2023 年的经典真题，每道题均给出一题多解与复杂度分析。


### 一、顺序表类型定义

```cpp
#define MaxSize 100

typedef struct {
    int data[MaxSize];   // 存储空间
    int length;          // 当前表长
} SqList;
```


### 二、题型分类总览

| 题型 | 核心方法 | 时间复杂度 | 空间复杂度 | 真题年份 |
|------|----------|-----------|-----------|----------|
| **双指针压缩** | 保留满足条件的元素 | $O(n)$ | $O(1)$ | 2013、2021 |
| **逆置法** | 双端交换 + 三次逆置 | $O(n)$ | $O(1)$ | 2010 |
| **有序表归并** | 二路归并 | $O(m+n)$ | $O(1)$ 或 $O(n)$ | 2018 |
| **有序表去重** | 相邻比较 + 压缩 | $O(n)$ | $O(1)$ | 2016 |
| **原地哈希** | 值→下标映射 | $O(n)$ | $O(1)$ | 2018 |
| **多指针贪心** | 每次移动最小指针 | $O(n_1+n_2+n_3)$ | $O(1)$ | 2020 |


### 三、题型一：双指针压缩法

**适用场景**：删除满足某条件的元素，保留其余元素，保持原序。

**通用模板**：

```cpp
void Compress(SqList &L) {
    int k = 0;   // k 指向保留元素的存放位置
    for (int i = 0; i < L.length; i++) {
        if (L.data[i] 满足保留条件) {
            L.data[k++] = L.data[i];
        }
    }
    L.length = k;
}
```

**常见变形**：

| 变形 | 保留条件 | 代码变化 |
|------|----------|----------|
| 删除所有值为 $x$ 的元素 | `L.data[i] != x` | 仅改 if 条件 |
| 删除值在 `[min, max]` 之间的元素 | `L.data[i] < min \|\| L.data[i] > max` | 仅改 if 条件 |
| 删除所有偶数 | `L.data[i] % 2 != 0` | 仅改 if 条件 |

> [!example] **2013 统考真题：找主元素**
>
> **题目**：已知一个整数序列 $A=(a_0, a_1, \dots, a_{n-1})$，若存在某元素出现次数 $m > n/2$，则称其为主元素。设计算法找出主元素，不存在则输出 -1。
>
> **思路**：Boyer-Moore 投票法——候选阶段（抵消）+ 验证阶段。
>
> ```cpp
> int FindMajority(int A[], int n) {
>     int candidate = -1, count = 0;
>     // 候选阶段
>     for (int i = 0; i < n; i++) {
>         if (count == 0) {
>             candidate = A[i];
>             count = 1;
>         } else if (A[i] == candidate) {
>             count++;
>         } else {
>             count--;
>         }
>     }
>     // 验证阶段
>     int times = 0;
>     for (int i = 0; i < n; i++) {
>         if (A[i] == candidate) times++;
>     }
>     return (times > n / 2) ? candidate : -1;
> }
> ```
>
> **复杂度**：$T(n) = O(n)$，$S(n) = O(1)$

> [!note] 英一词汇
> `majority`：多数，`candidate`：候选者


### 四、题型二：逆置法

**适用场景**：整体或部分逆置，循环移位。

**通用模板**：

```cpp
void Reverse(SqList &L, int left, int right) {
    for (int i = left, j = right; i < j; i++, j--) {
        int temp = L.data[i];
        L.data[i] = L.data[j];
        L.data[j] = temp;
    }
}
```

**常见变形**：

| 变形 | 操作 | 实现 |
|------|------|------|
| 整体逆置 | 逆置整个表 | `Reverse(L, 0, L.length - 1)` |
| 循环左移 $k$ 位 | 三次逆置 | `Reverse(L,0,n-1); Reverse(L,0,n-k-1); Reverse(L,n-k,n-1)` |
| 循环右移 $k$ 位 | 三次逆置 | `Reverse(L,0,n-1); Reverse(L,0,k-1); Reverse(L,k,n-1)` |

> [!example] **2010 统考真题变式：循环左移**
>
> **题目**：将顺序表 $L$ 循环左移 $k$ 位（$k < n$）。例如 `[1,2,3,4,5]` 左移 2 位 → `[3,4,5,1,2]`。
>
> ```cpp
> void LeftShift(SqList &L, int k) {
>     int n = L.length;
>     k = k % n;
>     Reverse(L, 0, n - 1);        // 整体逆置
>     Reverse(L, 0, n - k - 1);    // 前 n-k 个逆置
>     Reverse(L, n - k, n - 1);    // 后 k 个逆置
> }
> ```

> [!tip] 数学原理（数一关联）
> 三次逆置本质是**置换群的分解**：左移 $k$ 位可视为将序列分成前后两段 $[A|B]$，目标为 $[B|A]$。逆置操作 $(AB)^T = B^T A^T$ 实现了这一变换。


### 五、题型三：有序表归并

**适用场景**：两个有序顺序表合并为一个有序顺序表。

```cpp
void Merge(SqList A, SqList B, SqList &C) {
    int i = 0, j = 0, k = 0;
    while (i < A.length && j < B.length) {
        if (A.data[i] <= B.data[j]) {
            C.data[k++] = A.data[i++];
        } else {
            C.data[k++] = B.data[j++];
        }
    }
    while (i < A.length) C.data[k++] = A.data[i++];
    while (j < B.length) C.data[k++] = B.data[j++];
    C.length = k;
}
```

**复杂度**：$T(n) = O(m+n)$，$S(n) = O(m+n)$（若合并到新表）

> [!example] **2018 统考真题：找未出现的最小正整数**
>
> **题目**：给定含 $n$ 个整数的数组，找出未出现的最小正整数。例如 `{-5,3,2,3}` → 1，`{1,2,3}` → 4。
>
> **思路**：原地哈希——将值 $v$（$1 \le v \le n$）放到下标 $v-1$ 处。
>
> ```cpp
> int FindFirstMissingPositive(int A[], int n) {
>     for (int i = 0; i < n; i++) {
>         while (A[i] >= 1 && A[i] <= n && A[i] != A[A[i] - 1]) {
>             int temp = A[i];
>             A[i] = A[temp - 1];
>             A[temp - 1] = temp;
>         }
>     }
>     for (int i = 0; i < n; i++) {
>         if (A[i] != i + 1) return i + 1;
>     }
>     return n + 1;
> }
> ```
>
> **复杂度**：$T(n) = O(n)$，$S(n) = O(1)$

> [!tip] 408 常考变形
> - 求两个有序表的中位数（2011 真题）
> - 求两个有序表的公共元素
> - 有序表合并后去重


### 六、题型四：有序表去重

**适用场景**：有序顺序表中删除重复元素，每个值只保留一个。

```cpp
void RemoveDuplicates(SqList &L) {
    if (L.length <= 1) return;
    int k = 0;
    for (int i = 1; i < L.length; i++) {
        if (L.data[i] != L.data[k]) {
            L.data[++k] = L.data[i];
        }
    }
    L.length = k + 1;
}
```

**复杂度**：$T(n) = O(n)$，$S(n) = O(1)$


### 七、题型五：查找 + 删除（末位填补）

**适用场景**：查找特定元素并删除，**不要求保持原序**。

```cpp
bool DeleteByFill(SqList &L, ElemType &value) {
    if (L.length == 0) return false;
    int pos = 0;
    for (int i = 1; i < L.length; i++) {
        if (L.data[i] < L.data[pos]) pos = i;   // 找最小值
    }
    value = L.data[pos];
    L.data[pos] = L.data[L.length - 1];
    L.length--;
    return true;
}
```


### 八、题型六：多指针贪心

**适用场景**：多个有序数组，求满足条件的最优组合。

> [!example] **2020 统考真题：三元组最小距离**
>
> **题目**：定义三元组 $(a,b,c)$ 的距离 $D = |a-b| + |b-c| + |c-a|$。给定三个升序数组，求所有三元组中的最小距离。
>
> **思路**：三指针 + 贪心——每次移动当前最小元素对应的指针。
>
> ```cpp
> int calcDistance(int a, int b, int c) {
>     return abs(a - b) + abs(b - c) + abs(c - a);
> }
>
> int findMinDistance(int S1[], int n1, int S2[], int n2, int S3[], int n3) {
>     int i = 0, j = 0, k = 0;
>     int minDist = INT_MAX;
>
>     while (i < n1 && j < n2 && k < n3) {
>         int a = S1[i], b = S2[j], c = S3[k];
>         minDist = min(minDist, calcDistance(a, b, c));
>
>         // 移动最小元素对应的指针
>         if (a <= b && a <= c) i++;
>         else if (b <= a && b <= c) j++;
>         else k++;
>     }
>     return minDist;
> }
> ```
>
> **复杂度**：$T(n) = O(n_1 + n_2 + n_3)$，$S(n) = O(1)$

> [!example] 数学原理（数一关联）
> $$|a-b| + |b-c| + |c-a| = 2 \times (\max(a,b,c) - \min(a,b,c))$$
>
> 因此最小化 $D$ 等价于最小化三个数中最大值与最小值的差。每次移动最小值指针是贪心最优策略。

> [!tip] 应试技巧
> 顺序表大题几乎都能归入以上六种题型。考试时：
> 1. **判断题型** → 套用对应框架
> 2. **补充边界条件**（空表、单元素、指针越界）
> 3. **注意引用传递**（C++ 中用 `&`）
> 4. **计算复杂度**（通常 $O(n)$）
