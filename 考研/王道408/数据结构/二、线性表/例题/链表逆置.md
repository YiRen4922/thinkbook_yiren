# 链表逆置（两种经典方法）

> [!abstract] 概述
> 单链表逆置是考研和面试最高频的链表题之一。  
> 本文整理两种最常用的 \(O(1)\) 空间解法：
> 1. **头插法**
> 2. **三指针原地反转法**

---

## 一、头插法

### 核心思想
把原链表的节点**一个一个取下来**，每次都插入到新链表的**最前面**。

因为后取的节点总是插到最前面，所以自然形成逆序。

### 图解过程

原链表：`1 -> 2 -> 3 -> 4 -> nullptr`

| 步骤 | 操作说明                  | 新链表状态              |
|------|---------------------------|-------------------------|
| 1    | 取1，插到新链表头部       | `1 -> nullptr`          |
| 2    | 取2，插到新链表头部       | `2 -> 1 -> nullptr`     |
| 3    | 取3，插到新链表头部       | `3 -> 2 -> 1 -> nullptr`|
| 4    | 取4，插到新链表头部       | `4 -> 3 -> 2 -> 1 -> nullptr` |

### 代码实现

```cpp
ListNode* reverseList_HeadInsert(ListNode* head) {
    ListNode* newHead = nullptr;   // 新链表头
    ListNode* p = head;

    while (p != nullptr) {
        ListNode* temp = p->next;  // 先保存下一个节点（防止断链）

        // 头插关键三步
        p->next = newHead;
        newHead = p;

        p = temp;                  // 继续处理下一个
    }
    return newHead;
}
```

### 记忆口诀
> **保存下一个 → 断链头插 → 更新新头 → 继续前进**

## 二、三指针原地反转法

### 核心思想
不新建链表，直接在原链表上修改指针方向。  
使用三个指针 `pre`、`cur`、`next` 完成原地反转。

### 图解过程

原链表：`1 -> 2 -> 3 -> 4 -> nullptr`

初始：`pre = nullptr`，`cur = 1`

| 步骤 | 操作 | 链表状态 |
|------|------|----------|
| 1 | 反转1的指针 | `1 -> nullptr`，剩余 `2->3->4` |
| 2 | 反转2的指针 | `2 -> 1 -> nullptr` |
| 3 | 反转3的指针 | `3 -> 2 -> 1 -> nullptr` |
| 4 | 反转4的指针 | `4 -> 3 -> 2 -> 1 -> nullptr` |

最终 `pre` 指向新的头节点。

### 代码实现

```cpp
ListNode* reverseList_ThreePointers(ListNode* head) {
    ListNode* pre = nullptr;
    ListNode* cur = head;

    while (cur != nullptr) {
        ListNode* next = cur->next;  // 1. 保存下一个节点

        cur->next = pre;             // 2. 反转指针

        // 3. 后移
        pre = cur;
        cur = next;
    }
    return pre;   // pre 就是新的头
}
```

### 记忆口诀
> **保存 next → 反转指针 → pre 和 cur 后移**

---

## 三、两种方法对比

| 对比项         | 头插法                     | 三指针原地反转法             |
|----------------|----------------------------|------------------------------|
| 是否原地修改   | 逻辑上使用新头指针         | 完全原地修改                 |
| 额外空间       | \(O(1)\)                   | \(O(1)\)                     |
| 指针数量       | 2个                        | 3个                          |
| 理解难度       | 更直观                     | 需要仔细跟踪指针变化         |
| 考研出现频率   | 高                         | 非常高                       |
| 推荐场景       | 初学理解、写题快速         | 面试/考试首选                |

**时间复杂度**：两种都是 \(O(n)\)  
**空间复杂度**：两种都是 \(O(1)\)

## 四、完整测试代码

```cpp
#include <iostream>
using namespace std;

struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};

// 头插法
ListNode* reverseList_HeadInsert(ListNode* head) {
    ListNode* newHead = nullptr;
    ListNode* p = head;
    while (p != nullptr) {
        ListNode* temp = p->next;
        p->next = newHead;
        newHead = p;
        p = temp;
    }
    return newHead;
}

// 三指针法
ListNode* reverseList_ThreePointers(ListNode* head) {
    ListNode* pre = nullptr;
    ListNode* cur = head;
    while (cur != nullptr) {
        ListNode* next = cur->next;
        cur->next = pre;
        pre = cur;
        cur = next;
    }
    return pre;
}

// 打印链表
void printList(ListNode* head) {
    while (head) {
        cout << head->val;
        if (head->next) cout << " -> ";
        head = head->next;
    }
    cout << endl;
}

int main() {
    // 构造链表 1 -> 2 -> 3 -> 4
    ListNode* head = new ListNode(1);
    head->next = new ListNode(2);
    head->next->next = new ListNode(3);
    head->next->next->next = new ListNode(4);

    cout << "原链表: ";
    printList(head);

    // 使用三指针法逆置（也可以换成头插法）
    ListNode* reversed = reverseList_ThreePointers(head);

    cout << "逆置后: ";
    printList(reversed);   // 4 -> 3 -> 2 -> 1

    return 0;
}
```

## 五、考研/面试提醒

1. 两种方法都必须掌握，尤其是**三指针法**。
2. 一定要先保存 `next`，否则会断链，这是最容易出错的地方。
3. 空链表和只有一个节点的情况也要能正确处理（两种代码都已覆盖）。
4. 如果题目要求返回新链表且不能修改原链表，则需要新建节点。
