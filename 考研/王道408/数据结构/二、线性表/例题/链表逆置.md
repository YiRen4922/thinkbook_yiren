## 单链表原地逆置 · 考研408笔记

> 单链表逆置是 408 链表题中最**高频**的考点之一，要求**不申请新结点**，仅通过修改指针实现反转。


### 一、题目描述

编写算法，将带头结点的单链表 $L$ **原地逆置**。要求空间复杂度为 $O(1)$。


### 二、算法思想（迭代头插法）

**核心思路**：将原链表中的每个结点，依次**摘下**并插入到头结点之后。

**具体步骤**：
1. 将原链表拆分为**空链表**（只有头结点）和**剩余结点**两部分
2. 依次遍历剩余结点，将每个结点用**头插法**插入到头结点之后
3. 遍历完成后，链表自然逆置


### 三、代码实现（C++）

```cpp
void Reverse(LinkList &L) {
    if (L == NULL || L->next == NULL) return;   // 空表或单元素表无需逆置

    LNode *p = L->next;      // p 指向待处理链表的第一个结点
    L->next = NULL;          // 将头结点与后续结点断开，构建空链表

    while (p != NULL) {
        LNode *q = p->next;  // 保存 p 的后继，防止丢失
        p->next = L->next;   // 头插法：p 指向当前第一个结点
        L->next = p;         // 头结点指向 p
        p = q;               // p 后移
    }
}
```


### 四、时空复杂度

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| 时间复杂度 | **$O(n)$** | 遍历一次链表 |
| 空间复杂度 | **$O(1)$** | 只用常数个辅助指针 |


### 五、执行过程示例

**输入**：`L = 头 → 1 → 2 → 3 → 4 → NULL`

| 步骤 | 操作 | 链表状态 |
|------|------|----------|
| 初始 | `L->next = NULL` | 头 → NULL；待处理：1→2→3→4 |
| 第1轮 | 摘下 1，头插 | 头 → 1 → NULL；待处理：2→3→4 |
| 第2轮 | 摘下 2，头插 | 头 → 2 → 1 → NULL；待处理：3→4 |
| 第3轮 | 摘下 3，头插 | 头 → 3 → 2 → 1 → NULL；待处理：4 |
| 第4轮 | 摘下 4，头插 | 头 → 4 → 3 → 2 → 1 → NULL |

**输出**：`头 → 4 → 3 → 2 → 1 → NULL` ✅


### 六、注意事项

| 要点 | 说明 |
|------|------|
| **保存后继** | 必须先 `q = p->next`，再改 `p->next`，否则会丢失后续链表 |
| **头结点处理** | 必须先将 `L->next = NULL`，否则会形成环 |
| **判空** | 空表或单元素表无需逆置 |
| **带头结点** | 题目明确“带头结点”，头结点不参与逆置 |


### 七、常犯错误

| 错误写法 | 问题 | 正确做法 |
|----------|------|----------|
| `p = p->next` 写在头插之前 | 丢失后继指针 | 先用 `q` 保存 `p->next` |
| 不设置 `L->next = NULL` | 头结点仍指向原首元，形成环 | 先 `L->next = NULL` |
| 直接修改头结点数据 | 头结点不应参与逆置 | 头结点只作为哨兵 |


### 八、递归法（扩展，不常用）

```cpp
ListNode* reverseRecursive(ListNode* head) {
    if (!head || !head->next) return head;
    ListNode *newHead = reverseRecursive(head->next);
    head->next->next = head;
    head->next = NULL;
    return newHead;
}
```

**复杂度**：$T(n) = O(n)$，$S(n) = O(n)$（递归栈），空间不满足 $O(1)$，考研中**不推荐**。
