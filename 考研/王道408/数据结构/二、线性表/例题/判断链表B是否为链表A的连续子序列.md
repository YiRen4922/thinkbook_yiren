判断链表B是否为A的连续子序列 · 考研408笔记

本题是链表模式匹配的经典问题，类似于字符串中的子串查找，但需考虑链表的顺序访问特性。

一、题目描述

两个整数序列 $A = a_1, a_2, \dots, a_m$ 和 $B = b_1, b_2, \dots, b_n$ 已分别存入两个单链表（带头结点）。设计一个算法，判断序列 $B$ 是否为序列 $A$ 的连续子序列。

二、算法思想

核心思路：枚举 $A$ 中每个结点作为起点，与 $B$ 的结点逐位比较。

具体步骤：

1. 用指针 pa 遍历 $A$ 的每个结点（作为匹配起点）
2. 对于每个起点，用 p 指向 pa，q 指向 $B$ 的首元结点
3. 同步遍历比较：
   · 若 p->data == q->data，则 p 和 q 同时后移
   · 若不等，跳出，换下一个起点
4. 若 q 遍历到 NULL（$B$ 完全匹配），返回 true
5. 若 pa 到 NULL 仍未匹配，返回 false

[!tip] 优化
若 $n > m$，$B$ 不可能成为 $A$ 的子序列，可直接返回 false（需先求表长，但本题可省略，因遍历过程中自然会失败）。

三、代码实现（C++）

```cpp
bool IsSubsequence(LinkList A, LinkList B) {
    if (B->next == NULL) return true;        // 空序列视为任意序列的子序列
    if (A->next == NULL) return false;       // A空而B非空，不可能

    LNode *pa = A->next;            // A 的起点指针
    LNode *pb = B->next;            // B 的首元结点

    while (pa != NULL) {
        LNode *p = pa;              // 从当前起点开始匹配
        LNode *q = pb;

        while (p != NULL && q != NULL && p->data == q->data) {
            p = p->next;
            q = q->next;
        }

        if (q == NULL) return true; // B 全部匹配成功
        pa = pa->next;              // 否则换下一个起点
    }

    return false;
}
```

四、时空复杂度

指标 复杂度 说明
时间复杂度 $O(m \times n)$ 最坏情况下（如 $A$ 和 $B$ 除最后一位外都匹配），需枚举 $O(m)$ 个起点，每个比较 $O(n)$
空间复杂度 $O(1)$ 只用常数个辅助指针

五、执行过程示例

输入：

· $A$ = 头 → 1 → 2 → 3 → 4 → 5
· $B$ = 头 → 2 → 3 → 4

起点 pa 匹配过程 结果
1 1≠2 失败，pa 后移
2 2=2，3=3，4=4，B 结束 ✅ 匹配成功

六、注意事项

要点 说明
空表处理 $B$ 为空，视为任意 $A$ 的子序列；$A$ 为空且 $B$ 非空，返回 false
匹配失败后起点移动 每次匹配失败后，pa = pa->next，继续枚举下一个起点
匹配成功标志 q == NULL 表示 $B$ 中所有结点都已匹配
带头结点 遍历从 A->next 和 B->next 开始，头结点不参与比较

七、变式思考

变式 改动点
返回匹配起点 若匹配成功，返回 pa 起始结点；否则返回 NULL
允许重复匹配（KMP思想） 可先对 $B$ 求 next 数组，进行链表 KMP，时间复杂度优化至 $O(m+n)$，但实现复杂
双向链表 若为双向链表，可考虑从两端加速匹配，但本题不涉及
