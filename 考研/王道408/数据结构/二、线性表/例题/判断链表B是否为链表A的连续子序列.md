## 算法题：判断链表B是否为链表A的连续子序列

> **题意**：$A$、$B$ 为两个**带头结点的单链表**，判断 $B$ 是否是 $A$ 的一段**连续子序列**（子串）。

**示例**：
- $A = 1 \to 2 \to 3 \to 4 \to 5$，$B = 2 \to 3 \to 4$ → ✅ 是连续子序列
- $A = 1 \to 2 \to 3 \to 4 \to 5$，$B = 1 \to 3$ → ❌ 不是（不连续）


### 一、算法基本设计思想

1. 指针 `start` 遍历 $A$ 链表；对于 $A$ 中每一个结点，尝试以此结点作为匹配起点，和 $B$ 链表从头开始逐结点比对。
2. 设置指针 `q` 用于遍历 $B$；每次匹配尝试前，`q` 重置到 $B$ 的头结点。
3. 若 `p->data == q->data`，则 `p`、`q` 同时后移，继续比对下一个结点：
   - 若 `q == NULL`：$B$ 全部匹配完毕，找到连续子序列，返回 `true`。
   - 若中途元素不相等：本次匹配失败，**`start` 后移一位**，`q` 重置到 $B$ 表头，开启下一轮尝试。
4. 若 $A$ 遍历完毕仍未完整匹配 $B$，返回 `false`。

> [!note] 为什么需要 `start`？
> 单链表**不能回退**，因此每一轮匹配前必须用 `start` 保存当前起点的位置，用 `p` 向前探测匹配，而不用 `start` 直接移动。

> [!tip] 空表处理
> 若 $B$ 为空，按题意通常视为任意序列的子序列，返回 `true`。若 $A$ 为空且 $B$ 非空，返回 `false`。


### 二、链表结点定义

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;
```


### 三、C 代码实现

```c
// 判断 B 是否是 A 的连续子序列，是返回 1，否返回 0
int IsContinuousSubSeq(LinkList A, LinkList B) {
    LNode *start = A->next;   // start：A 中每一轮匹配的起始结点（跳过头结点）
    LNode *p, *q;

    // start 遍历 A 所有可能的匹配起点
    while (start != NULL) {
        p = start;
        q = B->next;          // q 指向 B 的首元结点

        // 从 start 开始，连续比对
        while (p != NULL && q != NULL && p->data == q->data) {
            p = p->next;
            q = q->next;
        }

        // q 走到 NULL：B 全部匹配完成
        if (q == NULL) {
            return 1;
        }

        // 当前起点匹配失败，起点往后挪一位
        start = start->next;
    }

    return 0;
}
```


### 四、执行过程推演

**示例 1**：$A = 1 \to 2 \to 3 \to 4 \to 5$，$B = 2 \to 3 \to 4$

| 轮次 | start | 匹配过程 | 结果 |
|------|-------|----------|------|
| 1 | 1 | `1 ≠ 2` | 失败，start 后移 |
| 2 | 2 | `2=2`，`3=3`，`4=4`，q 到 NULL | ✅ 成功 |

**示例 2**：$A = 1 \to 2 \to 3 \to 4 \to 5$，$B = 3 \to 5$

| 轮次 | start | 匹配过程 | 结果 |
|------|-------|----------|------|
| 1 | 1 | `1 ≠ 3` | 失败 |
| 2 | 2 | `2 ≠ 3` | 失败 |
| 3 | 3 | `3=3`，`4 ≠ 5` | 失败 |
| 4 | 4 | `4 ≠ 3` | 失败 |
| 5 | 5 | `5 ≠ 3` | 失败，返回 0 |


### 五、时空复杂度

设 $A$ 长度为 $m$，$B$ 长度为 $n$。

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| 时间复杂度 | **$O(m \times n)$** | 最坏情况下，每个 $A$ 的位置最多匹配 $B$ 一遍 |
| 空间复杂度 | **$O(1)$** | 只用若干指针变量 |

> [!note] KMP 优化
> 可用 KMP 思想优化至 $O(m+n)$，但链表**不支持随机访问**，实现复杂。统考大题直接写朴素双重循环即可。


### 六、考试易错点

| 易错点 | 正确理解 |
|--------|----------|
| **连续子序列 vs 普通子序列** | 本题要求**连续**，一旦中间一个对不上，本轮全部作废，起点移动到下一个结点 |
| **单链表不能回退** | 必须用 `start` 保存本轮起点，`p` 用来向前探测匹配 |
| **终止条件** | `q == NULL` 代表 $B$ 全部匹配成功，直接返回 |
| **不要把 `p` 当起点** | `p` 会往前走，丢失起始位置，必须用 `start` 保存 |


### 七、答题背诵版（写在试卷上）

> 用 `start` 指针依次取 $A$ 的每个结点作为匹配起始点；每一轮 `p` 从 `start` 出发、`q` 从 $B$ 表头出发，循环比较对应结点数据；若 `q` 遍历完毕说明 $B$ 全部匹配成功，返回真；否则 `start` 后移，继续下一轮；$A$ 遍历结束仍未匹配成功返回假。
