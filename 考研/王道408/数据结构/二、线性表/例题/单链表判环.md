## 单链表判环 · 考研408笔记

> 单链表判环是链表双指针技巧的经典应用，也是408高频考点。核心思想是**快慢指针**（Floyd判圈算法）。


### 一、题目描述

单链表有环，是指单链表的最后一个结点的指针指向了链表中的某个结点（通常单链表的最后一个结点的指针域是空的）。试编写算法判断单链表是否存在环。


### 二、算法基本设计思想

**核心思路**：快慢指针（Floyd判圈算法）

设置两个指针 `slow` 和 `fast`，初始都指向头结点：

- `slow` 每次向后移动**一步**（`slow = slow->next`）
- `fast` 每次向后移动**两步**（`fast = fast->next->next`）

若链表中存在环，则 `fast` 和 `slow` 最终会在环内**相遇**（`slow == fast`）。若不存在环，`fast` 会先到达 `NULL` 并终止。

> [!example] 为什么一定会相遇？
> `slow` 和 `fast` 进入环后，可视为 `fast` 在追赶 `slow`。每走一轮，两者的距离差减少 1，因此有限步内必相遇。


### 三、代码实现（C++）

```cpp
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;

bool HasCycle(LinkList L) {
    if (L == NULL || L->next == NULL) {
        return false;                // 空表或只有一个结点，不可能有环
    }

    LNode *slow = L;                 // 慢指针，每次走一步
    LNode *fast = L;                 // 快指针，每次走两步

    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;           // 走一步
        fast = fast->next->next;     // 走两步

        if (slow == fast) {
            return true;             // 相遇，有环
        }
    }

    return false;                    // fast 到达 NULL，无环
}
```


### 四、执行过程示例

**有环链表**：`1 → 2 → 3 → 4 → 5 → 3`（5指向3，形成环）

| 轮次 | slow 位置 | fast 位置 | 是否相遇 |
|------|-----------|-----------|----------|
| 初始 | 1 | 1 | — |
| 第1轮 | 2 | 3 | 否 |
| 第2轮 | 3 | 5 | 否 |
| 第3轮 | 4 | 4（走两步：5→3→4） | ✅ 相遇 |


### 五、时空复杂度

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| 时间复杂度 | **$O(n)$** | $n$ 为链表结点数。若无环，`fast` 先到 `NULL`；若有环，`slow` 和 `fast` 在环内相遇，最多走 $O(n)$ 步 |
| 空间复杂度 | **$O(1)$** | 只用了 `slow` 和 `fast` 两个指针 |


### 六、注意事项

| 要点 | 说明 |
|------|------|
| **判空** | 若链表为空或只有一个结点，直接返回 `false` |
| **fast 移动条件** | `fast->next != NULL` 保证 `fast->next->next` 不越界 |
| **相遇证明** | `slow == fast` 说明快指针追上了慢指针，环存在 |
| **头结点** | 若带头结点，`slow = L`，`fast = L` 从头结点出发；也可从 `L->next` 出发，效果相同 |
| **死循环风险** | 若无环但 `fast` 移动未检查 `fast->next`，会访问空指针 |


### 七、扩展考点

| 扩展问题 | 思路 |
|----------|------|
| **求环的长度** | 相遇后，`slow` 继续走，再次遇到 `fast` 时走的步数即为环长 |
| **求环的入口结点** | 相遇后，将 `slow` 重置为头结点，`fast` 留在相遇点，两者同步走（均每次一步），再次相遇处即为环入口 |
| **求链表总长度** | 环入口前长度 + 环长 |


### 八、易错与易混点

| 易错判断 | 正确理解 |
|----------|----------|
| “`slow` 和 `fast` 初始都指向头结点，会一直相等” | `slow` 和 `fast` 在循环开始后才会移动，初始相等不影响 |
| “`fast` 每次走三步更高效” | 走两步是经典方案，走三步可能跳过相遇点，增加判断复杂度 |
| “有环则 `fast` 一定比 `slow` 多走一圈” | 不一定是一圈，可能是若干圈，但必相遇 |
