## 有序顺序表去重 · 考研408笔记


### 顺序表类型定义

```cpp
#define MaxSize 100

typedef struct {
    ElemType data[MaxSize];
    int length;
} SqList;
```


### 一、题目要求

从**有序顺序表**中删除所有其值重复的元素，使表中所有元素的值均不同。


### 二、算法思想

**双指针法**：

由于顺序表**有序**，重复元素必然**相邻存放**。设置两个指针：
- `i`：遍历指针，从 1 开始逐个扫描
- `k`：去重后新表的**最后一个元素下标**（即当前已确认的不重复元素个数 - 1）

遍历过程中，若当前元素 `data[i]` **不等于** `data[k]`，说明遇到了新值，将其放入 `data[++k]` 位置；若相等则跳过。最终表长为 `k + 1`。

> 本质：利用有序表的**有序性**，只需比较相邻元素，一次扫描完成去重。


### 三、代码实现

```cpp
void RemoveDuplicates(SqList &L) {
    if (L.length <= 1) return;        // 空表或单元素表无需去重

    int k = 0;                         // k 指向去重后新表的最后一个元素

    for (int i = 1; i < L.length; i++) {
        if (L.data[i] != L.data[k]) {  // 遇到不重复的新元素
            L.data[++k] = L.data[i];   // 放入新表尾部
        }
        // 若相等，跳过
    }

    L.length = k + 1;                  // 更新表长
}
```


### 四、时空复杂度

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| 时间复杂度 | **$O(n)$** | 只遍历一次顺序表 |
| 空间复杂度 | **$O(1)$** | 仅用两个整型变量 |


### 五、执行过程示例

**输入**：`L = [1, 2, 2, 2, 3, 3, 4, 5, 5]`

| 轮次 | i | data[i] | k | data[k] | 操作 | 数组状态 |
|------|---|---------|---|---------|------|----------|
| 初始 | — | — | 0 | 1 | — | `[1, 2, 2, 2, 3, 3, 4, 5, 5]` |
| 1 | 1 | 2 | 0 | 1 | `2 != 1`，放入 `data[1]` | `[1, 2, 2, 2, 3, 3, 4, 5, 5]` |
| 2 | 2 | 2 | 1 | 2 | `2 == 2`，跳过 | — |
| 3 | 3 | 2 | 1 | 2 | `2 == 2`，跳过 | — |
| 4 | 4 | 3 | 1 | 2 | `3 != 2`，放入 `data[2]` | `[1, 2, 3, 2, 3, 3, 4, 5, 5]` |
| 5 | 5 | 3 | 2 | 3 | `3 == 3`，跳过 | — |
| 6 | 6 | 4 | 2 | 3 | `4 != 3`，放入 `data[3]` | `[1, 2, 3, 4, 3, 3, 4, 5, 5]` |
| 7 | 7 | 5 | 3 | 4 | `5 != 4`，放入 `data[4]` | `[1, 2, 3, 4, 5, 3, 4, 5, 5]` |
| 8 | 8 | 5 | 4 | 5 | `5 == 5`，跳过 | — |

最终：`L.length = 5`，有效数据为 `[1, 2, 3, 4, 5]` ✅


### 六、与无序顺序表去重的对比

| 对比项 | 有序顺序表 | 无序顺序表 |
|--------|-----------|-----------|
| 重复元素位置 | **相邻** | 分散在各处 |
| 去重方法 | **一次扫描**，$O(n)$ | 需双重循环或哈希表 |
| 时间复杂度 | $O(n)$ | $O(n^2)$（无哈希）或 $O(n)$（哈希） |
| 空间复杂度 | $O(1)$ | $O(1)$ 或 $O(n)$ |

> 有序性使得算法设计大大简化——只需比较 `data[i]` 与 `data[k]`，而非与前面所有元素比较。


### 七、注意事项

| 要点 | 说明 |
|------|------|
| **有序前提** | 算法依赖于“有序”，若非有序，需先排序或改用其他方法 |
| **`k` 的初始化** | `k = 0`，从第一个元素开始（第一个元素必然保留） |
| **循环起点** | `i = 1`，从第二个元素开始扫描 |
| **表长更新** | 最终 `length = k + 1`（因为 `k` 是下标，元素个数为 `k + 1`） |
| **边界情况** | 空表或单元素表直接返回 |


### 八、扩展应用

| 变式 | 思路变化 |
|------|----------|
| 删除重复元素（保留一个） | 即本题 |
| 删除所有重复元素（一个不留） | 需判断相邻元素是否相等，额外处理边界 |
| 统计每种元素出现次数 | 同样利用有序性，一次扫描统计 |
| 有序链表去重 | 指针移动逻辑相同（`p = p->next`，跳过重复节点） |


### 总结

```
有序表去重的通用模板（双指针压缩法）：

k = 0                              // 新表最后一个元素下标
for i = 1 to L.length - 1:
    if L.data[i] != L.data[k]:     // 遇到新值
        L.data[++k] = L.data[i]    // 放入新表尾部
L.length = k + 1
```

**核心思想**：利用有序性，重复元素必相邻，只需**比较相邻元素**即可判断是否重复。一次遍历完成去重，时间复杂度 $O(n)$，空间复杂度 $O(1)$，是同类问题的最优解。
