## 2019统考真题 · 单链表重排

> 本题综合考察了**快慢指针找中点**、**链表反转**和**链表合并**三个经典操作，是408链表大题的典型代表。


### 一、题目描述

设线性表 $L = (a_1, a_2, a_3, \dots, a_{n-2}, a_{n-1}, a_n)$ 采用带头结点的单链表保存。请设计一个**空间复杂度为 $O(1)$** 且**时间上尽可能高效**的算法，重新排列 $L$ 中的各结点，得到线性表：

$$
L' = (a_1, a_n, a_2, a_{n-1}, a_3, a_{n-2}, \dots)
$$

**结点定义**：
```cpp
typedef struct node {
    int data;
    struct node *next;
} NODE;
```


### 二、算法基本设计思想

**核心思路**：将链表从中间断开，反转后半段，然后交替合并。

**具体步骤**：

1. **找中间结点**：用快慢指针找到链表的中间结点
   - `slow` 每次走一步，`fast` 每次走两步
   - `fast` 到达末尾时，`slow` 指向中间结点

2. **断开链表**：将链表从中间分为前后两段
   - 后半段头结点为 `slow->next`
   - 将 `slow->next = NULL`，切断前后联系

3. **反转后半段**：将后半段链表原地逆置

4. **交替合并**：将前半段和反转后的后半段交替合并
   - 按 `a1 → b1 → a2 → b2 → ...` 的顺序链接


### 三、代码实现（C++）

```cpp
typedef struct node {
    int data;
    struct node *next;
} NODE, *LinkList;

void Rearrange(LinkList L) {
    if (L == NULL || L->next == NULL) return;

    // ========== 第一步：快慢指针找中间结点 ==========
    NODE *slow = L;          // 慢指针，每次走一步
    NODE *fast = L;          // 快指针，每次走两步

    while (fast->next != NULL && fast->next->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
    }
    // 循环结束时，slow 指向中间结点（前段最后一个结点）

    // ========== 第二步：断开前后两段 ==========
    NODE *head2 = slow->next;    // head2 为后半段头结点
    slow->next = NULL;           // 切断前后联系

    // ========== 第三步：反转后半段链表 ==========
    NODE *prev = NULL;
    NODE *cur = head2;
    NODE *next = NULL;

    while (cur != NULL) {
        next = cur->next;
        cur->next = prev;
        prev = cur;
        cur = next;
    }
    head2 = prev;                // 反转后的后半段头结点

    // ========== 第四步：交替合并两段 ==========
    NODE *p = L->next;           // 前半段指针
    NODE *q = head2;             // 后半段指针
    NODE *tail = L;              // 结果链表尾指针

    while (p != NULL && q != NULL) {
        // 插入前半段结点
        tail->next = p;
        tail = p;
        p = p->next;

        // 插入后半段结点
        tail->next = q;
        tail = q;
        q = q->next;
    }

    // 若前半段还有剩余（n为奇数时），接到尾部
    if (p != NULL) {
        tail->next = p;
        tail = p;
    }

    // 若后半段还有剩余（n为偶数时，实际上后半段长度 ≤ 前半段，不会剩余）
    if (q != NULL) {
        tail->next = q;
    }

    tail->next = NULL;
}
```


### 四、执行过程示例

**输入**：$L =$ 头 → 1 → 2 → 3 → 4 → 5 → 6 → 7 → NULL（$n=7$）

| 步骤 | 操作 | 链表状态 |
|------|------|----------|
| 初始 | — | 头 → 1 → 2 → 3 → 4 → 5 → 6 → 7 |
| 找中点 | `slow` 指向 4 | — |
| 断开 | 前段：头 → 1 → 2 → 3 → 4；后段：5 → 6 → 7 | — |
| 反转后段 | — | 后段：7 → 6 → 5 |
| 交替合并 | — | 头 → 1 → 7 → 2 → 6 → 3 → 5 → 4 ✅ |


### 五、时空复杂度

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| 时间复杂度 | **$O(n)$** | 找中点 $O(n)$ + 反转 $O(n)$ + 合并 $O(n)$ = $O(n)$ |
| 空间复杂度 | **$O(1)$** | 只用了常数个辅助指针 |


### 六、注意事项

| 要点 | 说明 |
|------|------|
| **快慢指针终止条件** | `fast->next != NULL && fast->next->next != NULL`，确保 $n=1,2$ 时正确处理 |
| **断开链表** | 必须将 `slow->next = NULL`，否则前后段仍相连 |
| **合并条件** | 用 `while (p && q)`，最后处理剩余结点 |
| **带头结点** | 头结点不参与重排，始终作为结果链表的哨兵 |
| **尾指针置空** | 合并结束后必须 `tail->next = NULL` |


### 七、408命题规律总结

本题综合了链表的**三大核心操作**：

| 操作 | 方法 | 时间复杂度 | 用途 |
|------|------|-----------|------|
| **找中间结点** | 快慢指针 | $O(n)$ | 将链表分为前后两段 |
| **链表反转** | 三指针迭代 | $O(n)$ | 使后半段逆序，便于交替合并 |
| **链表合并** | 交替链接 | $O(n)$ | 按 `a1→b1→a2→b2→...` 模式重组 |
