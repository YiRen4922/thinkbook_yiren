## 顺序表删除最小值 · 解题框架

> 本题是顺序表“查找 + 删除”组合操作的经典代表，核心框架可套用于**所有“查找 + 删除”类题目**。


### 顺序表类型定义

```cpp
#define MaxSize 100

typedef struct {
    ElemType data[MaxSize];   // 存储空间（静态分配）
    int length;               // 当前表长
} SqList;
```

> 若采用**动态分配**，定义稍有不同：
> ```cpp
> typedef struct {
>     ElemType *data;         // 动态分配数组指针
>     int length;             // 当前表长
>     int maxSize;            // 最大容量
> } SqList;
> ```

后续代码均基于上述 `SqList` 类型定义。


### 一、题目要求

从顺序表中删除具有最小值的元素（假设唯一），由函数返回被删元素值，空位由**最后一个元素**填补。表空时显示错误信息并退出。


### 二、解题框架（三步走）

| 步骤 | 操作 | 说明 |
|------|------|------|
| **Step 1** | **合法性检查** | 表空 → 报错退出 |
| **Step 2** | **查找目标** | 遍历找最小值及其下标 |
| **Step 3** | **删除与填补** | 用最后一个元素覆盖目标位置，表长减 1 |


### 三、伪代码框架

```
函数 DeleteMin(L, &value):
    如果 L.length == 0:
        输出错误信息并退出

    minPos = 0
    循环 i = 1 到 L.length - 1:
        如果 L.data[i] < L.data[minPos]:
            minPos = i

    value = L.data[minPos]
    L.data[minPos] = L.data[L.length - 1]   // 最后一个元素填补
    L.length = L.length - 1

    返回 true 和 value
```


### 四、代码实现（C++）

```cpp
bool DeleteMin(SqList &L, ElemType &value) {
    // Step 1: 判空
    if (L.length == 0) {
        cout << "顺序表为空！" << endl;
        return false;
    }

    // Step 2: 查找最小值
    int minPos = 0;
    for (int i = 1; i < L.length; i++) {
        if (L.data[i] < L.data[minPos]) {
            minPos = i;
        }
    }

    // Step 3: 删除与填补
    value = L.data[minPos];
    L.data[minPos] = L.data[L.length - 1];
    L.length--;

    return true;
}
```


### 五、时空复杂度

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| 时间复杂度 | **$O(n)$** | 需遍历整个表查最小值 |
| 空间复杂度 | **$O(1)$** | 仅用常数个辅助变量 |


### 六、图示（填补过程）

```
删除前:  [5, 2, 8, 1, 9]    最小值 = 1 (下标 3)
                              ↓ 用最后一个元素 9 填补
删除后:  [5, 2, 8, 9, _]    length = 4
```


### 七、注意事项

| 要点 | 说明 |
|------|------|
| **引用传递** | 需修改表结构，参数用 `&L` |
| **最小值初始化** | `minPos = 0`（表非空时才安全） |
| **填补顺序** | 先取 `value`，再填补，最后 `length--` |
| **最后一个元素** | 用 `data[length-1]`（原表尾） |


### 八、本题框架的扩展应用

| 变式 | 改动点 | 框架适用性 |
|------|--------|-----------|
| 删除最大值 | 比较符号改为 `>` | ✅ 完全适用 |
| 删除最小值的所有重复 | 改查找为统计 + 批量覆盖 | ⚠️ 需扩充 Step 3 |
| 删除第 i 个元素（保持顺序） | 改为后续前移 | ❌ 不适用此框架 |
| 删除所有值为 x 的元素 | 双指针法（另作专题） | ❌ 不适用 |


### 总结

```
查找 + 删除类问题的通用步骤：
1. 判空 → 2. 遍历找目标 → 3. 删除（覆盖 / 移动 / 填补）→ 4. 更新表长
```

本题的核心在于 **“用最后一个元素填补”** ，打破了常规删除需要移动元素的思维定式，体现了**破坏顺序换取效率**的思想。掌握这个框架，遇到类似“删除 + 返回被删值”的题目均可复用。
