## 数据结构 · 链表综合应用题（考研408核心笔记）

> 链表是 408 数据结构部分**出题频率最高**的内容之一，常与递归、双指针、环检测、排序等算法结合考查。本篇系统梳理链表的**十大经典题型**，每种题型均给出一题多解、核心代码及复杂度分析。


### 一、题型分类总览

| 题型            | 核心方法        | 时间复杂度           | 空间复杂度             |
| ------------- | ----------- | --------------- | ----------------- |
| **链表反转**      | 迭代头插 / 递归   | $O(n)$          | $O(1)$ / $O(n)$   |
| **链表判环**      | 快慢指针（Floyd） | $O(n)$          | $O(1)$            |
| **链表合并**      | 二路归并（递归/迭代） | $O(m+n)$        | $O(1)$ / $O(m+n)$ |
| **链表去重**      | 双指针 / 哈希表   | $O(n)$          | $O(1)$ / $O(n)$   |
| **链表拆分**      | 双指针尾插       | $O(n)$          | $O(1)$            |
| **链表交点**      | 双指针（交替走）    | $O(m+n)$        | $O(1)$            |
| **删除倒数第 k 个** | 快慢指针        | $O(n)$          | $O(1)$            |
| **链表排序**      | 归并排序（自顶向下）  | $O(n\log n)$    | $O(\log n)$       |
| **约瑟夫环**      | 循环链表模拟      | $O(n \times m)$ | $O(n)$            |
| **双向链表操作**    | 指针修改（四步法）   | $O(1)$          | $O(1)$            |


### 二、链表结点定义（统一约定） 

```cpp
struct ListNode {
    int val;
    ListNode *next;
    ListNode(int x) : val(x), next(NULL) {}
};

struct DListNode {
    int val;
    DListNode *prev;
    DListNode *next;
    DListNode(int x) : val(x), prev(NULL), next(NULL) {}
};
```


### 三、题型一：链表反转

#### 3.1 迭代法（头插法）

```cpp
ListNode* reverseList(ListNode* head) {
    ListNode *prev = NULL, *cur = head, *next = NULL;
    while (cur) {
        next = cur->next;   // 保存后继
        cur->next = prev;   // 反转指针
        prev = cur;         // 前移
        cur = next;
    }
    return prev;
}
```

**复杂度**：$T(n) = O(n)$，$S(n) = O(1)$

#### 3.2 递归法

```cpp
ListNode* reverseListRecursive(ListNode* head) {
    if (!head || !head->next) return head;
    ListNode *newHead = reverseListRecursive(head->next);
    head->next->next = head;
    head->next = NULL;
    return newHead;
}
```

**复杂度**：$T(n) = O(n)$，$S(n) = O(n)$（递归栈）

> [!tip] 数一关联
> 递归反转链表本质上是**递推关系**：$f(head) = f(head \to next) + O(1)$，可得递归深度 $n$。

> [!note] 英一词汇
> - `reverse`：反转
> - `recursive`：递归的


### 四、题型二：链表判环（Floyd 判圈算法）

#### 4.1 判断是否有环

```cpp
bool hasCycle(ListNode *head) {
    ListNode *slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return true;
    }
    return false;
}
```

**复杂度**：$T(n) = O(n)$，$S(n) = O(1)$

#### 4.2 找到环的入口

```cpp
ListNode* detectCycle(ListNode *head) {
    ListNode *slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) {
            // 相遇后，从头开始同步走
            slow = head;
            while (slow != fast) {
                slow = slow->next;
                fast = fast->next;
            }
            return slow;
        }
    }
    return NULL;
}
```

> [!example] 数学原理（数一关联）
> 设从头到环入口距离为 $a$，环入口到相遇点距离为 $b$，环剩余为 $c$，则：
> $$2(a+b) = a + b + k(b+c)$$
> $$a = (k-1)(b+c) + c$$
> 即 **从头到入口的距离** 等于 **相遇点继续走到入口的距离**，因此双指针同步走必在入口相遇。

> [!tip] 408 常考变形
> - 求环的长度（相遇后走一圈计数）
> - 求环上结点个数
> - 判断两个链表是否相交（可转化为环问题）


### 五、题型三：链表合并（二路归并）

#### 5.1 迭代归并

```cpp
ListNode* mergeTwoLists(ListNode* l1, ListNode* l2) {
    ListNode dummy(0);
    ListNode *tail = &dummy;
    while (l1 && l2) {
        if (l1->val <= l2->val) {
            tail->next = l1;
            l1 = l1->next;
        } else {
            tail->next = l2;
            l2 = l2->next;
        }
        tail = tail->next;
    }
    tail->next = l1 ? l1 : l2;
    return dummy.next;
}
```

**复杂度**：$T(n) = O(m+n)$，$S(n) = O(1)$

#### 5.2 递归归并

```cpp
ListNode* mergeTwoListsRecursive(ListNode* l1, ListNode* l2) {
    if (!l1) return l2;
    if (!l2) return l1;
    if (l1->val <= l2->val) {
        l1->next = mergeTwoListsRecursive(l1->next, l2);
        return l1;
    } else {
        l2->next = mergeTwoListsRecursive(l1, l2->next);
        return l2;
    }
}
```

> [!note] 英一词汇
> - `merge`：合并
> - `tail`：尾指针


### 六、题型四：链表去重（有序链表）

```cpp
ListNode* deleteDuplicates(ListNode* head) {
    if (!head) return head;
    ListNode *cur = head;
    while (cur->next) {
        if (cur->val == cur->next->val) {
            ListNode *tmp = cur->next;
            cur->next = tmp->next;
            delete tmp;
        } else {
            cur = cur->next;
        }
    }
    return head;
}
```

**复杂度**：$T(n) = O(n)$，$S(n) = O(1)$

> [!tip] 变式
> 删除**所有重复元素**（一个不留）：
> ```cpp
> ListNode* deleteAllDuplicates(ListNode* head) {
>     ListNode dummy(0);
>     dummy.next = head;
>     ListNode *prev = &dummy, *cur = head;
>     while (cur) {
>         bool duplicate = false;
>         while (cur->next && cur->val == cur->next->val) {
>             duplicate = true;
>             ListNode *tmp = cur;
>             cur = cur->next;
>             delete tmp;
>         }
>         if (duplicate) {
>             ListNode *tmp = cur;
>             cur = cur->next;
>             delete tmp;
>             prev->next = cur;
>         } else {
>             prev->next = cur;
>             prev = cur;
>             cur = cur->next;
>         }
>     }
>     return dummy.next;
> }
> ```


### 七、题型五：链表拆分（奇偶分离）

**题目**：将链表按奇偶位置拆分为两个链表，保持相对顺序。

```cpp
void splitList(ListNode* head, ListNode* &odd, ListNode* &even) {
    ListNode dummyOdd(0), dummyEven(0);
    ListNode *tailOdd = &dummyOdd, *tailEven = &dummyEven;
    ListNode *cur = head;
    bool isOdd = true;
    while (cur) {
        if (isOdd) {
            tailOdd->next = cur;
            tailOdd = cur;
        } else {
            tailEven->next = cur;
            tailEven = cur;
        }
        cur = cur->next;
        isOdd = !isOdd;
    }
    tailOdd->next = tailEven->next = NULL;
    odd = dummyOdd.next;
    even = dummyEven.next;
}
```

**复杂度**：$T(n) = O(n)$，$S(n) = O(1)$


### 八、题型六：链表交点（双指针法）

**题目**：找到两个单链表相交的起始结点。

```cpp
ListNode* getIntersectionNode(ListNode *headA, ListNode *headB) {
    if (!headA || !headB) return NULL;
    ListNode *pa = headA, *pb = headB;
    while (pa != pb) {
        pa = pa ? pa->next : headB;
        pb = pb ? pb->next : headA;
    }
    return pa;
}
```

> [!example] 数学原理（数一关联）
> 设 A 独享长度为 $a$，B 独享长度为 $b$，公共长度为 $c$。则：
> - pa 走的路程：$a + c + b$
> - pb 走的路程：$b + c + a$
> 
> 两者相等，**必在交点相遇**。若不相交，最终同为 `NULL`。


### 九、题型七：删除倒数第 k 个结点

```cpp
ListNode* removeNthFromEnd(ListNode* head, int k) {
    ListNode dummy(0);
    dummy.next = head;
    ListNode *fast = &dummy, *slow = &dummy;
    
    // fast 先走 k+1 步
    for (int i = 0; i <= k; i++) {
        fast = fast->next;
    }
    
    while (fast) {
        slow = slow->next;
        fast = fast->next;
    }
    
    ListNode *tmp = slow->next;
    slow->next = tmp->next;
    delete tmp;
    return dummy.next;
}
```

**复杂度**：$T(n) = O(n)$，$S(n) = O(1)$

> [!tip] 408 常考变形
> - 找倒数第 $k$ 个结点（不删除）
> - 找中间结点（快慢指针，fast 走两步，slow 走一步）


### 十、题型八：链表排序（归并排序）

```cpp
ListNode* sortList(ListNode* head) {
    if (!head || !head->next) return head;
    
    // 1. 找中间结点（快慢指针）
    ListNode *slow = head, *fast = head->next;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
    }
    ListNode *mid = slow->next;
    slow->next = NULL;
    
    // 2. 递归排序
    ListNode *left = sortList(head);
    ListNode *right = sortList(mid);
    
    // 3. 归并
    return mergeTwoLists(left, right);
}
```

**复杂度**：$T(n) = O(n \log n)$，$S(n) = O(\log n)$（递归栈）


### 十一、题型九：约瑟夫环（循环链表模拟）

```cpp
int josephus(int n, int m) {
    ListNode *head = new ListNode(1);
    ListNode *tail = head;
    for (int i = 2; i <= n; i++) {
        tail->next = new ListNode(i);
        tail = tail->next;
    }
    tail->next = head;   // 构成环
    
    ListNode *prev = tail;
    ListNode *cur = head;
    while (cur->next != cur) {
        for (int i = 1; i < m; i++) {
            prev = cur;
            cur = cur->next;
        }
        // 删除 cur
        prev->next = cur->next;
        delete cur;
        cur = prev->next;
    }
    int result = cur->val;
    delete cur;
    return result;
}
```

**复杂度**：$T(n) = O(n \times m)$，$S(n) = O(n)$

> [!tip] 数学最优解（数一关联）
> 约瑟夫环的数学递推公式：
> $$f(1) = 0$$
> $$f(i) = (f(i-1) + m) \bmod i \quad (i \ge 2)$$
> 时间复杂度 $O(n)$，空间复杂度 $O(1)$。这是数一中**递推数列**与数据结构问题的典型交汇点。


### 十二、题型十：双向链表插入与删除

#### 12.1 在 p 之后插入 s

```cpp
void insertAfter(DListNode *p, DListNode *s) {
    s->next = p->next;
    s->prev = p;
    if (p->next) p->next->prev = s;
    p->next = s;
}
```

#### 12.2 删除结点 p

```cpp
void deleteNode(DListNode *p) {
    p->prev->next = p->next;
    if (p->next) p->next->prev = p->prev;
    delete p;
}
```

> [!warning] 指针修改顺序
> 双向链表的插入/删除必须**同时维护 `prev` 和 `next` 两个指针**，顺序错误会导致链表断裂。记忆口诀：
> **“先连新结点，再断旧指针；后继的 `prev`，前驱的 `next`”**
