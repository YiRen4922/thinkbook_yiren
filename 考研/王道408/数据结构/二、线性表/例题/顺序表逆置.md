## 顺序表逆置 · 考研408笔记


### 顺序表类型定义

```cpp
#define MaxSize 100

typedef struct {
    ElemType data[MaxSize];   // 存储空间
    int length;               // 当前表长
} SqList;
```


### 一、题目要求

设计一个高效算法，将顺序表 `L` 的所有元素逆置，要求算法的**空间复杂度为 $O(1)$**。
### 二、算法思想

**双指针交换法：**

1. 设置两个指针（下标）`i = 0`（指向表头），`j = length - 1`（指向表尾）
2. 交换 `data[i]` 和 `data[j]`
3. `i++`，`j--`，重复直到 `i >= j`

本质是将第 1 个与第 $n$ 个交换，第 2 个与第 $n-1$ 个交换，……，共交换 $\lfloor n/2 \rfloor$ 次。


### 三、代码实现

```cpp
void Reverse(SqList &L) {
    if (L.length <= 1) return;

    ElemType temp;
    for (int i = 0, j = L.length - 1; i < j; i++, j--) {
        temp = L.data[i];
        L.data[i] = L.data[j];
        L.data[j] = temp;
    }
}
```


### 四、时空复杂度

| 指标 | 复杂度 | 说明 |
|------|--------|------|
| 时间复杂度 | **$O(n)$** | 交换 $\lfloor n/2 \rfloor$ 次 |
| 空间复杂度 | **$O(1)$** | 仅用一个临时变量 `temp` |


### 五、执行过程示例

**输入**：`L = [1, 2, 3, 4, 5]`

| 轮次 | i | j | 操作 | 结果 |
|------|---|---|------|------|
| 1 | 0 | 4 | 交换 `data[0]` 和 `data[4]` | `[5, 2, 3, 4, 1]` |
| 2 | 1 | 3 | 交换 `data[1]` 和 `data[3]` | `[5, 4, 3, 2, 1]` |
| 3 | 2 | 2 | `i >= j`，停止 | ✅ 逆置完成 |


### 六、注意事项

| 要点 | 说明 |
|------|------|
| **空间 $O(1)$** | 只能用一个 `temp` 临时变量，**不能**用辅助数组 |
| **循环条件** | `i < j` 或 `i <= length / 2` |
| **空表/单元素** | 直接返回，无需处理 |
| **引用传递** | 参数用 `&L`，因需修改表内容 |


### 七、变式与应用

| 变式 | 思路变化 |
|------|----------|
| 逆置前 $k$ 个元素 | 将 `j = k-1`，其余不变 |
| 逆置区间 `[left, right]` | 设置 `i = left`，`j = right` |
| 循环左移 $k$ 位 | 三次逆置：整体逆置 → 前 $n-k$ 个逆置 → 后 $k$ 个逆置 |
| 循环右移 $k$ 位 | 三次逆置：整体逆置 → 前 $k$ 个逆置 → 后 $n-k$ 个逆置 |


### 总结

```
逆置类问题的通用模板：
i = 0, j = length - 1
while i < j:
    swap(L.data[i], L.data[j])
    i++, j--
```

**核心技巧**：双指针从两端向中间靠拢，每次交换一对元素，时间复杂度 $O(n)$，空间复杂度 $O(1)$，是顺序表逆置的标准最优解。
