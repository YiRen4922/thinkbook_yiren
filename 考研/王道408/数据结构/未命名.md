## 树、森林与二叉树的转换 · 考研408核心笔记

> 转换核心基于**孩子兄弟表示法**，口诀是 **“左孩子，右兄弟”**。

---

### 一、树 → 二叉树

**口诀**：左孩子，右兄弟

**步骤**：

1. 每个结点的**第一个孩子**作为左孩子
    
2. 每个结点的**下一个兄弟**作为右孩子
    

**转换前**：

```tikz
\begin{tikzpicture}[
  every node/.style={circle, draw, minimum size=1.6em, inner sep=1pt},
  level distance=1.6cm,
  sibling distance=2.2cm,
  edge from parent/.style={draw, -latex}
]
\node {A}
  child {node {B}
    child {node {E}}
    child {node {F}
      child {node {H}}
      child {node {I}}
    }
  }
  child {node {C}
    child {node {G}}
  }
  child {node {D}};
\end{tikzpicture}
```

**转换后**：

```tikz
\begin{tikzpicture}[
  every node/.style={circle, draw, minimum size=1.6em, inner sep=1pt},
  level distance=1.5cm,
  sibling distance=2.4cm,
  edge from parent/.style={draw, -latex}
]
\node {A}
  child {node {B}
    child {node {E}
      child[missing] {}
      child {node {F}
        child {node {H}
          child[missing] {}
          child {node {I}}
        }
      }
    }
    child {node {C}
      child {node {G}}
      child {node {D}}
    }
  };
\end{tikzpicture}
```

> **验证**：
> 
> - A 的左孩子是 B（A 的第一个孩子）
>     
> - B 的右孩子是 C（B 的下一个兄弟）
>     
> - C 的右孩子是 D（C 的下一个兄弟）
>     
> - B 的左孩子是 E（B 的第一个孩子）
>     
> - E 的右孩子是 F（E 的下一个兄弟）
>     
> - F 的左孩子是 H（F 的第一个孩子）
>     
> - H 的右孩子是 I（H 的下一个兄弟）
>     
> - C 的左孩子是 G（C 的第一个孩子）
>

### 二、森林 → 二叉树

**口诀**：先把每棵树转成二叉树，再以第一棵树的根为总根，依次将后一棵树作为前一棵树根的右孩子。

**步骤**：

1. 将森林中每棵树分别转换为二叉树
    
2. 第一棵树的根作为最终二叉树的根
    
3. 后续每棵树的根作为前一棵树根的**右孩子**（即兄弟关系）
    

**转换前**：三棵树 T_1, T_2, T_3 组成的森林

```tikz
\begin{tikzpicture}[
  every node/.style={circle, draw, minimum size=1.5em, inner sep=1pt},
  level distance=1.4cm,
  sibling distance=1.8cm,
  edge from parent/.style={draw, -latex}
]
\begin{scope}[local bounding box=T1]
  \node {A}
    child {node {B}
      child {node {E}}
      child {node {F}}
    }
    child {node {C}};
\end{scope}

\begin{scope}[xshift=5.5cm, local bounding box=T2]
  \node {D}
    child {node {G}
      child {node {I}}
    }
    child {node {H}};
\end{scope}

\begin{scope}[xshift=10.5cm, local bounding box=T3]
  \node {J}
    child {node {K}};
\end{scope}

\node[draw=none, above=0.3cm] at (T1.north) {$T_1$};
\node[draw=none, above=0.3cm] at (T2.north) {$T_2$};
\node[draw=none, above=0.3cm] at (T3.north) {$T_3$};
\end{tikzpicture}
```

**转换后**：

```tikz
\begin{tikzpicture}[
  every node/.style={circle, draw, minimum size=1.5em, inner sep=1pt},
  level distance=1.5cm,
  sibling distance=2.2cm,
  edge from parent/.style={draw, -latex}
]
\node {A}
  child {node {B}
    child {node {E}
      child[missing] {}
      child {node {F}}
    }
    child {node {C}}
  }
  child {node {D}
    child {node {G}
      child {node {I}
        child[missing] {}
        child {node {H}}
      }
    }
    child {node {J}
      child {node {K}}
    }
  };
\end{tikzpicture}
```

> **验证**：
> 
> - A 是总根（T_1 的根）
>     
> - A 的右孩子是 D（T_2 的根，即 T_1 的下一个“兄弟”）
>     
> - D 的右孩子是 J（T_3 的根）
>     
> - A 的左孩子是 B（A 的第一个孩子）
>     
> - B 的右孩子是 C（B 的下一个兄弟）
>     
> - D 的左孩子是 G（D 的第一个孩子）
>     
> - G 的右孩子是 H（G 的下一个兄弟）
>     
> - G 的左孩子是 I（G 的第一个孩子）
>     
> - H 的左孩子是 J 的左孩子 K？

### 三、二叉树 → 树

**口诀**：左孩子，右兄弟的逆操作

**步骤**：

1. 二叉树的根即为树的根
    
2. 二叉树中某结点的**左孩子**即为树中该结点的**第一个孩子**
    
3. 二叉树中某结点的**右孩子**即为树中该结点的**下一个兄弟**
    

---

### 四、二叉树 → 森林

**判断**：若二叉树的根**有右孩子**，则对应**森林**；否则对应**一棵树**。

**步骤**：

1. 从根开始，沿**右链**断开，每条右链对应的子树构成一棵树
    
2. 每棵子树按“二叉树 → 树”的规则还原
    

---

### 五、转换关系总结

|转换方向 核心规则||
|---|---|
|树 → 二叉树|左孩子，右兄弟|
|森林 → 二叉树|第一棵树根为总根，后续树根为前树根的右孩子|
|二叉树 → 树|左孩子是第一个孩子，右孩子是下一个兄弟|
|二叉树 → 森林|沿右链断开|

### 六、408 常考点

|考点 说明||
|---|---|
|树 → 二叉树|左孩子，右兄弟|
|森林 → 二叉树|第一棵树根为总根，后续树根为右孩子|
|二叉树 → 森林|沿右链断开|
|树的后根遍历|= 对应二叉树的**中序遍历**|
|树的先根遍历|= 对应二叉树的**先序遍历**|

### 七、易错与易混点

|易错判断 正确理解||
|---|---|
|二叉树 → 森林时所有二叉树都能转|❌ 只有根有右孩子的二叉树才对应森林|
|树的后根遍历 = 二叉树的后序遍历|❌ 树的后根遍历 = 二叉树的**中序遍历**|
|森林的先序遍历 = 二叉树的后序遍历|❌ 森林的先序遍历 = 二叉树的**先序遍历**|
|转换后左右子树顺序无所谓|❌ 左右子树严格对应“第一个孩子”和“下一个兄弟”，顺序不可颠倒|
