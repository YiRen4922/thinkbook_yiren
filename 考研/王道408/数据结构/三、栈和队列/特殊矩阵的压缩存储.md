## 特殊矩阵的压缩存储 · 考研408核心笔记

> 特殊矩阵的压缩存储是408中**数组与线性表**章节的核心考点，主要考察**对称矩阵、三角矩阵、三对角矩阵、稀疏矩阵**的存储方式与地址计算。在数一中，矩阵是线性代数的基本研究对象；在408中，压缩存储涉及**数组下标映射**与**空间复杂度优化**；在英语一中，`matrix`、`symmetric`、`sparse` 等词在科技类阅读中偶有出现。


### 1. 为什么要压缩存储？

**核心动机**：减少存储空间浪费。

| 矩阵类型 | 特点 | 压缩原理 |
|----------|------|----------|
| **对称矩阵** | $a_{ij} = a_{ji}$ | 只存储上三角或下三角 |
| **三角矩阵** | 一半元素为常数 $C$ | 只存储非 $C$ 的一半 + 1 个常数 |
| **三对角矩阵** | 非零元素仅出现在主对角线及相邻两侧 | 只存储三条对角线 |
| **稀疏矩阵** | 非零元素极少 | 只存储非零元素（三元组表） |


### 2. 对称矩阵的压缩存储

#### 2.1 定义

若 $n \times n$ 矩阵 $A$ 满足 $a_{ij} = a_{ji}$（$1 \le i, j \le n$），则称 $A$ 为**对称矩阵**。

> 对称矩阵中，上三角和下三角元素完全相同，只需存储其中一半即可节省近 50% 空间。

#### 2.2 存储方式：按行优先存储下三角（含主对角线）

将下三角元素（含主对角线）按行优先存入一维数组 $B$ 中：

$$
a_{11}, a_{21}, a_{22}, a_{31}, a_{32}, a_{33}, \dots, a_{n1}, a_{n2}, \dots, a_{nn}
$$

**存储元素总数**：
$$
1 + 2 + 3 + \cdots + n = \frac{n(n+1)}{2}
$$

#### 2.3 下标映射公式（408 绝对重点 ⭐）

**问题**：矩阵元素 $a_{ij}$（$i \ge j$，下三角）在一维数组 $B$ 中的下标 $k$ 是多少？

> [!important] 两种坐标体系
> - 若矩阵下标从 **1** 开始，数组下标从 **1** 开始，则 $B[k]$ 中 $k$ 从 1 开始
> - 若矩阵下标从 **1** 开始，数组下标从 **0** 开始，则 $B[k]$ 中 $k$ 从 0 开始
>
> **408 考试中默认矩阵下标从 1 开始，数组下标从 0 开始**，即 $B[0]$ 存储 $a_{11}$。

**按行优先存储下三角的公式**（数组从 0 开始）：

$$
\boxed{k = \frac{i(i-1)}{2} + (j-1)}
$$

其中 $i \ge j$，$i$、$j$ 从 1 开始，$k$ 从 0 开始。

**推导过程**：
- 第 $1$ 行有 $1$ 个元素
- 第 $2$ 行有 $2$ 个元素
- …
- 第 $i-1$ 行有 $i-1$ 个元素
- 前 $i-1$ 行共有 $1 + 2 + \cdots + (i-1) = \frac{i(i-1)}{2}$ 个元素
- 第 $i$ 行中 $a_{ij}$ 是该行的第 $j$ 个元素（从 1 开始），前 $j-1$ 个元素已存放
- 因此 $k = \frac{i(i-1)}{2} + (j-1)$

> [!example] 示例验证
> $n=5$，求 $a_{32}$ 在 $B$ 中的下标（矩阵下标从 1 开始，数组下标从 0 开始）：
> $$
> k = \frac{3 \times 2}{2} + (2-1) = 3 + 1 = 4
> $$
> 下三角按行存储顺序：$a_{11}, a_{21}, a_{22}, a_{31}, a_{32}, \dots$，$a_{32}$ 在 $B[4]$，验证 ✅

#### 2.4 上三角元素的访问

若 $i < j$（上三角），利用对称性 $a_{ij} = a_{ji}$，转换为访问下三角元素 $a_{ji}$：

$$
k = \frac{j(j-1)}{2} + (i-1)
$$

#### 2.5 使用 C++ 模拟对称矩阵压缩存储

```cpp
#include <vector>
#include <iostream>
using namespace std;

class SymmetricMatrix {
private:
    vector<int> data;  // 一维数组，存储下三角
    int n;             // 矩阵阶数

    int getIndex(int i, int j) const {
        if (i < j) swap(i, j);  // 确保 i >= j
        return i * (i + 1) / 2 + j;  // 0-based 版本公式
    }

public:
    SymmetricMatrix(int n) : n(n) {
        data.resize(n * (n + 1) / 2);
    }

    int& at(int i, int j) {
        if (i < 0 || i >= n || j < 0 || j >= n) throw out_of_range("Index out of range");
        return data[getIndex(i, j)];
    }

    const int& at(int i, int j) const {
        if (i < 0 || i >= n || j < 0 || j >= n) throw out_of_range("Index out of range");
        return data[getIndex(i, j)];
    }
};
```

> 此处的 `getIndex` 使用 0-based 版本：`i * (i + 1) / 2 + j`（当 $i \ge j$ 时）。


### 3. 三角矩阵的压缩存储

#### 3.1 下三角矩阵

**定义**：上三角所有元素均为同一常数 $C$，下三角元素任意。

$$
A = \begin{bmatrix}
a_{11} & C & \cdots & C \\
a_{21} & a_{22} & \cdots & C \\
\vdots & \vdots & \ddots & \vdots \\
a_{n1} & a_{n2} & \cdots & a_{nn}
\end{bmatrix}
$$

**存储结构**：存储**下三角元素 + 1 个常数 $C$**

$$
B[0 \dots \frac{n(n+1)}{2}]
$$

- $B[0 \dots \frac{n(n+1)}{2} - 1]$：存储下三角元素（按行优先）
- $B[\frac{n(n+1)}{2}]$：存储常数 $C$

**下标映射**：
- 若 $i \ge j$：$k = \frac{i(i-1)}{2} + (j-1)$
- 若 $i < j$：$k = \frac{n(n+1)}{2}$（常数 $C$ 的位置）

#### 3.2 上三角矩阵

**定义**：下三角所有元素均为同一常数 $C$，上三角元素任意。

**存储结构**：存储**上三角元素 + 1 个常数 $C$**

存储顺序：按行优先存储上三角元素

**下标映射**（行优先，$i \le j$，数组从 0 开始）：

$$
k = \frac{(i-1)(2n - i + 2)}{2} + (j-i)
$$

其中 $i \le j$，矩阵下标从 1 开始。


### 4. 三对角矩阵的压缩存储

#### 4.1 定义

除主对角线及其相邻两侧对角线外，其余元素均为 0：

$$
A = \begin{bmatrix}
a_{11} & a_{12} & 0 & \cdots & 0 \\
a_{21} & a_{22} & a_{23} & \cdots & 0 \\
0 & a_{32} & a_{33} & \cdots & 0 \\
\vdots & \vdots & \vdots & \ddots & \vdots \\
0 & 0 & 0 & \cdots & a_{nn}
\end{bmatrix}
$$

非零元素满足 $|i - j| \le 1$，共 $3n - 2$ 个非零元素。

#### 4.2 压缩存储方式

将三条对角线按行优先存入一维数组 $B$。

**下标映射**（矩阵从 1 开始，数组从 0 开始）：

$$
\boxed{k = 2i + j - 3}
$$

其中 $|i - j| \le 1$。

**推导**：第 $i$ 行有三个非零元素 $a_{i,i-1}, a_{i,i}, a_{i,i+1}$（边界行除外），前 $i-1$ 行共有 $3(i-1)-1$ 个非零元素（因为第一行只有 2 个），再计算当前行的偏移。

> 另一种常用写法：用二维数组 $B[3][n]$ 存储三条对角线。

#### 4.3 应用场景

三对角矩阵常见于**数值分析**中的三对角方程组求解（追赶法），是数一中线性代数与数值计算的交汇点。


### 5. 稀疏矩阵的压缩存储

#### 5.1 定义

**稀疏矩阵**：非零元素个数 $t$ 远小于矩阵元素总数 $m \times n$。

通常当 $t / (m \times n) \le 0.05$ 时视为稀疏矩阵。

#### 5.2 三元组表

**存储方式**：用三元组 $(行, 列, 值)$ 表示每个非零元素。

```cpp
typedef struct {
    int row;      // 行下标
    int col;      // 列下标
    ElemType value; // 元素值
} Triple;

typedef struct {
    Triple data[MaxSize];  // 非零元素三元组表
    int rows;              // 矩阵行数
    int cols;              // 矩阵列数
    int nums;              // 非零元素个数
} TSMatrix;
```

**示例**：

$$
A = \begin{bmatrix}
0 & 0 & 3 \\
0 & 5 & 0 \\
7 & 0 & 0
\end{bmatrix}
$$

三元组表：

| row | col | value |
|:---:|:---:|:-----:|
| 1 | 3 | 3 |
| 2 | 2 | 5 |
| 3 | 1 | 7 |

**空间复杂度**：$O(t)$（$t$ 为非零元素个数），远小于 $O(m \times n)$。

#### 5.3 十字链表

**定义**：用链表存储稀疏矩阵，每个非零结点包含行、列、值和两个指针：

- `right`：指向同一行的下一个非零元素
- `down`：指向同一列的下一个非零元素

```cpp
typedef struct OLNode {
    int row, col;
    ElemType value;
    struct OLNode *right, *down;
} OLNode, *OLink;

typedef struct {
    OLink *rhead;   // 行头指针数组
    OLink *chead;   // 列头指针数组
    int rows, cols, nums;
} CrossList;
```

**优点**：支持高效的插入、删除、矩阵加减法操作。


### 6. 各种压缩存储方式对比

| 矩阵类型 | 存储元素数 | 空间节省 | 下标计算 |
|----------|-----------|----------|----------|
| 普通矩阵 | $n^2$ | — | 直接计算 |
| 对称矩阵 | $\frac{n(n+1)}{2}$ | ≈ 50% | $k = \frac{i(i-1)}{2} + (j-1)$ |
| 下三角矩阵 | $\frac{n(n+1)}{2} + 1$ | ≈ 50% | 下三角同对称矩阵，上三角为常数 |
| 上三角矩阵 | $\frac{n(n+1)}{2} + 1$ | ≈ 50% | 下三角为常数，上三角需特殊计算 |
| 三对角矩阵 | $3n - 2$ | ≈ $O(n)$ | $k = 2i + j - 3$ |
| 稀疏矩阵（三元组） | $3t$ | 取决于稀疏度 | 需查找，不支持随机存取 |


### 7. 408 典型例题

#### 例题1 · 对称矩阵地址计算

**题目**：一个 $10 \times 10$ 的对称矩阵 $A$，采用行优先存储下三角元素（含主对角线），每个元素占 4 个字节。已知 $A[1][1]$ 的地址为 100，求 $A[4][2]$ 的地址。

**解**：
$$
k = \frac{4 \times 3}{2} + (2-1) = 6 + 1 = 7
$$

$A[4][2]$ 是 $B[7]$（从 0 开始），地址为：
$$
100 + 7 \times 4 = 128
$$

#### 例题2 · 三对角矩阵地址计算

**题目**：一个 $8 \times 8$ 的三对角矩阵 $A$，按行优先压缩存储到一维数组 $B$ 中，每个元素占 4 个字节。已知 $B[0]$ 的地址为 200，求 $A[5][4]$ 的地址。

**解**：$|5-4| = 1 \le 1$，在三条对角线内。

$$
k = 2 \times 5 + 4 - 3 = 10 + 4 - 3 = 11
$$

地址：$200 + 11 \times 4 = 244$

### 9. 核心公式速查卡

| 矩阵类型 | 存储元素数 | 下标映射公式（矩阵从 1 开始，数组从 0 开始） |
|----------|-----------|---------------------------------------------|
| 对称矩阵（下三角） | $\frac{n(n+1)}{2}$ | $k = \frac{i(i-1)}{2} + (j-1)$（$i \ge j$） |
