## 栈在表达式求值中的应用 · 考研408核心笔记（完整版）

> 表达式求值是栈最经典的应用之一，也是408中栈的必考考点。**后缀表达式（逆波兰表达式）** 完全消除了括号和优先级，使得计算机可以用一个栈轻松完成计算；而**中缀表达式转后缀表达式**的过程，则充分体现了栈在处理**运算符优先级和括号嵌套**时的天然优势。


### 1. 三种表达式形式

| 表达式 | 形式 | 示例 | 特点 |
|--------|------|------|------|
| **中缀表达式** | 运算符在操作数**中间** | `(3+4)×5-6` | 符合人类习惯，需要括号和优先级 |
| **后缀表达式** | 运算符在操作数**后面** | `3 4 + 5 × 6 -` | 无括号、无优先级，**适合计算机计算** |
| **前缀表达式** | 运算符在操作数**前面** | `- × + 3 4 5 6` | 无括号、无优先级 |

> [!note] 408 命题方向
> 考研408主要考察**中缀转后缀**和**后缀表达式求值**，偶尔涉及**中缀转前缀**。前缀表达式相对较少考查。


### 2. 后缀表达式求值（核心算法）

**算法思想**：遇到**操作数**入栈；遇到**运算符**，弹出栈顶两个操作数进行计算，将结果压回栈中。

```cpp
#include <stack>
#include <string>
#include <cctype>
using namespace std;

int evaluatePostfix(const string& expr) {
    stack<int> stk;

    for (char ch : expr) {
        if (isdigit(ch)) {
            stk.push(ch - '0');          // 操作数入栈
        } else if (ch == '+' || ch == '-' || ch == '*' || ch == '/') {
            int b = stk.top(); stk.pop(); // 注意：先弹出的是右操作数
            int a = stk.top(); stk.pop(); // 后弹出的是左操作数
            switch (ch) {
                case '+': stk.push(a + b); break;
                case '-': stk.push(a - b); break;
                case '*': stk.push(a * b); break;
                case '/': stk.push(a / b); break;
            }
        }
    }
    return stk.top();
}
```

**执行示例**：后缀表达式 `3 4 + 5 × 6 -`

| 步骤 | 读入 | 操作 | 栈 |
|------|------|------|-----|
| 1 | 3 | 入栈 | `[3]` |
| 2 | 4 | 入栈 | `[3, 4]` |
| 3 | + | 弹出4、3，计算 3+4=7，入栈 | `[7]` |
| 4 | 5 | 入栈 | `[7, 5]` |
| 5 | × | 弹出5、7，计算 7×5=35，入栈 | `[35]` |
| 6 | 6 | 入栈 | `[35, 6]` |
| 7 | - | 弹出6、35，计算 35-6=29 | `[29]` |


### 3. 中缀表达式转后缀表达式（手算与机算）

#### 3.1 手算方法（左优先原则）

> **左优先原则**：只要左边的运算符能先计算，就优先算左边的，保证手算和机算结果相同。

**步骤**：
1. 根据运算优先级和括号，给每个运算符标号（从1开始）
2. 按标号顺序重写表达式——运算符写在对应操作数后面

**示例**：`a+b*(c-d)+e/f`

| 步骤 | 操作 | 结果 |
|------|------|------|
| 1 | 找出最先计算的运算符 | `c-d` → `cd-` |
| 2 | 次先计算 | `b*(cd-)` → `bcd-*` |
| 3 | 再计算 | `a+(bcd-*)` → `abcd-*+` |
| 4 | 再计算 | `e/f` → `ef/` |
| 5 | 最后计算 | `(abcd-*+)+(ef/)` → `abcd-*+ef/+` |

#### 3.2 机算方法（栈模拟）

**算法思想**：从左到右扫描中缀表达式：

| 遇到 | 操作 |
|------|------|
| **操作数** | 直接输出到后缀表达式 |
| **左括号 `(`** | 入栈 |
| **右括号 `)`** | 弹出栈顶运算符并输出，直到遇到左括号（左括号弹出但不输出） |
| **运算符** | 若栈顶运算符优先级**≥**当前运算符，弹出并输出；重复直到栈顶优先级更低或栈空，然后将当前运算符入栈 |
| **扫描结束** | 将栈中剩余运算符全部弹出并输出 |

**运算符优先级**：`×`、`/` > `+`、`-` > `(`

```cpp
#include <stack>
#include <string>
#include <unordered_map>
using namespace std;

string infixToPostfix(const string& infix) {
    unordered_map<char, int> prec = {
        {'+', 1}, {'-', 1},
        {'*', 2}, {'/', 2}
    };
    stack<char> stk;
    string postfix;

    for (char ch : infix) {
        if (isalnum(ch)) {
            postfix += ch;                    // 操作数直接输出
        } else if (ch == '(') {
            stk.push(ch);
        } else if (ch == ')') {
            while (!stk.empty() && stk.top() != '(') {
                postfix += stk.top(); stk.pop();
            }
            if (!stk.empty()) stk.pop();      // 弹出 '('
        } else {  // 运算符
            while (!stk.empty() && stk.top() != '(' &&
                   prec[stk.top()] >= prec[ch]) {
                postfix += stk.top(); stk.pop();
            }
            stk.push(ch);
        }
    }
    while (!stk.empty()) {
        postfix += stk.top(); stk.pop();
    }
    return postfix;
}
```

**执行示例**：中缀表达式 `a+b*(c-d)+e/f`

| 步骤 | 当前字符 | 操作 | 输出 | 栈 |
|------|----------|------|------|-----|
| 1 | a | 操作数 | `a` | 空 |
| 2 | + | 运算符入栈 | `a` | `+` |
| 3 | b | 操作数 | `ab` | `+` |
| 4 | * | 运算符入栈 | `ab` | `+ *` |
| 5 | ( | 左括号入栈 | `ab` | `+ * (` |
| 6 | c | 操作数 | `abc` | `+ * (` |
| 7 | - | 运算符入栈 | `abc` | `+ * ( -` |
| 8 | d | 操作数 | `abcd` | `+ * ( -` |
| 9 | ) | 弹出直到 `(` | `abcd-` | `+ *` |
| 10 | + | 弹出 * 和 + | `abcd-*+` | 空 |
| 11 | e | 操作数 | `abcd-*+e` | 空 |
| 12 | / | 运算符入栈 | `abcd-*+e` | `/` |
| 13 | f | 操作数 | `abcd-*+ef` | `/` |
| 结束 | — | 弹出剩余 | `abcd-*+ef/+` | 空 |

最终：`abcd-*+ef/+` ✅


### 4. 中缀表达式直接求值（双栈法）

**算法思想**：使用**两个栈**——`numStack`（运算数栈）和`opStack`（运算符栈）。

```cpp
int evaluateInfix(const string& expr) {
    stack<int> nums;
    stack<char> ops;
    unordered_map<char, int> prec = {{'+',1},{'-',1},{'*',2},{'/',2}};

    auto applyOp = [&]() {
        int b = nums.top(); nums.pop();
        int a = nums.top(); nums.pop();
        char op = ops.top(); ops.pop();
        switch (op) {
            case '+': nums.push(a+b); break;
            case '-': nums.push(a-b); break;
            case '*': nums.push(a*b); break;
            case '/': nums.push(a/b); break;
        }
    };

    for (char ch : expr) {
        if (isdigit(ch)) {
            nums.push(ch - '0');
        } else if (ch == '(') {
            ops.push(ch);
        } else if (ch == ')') {
            while (!ops.empty() && ops.top() != '(') applyOp();
            if (!ops.empty()) ops.pop(); // 弹出 '('
        } else if (prec.count(ch)) {
            while (!ops.empty() && ops.top() != '(' &&
                   prec[ops.top()] >= prec[ch]) {
                applyOp();
            }
            ops.push(ch);
        }
    }
    while (!ops.empty()) applyOp();
    return nums.top();
}
```

> 扫描中缀表达式时，遇到操作数入栈；遇到操作符，先完成栈中优先级更高或相等的运算，再入栈。


### 5. 中缀表达式转前缀表达式

#### 5.1 手算方法（右优先原则）

> **右优先原则**：只要右边的运算符能先计算，就优先算右边的，保证手算和机算结果相同。

**步骤**：
1. 从右到左扫描，根据运算优先级和括号，给每个运算符标号
2. 按标号顺序重写表达式——运算符写在对应操作数前面

**示例**：`a+b*(c-d)+e/f`

| 步骤 | 操作 | 结果 |
|------|------|------|
| 1 | 找出最先计算的运算符 | `c-d` → `-cd` |
| 2 | 次先计算 | `b*(-cd)` → `*b-cd` |
| 3 | 再计算 | `a+(*b-cd)` → `+a*b-cd` |
| 4 | 再计算 | `e/f` → `/ef` |
| 5 | 最后计算 | `(+a*b-cd)+(/ef)` → `++a*b-cd/ef` |

**最终**：`++a*b-cd/ef`（实际写为 `+ + a * b - c d / e f`）

#### 5.2 机算方法（从右到左扫描）

**算法思想**：从右到左扫描中缀表达式：

| 遇到 | 操作 |
|------|------|
| **操作数** | 直接输出到前缀表达式（最终需要反转） |
| **右括号 `)`** | 入栈 |
| **左括号 `(`** | 弹出栈顶运算符并输出，直到遇到右括号（右括号弹出但不输出） |
| **运算符** | 若栈顶运算符优先级**>**当前运算符（注意：不包含等于），弹出并输出；重复直到栈顶优先级更低或栈空，然后将当前运算符入栈 |
| **扫描结束** | 将栈中剩余运算符全部弹出并输出 |
| **最终** | 将输出结果**反转**得到前缀表达式 |

```cpp
string infixToPrefix(const string& infix) {
    unordered_map<char, int> prec = {
        {'+', 1}, {'-', 1},
        {'*', 2}, {'/', 2}
    };
    stack<char> stk;
    string prefix;

    // 从右到左扫描
    for (int i = infix.length() - 1; i >= 0; i--) {
        char ch = infix[i];

        if (isalnum(ch)) {
            prefix += ch;
        } else if (ch == ')') {
            stk.push(ch);
        } else if (ch == '(') {
            while (!stk.empty() && stk.top() != ')') {
                prefix += stk.top(); stk.pop();
            }
            if (!stk.empty()) stk.pop(); // 弹出 ')'
        } else if (prec.count(ch)) {
            // 注意：前缀表达式中，栈顶优先级 > 当前优先级时才弹出
            // （不包含等于，因为右优先原则）
            while (!stk.empty() && stk.top() != ')' &&
                   prec[stk.top()] > prec[ch]) {
                prefix += stk.top(); stk.pop();
            }
            stk.push(ch);
        }
    }

    while (!stk.empty()) {
        prefix += stk.top(); stk.pop();
    }

    reverse(prefix.begin(), prefix.end());
    return prefix;
}
```

**执行示例**：中缀表达式 `a+b*(c-d)+e/f`

从右到左扫描，输出后反转得到：`++a*b-cd/ef` ✅


### 6. 前缀表达式求值

**算法思想**：从**右到左**扫描前缀表达式，遇到操作数入栈，遇到运算符弹出栈顶两个操作数进行计算。

```cpp
int evaluatePrefix(const string& expr) {
    stack<int> stk;

    // 从右到左扫描
    for (int i = expr.length() - 1; i >= 0; i--) {
        char ch = expr[i];

        if (isdigit(ch)) {
            stk.push(ch - '0');
        } else if (ch == '+' || ch == '-' || ch == '*' || ch == '/') {
            int a = stk.top(); stk.pop(); // 先弹出的是左操作数
            int b = stk.top(); stk.pop(); // 后弹出的是右操作数
            switch (ch) {
                case '+': stk.push(a + b); break;
                case '-': stk.push(a - b); break;
                case '*': stk.push(a * b); break;
                case '/': stk.push(a / b); break;
            }
        }
    }
    return stk.top();
}
```

**执行示例**：前缀表达式 `+ + a * b - c d / e f`

将变量替换为值：`+ + 3 * 4 - 5 2 / 6 3`

| 步骤 | 读入 | 操作 | 栈 |
|------|------|------|-----|
| 1 | 3 | 入栈 | `[3]` |
| 2 | 6 | 入栈 | `[3, 6]` |
| 3 | / | 弹出6、3，计算 6÷3=2 | `[2]` |
| 4 | 2 | 入栈 | `[2, 2]` |
| 5 | 5 | 入栈 | `[2, 2, 5]` |
| 6 | - | 弹出5、2，计算 5-2=3 | `[2, 3]` |
| 7 | c(4) | 入栈 | `[2, 3, 4]` |
| 8 | b(3) | 入栈 | `[2, 3, 4, 3]` |
| 9 | * | 弹出3、4，计算 4×3=12 | `[2, 3, 12]` |
| 10 | a(3) | 入栈 | `[2, 3, 12, 3]` |
| 11 | + | 弹出3、12，计算 3+12=15 | `[2, 3, 15]` |
| 12 | + | 弹出15、2，计算 15+2=17 | `[2, 17]` |

值 = 17 ✅（对应中缀表达式的值）

> 注意：前缀和后缀都是**无歧义**的表达式，任何顺序都能正确计算。


### 7. 三种表达式转换对比

| 转换方向 | 扫描方向 | 优先级比较 | 括号处理 | 最终操作 |
|----------|----------|------------|----------|----------|
| 中缀→后缀 | 左→右 | `>=` 弹出 | `(`入栈，`)`弹出 | 直接输出 |
| 中缀→前缀 | 右→左 | `>` 弹出 | `)`入栈，`(`弹出 | 输出后反转 |
