### 例题一：经典括号匹配 (AcWing 3693)

**题目来源**：AcWing 3693

**题目描述**：
给定一个只包含 `'('`、`'['`、`'{'`、`'<'` 和 `')'`、`']'`、`'}'`、`'>'` 的字符串，判断其中的括号是否匹配。

**输入格式**：
一个字符串，长度不超过 10000。

**输出格式**：
若匹配，输出 `yes`；否则输出 `no`。

**算法思想**：
这是最经典的括号匹配问题。核心思想是使用一个栈来存储所有遇到的左括号。当遇到一个右括号时，检查栈顶的左括号是否与之匹配。如果匹配，则弹出栈顶元素；否则，括号序列无效。

**代码实现 (C++)**：

```cpp
#include <iostream>
#include <cstring>
#include <algorithm>
using namespace std;

const int N = 10010;
char str[N];
char stack[N];
int top = -1;

int main() {
    cin >> str;
    int n = strlen(str);
    bool flag = true;

    for (int i = 0; i < n; i++) {
        // 如果是左括号，入栈
        if (str[i] == '(' || str[i] == '[' || str[i] == '{' || str[i] == '<') {
            stack[++top] = str[i];
        } 
        // 如果是右括号
        else {
            // 检查栈顶是否匹配
            if ( (str[i] == ')' && stack[top] == '(') ||
                 (str[i] == ']' && stack[top] == '[') ||
                 (str[i] == '}' && stack[top] == '{') ||
                 (str[i] == '>' && stack[top] == '<') ) {
                top--; // 匹配，弹出栈顶
            } else {
                flag = false; // 不匹配
                top--; // 跳过当前非法字符或简单处理，核心是标记失败
            }
        }
    }

    // 所有字符处理完，栈应为空，且过程中没有出现不匹配
    if (flag && top < 0) cout << "yes";
    else cout << "no";

    return 0;
}
```

> **复杂度分析**：算法只需遍历字符串一次，每个字符最多执行一次入栈或出栈操作，因此时间复杂度为 $O(n)$，空间复杂度为 $O(n)$。
