## 栈在表达式求值中的应用 · 典型例题集

> 以下题目覆盖表达式求值的**全部考点**，包括中缀转后缀、后缀求值、栈状态模拟、栈容量限制、双栈求值等。


### 考点一：中缀表达式转后缀表达式

#### 例题1 · 直接转换（选择题）

**题目**：将中缀表达式 `a*(b+c)-d/e` 转换为后缀表达式，正确的是？

A. `abc+*de/-`  
B. `abc+*de-/`  
C. `ab+c*de/-`  
D. `abc+*d/e-`

**答案**：**A**

**解析**：

| 步骤 | 当前字符 | 操作 | 输出 | 栈 |
|------|----------|------|------|-----|
| 1 | a | 操作数 | `a` | 空 |
| 2 | * | 入栈 | `a` | `*` |
| 3 | ( | 入栈 | `a` | `* (` |
| 4 | b | 操作数 | `ab` | `* (` |
| 5 | + | 入栈（栈顶是`(`） | `ab` | `* ( +` |
| 6 | c | 操作数 | `abc` | `* ( +` |
| 7 | ) | 弹出直到`(` | `abc+` | `*` |
| 8 | - | 比较：`*`优先级≥`-`，弹出`*` | `abc+*` | 空 |
| 9 | d | 操作数 | `abc+*d` | 空 |
| 10 | / | 入栈 | `abc+*d` | `/` |
| 11 | e | 操作数 | `abc+*de` | `/` |
| 结束 | — | 弹出剩余 | `abc+*de/` | 空 |

得到 `abc+*de/`，其中 `*` 在 `-` 之前输出，正确表示 `a*(b+c)` 先计算。


#### 例题2 · 含括号的转换（填空题）

**题目**：中缀表达式 `(a+b)*(c-d)/(e+f)` 转换为后缀表达式为：__________

**答案**：`ab+cd-*ef+/`

**解析**：
```
(a+b) → ab+
(c-d) → cd-
(ab+)*(cd-) → ab+cd-*
(e+f) → ef+
(ab+cd-*)/(ef+) → ab+cd-*ef+/
```


### 考点二：后缀表达式求值

#### 例题3 · 数值后缀表达式（选择题）

**题目**：后缀表达式 `3 4 2 * + 5 -` 的值为？

A. 9  
B. 6  
C. 3  
D. 12

**答案**：**B**

**解析**：

| 步骤 | 读入 | 操作 | 栈 |
|------|------|------|-----|
| 1 | 3 | 入栈 | `[3]` |
| 2 | 4 | 入栈 | `[3, 4]` |
| 3 | 2 | 入栈 | `[3, 4, 2]` |
| 4 | * | 弹出4、2，计算 4×2=8 | `[3, 8]` |
| 5 | + | 弹出8、3，计算 3+8=11 | `[11]` |
| 6 | 5 | 入栈 | `[11, 5]` |
| 7 | - | 弹出5、11，计算 11-5=6 | `[6]` |

值 = 6 ✅


### 考点三：转换过程中栈的状态（408高频）

#### 例题4 · 栈状态模拟（选择题）

**题目**：将中缀表达式 `a+b*(c-d)/e` 转换为后缀表达式的过程中，当扫描到字符 `*` 时，栈中元素为？

A. `+`  
B. `+ *`  
C. `+ * (`  
D. `*`

**答案**：**A**

**解析**：扫描到 `*` 时：

| 当前字符 | 操作 | 输出 | 栈 |
|----------|------|------|-----|
| a | 操作数 | `a` | 空 |
| + | 入栈 | `a` | `+` |
| b | 操作数 | `ab` | `+` |

此时扫描到 `*`，栈顶是 `+`，`*` 优先级高于 `+`，直接入栈，栈为 `+ *`。

> 注意：是在扫描到 `*` 的时刻，`c-d` 还没处理，因此 `(` 不在栈中。

**修正答案**：**B**


#### 例题5 · 栈的弹出判断（选择题）

**题目**：将中缀表达式 `a+b*c-d` 转换为后缀表达式，当扫描到运算符 `-` 时，会弹出哪些栈中元素？

A. `*`  
B. `+ *`  
C. `+`  
D. 都不弹出

**答案**：**B**

**解析**：

| 步骤 | 当前 | 操作 | 输出 | 栈 |
|------|------|------|------|-----|
| 1 | a | 操作数 | `a` | 空 |
| 2 | + | 入栈 | `a` | `+` |
| 3 | b | 操作数 | `ab` | `+` |
| 4 | * | 入栈 | `ab` | `+ *` |
| 5 | c | 操作数 | `abc` | `+ *` |
| 6 | - | 弹出*，弹出+ | `abc*+` | 空 |

`-` 优先级低于 `*` 和 `+`（同为1级），因此弹出所有优先级≥`-`的运算符，即 `*` 和 `+`。


### 考点四：栈容量限制

#### 例题6 · 栈容量与表达式转换（选择题）

**题目**：将中缀表达式 `a+b*(c+d*(e+f))` 转换为后缀表达式，符号栈的最大深度至少为？

A. 3  
B. 4  
C. 5  
D. 6

**答案**：**B**

**解析**：分析嵌套深度：
```
a + b * ( c + d * ( e + f ) )
          ↑     ↑     ↑
          括号1  括号2  括号3
```
最大嵌套层数 = 3。但加上运算符 `+ *` 和 `+` 的累积，栈深度为 **4**（`+ * ( +` 或 `+ * ( +` 的情况）。最深层是：
- 栈中：`+ * ( + ( +`？计算一下最坏情况：
```
a + b * ( c + d * ( e + f ) )
```
扫描到最后一个 `(` 时，栈中为：`+ * ( + (`
共 5 个元素 → 最大深度为 5。

**修正答案**：**C**

> 更严谨地说，实际最大深度为 5，对应栈中元素：`+ * ( + (`。


### 考点五：中缀表达式直接求值（双栈法）

#### 例题7 · 双栈法求值（计算题）

**题目**：使用双栈法计算中缀表达式 `(3+5)*(2-4)+6/3` 的值。

**答案**：`-14`

**解析**：

| 步骤 | 当前 | 操作 | 运算数栈 | 运算符栈 |
|------|------|------|----------|----------|
| 1 | ( | 入栈 | `[]` | `[ ( ]` |
| 2 | 3 | 入栈 | `[3]` | `[ ( ]` |
| 3 | + | 入栈 | `[3]` | `[ ( + ]` |
| 4 | 5 | 入栈 | `[3, 5]` | `[ ( + ]` |
| 5 | ) | 计算 3+5=8 | `[8]` | `[]` |
| 6 | * | 入栈 | `[8]` | `[ * ]` |
| 7 | ( | 入栈 | `[8]` | `[ * ( ]` |
| 8 | 2 | 入栈 | `[8, 2]` | `[ * ( ]` |
| 9 | - | 入栈 | `[8, 2]` | `[ * ( - ]` |
| 10 | 4 | 入栈 | `[8, 2, 4]` | `[ * ( - ]` |
| 11 | ) | 计算 2-4=-2 | `[8, -2]` | `[ * ]` |
| 12 | + | 计算 8×(-2)=-16 | `[-16]` | `[]` |
| 13 | 6 | 入栈 | `[-16, 6]` | `[ + ]` |
| 14 | / | 入栈 | `[-16, 6]` | `[ + / ]` |
| 15 | 3 | 入栈 | `[-16, 6, 3]` | `[ + / ]` |
| 结束 | — | 计算 6÷3=2，再算 -16+2=-14 | `[-14]` | `[]` |

值 = -14 ✅

### 考点七：栈的动态模拟（手动模拟题，408常考）

#### 例题9 · 手动模拟栈（选择题）

**题目**：要将中缀表达式 `a+b*c-d` 转换为后缀表达式，扫描完整个表达式后，运算符栈中剩余的元素是什么？

A. `-`  
B. `+ *`  
C. `*`  
D. 空

**答案**：**A**

**解析**：转换过程如下：

| 步骤 | 当前 | 操作 | 输出 | 栈 |
|------|------|------|------|-----|
| 1 | a | 操作数 | `a` | 空 |
| 2 | + | 入栈 | `a` | `+` |
| 3 | b | 操作数 | `ab` | `+` |
| 4 | * | 入栈 | `ab` | `+ *` |
| 5 | c | 操作数 | `abc` | `+ *` |
| 6 | - | 弹出*，弹出+ | `abc*+` | 空 |
| 7 | d | 操作数 | `abc*+d` | 空 |
| 结束 | — | 弹出剩余运算符 | `abc*+d-` | 空 |

最终栈为空，后缀表达式为 `abc*+d-`。因此栈中剩余为空，不是 `-`。

**修正答案**：**D**


### 考点八：错误检测（括号不匹配）

#### 例题10 · 表达式错误检测（选择题）

**题目**：以下哪个中缀表达式在转后缀时，会触发括号匹配错误？

A. `(a+b)*c`  
B. `a+(b*c`  
C. `a+b)*c`  
D. `a+(b)*c`

**答案**：**B 和 C**

**解析**：
- A：`(a+b)*c` → 括号匹配 ✅
- B：`a+(b*c` → 缺少右括号 ❌
- C：`a+b)*c` → 缺少左括号 ❌
- D：`a+(b)*c` → 括号匹配 ✅

### 考点十：栈内容追踪（408真题风格）

#### 例题12 · 栈内容追踪（选择题）

**题目**：将中缀表达式 `a*(b+c)-d/e` 转换为后缀表达式，当扫描到右括号 `)` 时，栈中元素（从栈底到栈顶）为？

A. `* ( +`  
B. `*`  
C. `+`  
D. `* (`

**答案**：**B**

**解析**：

| 步骤 | 当前 | 操作 | 输出 | 栈（栈底→栈顶） |
|------|------|------|------|-----------------|
| 1 | a | 操作数 | `a` | 空 |
| 2 | * | 入栈 | `a` | `*` |
| 3 | ( | 入栈 | `a` | `* (` |
| 4 | b | 操作数 | `ab` | `* (` |
| 5 | + | 入栈 | `ab` | `* ( +` |
| 6 | c | 操作数 | `abc` | `* ( +` |
| 7 | ) | 弹出直到`(` | `abc+` | `*` |

当扫描到 `)` 时，栈中从栈底到栈顶为 `* ( +`，但此时已经完成了弹出操作，所以正确答案是 `*`。

> 本题关键在于：题问的是“扫描到右括号时”这一时刻的栈状态。刚刚扫描到右括号时，还未执行弹出操作，此时栈中为 `* ( +`。

**修正答案**：**A**


### 考点十一：综合题（408大题风格）

#### 例题13 · 设计算法判断表达式合法性（简答题）

**题目**：设计一个算法，判断一个中缀表达式中的运算符数量是否合法（即操作数比运算符多1）。

**解**：扫描表达式，统计操作数和运算符的数量：

```cpp
bool isValidExpression(const string& expr) {
    int nums = 0, ops = 0;
    for (char ch : expr) {
        if (isdigit(ch) || isalpha(ch)) nums++;
        else if (ch == '+' || ch == '-' || ch == '*' || ch == '/') ops++;
    }
    // 合法表达式中：操作数 = 运算符 + 1
    return nums == ops + 1;
}
```

> 这只是简单的合法性判断，实际应用还需结合括号匹配、操作数检查等。


### 考点十二：扩展——前缀表达式求值（408趋势）

#### 例题14 · 前缀表达式求值（选择题）

**题目**：前缀表达式 `- + * 3 4 5 6` 的值为？

A. 21  
B. 15  
C. 9  
D. 6

**答案**：**A**

**解析**：前缀表达式从**右到左**扫描：

| 步骤 | 读入 | 操作 | 栈 |
|------|------|------|-----|
| 1 | 6 | 入栈 | `[6]` |
| 2 | 5 | 入栈 | `[6, 5]` |
| 3 | 4 | 入栈 | `[6, 5, 4]` |
| 4 | 3 | 入栈 | `[6, 5, 4, 3]` |
| 5 | * | 弹出3、4，计算 3×4=12 | `[6, 5, 12]` |
| 6 | + | 弹出12、5，计算 5+12=17 | `[6, 17]` |
| 7 | - | 弹出17、6，计算 17-6=11 | `[11]` |

前缀表达式求值时，运算符先于操作数出现，因此需要从右向左扫描，或者先将表达式反转，使用与后缀表达式相同的方法。


### 考点十三：对比不同形式表达式的效率（408拔高）

#### 例题15 · 比较中缀与后缀的求值效率（选择题）

**题目**：关于中缀表达式和后缀表达式的求值效率，以下说法正确的是：

A. 中缀表达式求值更快  
B. 后缀表达式求值更快  
C. 两者时间复杂度相同  
D. 后缀表达式求值空间复杂度更大

**答案**：**C**

**解析**：中缀表达式和后缀表达式求值的**时间复杂度相同**，均为 $O(n)$。但中缀表达式需要考虑运算符优先级和括号，需要双栈处理；后缀表达式只需一个栈，实现更简单。

### 考点十五：竞赛式综合题（AcWing/LeetCode 风格）

#### 例题17 · 计算器实现（设计题）

**题目**：设计一个算法，实现一个支持 `+`、`-`、`*`、`/` 和括号的计算器，输入为中缀表达式字符串，输出计算结果。

**解**：使用双栈法（或先转后缀再求值），代码如下：

```cpp
class Calculator {
public:
    int calculate(string s) {
        stack<int> nums;
        stack<char> ops;
        unordered_map<char, int> prec = {{'+',1}, {'-',1}, {'*',2}, {'/',2}};

        auto applyOp = [&]() {
            int b = nums.top(); nums.pop();
            int a = nums.top(); nums.pop();
            char op = ops.top(); ops.pop();
            switch (op) {
                case '+': nums.push(a+b); break;
                case '-': nums.push(a-b); break;
                case '*': nums.push(a*b); break;
                case '/': nums.push(a/b); break;
            }
        };

        for (int i = 0; i < s.size(); i++) {
            char ch = s[i];
            if (isdigit(ch)) {
                int val = 0;
                while (i < s.size() && isdigit(s[i])) {
                    val = val*10 + (s[i]-'0');
                    i++;
                }
                nums.push(val);
                i--;
            } else if (ch == '(') {
                ops.push(ch);
            } else if (ch == ')') {
                while (!ops.empty() && ops.top() != '(') applyOp();
                if (!ops.empty()) ops.pop();
            } else if (prec.count(ch)) {
                while (!ops.empty() && ops.top() != '(' &&
                       prec[ops.top()] >= prec[ch]) {
                    applyOp();
                }
                ops.push(ch);
            }
        }
        while (!ops.empty()) applyOp();
        return nums.top();
    }
};
```
