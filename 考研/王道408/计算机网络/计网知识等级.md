计算机网络在408中占 **25分**：选择约8题16分，综合约1题9分。它的特点是 **协议多、细节碎，但大题高度集中**。综合题常考 **子网划分、路由聚合、IP分片、TCP连接与拥塞控制、CSMA/CD、DNS/HTTP访问过程**。所以分级标准仍是：**考频 × 题型分值 × 难度 × 个人掌握，最后按性价比排优先级**。

计网S级不是“背得多”，而是：**能算IP、能分析TCP、能走通一次Web访问全过程**。

### 一、计网分级总原则

- **S级：综合题核心**  
  高频 + 可出综合 + 过程复杂。必须会算地址、会分析协议交互、会画封装/转发过程。
- **A级：选择题主力**  
  高频选择或中频综合。要求概念清、结论熟、协议特点能区分。
- **B级：眼熟即可**  
  中低频选择，考纲理解层次。刷选择题、记结论。
- **C级：后置**  
  低频、偏难、性价比低或纯细节。最后浏览。

二维矩阵同样适用：

|  | 难度低 | 难度高 |
|---|---|---|
| **考频高** | 优先拿分，快速刷熟 | 重点攻坚，专题+真题反复练 |
| **考频低** | 快速记忆，别花太多时间 | 战略后置，最后看结论 |

叠加个人掌握：  
**高频 + 你不会 = 最高优先级；高频 + 你已会 = 保持；低频 + 难 + 不会 = 后置。**

### 三、综合题常考组合，必须专题突破

1. **子网划分 + 路由聚合 + 最长前缀匹配**  
   给定拓扑和地址块，划分子网、填路由表、判断分组转发接口。

2. **IP分片计算**  
   给定MTU、IP数据报长度，算分片数、每片长度、片偏移、MF标志。

3. **TCP连接与拥塞控制**  
   三次握手/四次挥手序号变化；慢开始、拥塞避免、快重传、快恢复；cwnd、ssthresh、发送窗口变化。

4. **CSMA/CD与以太网帧**  
   争用期、最小帧长、退避时间、MAC帧格式、交换机转发。

5. **DNS + HTTP + TCP访问过程**  
   从输入URL到页面显示：DNS解析、ARP、TCP握手、HTTP请求、IP转发、以太网封装。

6. **路由协议与路由表更新**  
   RIP距离向量算法、OSPF链路状态、BGP路径向量，更新路由表。

### 四、复习优先级建议

**第一梯队：S级全掌握**  
IP地址/子网划分、路由聚合、IP分片、ARP/DHCP/ICMP/NAT、TCP连接、TCP可靠传输/流量控制/拥塞控制、CSMA/CD、交换机、DNS、HTTP。

**第二梯队：A级熟练**  
体系结构、物理层公式、差错控制、滑动窗口、路由协议、IPv6、端口、应用层协议、网络设备。

**第三梯队：B级刷选择**  
传输介质、无线局域网、网络安全、流媒体、P2P、CDN。

**第四梯队：C级后置**  
冷门标准、历史协议、复杂加密推导。

### 五、操作建议

做一张真题分类表：  
**知识点 | 选择题次数 | 综合题次数 | 最近年份 | 难度 | 我的掌握 | 优先级**

复习顺序可按：  
**体系结构 → 数据链路层 → 网络层 → 传输层 → 应用层 → 物理层**  
但优先级上，**网络层 + 传输层 + 应用层访问过程** 必须最先攻下。

一句话：计网的S级是 **“能算子网/IP分片/TCP窗口，能走通一次Web访问全过程”**；A级是“选择题能秒判”；B级是“眼熟”；C级是“最后看”。
