操作系统在408中占 **35分**：选择约10题20分，综合约1-2题15分。它的综合题高度集中在 **PV操作、内存管理、文件系统、磁盘调度、调度算法**。所以分级标准仍是：**考频 × 题型分值 × 难度 × 个人掌握，最后按性价比排优先级**。

OS的S级不是“考得多”，而是：**能写PV代码、能算地址/缺页/索引/调度/移臂**。

### 一、OS分级总原则

- **S级：综合题核心**  
  高频 + 可出综合 + 过程复杂。必须会写信号量代码、会算地址转换、缺页率、混合索引、调度指标、磁盘移臂。
- **A级：选择题主力**  
  高频选择或中频综合。要求概念清、结论熟、计算快。
- **B级：眼熟即可**  
  中低频选择，考纲理解层次。刷选择题、记结论。
- **C级：后置**  
  低频、偏难、性价比低或纯细节。最后浏览。

二维矩阵同样适用：

|  | 难度低 | 难度高 |
|---|---|---|
| **考频高** | 优先拿分，快速刷熟 | 重点攻坚，专题+真题反复练 |
| **考频低** | 快速记忆，别花太多时间 | 战略后置，最后看结论 |

叠加个人掌握：  
**高频 + 你不会 = 最高优先级；高频 + 你已会 = 保持；低频 + 难 + 不会 = 后置。**

### 三、综合题常考组合，必须专题突破

1. **PV操作建模与代码**  
   生产者-消费者、读者-写者、哲学家、理发师、流水线。要会设信号量、写P/V、分析互斥与同步。

2. **分页/分段地址转换 + TLB + 缺页 + 置换**  
   虚拟地址 → 页号/页内偏移 → 页表 → 物理地址 → TLB → 缺页中断 → 页面置换。要会算缺页率、有效访问时间。

3. **文件系统混合索引**  
   给定索引节点，算最大文件大小、某偏移需要几次磁盘访问、直接/一级/二级/三级索引覆盖范围。

4. **磁盘调度移臂计算**  
   FCFS、SSTF、SCAN、C-SCAN，计算磁头移动总量和顺序。

5. **调度算法计算**  
   RR、SJF、优先级、多级队列，计算周转时间、等待时间、带权周转时间。

6. **银行家算法**  
   判断安全状态、找安全序列、判断请求能否分配。

### 四、复习优先级建议

**第一梯队：S级全掌握**  
PV操作、进程调度、死锁/银行家算法、分页/分段、虚拟内存/页面置换、文件系统、磁盘调度。

**第二梯队：A级熟练**  
进程与线程、进程通信、系统调用、I/O控制、缓冲、目录、磁盘访问时间、概述。

**第三梯队：B级刷选择**  
实时调度、内存映射、文件保护、I/O层次、RAID、引导。

**第四梯队：C级后置**  
冷门历史、内核源码细节、过时系统。

### 五、操作建议

做一张真题分类表：  
**知识点 | 选择题次数 | 综合题次数 | 最近年份 | 难度 | 我的掌握 | 优先级**

复习顺序可按：  
**进程管理 → 内存管理 → 文件管理 → I/O管理 → 概述**  
但优先级上，**PV操作、内存管理、文件系统、调度算法** 必须最先攻下。

一句话：OS的S级是 **“能写PV、能算地址/缺页/索引/调度/移臂”**；A级是“选择题能秒判”；B级是“眼熟”；C级是“最后看”。
