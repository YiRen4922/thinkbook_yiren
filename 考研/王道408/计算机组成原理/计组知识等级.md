计组和数据结构不同：数据结构综合题常靠算法设计拉分，计组综合题则高度集中在 **存储系统 + CPU/数据通路 + 流水线 + 中断/DMA**。所以计组分级更要看：**能否独立走完一个计算/过程流程**。只按考频不够，建议仍是 **考频×题型分值×难度×个人掌握**，最后按性价比排优先级。

408计组：45分，选择约11题22分，综合约2题23分。综合题权重极高，S级必须能算、能画、能写流程。

### 一、计组分级总原则

- **S级：综合题核心**  
  高频 + 可出综合 + 过程复杂。必须会画图、会算地址、会写微操作、会分析冒险。
- **A级：选择题主力**  
  高频选择或中频综合。要求概念清、结论熟、计算快。
- **B级：眼熟即可**  
  中低频选择，考纲理解层次。刷选择题、记结论。
- **C级：后置**  
  低频、偏难、性价比低或纯细节。最后浏览。

二维矩阵同样适用：

|  | 难度低 | 难度高 |
|---|---|---|
| **考频高** | 优先拿分，快速刷熟 | 重点攻坚，专题+真题反复练 |
| **考频低** | 快速记忆，别花太多时间 | 战略后置，最后看结论 |

叠加个人掌握：  
**高频 + 你不会 = 最高优先级；高频 + 你已会 = 保持；低频 + 难 + 不会 = 后置。**

### 三、综合题常考组合，必须专题突破

1. **虚拟地址 → TLB → 页表 → 物理地址 → Cache → 命中/缺失**  
   这是计组最经典的“一条龙”，要能算页号、页内偏移、TLB标记、Cache标记、组号、块内偏移。

2. **指令格式 → 取指 → 译码 → 执行 → 数据通路 → 微操作 → 控制信号**  
   要会写每个时钟周期的微操作，知道PC、IR、MAR、MDR、ALU、寄存器的作用。

3. **五段流水线 → 冒险判断 → 转发/暂停 → 时空图 → 吞吐率/加速比**  
   数据冒险、控制冒险、结构冒险要能判断，会画流水线时空图。

4. **主存扩展 → 芯片数量 → 地址范围 → 片选逻辑**  
   位扩展、字扩展、字位同时扩展，计算要熟练。

5. **中断/DMA → 处理流程 → CPU干预时机 → 数据传送路径**  
   中断隐指令、中断服务程序、DMA预处理/后处理要清楚。

### 四、复习优先级建议

**第一梯队：S级全掌握**  
Cache、虚拟存储、主存扩展、流水线、数据通路、浮点/补码、寻址与指令格式、中断/DMA。

**第二梯队：A级熟练**  
性能指标、SRAM/DRAM、磁盘、控制器、总线、IO方式、校验码。

**第三梯队：B级刷选择**  
ALU细节、浮点舍入、总线标准、RAID、外部设备。

**第四梯队：C级后置**  
冷门芯片、历史标准、门级电路。

### 五、操作建议

做一张真题分类表：  
**知识点 | 选择题次数 | 综合题次数 | 最近年份 | 难度 | 我的掌握 | 优先级**

复习顺序可按：  
**数据表示 → 存储系统 → 指令系统 → CPU数据通路 → 流水线 → 中断/DMA → 总线/IO**  
但优先级上，**存储 + CPU + 流水线 + 中断/DMA** 必须最先攻下。

一句话：计组的S级不是“考得多”，而是 **“综合题能独立走完流程”**；A级是“选择题能秒判”；B级是“眼熟”；C级是“最后看”。
