1. 标准形式

$ax^2 + bx + c = 0 \quad (a \neq 0)$

2. 求根公式（核心）

$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$

3. 判别式（决定根的性质）
$\Delta = b^2 - 4ac$
· $\Delta > 0$：两个不等实根
· $\Delta = 0$：两个相等实根（重根）
· $\Delta < 0$：一对共轭复根

4. 根与系数的关系（韦达定理）

若 $x_1, x_2$ 为两根，则：
$x_1 + x_2 = -\frac{b}{a}, \quad x_1 \cdot x_2 = \frac{c}{a}$

5. 以两根构造方程

若已知两根 $x_1, x_2$，则方程为：
$x^2 - (x_1 + x_2)x + x_1 x_2 = 0$

6. 完全平方公式（配方法基础）

$ax^2 + bx + c = a\left(x + \frac{b}{2a}\right)^2 + \frac{4ac - b^2}{4a}$

7. 根的对称式（常用变形）

· $\frac{1}{x_1} + \frac{1}{x_2} = \frac{x_1 + x_2}{x_1 x_2} = -\frac{b}{c} \quad (c \neq 0)$
· $x_1^2 + x_2^2 = (x_1 + x_2)^2 - 2x_1x_2 = \frac{b^2 - 2ac}{a^2}$
· $(x_1 - x_2)^2 = (x_1 + x_2)^2 - 4x_1x_2 = \frac{\Delta}{a^2}$
· $x_1^3 + x_2^3 = (x_1+x_2)^3 - 3x_1x_2(x_1+x_2)$

8. 因式分解法（有理根）

若 $\Delta$ 为完全平方数，则可分解为：
$ax^2 + bx + c = a(x - x_1)(x - x_2)$

9. 判别式的其他用途

· 判断符号：若 $\Delta < 0$ 且 $a > 0$，则恒正；若 $a < 0$，则恒负。
· 与x轴交点：$\Delta$ 决定抛物线 $y=ax^2+bx+c$ 与 $x$ 轴的交点个数。

10. 顶点坐标（抛物线）

$\left(-\frac{b}{2a},\ \frac{4ac - b^2}{4a}\right)$


对称轴：$x = -\dfrac{b}{2a}$

11. 参数条件（两根分布）

· 两根同号：$\Delta \geq 0,\ \dfrac{c}{a} > 0$
· 两根异号：$\dfrac{c}{a} < 0$
· 两根均为正：$\Delta \geq 0,\ -\dfrac{b}{a} > 0,\ \dfrac{c}{a} > 0$
· 两根均为负：$\Delta \geq 0,\ -\dfrac{b}{a} < 0,\ \dfrac{c}{a} > 0$

12. 换元法与特殊类型

· 双二次方程：$ax^4 + bx^2 + c = 0$，令 $t = x^2$，需检验 $t \geq 0$
· 分式方程：去分母后可能产生增根，需验根
· 含参方程：讨论 $a=0$ 退化为一次方程的情形

13. 判别式法与韦达定理的联合应用

· 已知一根求另一根及参数：代入求根公式或韦达定理
· 已知两根关系（如 $x_1 = 2x_2$），联立韦达定理求解参数
