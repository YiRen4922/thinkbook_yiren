## 数学归纳法 · 考研数一核心笔记

> 数学归纳法是证明与正整数 $n$ 有关命题的**标准工具**，在数列单调性、有界性、不等式证明中高频使用。

### 一、基本步骤（第一数学归纳法）

要证明命题 $P(n)$ 对所有 $n \ge n_0$ 成立：

1. **验证初始项**：证明 $P(n_0)$ 成立。
2. **归纳假设**：假设 $P(k)$ 成立（$k \ge n_0$）。
3. **归纳递推**：利用假设证明 $P(k+1)$ 成立。
4. **结论**：由 1、2、3 知，对一切 $n \ge n_0$，$P(n)$ 成立。

> 口诀：**“奠基 + 假设 + 递推”**，三者缺一不可。

### 二、第二数学归纳法（强归纳法）

若假设 $P(n_0), P(n_0+1), \dots, P(k)$ 都成立，来证明 $P(k+1)$ 成立，则同样可证。

> 适用于递推关系依赖**前多项**的情形，如 $x_{n+1}$ 由 $x_n$ 和 $x_{n-1}$ 共同决定。

### 三、在数列单调性证明中的应用

#### 3.1 证明单调递增

- 验证 $x_2 > x_1$；
- 假设 $x_k > x_{k-1}$，证明 $x_{k+1} > x_k$。

#### 3.2 证明有上界

- 验证 $x_1 \le M$；
- 假设 $x_k \le M$，证明 $x_{k+1} \le M$。

> 通常**单调性与有界性同时归纳**，两者结合使用单调有界准则。

### 四、典型例题

**题目**：设 $x_1 = 1$，$x_{n+1} = \sqrt{2 + x_n}$，证明 $\{x_n\}$ 单调递增且有上界 $2$。

**证明**：

1. **单调性**：
   - $x_2 = \sqrt{3} > 1 = x_1$；
   - 假设 $x_k > x_{k-1}$，则 $x_{k+1} = \sqrt{2+x_k} > \sqrt{2+x_{k-1}} = x_k$。
   - 故 $\{x_n\}$ 单调递增。

2. **有界性**：
   - $x_1 = 1 < 2$；
   - 假设 $x_k < 2$，则 $x_{k+1} = \sqrt{2+x_k} < \sqrt{4} = 2$。
   - 故 $x_n < 2$ 对一切 $n$ 成立。

由单调有界准则，$\{x_n\}$ 收敛。设极限为 $a$，则 $a = \sqrt{2+a}$，解得 $a=2$。

### 五、使用要点

| 要点 | 说明 |
| :--- | :--- |
| 初始项不可少 | 必须验证 $n_0$ 时成立 |
| 假设要明确 | “假设 $n=k$ 时成立”必须写清楚 |
| 递推要完整 | 必须用到归纳假设，不能循环论证 |
| 适用题型 | 数列单调性、有界性、不等式、整除性、恒等式 |
| 常见变形 | 从 $k$ 到 $k+1$、从 $k-1$ 到 $k$、强归纳法 |

### 六、易错点

| 易错点 | 正确理解 |
| :--- | :--- |
| 忘记验证初始项 | 必须验证，否则可能对 $n \ge 2$ 才成立 |
| 假设与递推混淆 | 先假设 $P(k)$，再证 $P(k+1)$，顺序不能颠倒 |
| 递推中未用假设 | 必须用到归纳假设，否则不是归纳法 |
| 强归纳与弱归纳混用 | 依赖前多项时用强归纳 |
