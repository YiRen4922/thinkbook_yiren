## 数列及其单调性 · 考研数一核心笔记

> 数列是高等数学的起点，也是考研数一中**极限论**的基础。在408中，递归算法的时间复杂度分析本质上就是数列递推问题；在英语一中，`sequence`、`monotone`、`converge` 等词为科技类高频词汇。


### 1. 数列的定义

**定义**：按一定次序排列的一列数，称为数列。记作：

$$
\{a_n\}_{n=1}^{\infty} \quad \text{或简写为} \quad \{a_n\}
$$

其中 $a_n$ 称为数列的**通项**（或一般项）。

**示例**：
- $\{1, 2, 3, \dots\}$，$a_n = n$
- $\{1, \frac12, \frac13, \dots\}$，$a_n = \frac1n$
- $\{1, -1, 1, -1, \dots\}$，$a_n = (-1)^{n+1}$


### 2. 数列的分类

| 分类方式 | 类型 | 定义 | 示例 |
|----------|------|------|------|
| 按项数 | **有穷数列** | 项数有限 | $\{1,2,3\}$ |
| | **无穷数列** | 项数无限 | $\{\frac1n\}$ |
| 按单调性 | **递增数列** | $a_{n+1} > a_n$ | $\{n\}$ |
| | **递减数列** | $a_{n+1} < a_n$ | $\{\frac1n\}$ |
| | **非递减数列** | $a_{n+1} \ge a_n$ | $\{1,1,2,2,3\}$ |
| | **非递增数列** | $a_{n+1} \le a_n$ | $\{1,1,\frac12,\frac12,\frac13\}$ |
| | **摆动数列** | 符号交替变化 | $\{(-1)^n\}$ |
| 按有界性 | **有界数列** | $\exists M > 0$，$\|a_n\| \le M$ | $\{\frac1n\}$ |
| | **无界数列** | 任意正数都能被超过 | $\{n\}$ |


### 3. 数列的单调性

#### 3.1 定义

若对任意正整数 $n$，都有：

$$
a_{n+1} > a_n
$$

则称数列 $\{a_n\}$ 为**严格递增数列**（单调递增）。

若 $a_{n+1} < a_n$，则称数列为**严格递减数列**（单调递减）。

> 考研中“递增”通常指**严格递增**（$a_{n+1} > a_n$），若允许相等会特别说明“非递减”。

#### 3.2 判定方法

| 方法      | 操作                                             | 适用场景       |
| ------- | ---------------------------------------------- | ---------- |
| **作差法** | 判断 $a_{n+1} - a_n$ 的符号                         | 通项为多项式或有理式 |
| **作商法** | 判断 $\dfrac{a_{n+1}}{a_n}$ 与 1 的大小（需 $a_n > 0$） | 通项含指数或阶乘   |
| **函数法** | 将 $a_n$ 视为 $f(n)$，用导数判断 $f(x)$ 的单调性            | 通项可扩展为连续函数 |

> [!example] 作差法
> 判断数列 $\{a_n = \frac{n}{n+1}\}$ 的单调性：
> $$
> a_{n+1} - a_n = \frac{n+1}{n+2} - \frac{n}{n+1} = \frac{1}{(n+1)(n+2)} > 0
> $$
> 所以 $\{a_n\}$ 严格递增。

> [!example] 函数法
> 判断 $\{a_n = \frac{\ln n}{n}\}$ 的单调性：
> 令 $f(x) = \frac{\ln x}{x}$，$f'(x) = \frac{1 - \ln x}{x^2}$，当 $x > e$ 时 $f'(x) < 0$，所以 $\{a_n\}$ 从 $n \ge 3$ 开始递减。

### 4. 考研核心：单调有界准则

**单调有界准则**（数一必背）：

> 若数列 $\{a_n\}$ 单调递增且有上界，则 $\{a_n\}$ 必收敛。
> 若数列 $\{a_n\}$ 单调递减且有下界，则 $\{a_n\}$ 必收敛。

这是考研中**证明数列极限存在**的最常用方法！

> [!example] 典型例题
> 设 $a_1 = 1$，$a_{n+1} = \sqrt{2 + a_n}$，证明 $\{a_n\}$ 收敛并求极限。
>
> **证明**：
> - **单调性**：$a_2 = \sqrt{3} > 1 = a_1$，假设 $a_k > a_{k-1}$，则 $a_{k+1} - a_k = \sqrt{2+a_k} - \sqrt{2+a_{k-1}} > 0$，故 $\{a_n\}$ 单调递增。
> - **有界性**：$a_n < 2$（归纳可证），故有上界。
> - 由单调有界准则，$\{a_n\}$ 收敛。设极限为 $A$，则 $A = \sqrt{2+A}$，解得 $A = 2$（舍去 $-1$）。


### 5. 数列单调性与极限的常见题型

| 题型 | 方法 | 关键步骤 |
|------|------|----------|
| **证明极限存在** | 单调有界准则 | 先证单调，再证有界，最后列方程求极限 |
| **求递推数列极限** | 压缩映射 / 不动点法 | 设极限为 $A$，解方程 $A = f(A)$ |
| **比较无穷小的阶** | 数列极限比值 | $\lim \dfrac{a_n}{b_n}$ |
| **判断收敛性** | 单调有界 + 夹逼 | 利用单调性和有界性判断收敛 |


### 6. 数列极限的重要结论

> [!important] 常用极限
> 考研中必须熟练掌握以下数列极限：
> 1. $\lim_{n\to\infty} \sqrt[n]{n} = 1$
> 2. $\lim_{n\to\infty} \sqrt[n]{a} = 1$（$a > 0$）
> 3. $\lim_{n\to\infty} \dfrac{\ln n}{n} = 0$
> 4. $\lim_{n\to\infty} \left(1 + \frac1n\right)^n = e$
> 5. $\lim_{n\to\infty} n^{\frac1n} = 1$

### 7. 408 关联：算法复杂度与数列

在算法分析中，数列是描述时间复杂度的**核心数学工具**。

| 算法 | 递推数列 | 时间复杂度 |
|------|----------|-----------|
| 二分查找 | $T(n) = T(n/2) + O(1)$ | $O(\log n)$ |
| 归并排序 | $T(n) = 2T(n/2) + O(n)$ | $O(n\log n)$ |
| 斐波那契（递归） | $F_n = F_{n-1} + F_{n-2}$ | $O(2^n)$ |
| 快速排序（期望） | $T(n) = 2T(n/2) + O(n)$ | $O(n\log n)$ |

**数列单调性在 408 中的体现**：
- 递归算法的时间复杂度分析中，递推数列的单调性决定算法效率
- 分治算法的递归树本质上是数列求和问题
- 二分查找要求数组有序，等价于数列的**单调性**保证

> [!example] 时间复杂度比较
> 用数列极限比较复杂度：
> $$
> \lim_{n\to\infty} \frac{\log n}{n} = 0
> $$
> 说明 $\log n$ 比 $n$ 增长慢，即 $O(\log n) < O(n)$。

### 9. 易错与易混点

| 易错判断 | 正确理解 |
|----------|----------|
| “单调有界数列一定收敛” | ✅ 正确（单调有界准则） |
| “有界数列一定收敛” | ❌ 错误，如 $(-1)^n$ 有界但不收敛 |
| “收敛数列一定有界” | ✅ 正确 |
| “数列极限为 0 则对应级数收敛” | ❌ 错误，$\sum \frac1n$ 发散 |
| “$\ln n$ 比 $n$ 增长快” | ❌ 错误，$\ln n \ll n$ |
| “$a_{n+1} > a_n$ 对所有 $n$ 成立才是递增” | ✅ 正确（严格递增） |


### 10. 核心公式速查卡

| 类别 | 公式 |
|------|------|
| 数列定义 | $\{a_n\}$，$a_n = f(n)$ |
| 单调递增 | $a_{n+1} > a_n$ 或 $\dfrac{a_{n+1}}{a_n} > 1$（$a_n > 0$） |
| 单调递减 | $a_{n+1} < a_n$ 或 $\dfrac{a_{n+1}}{a_n} < 1$（$a_n > 0$） |
| 单调有界准则 | 递增有上界 → 收敛；递减有下界 → 收敛 |
| 重要极限 | $\lim_{n\to\infty} \left(1+\frac1n\right)^n = e$ |
| 408 复杂度 | $T(n) = 2T(n/2) + O(n) \Rightarrow O(n\log n)$ |
