## 牛顿迭代法（Newton's Method）· 考研数一/408 核心笔记

> 牛顿迭代法是**数值分析**中求解方程 $f(x)=0$ 最经典的迭代算法，也是**非线性方程求根**的基石。在408中，其思想被用于**算法收敛性分析**和**复杂度优化**；在数一中，它是**微分中值定理**与**泰勒展开**的典型应用。在英语一中，`Newton's method`、`iteration`、`convergence` 等词在科技类阅读中偶有出现。


### 1. 核心思想

**问题**：求解方程 $f(x) = 0$。

**牛顿迭代法的本质**：用**切线**近似曲线，将非线性问题转化为线性问题，反复逼近根。

$$
\boxed{x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}} \qquad (f'(x_n) \ne 0)
$$

从几何上看：在点 $(x_n, f(x_n))$ 处作切线，切线与 $x$ 轴的交点即为 $x_{n+1}$。重复此过程，逼近真实根。

### 2. 几何原理（数形结合）

1. 在曲线上取一点 $(x_n, f(x_n))$
2. 作该点的切线：$y - f(x_n) = f'(x_n)(x - x_n)$
3. 令 $y=0$，解得切线与 $x$ 轴的交点横坐标：
   $$
   x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}
   $$
4. 以 $x_{n+1}$ 为新的近似点，重复上述过程，直至收敛。


### 3. 收敛条件

| 条件                      | 说明                   |
| ----------------------- | -------------------- |
| $f'(x) \ne 0$           | 切线不能水平，否则无法与 $x$ 轴相交 |
| 初始值 $x_0$ 足够靠近根         | 牛顿迭代**局部收敛**，初值需在根附近 |
| $f''(x)$ 连续且 $f'(x)$ 有界 | 保证收敛速度               |

**收敛速度**：当 $x_n \to x^*$ 时，误差满足：
$$
e_{n+1} \approx \frac{f''(x^*)}{2f'(x^*)} e_n^2
$$
即**平方收敛**（二次收敛），每迭代一次，有效数字位数大致翻倍。


### 4. 典型应用

#### 4.1 求平方根 $\sqrt{a}$

令 $f(x) = x^2 - a$，则 $f'(x) = 2x$，迭代公式化为：

$$
x_{n+1} = \frac{1}{2}\left(x_n + \frac{a}{x_n}\right)
$$

> 这就是**巴比伦算法**，也是牛顿迭代法最经典的特例。

#### 4.2 求立方根 $\sqrt[3]{a}$

令 $f(x) = x^3 - a$，$f'(x) = 3x^2$，迭代公式：

$$
x_{n+1} = \frac{1}{3}\left(2x_n + \frac{a}{x_n^2}\right)
$$


### 5. 代码实现（C++）

```cpp
#include <cmath>
#include <iostream>
using namespace std;

double newton(double (*f)(double), double (*df)(double), double x0, double eps = 1e-8) {
    double x = x0;
    while (fabs(f(x)) > eps) {
        x = x - f(x) / df(x);
    }
    return x;
}

// 求 sqrt(2)
double f(double x) { return x*x - 2; }
double df(double x) { return 2*x; }

int main() {
    cout << newton(f, df, 1.5) << endl;  // 输出 1.41421356
}
```


### 6. 执行过程示例（求 $\sqrt{2}$）

| $n$ | $x_n$ | $f(x_n)$ | $x_{n+1}$ |
|-----|-------|----------|-----------|
| 0 | 1.5 | 0.25 | $1.5 - 0.25/3 = 1.4166667$ |
| 1 | 1.4166667 | 0.006944 | $1.4166667 - 0.006944/2.8333 = 1.4142157$ |
| 2 | 1.4142157 | 0.000006 | $1.4142157 - 0.000006/2.82843 = 1.41421356$ |
| 3 | 1.41421356 | $\approx 0$ | 收敛 |

3 次迭代达到 $10^{-8}$ 精度，验证了**平方收敛**。


### 7. 优缺点分析

| 优点 | 缺点 |
|------|------|
| 收敛速度快（二次收敛） | 需要计算导数，可能复杂 |
| 算法简单，易于实现 | 局部收敛，初值需靠近根 |
| 可推广到复数域 | 若 $f'(x)=0$ 在根附近，可能发散 |
| 广泛应用于数值计算 | 多重根时收敛速度降为线性 |


### 8. 408 关联：算法分析与复杂度

在408中，牛顿迭代法常作为**数值算法**的典型例子，考察点包括：

| 考察点 | 说明 |
|--------|------|
| **时间复杂度** | 每次迭代 $O(1)$ 或 $O(M(n))$（大数乘法），迭代次数受收敛速度影响 |
| **空间复杂度** | $O(1)$（只存几个变量） |
| **收敛性判断** | 何时停止、是否收敛到根 |
| **误差分析** | 绝对误差、相对误差 |
| **近似算法** | 用于求 $\sqrt{n}$、$\ln n$ 等基本函数的快速计算 |

> 在算法题中，若要求实现 `sqrt(double x)` 函数，牛顿迭代法是**最标准**的解法。

### 10. 易错与易混点

| 易错判断 | 正确理解 |
|----------|----------|
| “牛顿法可以求任意方程的根” | ❌ 仅适用于**可导**且导数不为零的函数 |
| “初值任意都能收敛” | ❌ 需**足够靠近**根（局部收敛） |
| “牛顿法是线性收敛” | ❌ 通常为**平方收敛**（多重根除外） |
| “$x_{n+1}=x_n - \frac{f(x_n)}{f'(x_n)}$ 是牛顿法唯一形式” | ✅ 是标准形式，但可推广到方程组、优化问题 |
| “牛顿法一定能找到根” | ❌ 可能振荡或发散 |
