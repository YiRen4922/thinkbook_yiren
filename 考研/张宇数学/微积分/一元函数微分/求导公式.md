## 微积分 · 导数公式与运算法则（考研数一核心笔记）

> 导数是**高等数学的基石**，也是分析函数变化率的核心工具。在408算法分析中，导数用于理解算法时间复杂度的变化趋势；在英语一中，`derivative`、`rate of change` 等词在科技类阅读中偶有出现。

---

### 1. 导数的定义

函数 $y = f(x)$ 在点 $x_0$ 处的导数定义为：

$$
\boxed{f'(x_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}}
$$

**几何意义**：导数表示曲线在点 $x_0$ 处的**切线斜率**。

**物理意义**：导数表示函数在该点的**瞬时变化率**。

```desmos-graph

bottom=-0.5; top=3.5
grid=true
---
y=x^2|blue|label:y=x^2
y=2x-1|red|label:y=2x-1 (切线)

```

> 抛物线 $y=x^2$ 在点 $(1,1)$ 处的切线斜率为 $f'(1)=2$，切线方程为 $y=2x-1$。

---

### 2. 导数的几何意义（数形结合）

| 导数符号 | 几何含义 | 函数趋势 |
|----------|----------|----------|
| $f'(x) > 0$ | 切线斜率为正 | 函数单调递增 |
| $f'(x) < 0$ | 切线斜率为负 | 函数单调递减 |
| $f'(x) = 0$ | 切线水平 | 可能为极值点 |
| $f''(x) > 0$ | 切线斜率递增 | 函数凹向上 |
| $f''(x) < 0$ | 切线斜率递减 | 函数凹向下 |

```desmos-graph

```

> $y=x^3-3x$ 在 $x=1$ 处切线斜率为0（极值点），在 $x=-1$ 处切线斜率为0（极值点）。

### 3. 基本初等函数求导公式

#### 3.1 常数函数

$$
(C)' = 0
$$

#### 3.2 幂函数

$$
(x^\mu)' = \mu x^{\mu-1}
$$

**考研常见形式**：

| 函数 | 导数 |
|------|------|
| $x^n$ | $n x^{n-1}$ |
| $\sqrt{x}$ | $\dfrac{1}{2\sqrt{x}}$ |
| $\dfrac{1}{x}$ | $-\dfrac{1}{x^2}$ |
| $\dfrac{1}{\sqrt{x}}$ | $-\dfrac{1}{2}x^{-3/2}$ |

#### 3.3 指数函数

$$
(a^x)' = a^x \ln a \quad (a > 0, a \neq 1)
$$

**特殊情况**：

$$
(e^x)' = e^x
$$

#### 3.4 对数函数

$$
(\log_a x)' = \frac{1}{x \ln a} \quad (a > 0, a \neq 1, x > 0)
$$

**自然对数**：

$$
(\ln x)' = \frac{1}{x}
$$

### 4. 三角函数求导公式

| 函数                        | 导数                         |
| ------------------------- | -------------------------- |
| $\sin x$                  | $\cos x$                   |
| $\cos x$                  | $-\sin x$                  |
| $\tan x$                  | $\sec^2 x$                 |
| $\cot x$                  | $-\csc^2 x$                |
| $\csc x$                  | $-\csc x \cot x$           |
| $\sec x$                  | $\sec x \tan x$            |
| $\arcsin x$               | $\dfrac{1}{\sqrt{1-x^2}}$  |
| $\arccos x$               | $-\dfrac{1}{\sqrt{1-x^2}}$ |
| $\arctan x$               | $\dfrac{1}{1+x^2}$         |
| $\operatorname{arccot} x$ | $-\dfrac{1}{1+x^2}$        |
> [!tip] 记忆口诀
> - $\arcsin$ 和 $\arccos$ 导数**只差一个负号**
> - $\arctan$ 和 $\operatorname{arccot}$ 导数**只差一个负号**
> - 正割与正切、余割与余切**成对出现**

### 5. 导数的四则运算法则

设 $u = u(x)$，$v = v(x)$ 均可导，$C$ 为常数。

| 法则   | 公式                                                                     |
| ---- | ---------------------------------------------------------------------- |
| 和与差  | $(u \pm v)' = u' \pm v'$                                               |
| 常数倍  | $(Cu)' = C u'$                                                         |
| 乘积法则 | $(uv)' = u'v + uv'$                                                    |
| 商法则  | $\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2} \quad (v \neq 0)$ |

> [!danger] 致命误区
> **乘积求导不是** $(uv)' = u'v'$，而是 $u'v + uv'$，少一项就全错！

### 6. 复合函数求导 · 链式法则

若 $y = f(u)$，$u = g(x)$，则：

$$
\boxed{[f(g(x))]' = f'(g(x)) \cdot g'(x)}
$$

**口诀**：**“外层求导，内层不动，再乘以内层导数”**

#### 考研常见复合类型

| 复合形式 | 导数 |
|----------|------|
| $[u(x)]^\mu$ | $\mu [u(x)]^{\mu-1} \cdot u'(x)$ |
| $e^{u(x)}$ | $e^{u(x)} \cdot u'(x)$ |
| $\ln u(x)$ | $\dfrac{u'(x)}{u(x)}$ |
| $\sin u(x)$ | $\cos u(x) \cdot u'(x)$ |
| $\cos u(x)$ | $-\sin u(x) \cdot u'(x)$ |
| $\arcsin u(x)$ | $\dfrac{u'(x)}{\sqrt{1-u^2(x)}}$ |
| $\arctan u(x)$ | $\dfrac{u'(x)}{1+u^2(x)}$ |

> [!example] 典型例题
>
> 求 $y = \sin(x^2)$ 的导数。
>
> **解**：外层 $\sin u$，内层 $u = x^2$。
> $$
> y' = \cos(x^2) \cdot 2x = 2x\cos(x^2)
> $$

```desmos-graph

---
y=\sin(x^2)|blue|label:y=\sin(x^2)
y=2x\cos(x^2)|red|label:y'=2x\cos(x^2)
```

> 复合函数 $\sin(x^2)$ 的导数为 $2x\cos(x^2)$，图像显示其变化频率随 $x$ 增大而加快。

### 7. 反函数求导法则

若 $y = f(x)$ 存在反函数 $x = f^{-1}(y)$，则：

$$
\boxed{[f^{-1}(x)]' = \frac{1}{f'(f^{-1}(x))}}
$$

**使用条件**：
- 函数在相应区间内严格单调（存在反函数）
- $f'(x) \neq 0$

> [!example] 典型应用
>
> 已知 $y = \arcsin x$ 是 $x = \sin y$（$-\frac{\pi}{2} < y < \frac{\pi}{2}$）的反函数：
> $$
> (\arcsin x)' = \frac{1}{\cos y} = \frac{1}{\sqrt{1-\sin^2 y}} = \frac{1}{\sqrt{1-x^2}}
> $$

### 8. 高阶导数

若函数 $f(x)$ 的导数 $f'(x)$ 仍然可导，则其导数为二阶导数：

$$
f''(x) = [f'(x)]'
$$

**考研常见高阶导数**：

| 函数 | $n$ 阶导数 |
|------|-----------|
| $e^x$ | $e^x$ |
| $\sin x$ | $\sin(x + \frac{n\pi}{2})$ |
| $\cos x$ | $\cos(x + \frac{n\pi}{2})$ |
| $x^\mu$ | $\mu(\mu-1)\cdots(\mu-n+1)x^{\mu-n}$ |
| $\ln x$ | $(-1)^{n-1}\frac{(n-1)!}{x^n}$ |

> [!example] 典型例题
>
> 求 $y = e^x \sin x$ 的 $n$ 阶导数。
>
> **解**：$e^x \sin x = \operatorname{Im}(e^{(1+i)x})$，故：
> $$
> y^{(n)} = (\sqrt{2})^n e^x \sin(x + \frac{n\pi}{4})
> $$

### 9. 408关联 · 导数与算法分析

在算法复杂度分析中，导数可用于理解函数增长趋势的**局部特征**。

> [!example] 复杂度曲线的变化率
>
> 若 $f(n) = n \log n$，则：
> $$
> f'(n) = \log n + 1
> $$
> 说明复杂度随 $n$ 增大，增长率也在缓慢增加（但远低于 $n^2$）。

> [!example] 牛顿法
>
> 牛顿法是典型的**利用导数迭代求解方程**的方法，在数值算法中广泛应用：
> $$
> x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}
> $$

### 10. 求导解题流程

```
识别函数结构
    ↓
是否为基本初等函数？ → 是 → 直接套公式
    ↓ 否
是否存在四则运算？ → 是 → 和/差/积/商法则
    ↓ 是
是否存在复合结构？ → 是 → 链式法则
    ↓ 是
是否存在反函数结构？ → 是 → 反函数求导法则
    ↓
化简结果
```

> [!tip] 核心四组公式
> 考研求导题的绝大多数情况，只需要掌握以下四组公式：
>
> 1. **基本公式**：$(x^\mu)' = \mu x^{\mu-1}$
> 2. **乘积法则**：$(uv)' = u'v + uv'$
> 3. **商法则**：$\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}$
> 4. **链式法则**：$[f(g(x))]' = f'(g(x)) \cdot g'(x)$
