## 罗尔中值定理 · 考研数一核心笔记

> 罗尔中值定理是微分中值定理体系的**基石**，拉格朗日中值定理和柯西中值定理均可由它推导。在考研中，罗尔定理是**证明等式、讨论方程根**的核心工具，几乎每年都有涉及。


### 一、定理内容

若函数 $f(x)$ 满足以下三个条件：

1. **在闭区间 $[a,b]$ 上连续**
2. **在开区间 $(a,b)$ 内可导**
3. **端点值相等**：$f(a) = f(b)$

则至少存在一点 $\xi \in (a,b)$，使得

$$
\boxed{f'(\xi) = 0}
$$


### 二、几何意义

若曲线 $y = f(x)$ 在闭区间 $[a,b]$ 上连续、在开区间 $(a,b)$ 内可导，且两个端点在同一水平线上，则曲线上至少存在一点，其**切线是水平的**。


> 图中虚线 $y=1$ 对应 $f(a)=f(b)=1$，曲线在 $x=1$ 处切线水平，$f'(1)=0$。


### 三、定理的三个条件缺一不可

| 条件 | 缺失后的反例 |
| :--- | :--- |
| 闭区间连续 | $f(x)=\frac{1}{x}$ 在 $[-1,1]$ 上不连续，不存在 $\xi$ |
| 开区间可导 | $f(x)=\|x\|$ 在 $[-1,1]$ 上 $x=0$ 处不可导，不存在 $\xi$ |
| 端点值相等 | $f(x)=x$ 在 $[0,1]$ 上 $f(0)\neq f(1)$，不存在 $\xi$ |

> [!warning] 考研易错点
> 三个条件是**充分条件**，不是必要条件。即使不满足某个条件，也可能存在 $f'(\xi)=0$，但定理**不能保证**。


### 四、定理的证明

**证明**：因为 $f(x)$ 在 $[a,b]$ 上连续，由**最值定理**，$f(x)$ 在 $[a,b]$ 上必取得最大值 $M$ 和最小值 $m$。

**情形一**：若 $M = m$，则 $f(x)$ 在 $[a,b]$ 上为常数，$f'(x) = 0$ 对一切 $x \in (a,b)$ 成立，任取 $\xi \in (a,b)$ 即可。

**情形二**：若 $M > m$。由于 $f(a) = f(b)$，最大值 $M$ 和最小值 $m$ 中至少有一个不等于端点值，即最值点不可能是两个端点。不妨设最大值 $M$ 在内部点 $\xi$ 处取得（$a<\xi<b$）。由**费马引理**，$f'(\xi)=0$。

证毕。$\square$


### 五、与其他中值定理的关系

$$
\text{罗尔定理} \xrightarrow{\text{构造辅助函数}} \text{拉格朗日中值定理} \xrightarrow{\text{推广}} \text{柯西中值定理}
$$

| 定理 | 条件 | 结论 |
| :--- | :--- | :--- |
| **罗尔定理** | $f(a)=f(b)$ | $f'(\xi)=0$ |
| **拉格朗日** | 无端点条件 | $f(b)-f(a)=f'(\xi)(b-a)$ |
| **柯西** | $g'(x)\neq 0$ | $\frac{f(b)-f(a)}{g(b)-g(a)}=\frac{f'(\xi)}{g'(\xi)}$ |

> 拉格朗日中值定理的证明思路：构造 $F(x) = f(x) - \frac{f(b)-f(a)}{b-a}(x-a)$，验证 $F(a)=F(b)$，对 $F$ 用罗尔定理。


### 六、考研应用：证明题的常用技巧

#### 6.1 直接验证型

**题目**：验证 $f(x) = x^3 - 3x$ 在 $[-1,1]$ 上是否满足罗尔定理。

**解**：
- 多项式函数，连续且可导 ✓
- $f(-1) = -1+3 = 2$，$f(1) = 1-3 = -2$，**$f(-1) \neq f(1)$** ✗

不满足罗尔定理条件。

#### 6.2 构造辅助函数型（考研核心）

> [!important] 核心思想
> 要证明 $F'(\xi)=0$，关键是**构造 $F(x)$**，使 $F(a)=F(b)$。

**常见题型与辅助函数构造**：

| 待证结论 | 辅助函数构造 |
| :--- | :--- |
| $f'(\xi)=0$ | 直接对 $f$ 用罗尔定理 |
| $f'(\xi)+f(\xi)=0$ | $F(x)=e^x f(x)$ |
| $f'(\xi)-f(\xi)=0$ | $F(x)=e^{-x}f(x)$ |
| $f'(\xi)+g'(\xi)f(\xi)=0$ | $F(x)=e^{g(x)}f(x)$ |
| $xf'(\xi)+f(\xi)=0$ | $F(x)=xf(x)$ |
| $xf'(\xi)-f(\xi)=0$ | $F(x)=\frac{f(x)}{x}$ |
| $f'(\xi)+kf(\xi)=0$ | $F(x)=e^{kx}f(x)$ |

**构造口诀**：看到 $f'$ 与 $f$ 的组合，想想 $e^{\int p(x)dx}$；看到 $xf'$ 与 $f$，想想乘积的导数。


### 七、典型例题

**题目**：设 $f(x)$ 在 $[0,1]$ 上连续，在 $(0,1)$ 内可导，$f(0)=f(1)=0$。证明：存在 $\xi \in (0,1)$，使 $f'(\xi) = f(\xi)$。

**证明**：

**构造辅助函数**：
$$
F(x) = e^{-x}f(x)
$$
则 $F(x)$ 在 $[0,1]$ 上连续，在 $(0,1)$ 内可导，且
$$
F(0) = e^0 f(0) = 0,\quad F(1) = e^{-1}f(1) = 0.
$$
所以 $F(0)=F(1)$。

由罗尔定理，存在 $\xi \in (0,1)$，使 $F'(\xi)=0$。

计算 $F'(x)$：
$$
F'(x) = -e^{-x}f(x) + e^{-x}f'(x) = e^{-x}[f'(x)-f(x)].
$$
代入 $x=\xi$：
$$
F'(\xi)=e^{-\xi}[f'(\xi)-f(\xi)]=0.
$$
因为 $e^{-\xi}\neq 0$，所以
$$
f'(\xi)=f(\xi).
$$

证毕。$\square$


### 八、讨论方程根的存在性

**题目**：证明方程 $x^3 - 3x + 1 = 0$ 在 $(0,1)$ 内有且仅有一个实根。

**证明**：

**① 存在性（零点定理）**：令 $f(x)=x^3-3x+1$。
- $f(0)=1>0$
- $f(1)=1-3+1=-1<0$

由零点定理，存在 $\xi\in(0,1)$，使 $f(\xi)=0$。

**② 唯一性（罗尔定理反证）**：假设有两个零点 $\xi_1<\xi_2$ 在 $(0,1)$ 内。
- $f(\xi_1)=f(\xi_2)=0$
- 由罗尔定理，存在 $\eta\in(\xi_1,\xi_2)\subset(0,1)$，使 $f'(\eta)=0$。

但
$$
f'(x)=3x^2-3=3(x^2-1)<0\quad (0<x<1),
$$
即 $f'(x)$ 在 $(0,1)$ 内恒不为零，矛盾。

所以方程在 $(0,1)$ 内有且仅有一个实根。$\square$

### 十、易错点

| 易错点 | 正确理解 |
| :--- | :--- |
| 忽略三个条件中的任何一个 | 三条件缺一不可，必须逐一验证 |
| 忘记验证 $f(a)=f(b)$ | 使用前先检查端点值 |
| 辅助函数构造错误 | 熟练掌握常见类型，如 $e^x f(x)$、$xf(x)$ |
| 认为 $\xi$ 唯一 | 罗尔定理只保证**至少存在一个**，不保证唯一 |
| 证明唯一性时不用反证 | 唯一性证明通常用反证法 + 罗尔定理 |


### 十一、核心公式速查卡

| 类别 | 公式/结论 |
| :--- | :--- |
| 罗尔定理 | 闭区间连续、开区间可导、端点相等 $\Rightarrow$ $\exists\xi,\ f'(\xi)=0$ |
| 辅助函数 $e^x f(x)$ | 用于 $f'+f=0$ |
| 辅助函数 $e^{-x}f(x)$ | 用于 $f'-f=0$ |
| 辅助函数 $xf(x)$ | 用于 $xf'+f=0$ |
| 辅助函数 $\frac{f(x)}{x}$ | 用于 $xf'-f=0$ |
| 辅助函数 $e^{g(x)}f(x)$ | 用于 $f'+g'f=0$ |
