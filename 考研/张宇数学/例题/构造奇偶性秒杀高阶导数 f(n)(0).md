## 考研数学 · 构造奇偶性秒杀高阶导数 $f^{(n)}(0)$

> 核心思想：很多函数本身非奇非偶，但通过**加减一个常数或一次多项式**，可以变成奇函数或偶函数，从而快速判断 $f^{(n)}(0)$ 是否为零，避免硬求导。


### 一、核心原理

| 函数类型 | 在 $x=0$ 处的导数性质 |
| :--- | :--- |
| **奇函数** | 偶阶导数为零：$f^{(2k)}(0)=0$ |
| **偶函数** | 奇阶导数为零：$f^{(2k+1)}(0)=0$ |

> [!important] 使用前提
> 该结论**仅在 $x=0$ 处成立**，其他点不适用。选择题、填空题可直接秒杀；大题需写出构造 $g(x)$ 并证明奇偶性。

> [!warning] 常见错误
> - 不是所有函数都能通过加减常数变成奇偶函数
> - 不要混淆奇函数和偶函数的导数性质
> - 构造时要注意定义域是否关于原点对称


### 二、指数分式型

#### 1. $f(x) = \dfrac{1}{e^x+1}$

原函数非奇非偶。构造：
$$
g(x) = f(x) - \frac{1}{2} = \frac{1}{e^x+1} - \frac{1}{2} = \frac{1-e^x}{2(e^x+1)}
$$
验证 $g(-x) = -g(x)$，故 $g(x)$ 为**奇函数**。

**结论**：$f^{(2k)}(0)=0$。

> 推广：$f(x)=\dfrac{1}{a^x+1}$（$a>0$，$a\neq1$），$f(x)-\dfrac{1}{2}$ 为奇函数。
	
#### 2. $f(x) = \dfrac{e^x}{e^x+1}$

构造：
$$
g(x) = f(x) - \frac{1}{2} = \frac{e^x-1}{2(e^x+1)}
$$
$g(x)$ 为**奇函数**。

**结论**：$f^{(2k)}(0)=0$。

#### 3. $f(x) = \dfrac{e^x-1}{e^x+1}$

本身为**奇函数**。

**结论**：$f^{(2k)}(0)=0$。

> 这是双曲正切 $\tanh\dfrac{x}{2}$ 的形式。

#### 4. $f(x) = \dfrac{a^x-1}{a^x+1}$（$a>0$，$a\neq1$）

本身为**奇函数**。

**结论**：$f^{(2k)}(0)=0$。

#### 5. $f(x) = \dfrac{1}{e^x-1} + \dfrac{1}{2}$

本身为**奇函数**。

**结论**：$f^{(2k)}(0)=0$。

#### 6. $f(x) = \dfrac{x}{e^x-1}$（修正）

原函数非奇非偶。构造：
$$
g(x) = f(x) + \frac{x}{2} = \frac{x}{e^x-1} + \frac{x}{2}
$$
$g(x)$ 为**偶函数**。

**结论**：$g^{(2k+1)}(0)=0$，即 $f^{(2k+1)}(0) + \left(\dfrac{x}{2}\right)^{(2k+1)}$ 的贡献需单独考虑。

> 注意：原函数本身不是偶函数，必须加上 $\dfrac{x}{2}$ 后才成为偶函数。


### 三、对数型

#### 7. $f(x) = \ln(1+e^x)$

构造：
$$
g(x) = f(x) - \frac{x}{2} = \ln(1+e^x) - \frac{x}{2}
$$
$g(x)$ 为**偶函数**。

**结论**：$g^{(2k+1)}(0)=0$，即 $f^{(2k+1)}(0)$ 中偶数阶项贡献为零，只剩 $\dfrac{x}{2}$ 的贡献。

#### 8. $f(x) = \ln(\sqrt{x^2+1}+x)$

本身为**奇函数**（反双曲正弦 $\operatorname{arsinh}x$）。

**结论**：$f^{(2k)}(0)=0$。

#### 9. $f(x) = \ln\dfrac{1-x}{1+x}$

本身为**奇函数**。

**结论**：$f^{(2k)}(0)=0$。


### 四、反三角函数型

#### 10. $f(x) = \arctan e^x$

构造：
$$
g(x) = f(x) - \frac{\pi}{4} = \arctan e^x - \frac{\pi}{4}
$$
$g(x)$ 为**奇函数**。

**结论**：$f^{(2k)}(0)=0$。

#### 11. $f(x) = \arctan\dfrac{1-x}{1+x}$

利用恒等式 $\arctan\dfrac{1-x}{1+x} = \dfrac{\pi}{4} - \arctan x$（$x>-1$）。

构造：
$$
g(x) = f(x) - \frac{\pi}{4} = -\arctan x
$$
$g(x)$ 为**奇函数**。

**结论**：$f^{(2k)}(0)=0$。


### 五、双曲函数型

#### 12. $\sinh x = \dfrac{e^x-e^{-x}}{2}$

本身为**奇函数**。

**结论**：$f^{(2k)}(0)=0$。

#### 13. $\cosh x = \dfrac{e^x+e^{-x}}{2}$

本身为**偶函数**。

**结论**：$f^{(2k+1)}(0)=0$。

#### 14. $\tanh x = \dfrac{e^x-e^{-x}}{e^x+e^{-x}}$

本身为**奇函数**。

**结论**：$f^{(2k)}(0)=0$。


### 六、基础必背

| 函数 | 奇偶性 | 结论 |
| :--- | :--- | :--- |
| $\sin x$ | 奇函数 | $f^{(2k)}(0)=0$ |
| $\cos x$ | 偶函数 | $f^{(2k+1)}(0)=0$ |
| $x^n$（$n$ 为奇数） | 奇函数 | 偶阶导数为 0 |
| $x^n$（$n$ 为偶数） | 偶函数 | 奇阶导数为 0 |

### 八、使用技巧与易错点

> [!tip] 使用技巧
> 1. 看到“求 $f^{(n)}(0)$”时，**优先考虑构造奇偶性**，比泰勒展开更快。
> 2. 选择题、填空题可直接用结论秒杀。
> 3. 大题需写出构造 $g(x)$ 并证明奇偶性的过程。
> 4. 注意区分“原函数”和“构造后函数”的奇偶性。

> [!warning] 易错点
> - 奇函数：偶阶导数为 0；偶函数：奇阶导数为 0。**不要记反**。
> - 构造的常数或多项式可能影响低阶导数，但高阶导数的零值性质不变。
> - 仅在 $x=0$ 处有效，其他点不适用。
> - 定义域必须关于原点对称，否则无法讨论奇偶性。
> - 原函数 $\dfrac{x}{e^x-1}$ **本身不是偶函数**，必须加上 $\dfrac{x}{2}$ 后才成为偶函数。
