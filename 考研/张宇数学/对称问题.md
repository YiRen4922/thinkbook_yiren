## 对称问题 · 考研数一专题详解

> 对称是高等数学中贯穿始终的核心思想，在极限、导数、积分中均有重要应用。掌握对称性，可以有效简化计算，避免分类讨论，是考研数一的高频技巧。

---

### 1. 函数图像的两类对称

#### 1.1 轴对称（关于直线 $x = a$）

若函数 $y = f(x)$ 的图像关于直线 $x = a$ 对称，则对定义域内任意 $x$，有：

$$
\boxed{f(a + x) = f(a - x)}
$$

**几何含义**：距离直线 $x = a$ 左右两侧相等距离的点，函数值相等。

**特例**：当 $a = 0$ 时，即为**偶函数**：

$$
f(-x) = f(x)
$$

图像关于 $y$ 轴对称。

> [!example] 典型例子
> - $y = x^2$，$y = |x|$，$y = \cos x$ 均为偶函数（关于 $y$ 轴对称）
> - 二次函数 $y = ax^2 + bx + c$ 的对称轴为 $x = -\dfrac{b}{2a}$
> - 判断方法：若 $f(x) = f(2a - x)$，则关于 $x = a$ 对称

> 抛物线 $y=x^2$ 关于 $y$ 轴（$x=0$）对称。

#### 1.2 中心对称（关于点 $(a, b)$）

若函数 $y = f(x)$ 的图像关于点 $(a, b)$ 对称，则对定义域内任意 $x$，有：

$$
\boxed{f(a + x) + f(a - x) = 2b}
$$

**几何含义**：点 $(a+x, f(a+x))$ 和点 $(a-x, f(a-x))$ 关于点 $(a, b)$ 中心对称。

**特例**：当 $(a, b) = (0, 0)$ 时，即为**奇函数**：

$$
f(-x) = -f(x)
$$

图像关于原点对称。

> [!example] 典型例子
> - $y = x^3$，$y = \sin x$，$y = \tan x$ 均为奇函数（关于原点对称）
> - 三次函数 $y = ax^3 + bx^2 + cx + d$ 的对称中心为 $\left(-\dfrac{b}{3a}, f\left(-\dfrac{b}{3a}\right)\right)$
> - 分式函数 $y = \dfrac{ax+b}{cx+d}$ 的对称中心为 $\left(-\dfrac{d}{c}, \dfrac{a}{c}\right)$

> 三次函数 $y=x^3$ 关于原点 $(0,0)$ 中心对称。

### 2. 奇偶性的运算规律

| 运算           | 结果  | 示例                    |
| ------------ | --- | --------------------- |
| 偶 $\pm$ 偶    | 偶   | $x^2 + x^4$           |
| 奇 $\pm$ 奇    | 奇   | $x^3 + x$             |
| 偶 $\times$ 偶 | 偶   | $x^2 \cdot x^4 = x^6$ |
| 奇 $\times$ 奇 | 偶   | $x^3 \cdot x = x^4$   |
| 偶 $\times$ 奇 | 奇   | $x^2 \cdot x^3 = x^5$ |
| 偶 $\circ$ 任意 | 偶   | $f(\cos x)$           |
| 奇 $\circ$ 偶  | 偶   | $\sin(\cos x)$        |
| 奇 $\circ$ 奇  | 奇   | $\sin(x^3)$           |

> [!tip] 记忆口诀
> **“奇奇得偶，奇偶得奇，偶偶得偶”**（乘法）

### 3. 导函数的对称性（考研高频）

| 原函数的对称性 | 导函数的对称性 |
|----------------|---------------|
| $f(x)$ 为偶函数（关于 $y$ 轴对称） | $f'(x)$ 为**奇函数**（关于原点对称） |
| $f(x)$ 为奇函数（关于原点对称） | $f'(x)$ 为**偶函数**（关于 $y$ 轴对称） |
| $f(x)$ 关于 $x = a$ 轴对称 | $f'(x)$ 关于点 $(a, 0)$ 中心对称 |
| $f(x)$ 关于点 $(a, b)$ 中心对称 | $f'(x)$ 关于直线 $x = a$ 轴对称 |

> [!important] 记忆口诀
> **“求导一次，奇偶互换”**——偶函数求导变奇函数，奇函数求导变偶函数。

**验证**：
- $f(x) = x^2$（偶函数），$f'(x) = 2x$（奇函数）✅
- $f(x) = x^3$（奇函数），$f'(x) = 3x^2$（偶函数）✅

### 4. 对称性在定积分中的应用（绝对重点）

#### 4.1 基本结论

对于对称区间 $[-a, a]$：

- 若 $f(x)$ 为**偶函数**，则：

$$
\int_{-a}^{a} f(x) \, dx = 2\int_{0}^{a} f(x) \, dx
$$

- 若 $f(x)$ 为**奇函数**，则：

$$
\int_{-a}^{a} f(x) \, dx = 0
$$

#### 4.2 任意函数的拆分（万能技巧）

任意函数 $f(x)$ 都可拆分为偶函数部分和奇函数部分：

$$
f(x) = \frac{f(x) + f(-x)}{2} + \frac{f(x) - f(-x)}{2}
$$

其中第一项为偶函数，第二项为奇函数。

在 $[-a, a]$ 上积分时，奇函数部分贡献为 $0$，故：

$$
\boxed{\int_{-a}^{a} f(x) \, dx = \int_{-a}^{a} \frac{f(x) + f(-x)}{2} \, dx = \int_{0}^{a} [f(x) + f(-x)] \, dx}
$$

> [!example] 典型例题
>
> 计算 $\displaystyle \int_{-\pi}^{\pi} x^3 \cos x \, dx$。
>
> **解**：设 $f(x) = x^3 \cos x$，则：
> $$
> f(-x) = (-x)^3 \cos(-x) = -x^3 \cos x = -f(x)
> $$
> 故 $f(x)$ 为奇函数，在对称区间 $[-\pi, \pi]$ 上的积分为 $0$。
> $$
> \boxed{0}
> $$

> [!example] 构造奇偶部分
>
> 计算 $\displaystyle \int_{-1}^{1} \frac{x^2}{e^x + 1} \, dx$。
>
> **解**：设 $f(x) = \dfrac{x^2}{e^x + 1}$，直接积分困难。将其拆分为偶函数部分：
> $$
> \frac{f(x) + f(-x)}{2} = \frac{1}{2}\left(\frac{x^2}{e^x+1} + \frac{x^2}{e^{-x}+1}\right)
> = \frac{1}{2}\left(\frac{x^2}{e^x+1} + \frac{x^2 e^x}{e^x+1}\right) = \frac{x^2}{2}
> $$
> 故：
> $$
> \int_{-1}^{1} \frac{x^2}{e^x + 1} \, dx = \int_{-1}^{1} \frac{x^2}{2} \, dx = \int_{0}^{1} x^2 \, dx = \frac{1}{3}
> $$

### 5. 对称性在二重积分中的应用（数一进阶）

对于关于坐标轴对称的积分区域 $D$：

- 若 $f(x,y)$ 关于 $x$ 为奇函数，则 $\iint_D f(x,y) \, d\sigma = 0$
- 若 $f(x,y)$ 关于 $y$ 为奇函数，则 $\iint_D f(x,y) \, d\sigma = 0$
- 若 $f(x,y)$ 关于 $x,y$ 均为偶函数，则 $\iint_D f(x,y) \, d\sigma = 4\iint_{D_1} f(x,y) \, d\sigma$（$D_1$ 为第一象限部分）

> [!example] 典型例题
>
> 计算 $\displaystyle \iint_{x^2+y^2 \le 1} xy \, dxdy$。
>
> **解**：被积函数 $f(x,y) = xy$ 关于 $x$ 为奇函数（$f(-x,y) = -xy$），区域 $D$ 关于 $y$ 轴对称，故：
> $$
> \iint_D xy \, dxdy = 0
> $$

### 6. 对称性在微分方程中的应用

若微分方程具有对称结构，可利用对称性简化求解或判断解的性质。

> [!example] 典型例题
>
> 已知 $y = f(x)$ 是微分方程 $y' + y = e^{-x}$ 的解，且 $f(x)$ 为偶函数，求 $f(0)$。
>
> **解**：由 $f(x)$ 为偶函数，$f'(x)$ 为奇函数，故 $f'(0) = 0$。
>
> 代入原方程 $y' + y = e^{-x}$，令 $x = 0$：
> $$
> f'(0) + f(0) = e^0 = 1 \quad \Longrightarrow \quad f(0) = 1
> $$

### 7. 对称性与408的关联（跨学科拓展）

虽然408不直接考函数对称性，但“对称思想”贯穿算法设计：

| 数学对称 | 算法对称 | 对应关系 |
|----------|----------|----------|
| $f(x) = f(-x)$（偶函数） | 回文串 $s[i] = s[n-1-i]$ | 镜像相等 |
| 函数关于直线对称 | 二叉树镜像（左右子树交换） | 递归镜像 |
| 奇函数在对称区间积分为0 | 对称矩阵压缩存储（$a_{ij} = a_{ji}$） | 利用对称性减少存储 |
| 二分法（区间对称分割） | 归并排序、二分查找 | 分治思想 |

### 8. 易错点汇总

| 易错判断 | 正确理解 |
|----------|----------|
| “偶函数的导函数也是偶函数” | ❌ 错误。偶函数求导变**奇函数**。 |
| “关于 $x=a$ 对称满足 $f(a+x) = f(x-a)$” | ❌ 错误。正确为 $f(a+x) = f(a-x)$。 |
| “奇函数在 $[-a,a]$ 上的积分一定为0” | ✅ 正确。前提是积分存在且区间关于原点对称。 |
| “$f(x) = \ln(x + \sqrt{x^2+1})$ 是偶函数” | ❌ 错误。$\ln(x + \sqrt{x^2+1})$ 是**奇函数**。 |
| “任意函数都能拆成奇函数和偶函数之和” | ✅ 正确。公式为 $f(x) = \frac{f(x)+f(-x)}{2} + \frac{f(x)-f(-x)}{2}$。 |

### 9. 核心公式速查卡

| 类别 | 公式 |
|------|------|
| 轴对称（直线 $x = a$） | $f(a+x) = f(a-x)$ |
| 中心对称（点 $(a, b)$） | $f(a+x) + f(a-x) = 2b$ |
| 偶函数（$a=0$） | $f(-x) = f(x)$ |
| 奇函数（$a=0, b=0$） | $f(-x) = -f(x)$ |
| 偶函数积分 | $\displaystyle \int_{-a}^{a} f(x) \, dx = 2\int_{0}^{a} f(x) \, dx$ |
| 奇函数积分 | $\displaystyle \int_{-a}^{a} f(x) \, dx = 0$ |
| 任意函数拆分 | $\displaystyle f(x) = \frac{f(x)+f(-x)}{2} + \frac{f(x)-f(-x)}{2}$ |
| 导函数对称性 | 偶 $\to$ 奇，奇 $\to$ 偶（求导一次） |
