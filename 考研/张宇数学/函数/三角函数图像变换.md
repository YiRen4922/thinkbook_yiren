## 三角函数图像变换 · 考研数一核心笔记

> 三角函数图像变换是数一中**函数图像变换**与**三角函数**的交汇点，也是每年必考内容。核心是掌握 $y = A\sin(\omega x + \varphi) + B$ 中每个参数对图像的影响，以及**变换的顺序**对最终结果的决定作用。在408中，FFT（快速傅里叶变换）和图形学旋转矩阵均依赖三角函数；在英语一中，`amplitude`、`phase`、`period` 等词为科技类高频词汇。


### 1. 标准形式

$$
\boxed{y = A\sin(\omega x + \varphi) + B}
$$

| 参数 | 名称 | 几何意义 |
|------|------|----------|
| $A$ | **振幅** | 纵向伸缩，$y$ 的范围为 $[-A, A]$ |
| $\omega$ | **角频率** | 横向伸缩，周期 $T = \dfrac{2\pi}{\omega}$ |
| $\varphi$ | **初相** | 水平平移（相位） |
| $B$ | **纵向平移** | 整体上下移动 |


### 2. 图像变换的**核心顺序**（考研高频 ⭐）

**先平移后伸缩**与**先伸缩后平移**，结果是**不一样**的！这是考研选择题和大题中**最容易失分**的陷阱。

#### 2.1 先平移后伸缩（推荐，不易出错）

从 $y = \sin x$ 变换到 $y = \sin(2x + \frac{\pi}{3})$：

| 步骤 | 操作 | 结果 |
|------|------|------|
| ① | $y = \sin x$ 向左平移 $\frac{\pi}{3}$ | $y = \sin(x + \frac{\pi}{3})$ |
| ② | 横向压缩为原来的 $\frac{1}{2}$（$\omega = 2$） | $y = \sin(2x + \frac{\pi}{3})$ ✅ |

#### 2.2 先伸缩后平移（易错）

| 步骤 | 操作 | 结果 |
|------|------|------|
| ① | $y = \sin x$ 横向压缩为原来的 $\frac{1}{2}$ | $y = \sin 2x$ |
| ② | 向左平移 **$\frac{\pi}{6}$**（不是 $\frac{\pi}{3}$！） | $y = \sin 2(x + \frac{\pi}{6}) = \sin(2x + \frac{\pi}{3})$ ✅ |

> [!warning] 致命误区
> 先伸缩后平移时，平移量必须**除以 $\omega$**，即 $y = \sin(2x + \frac{\pi}{3})$ 的平移量为 $\frac{\pi/3}{2} = \frac{\pi}{6}$，而不是 $\frac{\pi}{3}$。

### 4. 三种基本变换速查表

#### 4.1 振幅变换（纵向伸缩）

| 操作 | 表达式 | 效果 |
|------|--------|------|
| 纵向拉伸 $A$ 倍 | $y = A f(x)$（$A > 1$） | 图像变高，值域扩大 |
| 纵向压缩 $A$ 倍 | $y = A f(x)$（$0 < A < 1$） | 图像变矮，值域缩小 |

#### 4.2 周期变换（横向伸缩）

| 操作              | 表达式                                 | 效果                   |
| --------------- | ----------------------------------- | -------------------- |
| 横向压缩 $\omega$ 倍 | $y = f(\omega x)$（$\omega > 1$）     | 周期变为 $T/\omega$，图像变窄 |
| 横向拉伸 $\omega$ 倍 | $y = f(\omega x)$（$0 < \omega < 1$） | 周期变为 $T/\omega$，图像变宽 |

> 周期公式：$T = \dfrac{2\pi}{\omega}$

#### 4.3 相位变换（水平平移）

| 操作 | 表达式 | 效果 |
|------|--------|------|
| 向左平移 $\varphi$ | $y = f(x + \varphi)$（$\varphi > 0$） | 图像左移（“左加”） |
| 向右平移 $\varphi$ | $y = f(x - \varphi)$（$\varphi > 0$） | 图像右移（“右减”） |


### 5. 快速判断变换顺序的“三步法”

给定 $y = \sin x$ 变换到 $y = A\sin(\omega x + \varphi) + B$：

| 步骤  | 操作                        | 注意事项          |
| --- | ------------------------- | ------------- |
| ①   | 先平移：$x$ 替换为 $x + \varphi$ | 直接加 $\varphi$ |
| ②   | 再伸缩：$x$ 替换为 $\omega x$    | 整体替换          |
| ③   | 最后纵向：振幅 $A$ + 平移 $B$      | 最后处理          |

即：$y = \sin x \xrightarrow{\text{平移}} \sin(x+\varphi) \xrightarrow{\text{伸缩}} \sin(\omega x + \varphi) \xrightarrow{\text{纵向}} A\sin(\omega x + \varphi) + B$


### 6. 考研常见题型

| 题型 | 核心方法 | 示例 |
|------|----------|------|
| **由图像求解析式** | 从图像读出 $A$、$T$、$\varphi$、$B$ | 给出图像求 $y = A\sin(\omega x + \varphi) + B$ |
| **由解析式画图像** | 按照平移→伸缩→纵向的步骤 | 写出变换过程 |
| **判断变换是否正确** | 检查平移量是否除以 $\omega$ | “$y = \sin(2x + \frac{\pi}{3})$ 是 $y = \sin 2x$ 左移 $\frac{\pi}{3}$” → ❌ |
| **由平移求参数** | 逆向计算 $\varphi$ | 图像左移 $a$ 后过某点，求 $\omega$ 或 $\varphi$ |


### 7. 408 关联：三角函数在算法中的应用

| 方向 | 关联内容 |
|------|----------|
| **FFT（快速傅里叶变换）** | 将信号分解为正弦/余弦波，核心为 $e^{i\omega t} = \cos(\omega t) + i\sin(\omega t)$，依赖三角函数 |
| **计算机图形学旋转矩阵** | 二维旋转：$\begin{pmatrix}\cos\theta & -\sin\theta \\ \sin\theta & \cos\theta\end{pmatrix}$，图像变换与此完全一致 |
| **信号处理** | 振幅 $A$ 对应信号的强度，周期 $T$ 对应频率，相位 $\varphi$ 对应时延 |
| **递归与分治** | FFT 的分治结构与三角函数的周期性紧密相关 |


### 8. 易错与易混点

| 易错判断 | 正确理解 |
|----------|----------|
| “$y = \sin(2x + \frac{\pi}{3})$ 是 $y = \sin x$ 左移 $\frac{\pi}{3}$ 再横向压缩” | ✅ 正确（先平移后伸缩） |
| “$y = \sin(2x + \frac{\pi}{3})$ 是 $y = \sin x$ 横向压缩再左移 $\frac{\pi}{3}$” | ❌ 错误。先伸缩后平移，平移量应为 $\frac{\pi}{6}$ |
| “振幅 $A$ 影响周期” | ❌ 错误。$A$ 只影响值域，不影响周期 |
| “$B$ 影响值域” | ✅ 正确。$B$ 整体上下平移 |
| “$\omega$ 为负值时，周期为负” | ❌ 错误。周期 $T = \dfrac{2\pi}{|\omega|}$ |


### 9. 核心公式速查卡

| 类别 | 公式 |
|------|------|
| 标准形式 | $y = A\sin(\omega x + \varphi) + B$ |
| 周期 | $T = \dfrac{2\pi}{\omega}$ |
| 值域 | $[-A + B, A + B]$ |
| 振幅 | $\|A\|$ |
| 相位 | $\varphi$ |
| 频率 | $f = \dfrac{\omega}{2\pi}$ |
| 先平移后伸缩 | $y = \sin x \to \sin(x+\varphi) \to \sin(\omega x + \varphi)$ |
| 先伸缩后平移 | $y = \sin x \to \sin(\omega x) \to \sin(\omega(x + \frac{\varphi}{\omega}))$ |
