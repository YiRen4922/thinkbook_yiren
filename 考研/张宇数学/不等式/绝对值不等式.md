### 🎯 考研数学·绝对值不等式全攻略

绝对值问题的核心，就是 **“去绝对值符号”** ，而方法的选择取决于题目类型。

#### 1. 基础方法：公式法与平方法

这是你笔记中1、2、4题用到的方法，适用场景很明确。

- **公式法（适用于$a \ge 0$）**
  - $|x| > a \iff x > a$ 或 $x < -a$（“大于号，取两边”）。
  - $|x| < a \iff -a < x < a$（“小于号，取中间”）。
- **平方法（适用于两边都非负的情况）**
  - $|a| < |b| \iff a^2 < b^2$。这个方法很强大，特别适合解像$|2x-1| < \sqrt{3x+2}$这样的题，可以避免复杂的讨论。需要注意，平方后可能会产生增根，需要代入检验。
  - $|f(x)| < g(x)$ 也可以先平方转化为 $f^2(x) < g^2(x)$，同时别忘了保证 $g(x) \ge 0$。

#### 2. 核心方法：零点分段讨论法

这是解**多个绝对值之和（或差）**不等式（如你笔记中的5、6题）的通用必杀技。

核心原则是“**分段讨论，分别求解，最后取并集**”。

- **操作步骤**
  1.  **找零点**：令每个绝对值内的表达式为0，求出所有零点。
  2.  **分区间**：用这些零点把数轴分成若干个区间。
  3.  **去符号**：在每个区间内，根据绝对值内表达式的正负，去掉绝对值，得到一个普通不等式。
  4.  **求交集**：解出每个区间内不等式的解集，并与当前区间求交集。
  5.  **取并集**：将所有区间上得到的解集合并起来。
- **实战分析（修正你的笔记）**
  - **第5题**：$|x+1| + |x-3| \ge 8$。零点为 $-1, 3$。
    - $x \le -1$ 时，原式为 $-(x+1) - (x-3) \ge 8 \Rightarrow -2x+2 \ge 8 \Rightarrow x \le -3$。
    - $-1 < x < 3$ 时，$(x+1) - (x-3) \ge 8 \Rightarrow 4 \ge 8$，无解。
    - $x \ge 3$ 时，$(x+1) + (x-3) \ge 8 \Rightarrow 2x-2 \ge 8 \Rightarrow x \ge 5$。
    - **最终解集**：$x \in (-\infty, -3] \cup [5, +\infty)$。你笔记中的 $-1 \le x \le 3$ 和 $x \ge 5$、$x \le -3$ 这几个结论，整合一下就对了。
  - **第6题**：$|2x-1| + |3x+5| - |x-2| \le 12$。零点为 $-5/3, 1/2, 2$。
    - $x < -\frac{5}{3}$ 时，原式为 $-(2x-1) - (3x+5) - [-(x-2)] \le 12$，计算得 $-4x -6 \le 12 \Rightarrow x \ge -\frac{9}{2}$，交集为 $[-\frac{9}{2}, -\frac{5}{3})$。
    - $-\frac{5}{3} \le x < \frac{1}{2}$ 时，$-(2x-1) + (3x+5) - [-(x-2)] \le 12$，得 $2x+4 \le 12 \Rightarrow x \le 4$，交集为 $[-\frac{5}{3}, \frac{1}{2})$。
    - $\frac{1}{2} \le x < 2$ 时，$(2x-1) + (3x+5) - [-(x-2)] \le 12$，得 $6x+2 \le 12 \Rightarrow x \le \frac{5}{3}$，交集为 $[\frac{1}{2}, \frac{5}{3}]$。
    - $x \ge 2$ 时，$(2x-1) + (3x+5) - (x-2) \le 12$，得 $4x+6 \le 12 \Rightarrow x \le \frac{3}{2}$，与 $x \ge 2$ 无交集。
    - **最终解集**：$[-\frac{9}{2}, \frac{5}{3}]$。

#### 3. 几何法与特殊技巧

- **几何法（数轴距离）**：$|x-a|$ 在数轴上表示点 $x$ 到点 $a$ 的**距离**。所以 $|x+1| + |x-3| \ge 8$ 的几何意义是：数轴上一点到 $-1$ 和 $3$ 的距离之和至少为8。你可以用这个思路快速验证第5题的答案。
- **最大值/最小值结论**：$|x-a| + |x-b| \ge |a-b|$，等号成立条件为 $x$ 在 $a, b$ 之间。这个结论在求最值时很有用。

### 📈 数一视角：绝对值与高数考点的结合

考研数学一很少直接考你解绝对值不等式，但它是一个**基础工具**，会隐藏在这些地方：

- **1. 证明绝对值不等式（拉格朗日中值定理）**
  - **题型**：证明 $|f(x) - f(y)| \le M |x-y|$。
  - **解法**：直接套用拉格朗日中值定理：$f(x)-f(y) = f'(\xi)(x-y)$，两边取绝对值，再利用题目给的 $|f'(\xi)| \le M$ 的条件。
- **2. 求函数极值与最值**
  - **题型**：求 $f(x) = |x^2-3x+2|$ 在区间上的最值。
  - **解法**：先去绝对值符号，转化为分段函数，然后分别求各段的最值，再比较得出全局最值。
- **3. 判断级数与积分的敛散性**
  - **题型**：判断 $\sum \left|\frac{(-1)^n}{n^p}\right|$ 的敛散性。
  - **解法**：判断绝对值级数是否收敛，这是判断原级数是否**绝对收敛**的前提。

### 💎 解题核心心法

处理绝对值问题，你的思考路径应该是这样：

1.  **一眼看穿**：式子两边是否都非负？如果是，**优先考虑平方**。
2.  **“零点”定江山**：如果出现多个绝对值相加或相减，**立刻用零点分段法**，这是最稳妥的通用方法。
3.  **高数考题转化**：如果在导数、积分或级数题里看到绝对值，思路要立刻切换到**分段函数讨论**或**放缩法**。
