# 考研英语一 · 常见词根总览

> [!abstract] 使用方法
> **单词 = 前缀（方向）+ 词根（核心义）+ 后缀（词性）**
> - 词根决定一个词"本来是什么意思"，前缀决定"往哪个方向引申"
> - 词根只能帮助**猜测与串联**词义，具体含义务必结合语境与真题
> - 建议先背本页"优先掌握 TOP 10"，再结合下方的分类总表逐个击破

## 四、易混词根辨析

| 词根 A | 含义 | 例词 | 词根 B | 含义 | 例词 |
|---|---|---|---|---|---|
| dict | 说 | predict 预言 | duct | 引导 | produce 生产 |
| cept | 拿 | concept 概念 | sect | 切 | insect 昆虫 |
| cess | 走 | process 过程 | sess | 坐 | session 会议 |
| pos | 放 | compose 组成 | port | 搬 | transport 运输 |
| ten | 握住 | retain 保留 | tend | 伸展 | extend 延伸 |
| grad | 步 | graduate 毕业 | gress | 走（同源双形） | progress 进步 |

> [!tip] 同根两义注意
> **vol** 有两条独立的语义线：
> - **意愿**：voluntary 自愿的、benevolent 善意的
> - **滚/卷**：involve 卷入、evolve 进化、revolution 革命、volume 卷/册/音量
> 看到含 vol 的词，先判断是"意志"还是"滚动"，再结合上下文。

## 五、优先掌握 TOP 10（第一优先级）

> [!important] 先背这十个，性价比最高
> 1. **spect = 看** → inspect / respect / suspect / prospect（[[spect]]）
> 2. **dict = 说** → predict / contradict / indicate / dictate
> 3. **port = 搬** → transport / export / import / support / report
> 4. **tract = 拉** → attract / extract / contract / distract
> 5. **cess / ceed = 走** → process / proceed / exceed / access
> 6. **struct = 建** → construct / instruct / structure / infrastructure（[[struct]]）
> 7. **form = 形** → reform / inform / conform / formal（[[form]]）
> 8. **vert / vers = 转** → convert / reverse / diverse / advertise / universe
> 9. **pos / pon = 放** → compose / expose / propose / deposit / opponent
> 10. **fer = 带** → transfer / prefer / refer / conference / offer


> [!tip] 一句话记忆
> **词根 = 核心动作，前缀 = 方向**：
> - **in** 向内 → inspect 往里看 → 检查
> - **ex** 向外 → export 往外搬 → 出口
> - **re** 向后 → reverse 往回转 → 逆转
> - **con** 一起 → connect 连到一起 → 连接
> - **pre** 在前 → predict 提前说 → 预言
> - **pro** 向前 → promote 往前推 → 促进
>
> 看到生词先分解：找词根想核心义，找前缀定方向，再放回语境验证。
