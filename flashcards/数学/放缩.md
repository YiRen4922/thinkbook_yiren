### 一、重要不等式（用于夹逼与放缩）

利用简单的放大与缩小求极限时，针对无穷项相加的放缩规则是什么？
??
设数列各项为 $u_i$，则：
$n \cdot u_{\min} \le u_1 + u_2 + \cdots + u_n \le n \cdot u_{\max}$
特别地，当 $u_i \ge 0$ 时：
$1 \cdot u_{\max} \le u_1 + u_2 + \cdots + u_n \le n \cdot u_{\max}$

绝对值不等式（两项）有哪些？
?
$|a+b| \le |a|+|b|$，等号成立当且仅当 $ab \ge 0$；
$|a-b| \le |a|+|b|$，等号成立当且仅当 $ab \le 0$；
$||a|-|b|| \le |a \pm b| \le |a|+|b|$；
特别地，$||a|-|b|| \le |a-b|$。

绝对值不等式（推广到 $n$ 个实数）？
:::
$|a_1 \pm a_2 \pm \dots \pm a_n| \le |a_1| + |a_2| + \dots + |a_n|$

二元均值不等式链？
:::
$\sqrt{ab} \le \frac{a+b}{2} \le \sqrt{\frac{a^2+b^2}{2}} \quad (a,b \ge 0)$

三元均值不等式链？
:::
$\sqrt[3]{abc} \le \frac{a+b+c}{3} \le \sqrt{\frac{a^2+b^2+c^2}{3}} \quad (a,b,c \ge 0)$

幂次不等式：已知 $a \ge b \ge 0$？
:::
当 $m>0$ 时，$a^m \ge b^m$；当 $m<0$ 时，$a^m \le b^m$

分式不等式：若 $0<a<x<b$，$0<c<y<d$？
:::
$\frac{c}{b} < \frac{y}{x} < \frac{d}{a}$（分母大，值反而小）

三角函数不等式（$0 < x < \frac{\pi}{2}$）？
:::
$\sin x < x < \tan x$

三角函数不等式（$x > 0$）？
:::
$\sin x < x$

三角函数不等式（$0 < x < \frac{\pi}{4}$）？
:::
$x < \tan x < \frac{4}{\pi}x$

三角函数不等式（$0 < x < \frac{\pi}{2}$）？
:::
$\sin x > \frac{2}{\pi}x$

反三角函数不等式（$0 \le x \le 1$）？
:::
$\arctan x \le x \le \arcsin x$

指数不等式（任意 $x$）？
:::
$e^x \ge x+1$

对数不等式（$x>0$）？
:::
$x-1 \ge \ln x$

对数中值定理形式（$x>0$）？
:::
$\frac{1}{1+x} < \ln\left(1+\frac{1}{x}\right) < \frac{1}{x}$  
或 $\frac{x}{1+x} < \ln(1+x) < x$

### 二、数列极限核心原理（压缩映射）

闭区间上连续函数的重要性质？
:::
闭区间上连续函数必有最大值与最小值。

压缩映射原理一的内容？
:::
对数列 $\{x_n\}$，若存在常数 $k(0<k<1)$，使得 $|x_{n+1} - a| \le k|x_n - a|$，则 $\{x_n\}$ 收敛于 $a$。

压缩映射原理一如何证明？
:::
递推放缩：$|x_{n+1}-a| \le k|x_n-a| \le \dots \le k^n|x_1-a|$，由于 $\lim k^n = 0$，由夹逼准则得 $\lim |x_{n+1}-a| = 0$。

压缩映射原理二的内容？
:::
对数列 $x_{n+1} = f(x_n)$，若 $f(x)$ 可导，$a$ 是 $f(x)=x$ 的唯一解，且对任意 $x$ 有 $|f'(x)| \le k < 1$，则 $\{x_n\}$ 收敛于 $a$。

压缩映射原理二如何证明？
:::
由拉格朗日中值定理：$|x_{n+1}-a| = |f(x_n)-f(a)| = |f'(\xi)||x_n-a| \le k|x_n-a|$，再代入原理一即得证。

### 三、不等式应用（单调性）

利用 $\sin x < x$ 可得什么递推数列的单调性？
:::
当 $x_n >0$ 时，$x_{n+1} = \sin x_n < x_n$，故 $\{x_n\}$ 单调减少。

利用 $\arctan x \le x$ 可得什么递推数列的单调性？
:::
当 $x_n >0$ 时，$x_{n+1} = \arctan x_n < x_n$，故 $\{x_n\}$ 单调减少。

利用 $e^x \ge x+1$ 可得什么递推数列的单调性？
:::
当 $x_{n+1}=e^{x_n}-1$ 时，由 $e^{x_n}-1 \ge x_n$，得 $x_{n+1} \ge x_n$，即 $\{x_n\}$ 单调不减。

利用 $x-1 \ge \ln x$ 可得什么递推数列的单调性？
:::
当 $x_n >0$ 时，若 $x_{n+1}=\ln x_n+1$，由 $\ln x_n+1 \le x_n$，得 $x_{n+1} \le x_n$，即 $\{x_n\}$ 单调不增。

### 四、夹逼准则典型应用

当 $n \le x < n+1$ 时，$2n \le f(x) < 2(n+1)$，求 $\lim_{x\to\infty} \frac{f(x)}{x}$。
:::
由 $\frac{2n}{n+1} < \frac{f(x)}{x} < \frac{2(n+1)}{n}$，当 $x\to\infty$ 时 $n\to\infty$，两端均趋于 $2$，由夹逼准则得极限为 $2$。
