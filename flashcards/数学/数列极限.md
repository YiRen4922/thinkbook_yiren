# 数列极限 · Flashcards

### 一、数列的定义与分类

数列的定义是什么？
?
按一定次序排列的一列数称为数列，记作：
$$\{a_n\}_{n=1}^{\infty} \quad \text{或简写为} \quad \{a_n\}$$
其中 $a_n$ 称为**通项**（一般项）。
<!--SR:!2026-09-20,3,250-->

数列按单调性分为哪几类？
?
- **严格递增**：$a_{n+1} > a_n$（例：$a_n = n$）
- **严格递减**：$a_{n+1} < a_n$（例：$a_n = \frac{1}{n}$）
- **非递减**：$a_{n+1} \ge a_n$；**非递增**：$a_{n+1} \le a_n$
- **摆动数列**：符号交替变化（例：$a_n = (-1)^n$）

有界数列的定义是什么？
?
$$\exists M > 0,\ \forall n \in \mathbb{N}^+,\ |a_n| \le M$$
即所有项的绝对值都不超过某个正常数 $M$。例：$a_n = \frac{1}{n}$ 有界；$a_n = n$ 无界。

### 二、数列极限的 ε-N 定义

数列极限的 ε-N 定义是什么？
?
$$\lim_{n\to\infty} a_n = A \iff \forall \varepsilon > 0,\ \exists N \in \mathbb{N}^+,\ \text{当}\ n > N\ \text{时，有}\ |a_n - A| < \varepsilon$$
<!--SR:!2026-09-20,3,250-->

ε-N 定义中的四个关键词及口诀是什么？
?
$\forall \varepsilon > 0$（**任意小**）、$\exists N$（**存在正整数**）、$n > N$（**从某项起**）、$|a_n - A| < \varepsilon$（**距离小于 ε**）
口诀："任意小、存在 N、大于 N、距离小"

$\lim_{n\to\infty} a_n = A$ 的几何意义是什么？
?
无论 $\varepsilon$ 多小，总存在一项之后，所有项都落入开区间 $(A - \varepsilon,\ A + \varepsilon)$ 内 —— 区间**外至多只有有限项**。
也就是说：极限只由数列"**尾部**"决定。

什么叫做数列发散？
:::
<!--SR:!2026-09-20,3,250!2000-01-01,1,250-->
<!--SR:!2026-09-20,3,250!2000-01-01,1,250-->
数列不以任何有限数为极限。例：$a_n = (-1)^n$（在 1 与 -1 间摆动）、$a_n = n$（趋于 $+\infty$）。

改变数列的有限项会影响极限吗？
?
**不会**。极限只取决于 $n$ 足够大时的尾部项，去掉或修改有限项**不改变**收敛性与极限值。

### 三、收敛数列的性质

收敛数列有哪些重要性质？
?
- **唯一性**：极限若存在，则唯一
- **有界性**：收敛数列必有界
- **保号性**：若 $\lim a_n = A > 0$（$< 0$），则 $n$ 足够大时 $a_n$ 与 $A$ 同号
- **子列性质**：收敛数列的任何子列都收敛于同一极限

「收敛数列必有界」「有界数列必收敛」这两个命题分别正确吗？
?
- 收敛 ⇒ 有界：✅ **正确**
- 有界 ⇒ 收敛：❌ **错误**，反例 $a_n = (-1)^n$ 有界但不收敛

收敛数列的保号性是什么？
?
若 $\lim_{n\to\infty} a_n = A > 0$，则 $\exists N$，当 $n > N$ 时 $a_n > 0$；$A < 0$ 同理。
用途：由极限的符号推断通项最终符号。

收敛数列的子列有什么性质？
?
若 $\{a_n\}$ 收敛于 $A$，则其**任何子列** $\{a_{n_k}\}$ 都收敛于 $A$。
用途：**证明数列发散** —— 找出两个趋于同一位置的子列但极限不同（或某子列发散）。

数列极限的四则运算法则是什么？（前提？）
?
若 $\lim a_n = A$、$\lim b_n = B$，则：
$$\lim(a_n \pm b_n) = A \pm B,\qquad \lim(a_n b_n) = AB,\qquad \lim\frac{a_n}{b_n} = \frac{A}{B}\ (B \neq 0)$$
前提：**各极限存在**，且除法中分母极限不为 0。与函数极限的法则完全类似。

### 四、海涅定理（归结原则）

海涅定理（归结原则）的内容是什么？
?
$$\lim_{x\to x_0} f(x) = A \iff \forall \{x_n\} \to x_0\ (x_n \neq x_0),\ \lim_{n\to\infty} f(x_n) = A$$
即：函数极限存在 ⟺ 任何趋于 $x_0$ 的数列，对应的函数值数列都收敛于**同一值**。

海涅定理在考研中最主要的应用是什么？
?
证明函数极限**不存在**：找出两个都趋于 $x_0$ 的数列 $\{x_n\}$、$\{y_n\}$，使 $\lim f(x_n) \neq \lim f(y_n)$。
例：取 $x_n = \frac{1}{2n\pi} \to 0$（$\sin x_n \to 0$）、$y_n = \frac{1}{2n\pi + \pi/2} \to 0$（$\sin y_n \to 1$），故 $\lim_{x\to 0}\sin\frac{1}{x}$ 不存在。

海涅定理能用来证明极限**存在**吗？
:::
**不能**。海涅定理的否定形式只能证明极限**不存在**；证明存在需用 ε-N 语言、夹逼准则或单调有界准则。

海涅定理又叫什么？
:::
归结原则

### 五、极限存在准则

夹逼准则（数列版）的内容是什么？
?
若存在 $N$，当 $n > N$ 时 $y_n \le x_n \le z_n$，且 $\lim y_n = \lim z_n = a$，则 $\lim x_n = a$。
本质：**放缩 + 两端夹逼** —— 把复杂数列放缩到两端极限相同的简单数列之间。

夹逼准则适用于哪些典型题型？
?
- **和式极限**：如 $\sum_{k=1}^{n}\dfrac{1}{\sqrt{n^2+k}}$
- **含 n 次方**：找最大项，如 $\sqrt[n]{1^n + 2^n + \cdots + m^n}$
- **含阶乘**：如 $\dfrac{n!}{n^n}$
- **定积分定义**（夹逼准则的推广）
<!--SR:!2026-09-20,3,250-->

通用结论：$\lim_{n\to\infty}\sqrt[n]{a_1^n + a_2^n + \cdots + a_m^n}$ 等于什么？
?
$$\lim_{n\to\infty}\sqrt[n]{a_1^n + a_2^n + \cdots + a_m^n} = \max\{a_1, a_2, \dots, a_m\}\quad (a_i > 0)$$
放缩思路：$(a_{\max})^n \le \text{和式} \le m\cdot(a_{\max})^n$，开 $n$ 次方后两端都趋于 $a_{\max}$，由夹逼准则。

单调有界准则的内容是什么？
?
- 单调**递增**且有**上界** ⇒ 必收敛
- 单调**递减**且有**下界** ⇒ 必收敛
这是考研中**证明数列极限存在**的最常用方法，也是第二个重要极限 $\lim(1+\frac{1}{n})^n = e$ 存在性的证明基础。

用单调有界准则解递推数列的标准步骤是什么？
?
① 证**单调性**（数学归纳法 / 作差 / 作商）
② 证**有界性**（数学归纳法 / 放缩）
③ 由准则得极限存在，设 $\lim x_n = a$
④ 对递推式两边取极限，解方程
⑤ 验证并**舍去不合理的根**

### 六、重要数列极限

考研必背的常用数列极限有哪些？
?
1. $\lim_{n\to\infty}\left(1+\frac{1}{n}\right)^n = e$（第二个重要极限）
2. $\lim_{n\to\infty}\sqrt[n]{n} = 1$
3. $\lim_{n\to\infty}\sqrt[n]{a} = 1$（$a > 0$）
4. $\lim_{n\to\infty}\frac{\ln n}{n} = 0$

$\lim_{n\to\infty}\sqrt[n]{n}$ 等于什么？如何证明？
?
$$\lim_{n\to\infty}\sqrt[n]{n} = 1$$
取对数：$\ln\sqrt[n]{n} = \frac{\ln n}{n} \to 0$，故 $\sqrt[n]{n} = e^{\ln n/n} \to e^0 = 1$。
**易错**：结果是 1，不是 0！

为什么 $\lim_{n\to\infty}\left(1+\frac{1}{n}\right)^n$ 存在？
?
由二项式展开可证数列 $\left(1+\frac{1}{n}\right)^n$ **单调递增**且有**上界 3**，由单调有界准则收敛，其极限定义为 $e$。

$\lim_{n\to\infty}\frac{n!}{n^n}$ 等于什么？如何求？
?
$\lim_{n\to\infty}\frac{n!}{n^n} = 0$。放缩：
$$0 < \frac{n!}{n^n} = \frac{1}{n}\cdot\frac{2}{n}\cdots\frac{n}{n} \le \frac{1}{n}\cdot 1 \cdot 1 \cdots 1 = \frac{1}{n} \to 0$$
由夹逼准则得极限为 0。

### 七、数列极限的求法

求数列极限有哪些常用方法？
?
- 单调有界准则：递推数列，需先证极限存在
- 夹逼准则：和式、n 次方、阶乘
- 定积分定义：和式能提出 $\frac{1}{n}$
- 等价无穷小代换：通项含 $\frac{1}{n}$ 的分式
- 转化为函数极限：通项可扩展为连续函数（用洛必达）

定积分定义求数列极限的公式是什么？
?
$$\lim_{n\to\infty}\frac{1}{n}\sum_{k=1}^{n} f\left(\frac{k}{n}\right) = \int_0^1 f(x)\, dx$$
关键：**提出 $\frac{1}{n}$，识别出 $f\left(\frac{k}{n}\right)$**。

数列能不能直接对 $n$ 用洛必达法则？
?
**不能**！数列不可求导。需先将 $n$ 替换为连续变量 $x$，求函数极限后再还原为数列极限：
$$\lim_{n\to\infty} a_n = \lim_{x\to+\infty} f(x)$$

### 八、递推数列的极限

递推数列求极限的基本思路是什么？
?
先**证明极限存在**（单调有界准则或压缩映射），再设 $\lim x_n = a$，对递推式两边取极限解方程。
**易错**：未证存在就直接"两边取极限" ❌
<!--SR:!2026-09-20,3,250-->

常见递推数列的处理方法有哪些？
?
- $x_{n+1} = f(x_n)$（$f$ 单调）：证单调 + 证有界
- $x_{n+1} = \dfrac{ax_n+b}{cx_n+d}$：作差法证单调性
- $x_{n+1} = \dfrac{x_n}{2} + \dfrac{a}{2x_n}$：牛顿迭代（平方收敛），求 $\sqrt{a}$
- $x_{n+1} = \cos x_n$：压缩映射

压缩映射的收敛条件是什么？
?
若存在 $0 < q < 1$，使 $|x_{n+1} - x_n| \le q\,|x_n - x_{n-1}|$（相邻项距离不断缩短），则 $\{x_n\}$ 收敛。
例：$x_{n+1} = \cos x_n$，由拉格朗日中值定理 $|\cos x - \cos y| \le \sin 1\cdot|x-y|$，且 $\sin 1 < 1$ ⇒ 收敛。

经典例题：$x_1 = 1$，$x_{n+1} = \sqrt{2+x_n}$，求 $\lim_{n\to\infty} x_n$。
?
$\lim_{n\to\infty} x_n = 2$。
① 单调递增：$x_2 = \sqrt{3} > 1$，归纳得 $x_{k+1} > x_k$
② 有上界 2：$x_n < 2$ 归纳可证 ⇒ 收敛
③ 设 $\lim x_n = a$，则 $a = \sqrt{2+a} \Rightarrow a^2 - a - 2 = 0 \Rightarrow a = 2$（因 $x_n > 0$，舍 $-1$）。

### 九、易错与易混点

「单调有界数列一定收敛」对吗？
?
✅ **正确**（单调有界准则）。注意单调性与有界性**缺一不可**：
只单调不有界（$a_n = n$）发散，只有界不单调（$a_n = (-1)^n$）也发散。
<!--SR:!2026-09-20,3,250-->

「数列极限为 0 则对应级数收敛」对吗？
?
❌ **错误**。反例：$\lim_{n\to\infty}\frac{1}{n} = 0$，但调和级数 $\sum\frac{1}{n}$ **发散**。
级数敛散性要看部分和，不能只看通项是否趋于 0。

「$\ln n$ 比 $n$ 增长快」对吗？
?
❌ **错误**。$\lim_{n\to\infty}\frac{\ln n}{n} = 0$，$\ln n$ 增长**远慢于** $n$（任何正幂次都超过对数）。
<!--SR:!2026-09-20,3,250-->

夹逼准则有哪些使用注意事项？
?
- 两端极限必须**相同**，否则夹逼失败
- 不等式 $y_n \le x_n \le z_n$ 只需对**足够大的 $n$** 成立（不必从第 1 项开始）
- 放缩要"既能夹住、两端又能算出相同极限"
