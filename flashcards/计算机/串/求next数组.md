# 求next数组 · Flashcards

### 一、手工三步法

手工求 next 的三步法是什么？
?
1. $\text{next}[1] = 0$
2. $\text{next}[2] = 1$
3. 对 $j \ge 3$：前 $j-1$ 个字符的**最长相等前后缀**长度 $L$，则 $\text{next}[j] = L + 1$
<!--SR:!2026-09-15,4,270-->

求 next 时，前后缀的取值限制是什么？
?
前缀、后缀都**不能取整个子串本身**。前缀以 $T_1$ 开头、后缀以 $T_{j-1}$ 结尾。
<!--SR:!2026-09-13,2,210-->

求模式串 `ababaa` 的 next 数组。
?
next = [0, 1, 1, 2, 3, 4]
（j=5 时前 4 个 `abab` 最长前后缀 `ab` 长 2 → 3；j=6 时前 5 个 `ababa` 最长前后缀 `aba` 长 3 → 4）
<!--SR:!2026-09-15,4,270-->

求模式串 `aaaab` 的 next 数组。
?
next = [0, 1, 2, 3, 4]
（全是 a：j=3 时前 2 个 `aa` 最长前后缀 `a` 长 1 → 2；依次 +1）
<!--SR:!2026-09-15,4,270-->

### 二、递推求法

next 数组的递推公式是什么？
?
已知 $\text{next}[j] = k$：
- 若 $T[j] = T[k]$：$\text{next}[j+1] = k + 1$
- 若 $T[j] \ne T[k]$：$k = \text{next}[k]$ 继续比较，直到相等或 $k=0$（此时 $\text{next}[j+1]=1$）
<!--SR:!2026-09-13,2,210-->

get_next 代码中，失配时的回退语句是什么？
?
`j = next[j];`（沿 next 链回退）；成功分支为 `if (j == 0 || T.ch[i] == T.ch[j]) { ++i; ++j; next[i] = j; }`。
<!--SR:!2026-09-13,2,210-->

get_next 的时间复杂度是多少？
?
$O(m)$。$j$ 要么 +1（匹配）、要么沿 next 链回退，比较总次数与模式串长同阶。
<!--SR:!2026-09-13,2,210-->

### 三、易错与挖空

求 next 时最易犯的两个错误是什么？
?
① 忘记下标从 1 开始的约定（若从 0 开始则 $\text{next}[0] = -1$）；
② 前后缀取了整个子串本身（如把 `abab` 的最长相等前后缀误算成 2 以外的值）。
<!--SR:!2026-09-13,2,210-->

`ababaa` 的 next 数组为 ==[0, 1, 1, 2, 3, 4]==。
<!--SR:!2026-09-13,2,210-->

`aaaab` 的 next 数组为 ==[0, 1, 2, 3, 4]==。
<!--SR:!2026-09-12,1,230-->

`next[2]` 的值恒等于 ==1==（前 1 个字符无相等前后缀）。
