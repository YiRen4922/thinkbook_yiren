# KMP算法 · Flashcards

### 一、核心思想

KMP 算法与朴素算法的本质区别是什么？
?
**主串指针 $i$ 永不回溯**；失配时模式串指针 $j$ 借助 next 数组跳转到合理位置，已匹配的信息被充分利用。
<!--SR:!2026-09-15,4,270-->

next[j] 的含义是什么？
?
模式串第 $j$ 个字符失配时，**$j$ 应该跳转到的位置**。
数值上：$\text{next}[j]$ = 前 $j-1$ 个字符子串的**最长相等前后缀长度 + 1**。
<!--SR:!2026-09-15,4,270-->

next[1] 的值是多少？它的作用是什么？
?
$\text{next}[1] = 0$。当 $j$ 变为 0 时表示：主串指针后移一位、$j$ 回到 1 重新比较。
<!--SR:!2026-09-13,2,210-->

串的前缀和后缀分别是什么？（给出 `abab` 的例子）
?
前缀：除最后一个字符外所有**头部**子串——`abab` 的前缀为 a、ab、aba；
后缀：除第一个字符外所有**尾部**子串——`abab` 的后缀为 b、ab、bab。
最长相等前后缀为 `ab`，长度 2。
<!--SR:!2026-09-13,2,210-->

为什么 KMP 中主串指针可以不回溯？（正确性论证要点）
?
失配于 $j$ 时，$T[1..j-1] = S[i-j+1..i-1]$；设其最长相等前后缀长度为 $L$，则 $T[1..L] = S[i-L..i-1]$——前缀已与主串匹配过，$j$ 跳到 $L+1$ 后无需再比较；若跳过位置更靠前则前后缀矛盾（更长），故安全。
<!--SR:!2026-09-13,2,210-->

### 二、复杂度与手算

KMP 算法的总时间复杂度是多少？
?
求 next 数组 $O(m)$ + 匹配阶段 $O(n)$ = **$O(n + m)$**。
对比朴素算法最坏 $O(nm)$。
<!--SR:!2026-09-15,4,270-->

手工求 next 数组的规则是什么？（三步）
?
1. $\text{next}[1] = 0$（边界）
2. $\text{next}[2] = 1$（边界）
3. $j \ge 3$：前 $j-1$ 个字符的最长相等前后缀长度 $L$，$\text{next}[j] = L + 1$
<!--SR:!2026-09-15,4,270-->

求模式串 `abaabc` 的 next 数组。
?
next = [0, 1, 1, 2, 2, 3]
（j=4 时前 3 个字符 `aba` 最长前后缀 `a` 长 1 → 2；j=6 时前 5 个 `abaab` 最长前后缀 `ab` 长 2 → 3）
<!--SR:!2026-09-15,4,270-->

### 三、挖空卡片

KMP 的核心改进是 ==主串指针 i 永不回溯==，仅移动 ==j（借助 next 数组）==。
<!--SR:!2026-09-13,2,210-->

$\text{next}[j]$ = 前 ==$j-1$== 个字符的**最长相等前后缀长度 + 1**，边界 $\text{next}[1]$ = ==0==。
<!--SR:!2026-09-13,2,210-->

KMP 总时间复杂度为 ==$O(n+m)$==（求 next $O(m)$ + 匹配 $O(n)$）。
<!--SR:!2026-09-15,4,270-->

`abab` 的最长相等前后缀是 ==`ab`==，长度 ==2==。
