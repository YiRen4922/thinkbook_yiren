# KMP算法 · Flashcards

### 一、题目

**题目**：设主串 $S = \text{‘abaabaabcabaabc’}$，模式串 $T = \text{‘abaabc’}$。请写出 $T$ 的 next 数组，并给出 KMP 算法的匹配过程及首次匹配位置。
?
**next 数组**：$[0, 1, 1, 2, 2, 3]$
**匹配过程**：
- 第1趟：$i=6, j=6$ 失配，$j \to \text{next}[6]=3$，$i$ 不动；
- 继续比较，最终在 $S$ 的第 7 个字符处匹配成功。
- 首次匹配位置：$i - m = 10 - 6 = 4$（即从 $S$ 的第 4 个字符开始）。

### 二、算法思想

KMP 算法与朴素算法的本质区别是什么？
?
**主串指针 $i$ 永不回溯**；失配时模式串指针 $j$ 借助 next 数组跳转到合理位置，已匹配的信息被充分利用。
<!--SR:!2026-09-27,12,270-->

next[j] 的含义是什么？
?
模式串第 $j$ 个字符失配时，**$j$ 应该跳转到的位置**。
数值上：$\text{next}[j]$ = 前 $j-1$ 个字符子串的**最长相等前后缀长度 + 1**。
<!--SR:!2026-09-25,10,270-->

next[1] 的值是多少？它的作用是什么？
?
$\text{next}[1] = 0$。当 $j$ 变为 0 时表示：主串指针后移一位、$j$ 回到 1 重新比较。
<!--SR:!2026-09-19,6,230-->

串的前缀和后缀分别是什么？（给出 `abab` 的例子）
?
前缀：除最后一个字符外所有**头部**子串——`abab` 的前缀为 a、ab、aba；
后缀：除第一个字符外所有**尾部**子串——`abab` 的后缀为 b、ab、bab。
最长相等前后缀为 `ab`，长度 2。
<!--SR:!2026-09-17,4,210-->

为什么 KMP 中主串指针可以不回溯？（正确性论证要点）
?
失配于 $j$ 时，$T[1..j-1] = S[i-j+1..i-1]$；设其最长相等前后缀长度为 $L$，则 $T[1..L] = S[i-L..i-1]$——前缀已与主串匹配过，$j$ 跳到 $L+1$ 后无需再比较；若跳过位置更靠前则前后缀矛盾（更长），故安全。

### 三、代码实现

请写出求 next 数组的代码。
```c
void GetNext(SString T, int next[]) {
    int i = 1, j = 0;
    next[1] = 0;
    while (i < T.length) {
        if (j == 0 || T.ch[i] == T.ch[j]) {
            ++i; ++j;
            next[i] = j;
        } else {
            j = next[j];
        }
    }
}
```


请写出 KMP 匹配算法的代码。
```c
int Index_KMP(SString S, SString T, int next[]) {
    int i = 1, j = 1;
    while (i <= S.length && j <= T.length) {
        if (j == 0 || S.ch[i] == T.ch[j]) {
            ++i; ++j;
        } else {
            j = next[j];          // 主串指针 i 不回溯
        }
    }
    if (j > T.length)
        return i - T.length;      // 匹配成功，返回起始位置
    else
        return 0;                 // 匹配失败
}
```

### 四、时间复杂度

KMP 算法的总时间复杂度是多少？与朴素算法对比如何？
?
- **求 next**：$O(m)$
- **匹配阶段**：$O(n)$
- **总复杂度**：$O(n + m)$
对比朴素算法最坏 $O(nm)$，KMP 有显著优势。

### 五、易错点和重点

KMP 算法中有哪些易错点？
?
1. $\text{next}[1] = 0$，$\text{next}[2] = 1$ 是固定边界，不要算错；
2. 前后缀**不包含整个串**；
3. 主串指针 $i$ **永不回溯**，只有 $j$ 在变；
4. 求 next 时 `i` 从 1 开始，循环条件 `i < T.length`；
5. 匹配成功返回 `i - T.length`，不是 `i`。

- 与朴素算法的复杂度对比
- 主串指针不回溯的正确性论证
