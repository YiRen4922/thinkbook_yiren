# 朴素模式匹配算法 · Flashcards

### 一、算法思想

朴素模式匹配（BF）算法的基本思想是什么？
?
从主串第 $pos$ 个字符起与模式串逐个比较：相等则双指针后移；失配则**主串指针回溯**（回到本轮起点 +1）、模式串指针回到 1，重新匹配。

### 二、经典题目与代码实现

请写出朴素模式匹配（BF）算法的完整代码实现（含失配处理和返回值说明）。
?
```c
// 返回模式串 T 在主串 S 中第 pos 个字符之后第一次出现的位置
// 未找到返回 0
int Index_BF(SString S, SString T, int pos) {
    int i = pos, j = 1;
    while (i <= S.length && j <= T.length) {
        if (S.ch[i] == T.ch[j]) {
            i++; j++;           // 继续比较后继字符
        } else {
            i = i - j + 2;      // 主串指针回溯到本轮起点的下一位
            j = 1;              // 模式串指针回到 1
        }
    }
    if (j > T.length)
        return i - T.length;    // 匹配成功，返回起始位置
    else
        return 0;               // 匹配失败
}
```

### 三、复杂度

朴素模式匹配的最好、最坏、平均时间复杂度分别是多少？
?
- **最好**：$O(n)$（首字符即失配或很快匹配成功）
- **平均**：$O(n+m)$
- **最坏**：$O(nm)$（如 $S='00\cdots01'$，$T='00\cdots1'$，每趟都比到最后一个字符才失配）
<!--SR:!2026-09-25,10,270-->

### 四、返回值

朴素模式匹配匹配成功和失败分别返回什么？
?
- 成功：返回子串在主串中的**起始位置** `i - m`（$i$ 已到 $m+1$ 处，$m$ 为模式串长）
- 失败：返回 **0**
<!--SR:!2026-09-20,4,190-->

### 五、缺点

朴素模式匹配的主要缺点是什么？
?
① 主串指针 $i$ **频繁回溯**，已扫描过的字符被重复比较；
② 已匹配的“$S$ 某段 $= T$ 某段”信息被丢弃；
③ 每次失配 $j$ 都从 1 重新开始。
<!--SR:!2026-09-17,4,210-->

### 六、零碎问题

失配时，主串指针 $i$ 和模式串指针 $j$ 如何回溯？
?
$$i = i - j + 2, \qquad j = 1$$
（$i - j + 1$ 是本轮起点，加 1 到下一轮起点。）
<!--SR:!2026-09-17,4,210-->

为什么朴素模式匹配的最坏时间复杂度是 $O(nm)$？请举例说明。
?
例如 $S = \text{‘0000001’}$，$T = \text{‘0001’}$。每一趟匹配都在最后一个字符才失配，主串指针回退到本轮起点的下一位，导致前 $n-m$ 个位置都要比较 $m$ 次，因此总比较次数约为 $(n-m+1) \times m$，即 $O(nm)$。
