# 队列 · Flashcards

### 一、定义与基本操作

队列的定义是什么？它的核心特点是什么？
?
队列是只允许在一端进行插入、在另一端进行删除的线性表。
允许插入的一端称为队尾，允许删除的一端称为队头。
核心特点是先进先出（FIFO）。
<!--SR:!2026-09-19,3,250-->

队列的基本操作有哪些？（写出 ADT 中的主要操作名）
?
`InitQueue(&Q)`：初始化空队列
`DestroyQueue(&Q)`：销毁队列
`EnQueue(&Q, e)`：入队，将 e 插入队尾
`DeQueue(&Q, &e)`：出队，删除队头元素并用 e 返回
`GetHead(Q, &e)`：取队头元素，不删除
`QueueEmpty(Q)`：判空
`QueueLength(Q)`：求队列长度

### 二、顺序存储（循环队列）

循环队列的存储结构如何定义？（写出 C 结构体）
?
```c
#define MaxSize 100
typedef struct {
    ElemType data[MaxSize];
    int front;            // 队头指针
    int rear;             // 队尾指针
} SqQueue;
```
<!--SR:!2026-09-19,3,250-->

循环队列的入队、出队、判空、判满操作如何实现？
?
```c
// 判空
bool QueueEmpty(SqQueue Q) { return Q.front == Q.rear; }
// 判满（牺牲一个单元）
bool QueueFull(SqQueue Q) {
    return (Q.rear + 1) % MaxSize == Q.front;
}
// 入队
bool EnQueue(SqQueue &Q, ElemType e) {
    if (QueueFull(Q)) return false;
    Q.data[Q.rear] = e;
    Q.rear = (Q.rear + 1) % MaxSize;
    return true;
}
// 出队
bool DeQueue(SqQueue &Q, ElemType &e) {
    if (QueueEmpty(Q)) return false;
    e = Q.data[Q.front];
    Q.front = (Q.front + 1) % MaxSize;
    return true;
}
```
<!--SR:!2026-09-19,3,250-->

循环队列的判空条件和判满条件分别是什么？
?
判空：`front == rear`；判满：`(rear + 1) % MaxSize == front`
<!--SR:!2026-09-19,3,250-->

循环队列的队列长度如何计算？
?
`(rear - front + MaxSize) % MaxSize`
<!--SR:!2026-09-19,3,250-->

循环队列为什么要牺牲一个存储单元？
?
因为若不留空单元，队空（`front == rear`）和队满（`front == rear`）的条件会相同，无法区分。牺牲一个单元后，队满条件变为 `(rear + 1) % MaxSize == front`，与队空区分开。
<!--SR:!2026-09-20,4,270-->

### 三、链式存储（链队列）

链队列的结构定义是什么？它通常用哪种链表实现？
?
链队列通常用带头结点的单链表实现，队头指针指向头结点，队尾指针指向最后一个结点。
```c
typedef struct QNode {
    ElemType data;
    struct QNode *next;
} QNode, *QueuePtr;
typedef struct {
    QueuePtr front;       // 队头指针（指向头结点）
    QueuePtr rear;        // 队尾指针
} LinkQueue;
```
<!--SR:!2026-09-19,3,250-->

链队列的入队和出队操作如何实现？
?
```c
// 入队（尾插法）
void EnQueue(LinkQueue &Q, ElemType e) {
    QueuePtr s = (QueuePtr)malloc(sizeof(QNode));
    s->data = e;
    s->next = NULL;
    Q.rear->next = s;
    Q.rear = s;
}
// 出队（头删法）
bool DeQueue(LinkQueue &Q, ElemType &e) {
    if (Q.front == Q.rear) return false;
    QueuePtr p = Q.front->next;
    e = p->data;
    Q.front->next = p->next;
    if (Q.rear == p) Q.rear = Q.front;  // 删除的是最后一个结点
    free(p);
    return true;
}
```
<!--SR:!2026-09-19,3,250-->

链队列是否需要判满？为什么？
?
不需要。链队列是动态分配结点，除非内存耗尽，否则不会满。
这与循环队列需要判满不同。

### 四、队列的应用

队列在树的层次遍历中的应用思想是什么？
?
队列保证按层次顺序访问结点。
从根结点开始入队。
循环：出队一个结点并访问，将其孩子依次入队，直到队列为空。
<!--SR:!2026-09-19,3,250-->


队列在图广度优先遍历（BFS）中的应用思想是什么？
?
从起点入队并标记已访问。
循环：出队一个顶点，访问其所有未访问的邻接顶点，将它们入队并标记。
直到队列为空。
BFS 按距离起点的层次依次访问，可求无权图最短路径。
<!--SR:!2026-09-19,3,250-->

队列在操作系统 FCFS 调度中的应用思想是什么？
?
用就绪队列按进程到达顺序存放进程。
CPU 空闲时从队头取出进程执行，执行完毕或阻塞后从队头取下一个。
完全遵循 FIFO 原则，先到达的进程先被服务。
<!--SR:!2026-09-20,2,230-->

### 五、易错点

循环队列中，为什么入队和出队时指针要用取模运算？
?
因为循环队列的存储空间首尾相接，当指针到达数组末尾时，需要回到下标 0 继续使用。取模运算 `(指针 + 1) % MaxSize` 实现循环移动，避免越界。
<!--SR:!2026-09-19,3,250-->

链队列出队时，什么情况下需要修改队尾指针？
?
当出队的结点是队列中最后一个结点时（即 `Q.rear == p`），出队后队列变为空，需要将队尾指针重新指向头结点：`Q.rear = Q.front`。
<!--SR:!2026-09-19,3,250-->

### 六、易错点补充

链队列中，当队列只剩一个元素时出队，会发生什么？
?
出队后队列变为空，此时 `Q.front` 和 `Q.rear` 都应指向头结点。
代码：`if (Q.rear == p) Q.rear = Q.front;`（`p` 是被删除的最后一个结点）
如果漏写这一步，`Q.rear` 会变成悬空指针（dangling pointer）。
<!--SR:!2026-09-19,3,250-->

循环队列用"计数器"而非"牺牲单元"判满的方案是什么？
?
额外维护一个变量 `size` 记录当前队列元素个数。
入队时 `size++`，出队时 `size--`。
判空：`size == 0`；判满：`size == MaxSize`。
优点：不浪费存储单元；缺点：多用一个变量的空间。
