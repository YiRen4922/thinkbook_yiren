# 【2026统考真题】
假定二叉搜索树使用二叉链表存储，存储结构如下：
```c
typedef struct BSTNode {
    int data;
    struct BSTNode *left, *right;
} BSTNode;
```
给一棵二叉搜索树 $T$ 和整数 $K$，查找树中关键字与 $K$ 之差的绝对值最小的所有结点，并输出该绝对值与结点中的关键字。
(1) 给出算法的基本设计思想。（4 分）
(2) 使用 C/C++ 描述算法。（9 分）
??
### 1）算法基本设计思想

本题要求查找**所有**与 $K$ 差值绝对值最小的结点，而非仅一个。利用二叉搜索树的中序遍历有序性进行优化。

中序遍历二叉搜索树得到的是**递增有序序列**。在遍历过程中，维护当前找到的最小差值 `minDiff` 以及对应的结点关键字列表。对于每个结点，计算 $|data - K|$，与 `minDiff` 比较：

- 若**小于** `minDiff`：更新 `minDiff`，并**清空**之前记录的结果列表，将当前结点关键字加入列表。
- 若**等于** `minDiff`：将当前结点关键字加入列表。
- 若**大于** `minDiff`：由于中序遍历序列递增，后续结点的差值只会更大，可以**提前终止**遍历。

这一策略的时间复杂度为 $O(n)$（最坏情况），但在实际运行中往往能提前结束，效率较高。

### 2）C/C++ 算法描述

```c
// 全局变量，用于记录最小差值和所有满足条件的结点关键字
int minDiff = INT_MAX;      // 当前找到的最小差值
int result[100];            // 保存所有与K差值最小的结点关键字
int count = 0;              // 记录满足条件的结点个数

// 中序遍历二叉搜索树，查找与K差值绝对值最小的所有结点
void searchX(BSTNode *root, int K) {
    if (root == NULL) return;
    
    // 1. 递归遍历左子树
    searchX(root->left, K);
    
    // 2. 处理当前结点
    int diff = abs(root->data - K);
    
    if (diff < minDiff) {
        // 发现更小的差值：更新最小值，清空之前的结果
        minDiff = diff;
        count = 0;
        result[count++] = root->data;
    } else if (diff == minDiff) {
        // 差值等于当前最小值：加入结果列表
        result[count++] = root->data;
    } else {
        // 差值大于当前最小值：由于中序递增，后续只会更大，提前剪枝
        return;
    }
    
    // 3. 递归遍历右子树
    searchX(root->right, K);
}

// 调用方式
int main() {
    // 假设 root 已构建
    searchX(root, K);
    
    // 输出结果
    printf("最小差值: %d\n", minDiff);
    printf("满足条件的结点关键字: ");
    for (int i = 0; i < count; i++) {
        printf("%d ", result[i]);
    }
    printf("\n");
    return 0;
}
```

> **注意**：全局变量 `minDiff` 初始应设为 `INT_MAX`；`result` 数组大小需根据树中结点数合理设定（或改用 `vector` 动态存储）。若使用 C++，建议用 `std::vector<int>` 替代数组。

### 复杂度分析

| 指标 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(n)$（最坏） | 最坏情况需遍历所有结点；利用中序有序性，可在差值开始增大时提前终止，平均效率更高 |
| **空间复杂度** | $O(h)$（递归栈） | $h$ 为树高，最坏 $O(n)$，平均 $O(\log n)$；结果数组额外占用 $O(k)$（$k$ 为满足条件的结点数） |

### 易错点

| 易错点           | 正确理解                                   |
| :------------ | :------------------------------------- |
| **只记录一个结点**   | 题目要求输出**所有**差值最小的结点，需用列表保存全部结果         |
| **未利用BST有序性** | 中序遍历递增，当差值开始增大时可提前终止，避免无效遍历            |
| **清空逻辑遗漏**    | 更新 `minDiff` 时必须清空之前记录的结果列表，否则会混入非最优结点 |
| **全局变量未初始化**  | `minDiff` 初始设为 `INT_MAX`，`count` 初始为 0 |
| **中序顺序错误**    | 必须严格按“左 → 根 → 右”顺序，否则无法利用有序性进行剪枝       |

# 【2026统考真题】
栈的基本操作有出栈和入栈。将序列 $1, 2, 3, \dots, n$ 依次入栈，回答下列问题：

(1) 当 $n=9$ 时，可以得到出栈序列 $\{2, 3, 1, 6, 4, 7, 5, 9, 8\}$ 吗？可以得到出栈序列 $\{2, 3, 1, 5, 6, 7, 4, 9, 8\}$ 吗？（2分）
(2) 假设 $1, 2, \dots, n$ 组成任意序列的出栈序列 $P_1, P_2, \dots, P_n$，在序列中有 $P_i$、$P_j$、$P_k$（$i < j < k$），若该出栈序列不能由栈得到，则 $P_i$、$P_j$、$P_k$ 的大小关系是？（2分）
(3) 若 $n=4$，则以 $2$ 开头的序列个数有多少个？（2分）
(4) 若 $n=k-1$ 时，出栈序列总共共有 $M$ 个，如果 $n=k$，那么以 $1$ 开头的出栈序列个数有多少个？以 $2$ 开头的出栈序列有多少个？总共的出栈序列有多少个？（4分）
??

### 参考答案与解析

**(1) 判断两个序列是否可行（2分）**
- $\{2, 3, 1, 6, 4, 7, 5, 9, 8\}$：**不能**得到。当 $6$ 出栈后，栈中剩余 $4, 5$（$4$ 在栈底，$5$ 在栈顶），接下来只能先出 $5$，不可能先出 $4$。
- $\{2, 3, 1, 5, 6, 7, 4, 9, 8\}$：**可以**得到。依次入栈 $1,2$，出 $2,3,1$；入 $4,5$，出 $5$；入 $6$，出 $6$；入 $7$，出 $7,4$；入 $8,9$，出 $9,8$。

**(2) 不可能的大小关系（2分）**
$$
P_i > P_k > P_j
$$
**推导**：若 $P_i > P_k > P_j$，则 $P_i$ 最大却最先出栈，说明 $P_j$ 和 $P_k$ 在 $P_i$ 入栈前就已入栈。而 $P_j$ 比 $P_k$ 小，应比 $P_k$ 后入栈，却在 $P_k$ 之前出栈，这与栈“后进先出”矛盾。

**(3) 以 2 开头的出栈序列个数（2分）**
$n=4$ 时，以 $2$ 开头：先入 $1$，入 $2$，出 $2$。剩余 $3,4$ 可自由出入栈，对应 $C_2 = 2$ 种。但 $1$ 还在栈中，必须等待后续操作，最终 $1$ 必须在最后出栈（因为它在栈底）。
实际枚举：$2, 3, 4, 1$；$2, 3, 1, 4$；$2, 1, 4, 3$；$2, 1, 3, 4$；$2, 4, 3, 1$。共 **5** 个。

**(4) 出栈序列计数（4分）**
- $n=k-1$ 时，出栈序列总数为卡特兰数 $M = C_{k-1} = \frac{1}{k}\binom{2k-2}{k-1}$。
- 当 $n=k$ 时：
  - 以 $1$ 开头的出栈序列：$1$ 最先出栈（入 $1$ 后立即出），剩余 $k-1$ 个元素出栈序列数为 $M$，即 **$M$ 个**。
  - 以 $2$ 开头的出栈序列：入 $1,2$，出 $2$（此时 $1$ 在栈底）。剩余 $k-1$ 个元素（含栈中的 $1$）出栈序列数也为 **$M$ 个**。
  - 总出栈序列数：$C_k = \frac{1}{k+1}\binom{2k}{k}$。

### 复杂度与考点

| 指标 | 说明 |
| :--- | :--- |
| **时间复杂度** | 各项均为计数/判断，$O(1)$ |
| **空间复杂度** | $O(1)$ |
| **核心考点** | 栈的 LIFO 性质、出栈序列合法性判定、卡特兰数 |

### 易错点

| 易错点 | 正确理解 |
| :--- | :--- |
| 误判第一序列可行 | 出栈顺序必须严格满足“后进先出”，$4$ 在 $5$ 之前出栈不合法 |
| 大小关系写反 | 不可能关系是 $P_i > P_k > P_j$，即最大元素先出、中间元素后出、最小元素最后出 |
| 以 $2$ 开头序列数误算为 $C_3$ | $1$ 已在栈底无法自由出栈，需枚举验证，实际为 $5$ |
| 卡特兰数公式记错 | $C_n = \frac{1}{n+1}\binom{2n}{n}$，注意分母是 $n+1$ |
