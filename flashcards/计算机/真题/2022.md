### （1）算法基本设计思想

二叉搜索树（BST）的中序遍历序列是**严格递增**的。因此，只需对顺序存储的二叉树进行**中序遍历**，同时记录上一个访问的结点值 `prev`，检查当前结点值是否大于 `prev` 即可。

由于采用顺序存储，结点下标为 `i`（从 0 开始）时：
- 左孩子下标：`2*i + 1`
- 右孩子下标：`2*i + 2`

遍历时，若下标 `i >= ElemNum` 或 `SqBiTNode[i] == -1`，表示该结点为空，直接返回。中序遍历顺序为：左子树 → 当前结点 → 右子树。在访问当前结点时，判断其值是否大于 `prev`，若不满足则不是 BST；若满足则更新 `prev` 并继续。

### （2）C/C++ 算法描述

```cpp
// 中序遍历辅助函数
// T：顺序存储的二叉树
// i：当前结点在数组中的下标
// prev：引用传递，保存中序遍历中上一个访问的结点值
bool InOrder(SqBiTree T, int i, int &prev) {
    // 空结点或越界，视为空子树，直接返回 true
    if (i >= T.ElemNum || T.SqBiTNode[i] == -1)
        return true;
    
    // 1. 递归遍历左子树
    if (!InOrder(T, 2 * i + 1, prev))
        return false;
    
    // 2. 访问当前结点：必须大于上一个访问的值
    if (T.SqBiTNode[i] <= prev)
        return false;               // 违反严格递增，不是 BST
    prev = T.SqBiTNode[i];          // 更新 prev
    
    // 3. 递归遍历右子树
    if (!InOrder(T, 2 * i + 2, prev))
        return false;
    
    return true;
}

// 判断是否为二叉搜索树的主函数
bool IsBST(SqBiTree T) {
    int prev = -1;                  // 所有结点值为正整数，-1 小于任何结点值
    return InOrder(T, 0, prev);     // 从根结点（下标 0）开始中序遍历
}
```

### 复杂度分析

| 指标 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(n)$ | 每个非空结点恰好访问一次，$n$ 为实际结点数 |
| **空间复杂度** | $O(h)$ | 递归栈深度，$h$ 为树高，最坏 $O(n)$，平均 $O(\log n)$ |

### 易错点

| 易错点 | 正确理解 |
| :--- | :--- |
| 下标公式使用 1-based | 根据题目示例，根结点在下标 0，左孩子 `2*i+1`，右孩子 `2*i+2` |
| 空结点判断遗漏 | 必须同时检查 `i >= ElemNum` 和 `SqBiTNode[i] == -1` |
| `prev` 初始值设为 0 | 结点值为正整数，`prev` 初始应设为 `-1`（或 `INT_MIN`） |
| 使用非严格递增 | 二叉搜索树要求严格递增，判断条件为 `<= prev` 即失败 |
| 递归遍历顺序错误 | 必须是中序（左 → 根 → 右），否则无法利用有序性 |

**（1）算法思想**

维护一个大小为 10 的**大根堆**，遍历 $M$ 中所有 $n$ 个元素，让堆里始终保留“目前看到的最小 10 个数”。

- 用 $M$ 的前 10 个元素建一个大根堆（堆顶是这 10 个里最大的，记为 $top$）。
- 对剩余 $n-10$ 个元素 $v$ 逐个处理：
  - 与堆顶 $top$ 比较 1 次：若 $v \ge top$，直接跳过（$v$ 不可能进 top-10）；
  - 否则用 $v$ 替换堆顶，向下调整堆（最多 $\lceil \log_2 10 \rceil$ 层调整，约 4 次比较）。
- 遍历完成，堆里就是最小的 10 个数。

**为什么用大根堆？** 直觉上“找最小的 $k$ 个”应该用小根堆，这里反而用大根堆——因为要快速判断“新元素能不能挤进 top-$k$”。大根堆的堆顶是 top-$k$ 中最大的那个，它是“门槛”：新元素只要 $\ge$ 门槛就一定不在 top-$k$ 里，1 次比较即可淘汰；若 $<$ 门槛则替换它（让新的最大者作为新门槛）。

**为什么平均比较次数最少？** 绝大多数元素只与堆顶比 1 次就被淘汰（$n$ 大、$k$ 小，新元素是 top-$k$ 的概率极低），整体期望比较次数为 $O(n)$，常数因子接近 1。

**（2）复杂度分析**

| 指标 | 复杂度 | 说明 |
| :--- | :--- | :--- |
| **时间复杂度** | $O(n)$ | 建堆 $O(k \log k)$；后续每个元素 1 次门槛比较 + 至多 $O(\log k)$ 次下沉调整，$k=10$ 视为常数，总量级为 $O(n)$ |
| **空间复杂度** | $O(1)$ | 除入参 $M$ 外，只用了大小为 $k=10$ 的堆数组，与 $n$ 无关 |

**易错点**：① 误用小根堆（应用大根堆作为“门槛”）；② 空间复杂度误写为 $O(k)$，实际 $k$ 为常数，应写 $O(1)$；③ 建堆后应从第 11 个元素开始遍历，而不是“遍历数组进行初始建堆”。
