【2014统考真题】
二叉树的带权路径长度（WPL）是二叉树中所有叶结点的带权路径长度之和。
给定一棵二叉树 $T$，采用二叉链表存储，结点结构为：| left | weight | right |
其中叶结点的 weight 域保存该结点的非负权值。设 root 为指向 $T$ 的根结点的指针，请设计求 $T$ 的 WPL 的算法，要求：
1）给出算法的基本设计思想。
2）使用 C 或 C++ 语言，给出二叉树结点的数据类型定义。
3）根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。
??
1）**算法基本设计思想**  
采用递归遍历二叉树。设置一个深度参数 `L`（根结点深度为 1），当访问到叶子结点时，将 `L * weight` 累加到 WPL 中；非叶子结点则递归其左右子树，深度加 1。最终累加值即为整棵树的 WPL。
2）**二叉树结点的数据类型定义**  
```c
typedef struct BiTNode {
    struct BiTNode *left;      // 左孩子指针
    int weight;                // 权值（仅叶子结点有效）
    struct BiTNode *right;     // 右孩子指针
} BiTNode, *BiTree;
```
3）**算法描述（C++，引用累加）**  
```c
// L：当前结点的深度，WPL：累加总和（引用传递）
void CalWPL(BiTNode *T, int L, int &WPL) {
    if (T == NULL) return;                     // 空结点返回
    
    // 叶子结点：左右孩子都为空
    if (T->left == NULL && T->right == NULL) {
        WPL += L * T->weight;                  // 累加带权路径长度
        return;
    }
    
    // 非叶子结点：递归左右子树，深度加 1
    CalWPL(T->left,  L + 1, WPL);
    CalWPL(T->right, L + 1, WPL);
}
```
调用方式：`int WPL = 0; CalWPL(root, 1, WPL);`
**复杂度**：时间复杂度 $O(n)$，空间复杂度 $O(h)$（$h$ 为树高，最坏 $O(n)$，平均 $O(\log n)$）。
**易错点**：① 只有叶子结点的 `weight` 有效，非叶子不参与计算；② 路径长度是边数，根深度为 1 时叶子路径长度为 `L`（不是 `L-1`）；③ 叶子判断必须左右都空；④ C 语言需用 `int *WPL` 并传 `&WPL`。
