# 树和二叉树 · Flashcards

### 一、树的基本概念

树的定义是什么？
?
树是 $n$（$n \ge 0$）个结点的**有限集合**。$n = 0$ 时称为空树。非空树满足：① 有且仅有一个**根结点**；② 其余结点可分为 $m$（$m > 0$）个**互不相交**的有限集合，每个集合本身又是一棵树（称为根的子树）。
<!--SR:!2026-09-17,4,210-->

结点的度、树的度分别是什么？
?
**结点的度** = 该结点的**子树个数**；**树的度** = 所有结点度的**最大值**。
度为 0 的结点称为叶子（终端）结点。
<!--SR:!2026-09-19,4,210-->

结点的深度、层次、树的高度分别如何定义？
?
- **层次**：根在第 1 层，向下逐层 +1
- **结点的深度**：从**根**向下数，该结点所在的层次数
- **结点的高度**：从**该结点**向下数，以它为根的子树的高度
- **树的高度（深度）**：树中结点的最大层次数
<!--SR:!2026-09-16,3,230-->

树的结点数与度数之间有什么关系？（两个公式）
?
设度为 $i$ 的结点有 $n_i$ 个，则
$$n = n_0 + n_1 + \cdots + n_m = \sum_{i=0}^{m} n_i$$
$$n = \sum_{i=0}^{m} i \cdot n_i + 1 \quad \text{（结点数 = 总度数 + 1）}$$
消去 $n_0$ 可得：$n_0 = 1 + n_2 + 2n_3 + \cdots + (m-1)n_m$。
速记：结点就是元素，**度就是结点上方的线**，根节点上方没有线，所以**总度数=结点数+1**
<!--SR:!2026-09-17,4,210-->

树与二叉树有什么本质区别？
?
- 树中结点的**孩子数没有上限**（度数任意），二叉树每个结点**至多 2 个孩子**且**区分左右**（有序）
- 二叉树**不是**树的特殊情形，二者是两种不同的数据结构
<!--SR:!2026-09-24,9,250-->

### 二、二叉树的性质

二叉树第 $i$ 层最多有多少个结点？
?
$$\text{第 } i \text{ 层最多有 } 2^{i-1} \text{ 个结点} \quad (i \ge 1)$$
<!--SR:!2026-09-19,4,210-->

深度为 $h$ 的二叉树，最多和最少各有多少个结点？
?
最多 $2^h - 1$ 个（**满二叉树**）；最少 $h$ 个（每层只有一个结点，退化成一条链）。
<!--SR:!2026-09-16,3,230-->

二叉树中叶子结点数 $n_0$ 与度为 2 的结点数 $n_2$ 的关系是什么？
?
$$n_0 = n_2 + 1$$
由 $n = n_0 + n_1 + n_2$ 与 $n = n_1 + 2n_2 + 1$ 相减即得。
<!--SR:!2026-09-17,4,210-->

满二叉树和完全二叉树的定义是什么？
?
- **满二叉树**：每一层的结点数都达到最大值，深度为 $h$ 时有 $2^h - 1$ 个结点
- **完全二叉树**：只有**最后一层**可能不满，且缺的结点全部集中在最左侧——按层序编号与同深度满二叉树一一对应
<!--SR:!2026-09-23,8,250-->

具有 $n$ 个结点的完全二叉树，其高度是多少？
?
$$h = \lceil \log_2(n+1) \rceil = \lfloor \log_2 n \rfloor + 1$$
<!--SR:!2026-09-16,3,230-->

完全二叉树按层序编号（从 1 开始）后，结点 $i$ 的双亲和孩子如何表示？
?
设总结点数为 $n$：
- $i = 1$ 为根，无双亲；否则双亲为 $\lfloor i/2 \rfloor$
- 若 $2i \le n$，左孩子为 $2i$，否则无左孩子
- 若 $2i + 1 \le n$，右孩子为 $2i + 1$，否则无右孩子
<!--SR:!2026-09-17,4,210-->

### 三、二叉树的存储与遍历

二叉树的顺序存储和链式存储分别是什么？
?
- **顺序存储**：按层序编号存入数组（下标即编号）。适合完全二叉树；普通二叉树需按完全二叉树补空，会**浪费大量空间**
- **链式存储**：二叉链表，结点含 lchild、data、rchild 三个域，指针指向孩子
<!--SR:!2026-09-23,8,250-->

$n$ 个结点的二叉链表中共有多少个空指针域？
?
共 $2n$ 个指针域，$n$ 个结点间有 $n-1$ 条边（每条边占一个指针），空指针域 = $2n - (n-1) = n + 1$ 个。
这些空指针正是**线索二叉树**的基础。
<!--SR:!2026-09-16,3,230-->

先序、中序、后序遍历的访问顺序分别是什么？
?
- **先序**：根 → 左 → 右（根**最先**）
- **中序**：左 → 根 → 右
- **后序**：左 → 右 → 根（根**最后**）
记忆：名称中的"先/中/后"指的是**根**的访问时机。
<!--SR:!2026-09-19,4,210-->

三种遍历的递归算法怎么写？
?
```c
void PreOrder(BiTree T) {          // 先序：根左右
    if (T != NULL) {
        visit(T);
        PreOrder(T->lchild);
        PreOrder(T->rchild);
    }
}
void InOrder(BiTree T) {           // 中序：左根右
    if (T != NULL) {
        InOrder(T->lchild);
        visit(T);
        InOrder(T->rchild);
    }
}
void PostOrder(BiTree T) {         // 后序：左右根
    if (T != NULL) {
        PostOrder(T->lchild);
        PostOrder(T->rchild);
        visit(T);
    }
}
```
<!--SR:!2026-09-17,4,220-->

二叉树的层次遍历用什么数据结构？思路是什么？
?
用**队列**：根结点入队；循环——队头出队并访问，将其**左、右孩子依次入队**，直到队空。
<!--SR:!2026-09-24,9,250-->

由遍历序列确定二叉树，哪些组合能唯一确定？哪个不能？
?
- 能唯一确定：**先序 + 中序**、**后序 + 中序**、**层序 + 中序**
- 不能唯一确定：**先序 + 后序**（能确定根，但无法区分左右子树的边界）
关键：中序序列能把左右子树分开，所以必须**两个序列组合**且其中之一是中序。
<!--SR:!2026-09-16,3,230-->

遍历序列有哪些性质？（先序第一个、后序最后一个、中序中的根）
?
- 先序序列**第一个**结点、后序序列**最后一个**结点一定是**根**
- 中序序列中，**根把序列分成左右两段**：左段是左子树的中序，右段是右子树的中序
<!--SR:!2026-09-23,8,250-->

### 四、线索二叉树

什么是线索二叉树？
?
利用二叉链表的 $n+1$ 个**空指针**：**左空指针指向前驱、右空指针指向后继**（称为线索），并增设 ltag、rtag 标志：
- tag = 0 表示指向孩子；tag = 1 表示指向前驱/后继
线索是**按某种遍历序列**（先序/中序/后序）建立的，中序线索二叉树最常用。
<!--SR:!2026-09-16,3,230-->

在线索二叉树中，如何找某结点的中序后继？
?
- 若 rtag = 1：右指针本身就是中序后继，O(1)
- 若 rtag = 0：右孩子不是线索，中序后继 = 其**右子树中从左下走到最左**的结点
<!--SR:!2026-09-17,4,210-->

### 五、树与森林

树的三种存储结构分别是什么？各有什么特点？
?
- **双亲表示法**：存 data + 双亲下标（找双亲 O(1)，找孩子要遍历全表）
- **孩子表示法**：存 data + 孩子链表（找孩子 O(1)，找双亲要遍历）
- **孩子兄弟表示法**：存 data + firstchild + nextsibling（本质是二叉链表，可方便地与二叉树互转）
<!--SR:!2026-09-16,3,230-->

### 七、树与二叉树的转换

树（森林）与二叉树互相转换的核心逻辑是**左孩子右兄弟**（First Child, Next Sibling）：
- **`lchild` 指针**：指向该节点的**第一个孩子**（长子）
- **`rchild` 指针**：指向该节点的**下一个兄弟**（紧邻的右侧兄弟）
<!--SR:!2026-09-16,3,230-->

树与二叉树互相转换的核心存储思想是什么？其指针含义是什么？
?
- **核心思想**：左孩子右兄弟（First Child, Next Sibling）
- **`lchild` 指针**：指向该节点的**第一个孩子**（长子）
- **`rchild` 指针**：指向该节点的**下一个兄弟**（紧邻的右侧兄弟）
<!--SR:!2026-09-16,3,230-->

树转换为二叉树的三步画图规则是什么？
?
1. **加线**：在所有相邻的兄弟节点之间加一条连线
2. **抹线**：对每个节点，只保留它与**第一个孩子**（最左侧孩子）的连线，抹去与其他所有孩子的连线
3. **旋转**：顺时针旋转 45°，使原本的兄弟链变为右链
<!--SR:!2026-09-17,4,210-->

森林转换为二叉树的规则是什么？
?
1. 将森林中的每一棵树分别转换为对应的二叉树
2. 将所有树根视为"兄弟"关系，把第一棵树的根节点作为最终二叉树的根节点
3. 依次将第二棵树的根节点接为第一棵树根节点的**右孩子**，第三棵树的根节点接为第二棵树根节点的**右孩子**，以此类推
<!--SR:!2026-09-17,4,210-->

二叉树还原为单棵树的"口诀"与具体三步方法是什么？
?
**口诀**：左孩子的右链，全部拉回给父节点作孩子；然后斩断所有右链。
**三步方法**：
1. **拉线（找父子）**：若节点 `p` 是 `q` 的左孩子，将 `q` 与 `p` 的**所有右链节点**（`p` 的右孩子、右孩子的右孩子……）拉线相连
2. **抹线（断兄弟）**：抹去二叉树中所有节点与其**右孩子**之间的连线
3. **整理**：按层次重新排布节点
<!--SR:!2026-09-17,4,210-->

如何判断一棵二叉树还原后是"单棵树"还是"森林"？
?
看二叉树的**根节点是否存在右孩子**：
- **无右孩子**：还原后为**单棵树**
- **有右孩子**：还原后为**森林**
<!--SR:!2026-09-17,4,210-->

二叉树还原为森林的具体步骤是什么？
?
1. **切分**：沿着二叉树根节点的**右链**进行切割，把右链上的每个节点及其左子树切成若干独立的小二叉树
2. **还原**：对每一棵独立的小二叉树，运用"二叉树 → 树"的规则（左孩子的右链拉给父节点）分别还原为单棵树
3. **组合**：组合所有还原出的树，即得到原森林
<!--SR:!2026-09-17,4,210-->

树/森林的遍历与二叉树的遍历有何对应关系？（408 考研高频）
?
- **树的先根遍历 / 森林的先序遍历** $\longleftrightarrow$ **二叉树的先序遍历**
- **树的后根遍历 / 森林的后序遍历** $\longleftrightarrow$ **二叉树的中序遍历**
> **易错点**：树的后根遍历，森林的后序遍历（森林的中序遍历=森林的后序遍历），对应的是二叉树的**中序遍历**，而不是二叉树的后序遍历。
<!--SR:!2026-09-17,4,210-->

### 六、二叉排序树（BST）

二叉排序树（BST）的定义与重要性质是什么？
?
对每个结点：左子树所有结点值 **< 根 <** 右子树所有结点值。
因此 **BST 的中序遍历得到递增的有序序列**。
<!--SR:!2026-09-17,4,210-->

BST 的查找和插入过程是怎样的？
?
- **查找**：从根出发，目标值小于当前结点值往左走、大于往右走，相等即找到；走到空结点则查找失败
- **插入**：先按查找过程找插入位置，失败的位置就是插入点——新结点总是作为**叶子**插入
<!--SR:!2026-09-23,8,250-->

BST 删除结点分哪三种情况？
?
1. **叶子结点**：直接删除
2. **只有一棵子树**：用其子树顶替被删结点
3. **有两棵子树**：用其**中序前驱或中序后继**（数值上最接近的结点）替换被删结点，转化为情况 1 或 2
<!--SR:!2026-09-16,3,230-->

BST 查找的平均查找长度与树形有什么关系？
?
- 树越**平衡**，ASL 越接近 $O(\log_2 n)$（理想情况）
- 若按有序序列依次插入，BST 退化为**单链**，ASL 最坏为 $O(n)$
- 因此需要**平衡二叉树（AVL）**把树高控制在 $O(\log n)$
<!--SR:!2026-09-16,3,230-->

### 八、挖空卡片（Cloze）

树是 ==$n \ge 0$== 个结点的有限集合，$n = 0$ 时称为 ==空树==，非空树有且仅有一个 ==根== 结点。
<!--SR:!2026-09-19,4,210!2026-09-16,2,230!2000-01-01,1,250-->

二叉树第 $i$ 层最多有 ==$2^{i-1}$== 个结点，深度为 $h$ 的二叉树最多有 ==$2^h - 1$== 个结点。
<!--SR:!2026-09-16,3,230!2026-09-16,2,230-->

二叉树中 ==$n_0 = n_2 + 1$==（叶子数 = 度为 2 的结点数 + 1）。
<!--SR:!2026-09-17,4,210-->

$n$ 个结点的完全二叉树高度为 ==$\lceil \log_2(n+1) \rceil$==。
<!--SR:!2026-09-19,4,210-->

$n$ 个结点的二叉链表有 ==$n+1$== 个空指针域。
<!--SR:!2026-09-16,3,230-->

三种遍历顺序：先序 ==根左右==，中序 ==左根右==，后序 ==左右根==。
<!--SR:!2026-09-19,4,210!2000-01-01,1,250!2026-09-16,2,230-->

能唯一确定二叉树的两序列组合是 ==先序 + 中序==、==后序 + 中序==、==层序 + 中序== 。
<!--SR:!2026-09-16,3,230!2026-09-16,2,230!2026-09-18,3,250-->

BST（==Binary Search Tree 二叉查找树==） 的 ==中序== 遍历得到递增有序序列；删除有两棵子树的结点时用 ==中序前驱或中序后继== 替换。
<!--SR:!2026-09-15,3,250!2026-09-17,2,230!2026-09-16,2,230-->

树转换为二叉树的口诀是 ==左孩子右兄弟==；树的**先根遍历**对应二叉树的 ==先序== 遍历，树的**后根遍历**对应二叉树的 ==中序== 遍历。
<!--SR:!2026-09-17,4,210!2026-09-18,3,250!2026-09-17,3,250-->
