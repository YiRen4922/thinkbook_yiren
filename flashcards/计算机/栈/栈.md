# 栈 · Flashcards

### 一、定义与基本操作

栈的定义是什么？它的核心特点是什么？
?
栈是只允许在一端进行插入和删除的线性表。
允许操作的一端称为栈顶，另一端称为栈底。
核心特点是后进先出（LIFO）。
<!--SR:!2026-09-28,9,250-->

栈的基本操作有哪些？（写出 ADT 中的主要操作名）
?
`InitStack(&S)`：初始化空栈
`DestroyStack(&S)`：销毁栈
`Push(&S, e)`：入栈
`Pop(&S, &e)`：出栈，用 e 返回
`GetTop(S, &e)`：取栈顶元素，不弹出
`StackEmpty(S)`：判空
`StackLength(S)`：求栈长

### 二、顺序栈

顺序栈的存储结构如何定义？（写出 C 结构体）
?
```c
#define MaxSize 100
typedef struct {
    ElemType data[MaxSize];
    int top;              // 栈顶指针，空栈时 top = -1
} SqStack;
```
<!--SR:!2026-09-28,9,250-->

顺序栈的入栈、出栈、判空、判满操作如何实现？
?
```c
// 判空
bool StackEmpty(SqStack S) { return S.top == -1; }
// 判满
bool StackFull(SqStack S) { return S.top == MaxSize - 1; }
// 入栈
bool Push(SqStack &S, ElemType e) {
    if (StackFull(S)) return false;
    S.data[++S.top] = e;      // 先加 top，再赋值
    return true;
}
// 出栈
bool Pop(SqStack &S, ElemType &e) {
    if (StackEmpty(S)) return false;
    e = S.data[S.top--];      // 先取值，再减 top
    return true;
}
```
<!--SR:!2026-09-28,9,250-->

顺序栈入栈和出栈时，top 指针的操作顺序是什么？为什么？
?
- 入栈：先 `++top`，再赋值 `data[top] = e`
- 出栈：先取值 `e = data[top]`，再 `top--`
- 顺序不能颠倒，否则会覆盖数据或丢失数据。
<!--SR:!2026-09-26,7,250-->

共享栈的判满条件是什么？
?
`top1 + 1 == top2`
<!--SR:!2026-09-28,9,250-->

### 三、链栈

链栈的结构定义是什么？它通常用哪种链表实现？
?
链栈通常用带头结点的单链表实现，所有操作都在头结点之后进行（头插法入栈，头删法出栈）。
```c
typedef struct StackNode {
    ElemType data;
    struct StackNode *next;
} StackNode, *LinkStack;
```
<!--SR:!2026-09-25,5,230-->

链栈的入栈和出栈操作如何实现？
?
```c
// 入栈（头插法）
bool Push(LinkStack &S, ElemType e) {
    StackNode *s = (StackNode*)malloc(sizeof(StackNode));
    s->data = e;
    s->next = S->next;
    S->next = s;
    return true;
}
// 出栈（头删法）
bool Pop(LinkStack &S, ElemType &e) {
    if (S->next == NULL) return false;
    StackNode *p = S->next;
    e = p->data;
    S->next = p->next;
    free(p);
    return true;
}
```

### 四、栈的应用

栈在括号匹配中的应用思想是什么？
?
从左到右扫描字符串：遇到左括号入栈；遇到右括号则弹出栈顶检查是否匹配。
扫描结束后栈空则匹配成功，否则失败。
多类型括号必须用栈，因为需要记录嵌套顺序。
<!--SR:!2026-09-28,9,250-->

栈在表达式求值中的两种主要应用是什么？
?
1. 中缀转后缀（或前缀）：利用栈处理运算符优先级和括号。
2. 后缀表达式求值：遇到操作数入栈，遇到运算符弹出两个操作数计算，结果入栈。
<!--SR:!2026-09-27,8,250-->

中缀表达式转后缀表达式时，运算符栈的处理规则是什么？
?
- 操作数直接输出。
- 左括号 `(` 入栈。
- 右括号 `)`：弹出栈顶运算符输出，直到遇到 `(`（弹出但不输出）。
- 运算符：若栈顶优先级 ≥ 当前运算符，弹出并输出；重复直到栈顶优先级更低或栈空，然后当前运算符入栈。
- 扫描结束：弹出栈中剩余运算符。
<!--SR:!2026-09-28,9,250-->

后缀表达式求值的算法思想是什么？
?
从左到右扫描后缀表达式：
- 遇到操作数：入栈。
- 遇到运算符：弹出栈顶两个操作数（先弹出的是右操作数），计算后将结果压回栈中。
- 扫描结束，栈顶即为结果。
<!--SR:!2026-09-28,9,250-->

$n$ 个不同元素进栈，出栈序列的个数是多少？
?
$$\boxed{C_n = \frac{1}{n+1}\binom{2n}{n} = \frac{(2n)!}{(n+1)!\, n!}}$$

### 五、易错点

顺序栈中，入栈和出栈的 top 操作顺序为什么不能颠倒？
?
入栈若先赋值再 `++top`，会覆盖原栈顶或越界。
出栈若先 `top--` 再取值，会丢失栈顶元素。
必须：入栈先 `++top` 后赋值；出栈先取值后 `top--`。
<!--SR:!2026-09-27,8,250-->

链栈是否需要判满？为什么？
?
不需要。链栈是动态分配结点，除非内存耗尽，否则不会满。
这与顺序栈需要判满不同。
<!--SR:!2026-09-28,9,250-->

### 六、易错点补充

共享栈的结构定义是什么？它为什么有用？
?
```c
#define MaxSize 100
typedef struct {
    ElemType data[MaxSize];
    int top1;    // 栈 1 的栈顶指针，初始 -1
    int top2;    // 栈 2 的栈顶指针，初始 MaxSize
} SharedStack;
```
两个栈共享同一段数组空间，栈 1 从下标 0 向上增长，栈 2 从下标 MaxSize-1 向下增长。
优点：两个栈此消彼长，空间利用率更高。
<!--SR:!2026-09-28,9,250-->

顺序栈和链栈各有什么优缺点？怎么选？
?
顺序栈：
优点 — 随机访问 O(1)，缓存友好，无额外指针开销。
缺点 — 需要预先分配固定大小，可能溢出或浪费。
链栈：
优点 — 动态增长，不需要预分配，不会栈满（除非内存耗尽）。
缺点 — 每个结点多一个指针开销，缓存不友好。
408 选择题常见问法：**不需要判满的是链栈**；**空间利用率更高的是共享栈**。
