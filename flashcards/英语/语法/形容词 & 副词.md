# 第4讲：形容词 & 副词

## 一、形容词（Adj.）

**作用：修饰名词/代词，描述「什么样的」** 位置规则：

1. **前置**：放在名词前面（最常用） a beautiful girl；a tall tree
2. **后置**：
    - 修饰不定代词 something/anything/nothing 时，形容词放后面 something important 重要的事
    - 表语形容词（alive, afraid, asleep, awake）常放系动词后 He is asleep.

> 系动词 + 形容词（表语结构） 常见系动词：be(am/is/are), look, sound, smell, taste, feel, become, get, seem 例：The flower smells sweet.（❌sweetly）

## 二、副词（Adv.）

**作用：修饰动词、形容词、其他副词或整个句子，描述「怎么样、何时、何地」**

- 修饰动词：He runs **fast**.
- 修饰形容词：She is **very** beautiful.
- 修饰副词：He runs **quite** quickly.

### 形容词变副词规则

1. 一般直接 +ly：quick → quickly
2. 以 y 结尾：辅音+y → y变i+ly：happy → happily 元音+y直接+ly：gay → gayly
3. 以 le 结尾：去e+y：simple → simply
4. 特殊不规则：good → well；fast → fast；hard → hard
    
    > 陷阱：hardly 几乎不（≠hard 努力地）；late 迟地；lately 最近
    

## 三、比较级 & 最高级（本讲核心考点）

### 变化规则

#### 规则变化

1. 一般 +er / +est：tall → taller → tallest
2. 以 e 结尾 +r / +st：nice → nicer → nicest
3. 重读闭音节（辅+元+辅）双写尾字母：big → bigger → biggest；thin → thinner；hot → hotter
4. 辅音+y：变y为i +er/est：heavy → heavier → heaviest

#### 不规则变化（必须背）

good/well → better → best bad/badly → worse → worst many/much → more → most little → less → least far → farther（距离更远）/ further（程度进一步）；farthest / furthest

### 核心句型

1. 原级：as + 原级 + as “和……一样” He is as tall as me. 否定：not as/so … as 不如……
2. 比较级（两者对比）：A + be/动词 + 比较级 + than + B Tom is taller than Jack. 修饰比较级：much, a lot, a little, even 后面加比较级 much taller 高得多；a little colder 稍微冷一点
3. 最高级（三者及以上）：the + 最高级 + (in/of 范围) She is the tallest girl in our class.

> 易错点：最高级前面**一般要有the**；但前面有物主代词时不加the：my best friend

## 四、易混辨析

1. too…to… 太…而不能：too cold to go out
2. so + 形容词/副词 + that 如此…以至于：so fast that…
3. such + (a/an) + 形容词 + 名词 + that：such a beautiful girl that…
