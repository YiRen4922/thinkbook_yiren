忘了很正常。先别背 16 种时态，先把这两个东西分开：

> **过去式 = 一般过去时的谓语，自己就能当谓语。**  
> **过去分词 = 完成时和被动语态的“零件”，不能自己单独当谓语。**

---

## 1. 先看动词的五种形式

以 `do` 为例：

| 形式 | 样子 | 作用 |
|---|---|---|
| 原形 | do | 词典形，情态动词后、to 后 |
| 过去式 | did | 一般过去时的谓语 |
| 过去分词 | done | 完成时、被动语态的零件 |
| 现在分词 | doing | 进行时、非谓语 |
| 第三人称单数 | does | 一般现在时 |

再以 `go` 为例：

> go — went — gone

- **went** 是过去式。
- **gone** 是过去分词。

---

## 2. 过去式什么时候用？

过去式只干一件事：**作一般过去时的谓语**。

表示：过去某个时间发生的事，已经结束。

公式：

> **主语 + 过去式 + 其他**

例句：

- I **went** home yesterday.  
  我昨天回家了。
- He **worked** in Beijing in 2020.  
  他 2020 年在北京工作。
- She **saw** him last week.  
  她上周看见他了。

信号词：

> yesterday, last week, ago, in 2020, then, just now

看到这些，谓语就用过去式。

注意：  
过去式自己就是谓语，前面**不能**再加 have/has/had/be。

- ✓ I went.
- ✗ I have went.
- ✓ I have gone.

---

## 3. 过去分词什么时候用？

过去分词 `done` 不能自己当谓语。它前面通常要有“帮手”。

主要有 4 个使用场景：

### ① 完成时：have / has / had + 过去分词

- 现在完成：**have / has + done**  
  I **have finished** my homework.  
  我作业做完了。
- 过去完成：**had + done**  
  He **had left** before I arrived.  
  我到之前，他已经走了。

公式：

> have / has / had + 过去分词

所以：

- ✓ I have **gone**.
- ✗ I have **went**.
- ✓ He has **seen** it.
- ✗ He has **saw** it.

---

### ② 被动语态：be + 过去分词

被动 = **be + 过去分词**。

时态变化在 `be` 上。

- 一般现在被动：The letter **is written** in English.
- 一般过去被动：The bridge **was built** in 1990.
- 一般将来被动：The work **will be done** tomorrow.
- 现在完成被动：The work **has been done**.

这里 `written`、`built`、`done` 都是过去分词。

---

### ③ 情态动词 + have + 过去分词

表示对过去的推测、假设、遗憾。

- He **must have gone** home.  
  他一定回家了。
- You **should have told** me.  
  你本该告诉我。
- I **could have won**.  
  我本来能赢。

结构：

> 情态动词 + have + 过去分词

---

### ④ 非谓语：done 表被动 / 完成

过去分词还能降级成非谓语，作定语、状语。

- **Written** in English, the book is popular.  
  这本书是用英语写的，所以很受欢迎。
- **Faced** with difficulties, we should stay calm.  
  面对困难，我们应该保持冷静。

这里 `Written`、`Faced` 都是过去分词，不是谓语。

---

## 4. 一张表分清

| 句子 | 谓语 | 说明 |
|---|---|---|
| I **did** my homework. | did | 过去式，一般过去时 |
| I **have done** my homework. | have done | 过去分词，现在完成 |
| I **had done** my homework. | had done | 过去分词，过去完成 |
| My homework **was done**. | was done | 过去分词，被动 |
| I **should have done** it. | should have done | 过去分词，情态+have done |
| **Done** carefully, it works. | Done | 过去分词，非谓语 |

---

## 5. 怎么判断用过去式还是过去分词？

三步：

1. **前面有没有 have / has / had？**  
   有 → 后面用过去分词。  
   `have done`，不是 `have did`。

2. **前面有没有 be 动词？**  
   有 → 后面用过去分词，表被动。  
   `is done`，不是 `is did`。

3. **前面什么都没有，句子讲过去？**  
   用过去式作谓语。  
   `I went.`，不是 `I have went.`

一句话：

> **有帮手，用过去分词；没帮手，自己当谓语，用过去式。**

---

## 6. 最容易错的几个

- ✗ I have **went**. → ✓ I have **gone**.
- ✗ I have **saw**. → ✓ I have **seen**.
- ✗ He has **wrote**. → ✓ He has **written**.
- ✗ The bridge was **build**. → ✓ The bridge was **built**.
- ✗ I **done** my homework. → ✓ I **did** my homework. / I **have done** my homework.

规则动词好一点：  
work — worked — worked  
finish — finished — finished  
过去式和过去分词同形，都是 -ed。

不规则动词才需要背三列：  
go — went — gone  
see — saw — seen  
write — wrote — written

## 7. 你现在先记这几句

- 我昨天去了那里。  
  I **went** there yesterday.
- 他已经去了那里。  
  He **has gone** there.
- 我到之前，他已经去了那里。  
  He **had gone** there before I arrived.
- 这封信是用英语写的。  
  The letter **is written** in English.
- 他一定去了那里。  
  He **must have gone** there.

---

## 8. 最后给你一个最简口诀

> **过去式：自己当谓语，表过去。**  
> **过去分词：不能自己当谓语，前面要有 have/has/had/be，或者作非谓语。**

你先把 `go-went-gone`、`do-did-done`、`see-saw-seen`、`write-wrote-written`、`take-took-taken` 这几组背熟，然后每个造两个句子：一个用过去式，一个用 `have/had + 过去分词`。这样就不会再混了。
