## 第 2 讲：代词 Pronoun

**① 代词的定位**：代替名词，避免重复。"我、你、他、它、这个、那个、一些、每个"——中文靠这些词，英语也一样。

**② 七大类一览**

**人称代词（主格 / 宾格）**

|数|第一人称|第二人称|第三人称|
|---|---|---|---|
|单数|I / me|you / you|he, she, it / him, her, it|
|复数|we / us|you / you|they / them|

- 主格作主语：**She** likes music.　宾格作宾语：I like **her**.
- 介词后用宾格：between you and **me**（不用 I）

**物主代词（形容词性 / 名词性）**

||我|你|他|她|它|我们|你们|他们|
|---|---|---|---|---|---|---|---|---|
|形容词性|my|your|his|her|its|our|your|their|
|名词性|mine|yours|his|hers|its|ours|yours|theirs|

- 形容词性必须接名词：This is **my** book.
- 名词性独立使用、不接名词：This book is **mine**.
- 常见错误：`*This is mine book.` ❌

**反身代词**：myself, yourself, himself, herself, itself, ourselves, yourselves, themselves

- 作宾语：I taught **myself** English.（自学）
- 强调"亲自"：I did it **myself**.
- 固定搭配：enjoy oneself（玩得开心）、help oneself to（随便吃用）、by oneself（独自）

**指示代词**：this / that（单数），these / those（复数）——近指 this/these，远指 that/those。

**不定代词（本讲最难点）**，分组记忆：

1. **some / any**：some 用于肯定句，any 用于否定和疑问句；但表示请求、建议的疑问句用 some——Would you like **some** tea?
2. **many / much**：many + 可数（many books），much + 不可数（much water）。
3. **few / a few / little / a little**（常考点）：
    - few / little = 几乎没有（否定含义）；a few / a little = 有一些（肯定含义）
    - few / a few 修饰可数，little / a little 修饰不可数
    - 例：I have **few** friends.（没几个朋友）/ I have **a few** friends.（有几个朋友）
4. **两者 vs 三者**：both（两者都）、either（两者任一）、neither（两者都不）；all（全都）、any（任一）、none（全都不）。
5. **another / other**：another = 另一个（≥3 中再一个）；one...the other...（两个中一个…另一个）；some...others...（一些…另一些）。
6. **each / every**：each 强调个体（each of us），every 强调整体（every student），every 不能单独作主语、后接单数。

**疑问代词**：who（谁，主格）、whom（宾格）、whose（谁的）、what（什么）、which（哪个）——引出疑问句。 **关系代词**：who / whom / whose / which / that——引出定语从句（第 13 讲展开）。

**③ it 的特殊用法（高频）**

- 指时间/天气/距离：**It** is raining. / **It** is 9 o'clock.
- 形式主语：**It** is important to study hard.（真正主语是 to study hard）
- 形式宾语：I find **it** easy to learn English.

**小练习**

1. 选词：I have ______ friends, so I often feel lonely.（few / a few）
2. 填空：This is not my pen. ______（我的）is on the desk.
3. 改错：The book belongs to he.
