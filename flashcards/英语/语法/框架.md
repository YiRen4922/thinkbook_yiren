# 英语语法大框架

> [!abstract] English Grammar Framework
> 由 **词法** 与 **句法** 两大系统构成
> - 🟩 **词法 · 词汇层面**：词性
> - 🟦 **句法 · 句子层面**：成分 / 时态 / 从句 / 句式

---

## 一、词法 · 词汇层面

> [!info] 十大词性
> 实词承载意义，虚词辅助连接。

### 1. 实词 Content Words

| 词性 | 缩写 | 说明 |
|---|---|---|
| 名词 | Noun | 可数性 / 所有格 |
| 动词 | Verb | 及物性 / 限定与非限定 |
| 形容词 | Adj. | 比较级 / 最高级 |
| 副词 | Adv. | 比较级 / 最高级 |
| 数词 | Num. | 基数 / 序数 |

### 2. 虚词 Function Words

| 词性 | 缩写 | 说明 |
|---|---|---|
| 代词 | Pron. | 人称 / 物主 / 反身 / 不定 |
| 冠词 | Art. | 定 / 不定 / 零冠词 |
| 介词 | Prep. | 时间 / 地点 / 方式 |
| 连词 | Conj. | 并列 / 从属 |
| 感叹词 | Interj. | oh, wow, hey |

> [!tip] 核心提示
> **动词是语法的「发动机」**：时态、语态、非谓语、语气全部由动词形态承载——**掌握动词，就握住语法主干**。

## 二、句法 · 句子层面

> 从骨架到成品：成分与句型 → 时态语态 → 非谓语 → 从句 → 特殊句式

### ① 句子的骨架

**八大成分**：主语 S · 谓语 V · 宾语 O · 表语 P · 定语 · 状语 · 补语 C · 同位语

**句子种类**：陈述句 · 疑问句（一般 / 特殊 / 选择 / 反意）· 祈使句 · 感叹句

#### 五大基本句型

| 句型                | 名称   | 例句                   |
| ----------------- | ---- | -------------------- |
| **S + V**         | 主谓   | Birds sing.          |
| **S + V + P**     | 主系表  | He is a teacher.     |
| **S + V + O**     | 主谓宾  | I like music.        |
| **S + V + O + O** | 主谓双宾 | She gave me a book.  |
| **S + V + O + C** | 主谓宾补 | We made him captain. |

> [!note] 补充
> 另有 **There be 存在句**，常单独列出。

### ② 时态系统 · 16 种（时间 × 状态）

| 时间 \ 状态 | 一般 | 进行 | 完成 | 完成进行 |
|---|---|---|---|---|
| **现在** | 一般现在时<br>`do / does` | 现在进行时<br>`am/is/are doing` | 现在完成时<br>`have/has done` | 现在完成进行时<br>`have/has been doing` |
| **过去** | 一般过去时<br>`did` | 过去进行时<br>`was/were doing` | 过去完成时<br>`had done` | 过去完成进行时<br>`had been doing` |
| **将来** | 一般将来时<br>`will do` | 将来进行时<br>`will be doing` | 将来完成时<br>`will have done` | 将来完成进行时<br>`will have been doing` |
| **过去将来** | 一般过去将来时<br>`would do` | 过去将来进行时<br>`would be doing` | 过去将来完成时<br>`would have done` | 过去将来完成进行时<br>`would have been doing` |

### ③ 语态 & 非谓语动词

| 语态 Voice | 非谓语 Non-finite |
|---|---|
| 主动语态 `do`<br>被动语态 `be + 过去分词`<br>_The book was written._ | 不定式 `to do`（目的 / 将来）<br>动名词 `doing`（名词性）<br>现在分词 `doing`（主动 / 进行）<br>过去分词 `done`（被动 / 完成） |

### ④ 三大从句（复合句的核心）

> [!note] 名词性从句
> 主语从句 · 宾语从句 · 表语从句 · 同位语从句
> 引导词：`that / whether / if / wh-`

> [!note] 定语从句
> 限制性 · 非限制性
> 关系代词：`who / whom / whose / which / that / as`
> 关系副词：`when / where / why`

> [!note] 状语从句（9 类）
> 时间 · 地点 · 原因 · 结果 · 目的 · 条件 · 让步 · 方式 · 比较
> 常见引导词：`when / because / if / although …`

### ⑤ 语气 & 特殊句式

- **虚拟语气**：与现在 / 过去 / 将来事实相反；建议愿望 `should do`
- **倒装**：完全倒装 / 部分倒装
- **强调句**：`It is … that …`
- **省略**
- **主谓一致**
- 其他：独立主格 · 插入语 · 直接引语与间接引语 · 反意疑问句 · it 句型
