# 第6讲：动词总论（词法最后一讲，承上启下，动词是英语语法核心）

动词：表示**动作或状态**的词，是句子谓语的核心。所有时态、语态、非谓语、虚拟语气全部由动词变形实现。

## 一、动词四大分类

### 1. 实义动词（行为动词，有实际含义，可以单独作谓语）

1）**及物动词 vt.**：后面**必须直接接宾语**，意思才完整 例：I love **music**. love后面要有宾语music 2）**不及物动词 vi.**：本身意思完整，**后面不能直接加宾语**；如果要加宾语，必须搭配介词 例：He runs.（不及物，无宾语） He listens **to** music. listen不能直接接music，要加介词to

> 很多动词既是vt又是vi：study，read，start

### 2. 系动词（后面接表语，表语多为形容词/名词，**不表动作，表状态**）

五大类系动词：

1. be动词：am / is / are / was / were
2. 感官类：look看起来，sound听起来，smell闻起来，taste尝起来，feel摸起来/感觉
3. 变化类：become, get, turn, grow（变得）
4. 保持类：keep, stay（保持）
5. 似乎类：seem（似乎） ✅ 句型：主语 + 系动词 + 表语（SVP 主系表句型） ❌ 易错：系动词不能用副词修饰，要用形容词。 The flower smells **sweet**.（sweet形容词，不用sweetly）

### 3. 助动词（无实义，**帮助实义动词构成否定、疑问、时态**，不能单独作谓语）

基础助动词：do / does / did；have / has / had；will / would；be(am/is/are/was/were) 例：Do you like apples? do帮助构成疑问；I have finished. have帮助构成完成时

### 4. 情态动词（表语气：能够、可以、必须、应该；**后面直接加动词原形**，无人称变化）

基础情态动词：can/could, may/might, must, should, need, will/would 特点：

1. 否定直接加not：can not = can’t；must not = mustn’t
2. 不能单独作谓语，必须搭配动词原形 例：He can swim.
    
    > 重点辨析： must（必须）提问： —Must I go now? —Yes, you must. —No, you **needn’t / don’t have to**.（不必，不能用mustn’t；mustn’t表禁止）
    

## 二、动词的四种基本变形（重中之重，后面时态全靠这四个）

1. 原形：do（原形，用于情态、to后面、一般现在时复数主语）
2. 第三人称单数（三单）：does（一般现在时，主语第三人称单数） 变化规则：一般+s；s/x/ch/sh/o结尾+es；辅音+y→ies
3. 过去式：did（一般过去时谓语）
4. 过去分词：done（配合have/be，完成时、被动语态）

> 动词分为**规则动词**和**不规则动词** 规则：过去式&过去分词 +ed； 不规则：无ed，需要单独记忆（如do-did-done；go-went-gone）

## 三、谓语动词 vs 非谓语动词（先建立概念，第10、11讲细讲）

- **谓语动词**：句子真正的动词，跟着主语，受时态、人称变化。一个简单句**只能有一套谓语**。
- **非谓语动词**：不作句子谓语，变形：to do / doing / done；不受主语人称时态限制，一个句子里除谓语外，如果还要用动词，必须变成非谓语。 例：I want **to eat**. 谓语want；to eat是非谓语。

3. 判断：listen是及物还是不及物动词？
