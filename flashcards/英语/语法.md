# 英语语法 · 考研英语一 Flashcards（重写查漏版）

### 〇、总纲：考研语法怎么用

考研英语一语法主要考什么？
?
**不考语法单选**。语法主要用于：**长难句拆解、阅读定位、翻译表达、写作升格**。
核心动作：**找谓语 → 定主干 → 切从句/非谓语 → 理逻辑 → 翻译**。
理解：考研语法的"考场"在阅读和翻译里，学语法要能"看得懂句子"，而不是背规则。

长难句拆解五步？
?
1 找连接词、关系词、标点
2 找谓语动词（时态/情态/be）
3 去插入语、介词短语、非谓语
4 定主句主干
5 把从句、非谓语逐层挂回主干
例句：The boy **who** was crying **left** home. → 先找 who（连词）、left（谓语），删从句，主干 = The boy left home.（那个哭着的男孩离开了家）

一个简单句能有几个谓语动词？
?
通常**只有一个谓语动词**。
出现第二个动词时，要么变成**从句谓语**（加引导词），要么变成**非谓语 to do/doing/done**，要么**并列谓语**（and 连接）。
例句：I **want** to **buy** a book.（want 是谓语；buy 和 want 是同一主语的两个动作，buy 只能降级为非谓语 to buy）
理解：英语一个"动作层"只容一个谓语，多出来的动词必须"降级"。

谓语动词:::句子中承担**时态、语态、情态**变化的动词；一个简单句通常只有一个谓语。例：He **has gone** home.（has gone 承担时态 = 谓语）

### 一、谓语动词：时态、语态、情态

现在完成时和一般过去时的核心区别？
??
现在完成时：强调**过去动作对现在的影响**，或**一直持续到现在**（信号：for / since / so far / in recent years）
一般过去时：只陈述**过去某时间点**发生的事（信号：yesterday / in 2020 / ago / last...）
判断法：**有明确过去时间词用 did；没有则优先考虑 have done**
例句对比：I **have lost** my key.（现在没钥匙 → 影响现在）/ I **lost** my key yesterday.（只说昨天的事，钥匙现在找没找到不知道）

过去完成时 had done 表示什么？
?
表示"**过去的过去**"：以过去某个时间为参照点，在该时间之前已经完成的动作。
信号：**by the time / before / after / when / by 2020**。
例句：I **had finished** my homework when my mother came back.（妈妈回来 = 过去参照点；写作业在"更早"的时刻完成）
理解：画一条时间轴，**had done 永远在 did 的左边**。

一般将来时有哪几种表达？各自强调什么？
??
**will do**：中性将来，说话时临时决定——I **will call** you later.（现在才想到要打）
**be going to do**：有计划或有迹象——Look at the clouds! It **is going to rain**.（有迹象）
**be doing**：已安排好的近期计划——I **am leaving** tomorrow.（票都订好了）
**be to do**：正式安排——The meeting **is to start** at 9.（会议通知）
**be about to do**：即将，不接具体时间状语——He **is about to** leave.（马上就走）
理解：从上到下"计划性"越来越强：突然决定 → 有迹可循 → 已安排 → 正式 → 迫在眉睫。

现在完成进行时 have been doing 强调什么？
?
强调动作**从过去开始一直持续到现在**，且**很可能继续**。
例句：I **have been reading** this book for two weeks.（两周了，还在读）
与 have done 区别：完成时强调"**结果**"——I **have read** the book.（读完了）；完成进行时强调"**持续性/未停止**"。

被动语态的构成？
??
被动 = **be + 过去分词**，时态体现在 be 上。
一般现在 is/am/are done；一般过去 was/were done
一般将来 will be done；现在完成 has/have been done
情态动词：can / must / should be done
非谓语被动：to be done, being done, having been done
例句：The bridge **was built** in 1990.（时态过去 → be 用 was；动词用过去分词 built）

情态动词 + have done 怎么用？
??
**must have done**：对过去**肯定**推测——The ground is wet. It **must have rained**.（下过雨）
**can't / couldn't have done**：对过去**否定**推测——He **can't have gone** abroad; I saw him this morning.
**should / ought to have done**：**本该做而未做**——You **should have told** me earlier.（你没告诉）
**needn't have done**：**本不必做却做了**——We **needn't have booked** a hotel.（白订了）
**could have done**：**本来能做**却没做——I **could have won**, but I gave up.
**may / might have done**：过去可能——He **may have missed** the bus.
理解：结构都是"情态动词 + have done"，表对过去事实的判断/假设，意思由情态动词决定。
<!--SR:!2026-09-19,3,250!2000-01-01,1,250-->

哪些动名词结构主动表被动？
?
**need / want / require doing = need to be done**
**be worth doing**
例句：The car **needs repairing**.（= needs to be repaired 车"被"修）
The book is **well worth reading**.（值得"被"读）
理解：主语是"物/事"，doing 形式主动、意义被动；中文译"被"或直接按主动理解。

### 二、非谓语动词

三种非谓语 to do / doing / done 的分工？
??
**to do**：目的、将来、具体一次性动作——I came **to help** you.（目的）
**doing**：进行、主动、伴随、习惯——He is **reading**.（进行中，主动）
**done**：完成、被动——**Written** in English, the book is popular.（书"被写" → 被动）
一句话：**to do 目的/将来，doing 主动/进行，done 被动/完成**。
<!--SR:!2026-09-19,3,250!2000-01-01,1,250-->

非谓语完成式和被动式？
??
**to have done**：不定式动作**先于谓语**——He seems **to have finished** the work.（先写完，后"看起来"）
**to be done**：不定式被动——**To be invited** is an honor.（被邀请）
**having done**：分词动作先于谓语——**Having finished** homework, he went to bed.
**having been done**：分词完成被动——**Having been told** many times, he still forgot.
**done**：过去分词表被动/完成
理解：to have done / having done = 从句子里另一个谓语动词**之前**就发生的动作。

独立主格是什么？
?
非谓语有**自己的逻辑主语**，且与**主句主语不同**。
结构：名词/代词 + doing / done / to do / 形容词 / 介词短语。
例句：**The work done**, we went home.（逻辑主语 the work，主句主语是 we——两拨人/两件事）
**Weather permitting**, we'll go.（天气允许的话就去）
理解：逗号前是"没有谓语动词的小结构"，译成"……之后 / 如果……"。

with 复合结构？
?
**with + 宾语 + doing / done / to do / 形容词 / 介词短语**。
例句：**With prices going up**, people cut spending.（物价上涨 = 宾语 prices + doing，主动进行）
**With the problem solved**, we felt relieved.（问题被解决 = done，被动）
理解：翻译常作**伴随、原因、条件**："随着…… / 由于……"。

不定式省略 to 的情况？
?
使役 **make / let / have + sb + do**
感官 **see / watch / hear / feel / notice + sb + do**
变被动要还原 to：**be made to do, be seen to do**
例句：I **let** him **go**.（主动省略 to）/ He **was made** to **work** late.（被动 to 回来了）
help sb **(to) do** 可省可不省

remember / forget 后接 doing 和 to do 有什么区别？
??
**remember / forget doing**：记得/忘记**做过**（已做）
**remember / forget to do**：记得要/忘记**去做**（未做）
口诀：**doing 已做，to do 未做**
例句：I remember **locking** the door.（锁过了）/ Remember **to lock** the door before leaving.（待会儿要去锁）

stop / try / regret 后接 doing 和 to do 的区别？
??
**stop doing**：停止做手头的事；**stop to do**：停下来去做另一件事——He stopped **smoking**.（戒烟了）/ He stopped **to smoke**.（停下别的事去抽烟）
**try doing**：尝试做；**try to do**：努力做——Try **knocking** the door.（试一下敲门）/ Try **to finish** it on time.（努力按时完成）
**regret doing**：后悔做过；**regret to say/inform**：遗憾地告知——I regret **telling** him.（后悔说了）/ We regret **to inform** you.（遗憾地通知）——两个意思完全不同

interested 和 interesting 有什么区别？
??
**-ed 结尾**形容人"**感到……的**"：I'm **interested** in English.（我感兴趣）
**-ing 结尾**形容事物"**令人……的**"：an **interesting** book.（令人感兴趣的书）
规则：**-ing 表"令人"，-ed 表"感到"**。同类词：excited/exciting, tired/tiring, bored/boring
理解：先有事物"令人"怎样（-ing），人才"感到"怎样（-ed）。

感官动词 see / watch / hear 后面接 do 还是 doing？
??
**see sb do**：看到**全过程**，动作已完成——I saw him **cross** the street.（看他从这边走到那边，全程）
**see sb doing**：看到**正在做**，动作进行中——I saw him **crossing** the street.（路过时瞥见他正在过马路）
注意：变被动时省略的 to 要还原——sb **is seen to do** sth

"让某人做某事"：make / have / let / get 的用法差异？
?
**make / have / let + sb + 动词原形**（省略 to）——He **made** me **wait**.（强迫我等）
**get + sb + to do**（要还原 to）——He **got** me **to help** him.（说服/请我帮忙）
被动：sb **is made to do**——make 的被动要带 to
理解：make 最强硬（强迫），get 带"说服"的意味。

### 三、三大从句

定语从句关系词 that / which / who / whom / whose 怎么选？
??
**人**用 who / whom / that；**物**用 which / that；**所属**用 whose
作**主语**时不能省略；作**宾语**时可省略，介词后不行
**that 不能放在介词后**：in which ✓，in that ✗
例句：The man **who** called you is my uncle.（who 作从句主语）/ The book **(which) I bought** is cheap.（作宾语可省）

什么时候只能用 that？什么时候只能用 which？
??
**只用 that**：先行词被**序数词、最高级、the only / the very / all / no** 等修饰；先行词**既有人又有物**
**只用 which**：**非限制性**定语从句（逗号隔开）；**介词 + which**
例句：This is the **only** thing **that** matters.（the only → that）/ **Paris, which** is beautiful, attracts many tourists.（逗号非限 → which）

限制性 vs 非限制性定语从句？
??
**限制性**：无逗号，**必要信息**，that 可引导——The book **that I bought** is cheap.（"哪本书"靠它限定）
**非限制性**：逗号隔开，**补充信息**，不能用 that；which 可指代整个主句——He passed the exam, **which surprised us**.（"他及格"这件事令我们惊讶）
理解：非限制性是"顺带一提"，划掉也不影响句意。

介词 + 关系代词？
??
**介词 + which / whom**，不能用 that / who。
例句：The house **in which** he lives = The house **he lives in**.（介词可前置可后置；用 that 时只能放后面）
理解：介词来自短语搭配：live **in** the house → in which。

as 和 which 引导非限制定语的区别？
??
**as**："正如"，可放**句首、句中、句尾**，常与 know / see / expect / say 搭配——**As** is known to all, practice makes perfect.（众所周知）
**which**：只能放**主句后**，指代整个主句——He was late, **which** annoyed us.
判断：**句首只能用 as**（which 不能开头）。

定语从句和同位语从句怎么区分？
??
**定语从句**：修饰名词，"……的"；that 可换 which 或省略，**在从句中作成分**。
**同位语从句**：解释名词内容（news / fact / idea / suggestion）；that **不省略、不充当成分**。
判断法：**that 后是完整句子 → 同位语；缺成分 → 定语**。
例句：The news **that he won** is true.（he won 完整 → 同位语，"他赢了这个消息"）
The news **that he told me** is true.（told 缺宾语 → 定语，"他告诉我的那个消息"）

名词性从句有哪四种？语序要求？
??
四种：**主语从句、宾语从句、表语从句、同位语从句**。
引导词：that（无意义）、whether / if（是否）、what / which / who / how / why 等。
重要规则：名词性从句一律用**陈述语序**。
例句：**What he said** is true.（What he said 整个做主语 = 主语从句）
<!--SR:!2000-01-01,1,250!2026-09-17,1,230-->

what 和 that 引导名词性从句区别？
??
**what** = the thing(s) that，在从句中**作主语/宾语/表语**，不能省——I know **what** he said.（= the things that he said）
**that** 只起连接作用，**不作成分**；宾语从句中可省，主语/同位语中不可省——I know **(that) he said it.**（句子已完整）
理解：从句里"缺东西"用 what（what 自己顶个成分）；"什么都不缺"用 that。

宾语从句的时态呼应规则？
?
主句用过去时 → 从句相应用**过去时态**——He said he **was** tired.
例外：**客观真理保持一般现在时**——The teacher said the earth **goes** round the sun.
主句用现在时/将来时 → 从句按实际需要选时态。

状语从句主要类型和引导词？
??
时间：when / while / as, before / after, since / until
条件：if / unless / as long as / provided that
原因：because / since / as / for
结果：so...that / such...that
目的：so that / in order that
让步：although / though / even though / while / no matter wh- / wh-ever
方式：as / as if / as though
比较：than / as...as
例句：**Although** it rained, they still went out.（让步）/ She was so tired **that** she fell asleep.（结果）

"主将从现"是什么？
?
主句用**一般将来时**，if / when / before / until / as soon as 等从句用**一般现在时**表将来。
例句：**If it rains** tomorrow, we **will stay** at home.（✗ If it will rain）
理解：规则只作用于时间/条件从句，其他从句不受影响。

### 四、虚拟语气

与现在事实相反的虚拟条件句怎么构成？
??
从句：if + **一般过去时**（be 一律用 **were**）
主句：**would / could / might + 动词原形**
例句：**If I were you**, I would accept the offer.（事实：我不是你——我要是你）
理解：把"现在"**倒退一格**成过去式，表示与事实相反的假设。

与过去事实相反的虚拟条件句怎么构成？
??
从句：if + **had done**
主句：would / could / might + **have done**
例句：**If I had studied** harder, I **would have passed** the exam.（事实：没好好学，也没过）
理解：对过去的假设 = 时间再往后退一格 = 过去完成式。

与将来事实相反的虚拟条件句怎么构成？
??
从句：if + **should do / were to do** / 一般过去时
主句：would / could / might + 动词原形
例句：**If it should rain** tomorrow, we would cancel the picnic.（大概率不下雨）
理解：将来虚拟 = 可能性很低的假设，从句用 should / were to。

省略 if 的倒装虚拟？
??
**Had I known**... = If I had known...
**Were I you**... = If I were you...
**Should it rain**... = If it should rain...
例句：**Had I known** the truth, I would have come earlier.（要是早知道真相……）
注意：否定 not 不放句首：**Had I not** known / **Were it not for** your help.

"建议/要求/命令"类动词后的宾语从句用什么？
??
insist / suggest / order / demand / require / propose / recommend + that + **(should) + 动词原形**。
例句：The doctor suggested that he **(should) take** more exercise.
注意：**suggest 表"暗示、表明"、insist 表"坚持说"**时不用虚拟——His look suggested that he **was** angry.
延伸：**It is necessary / important / essential that + (should) do**。

wish 和 if only 后面的虚拟语气怎么变？
??
对现在：wish + 一般过去时（be 用 **were**）——I wish I **were** taller.
对过去：wish + **had done**——I wish I **had worked** harder.
对将来：wish + **would / could + 动词原形**——I wish he **would come**.
例句：**If only I had been more careful!**（要是当时更细心就好了）
另记：**It's (high) time that + 过去时**或 should do——It's time we **went** home.

but for / otherwise / without 虚拟？
??
**but for** = 要不是；**without** = 没有；**otherwise** = 否则
后接主句常用 **would / could / might + do / have done**。
例句：**But for** your help, I **would have failed**.（要不是你帮忙，我就失败了——事实上成功了）
**Without** water, nothing **could live**.
理解：隐含提供一个"虚拟条件"，相当于 if it weren't for / if there were no。

### 五、特殊句式

部分倒装什么时候用？怎么倒？
??
**否定/半否定词开头**：never, hardly, seldom, little, no sooner...than, not only...but also
**Only + 状语开头**
**So / Neither / Nor** 表"也……/也不……"
虚拟条件句省略 if（Had I...）
规则：**助动词 / be / 情态动词提到主语前**。
例句：**Never have I seen** such a scene.（= I have never seen...）
He can't swim, **neither can I**.（他不会游泳，我也不会）

完全倒装什么时候用？
?
here / there / now / then + 不及物动词 + **主语**。
方位副词或介词短语开头。
例句：**Here comes** the bus.（= The bus comes here.）
**In the center** of the square **stands** a statue.
注意：主语是代词时不倒装：**Here he comes.**（✗ Here comes he.）

as / though 让步倒装？
??
**形容词 / 副词 / 名词 / 动词 + as / though + 主语 + 谓语**。
例句：**Young as** he is, he knows a lot.（= Though he is young 虽然他年轻）
**Try as** he might, he failed.（不管多努力，还是失败了）
理解：这里的 as 等于 though（虽然），必须倒装。

强调句型 It is/was ... that ... 怎么用？怎么判断？
??
**It is/was + 被强调部分 + that/who + 其余部分**。
例句：**It was in 2020 that** the pandemic broke out.（强调时间状语，用 that 不用 when）
判断法：**去掉 It is/was...that 后句子仍完整 → 强调句**。
注意：强调人可用 who；强调时间/地点不用 when/where。

do / does / did 强调谓语？
?
用于**一般现在/一般过去肯定句**，强调动词本身。
例句：I **do believe** you.（我确实相信你）
He **did come** yesterday.（他昨天确实来了）
理解：想强调"动作确实发生"时，在谓语前加 do/does/did（谓语动词还原原形）。

### 六、主谓一致、平行、比较

主谓一致"就近原则"有哪些？
??
**either...or / neither...nor / not only...but also / there be**：谓语与**最近的主语**一致。
例句：Either you or **he is** wrong.（看离得最近的 he）
There **is** a pen and two books on the desk.（a pen 最近）
理解：靠近谓语的成分"说了算"。

主谓一致"就远原则"有哪些？
??
主语 + **with / together with / along with / as well as** + 其他成分：谓语只看**真正的首个主语**。
例句：The teacher, **together with** his students, **is** going to the museum.（谓语看 teacher）
Tom **as well as** his friends **likes** playing basketball.
理解：with 后面是"附带"成分，划掉不看，谓语跟真正的首主语。

集合名词、不定代词主谓一致？
??
**family / team / government** 看作**整体**用单数，强调成员用复数——The family **is** large.（整体）/ The family **are** watching TV.（成员们）
**each / every / either / neither / one / no one / nobody** 一律**单数**——Every student **has** a book.
**none 可单可复；the number of 单数；a number of 复数**——The number of students **is** 50. / A number of students **are** absent.

什么是平行结构？
?
**and / or / but / not only...but also / either...or / neither...nor / rather than** 连接的两边**语法形式必须一致**。
例句：Reading books and **watching movies** are both fun.（两边都是 doing）
She likes **swimming** but hates **running**.
比较对象也要一致：The weather in Beijing is colder than **that** in Shanghai.（that = the weather，拿天气比天气）

比较结构：as...as 和 the + 比较级？
??
**as + 原级 + as**：和……一样；否定 **not as/so ... as**——He is **as tall as** me.
**the + 比较级, the + 比较级**：越……就越……——**The more** you practice, **the better** you get.
**倍数 + as + 原级 + as / 倍数 + the size of**——This room is **twice as big as** yours. = **twice the size of** yours.
**no more than = 仅仅**；**not more than = 不超过**——He has **no more than** 10 yuan.（只有 10 元）
**more...than = 与其说……不如说……**——He is **more** lazy **than** stupid.（与其说笨，不如说懒）

### 七、长难句、翻译、写作迁移

that 的常见用法？
??
引导**定语从句、名词性从句、结果状语 so...that / such...that、强调句、目的 so that**——He is so tired **that** he fell asleep.
作**代词**指代前文，避免重复——The weather here is colder than **that** in Shanghai.
核心区分：**名词性从句中不作成分；定语从句中作成分**。

it 的形式主语 / 形式宾语？
??
**It** is important **to learn** grammar.（真正主语是 to learn grammar）
**It** is said **that**...（真正主语是 that 从句）
I find **it** hard **to solve** the problem.（真正宾语是 to solve）
理解：**it 先占位**，真正的主语/宾语（to do / doing / that 从句）挪到后面，避免头重脚轻。

省略现象？
?
并列句省略相同成分——I like tea **and** (I like) coffee.
状语从句省略主语 + be——**When (he was) young**, he lived in London.
不定式省略 to——make / let / see sb **do**。
翻译时**补出省略成分**。

否定转移？
??
**I don't think he is right.** = 我认为他不对。（不是"我不认为他是对的"）
not 形式上在主句（don't think），**意义上在从句**（isn't right）。
常见动词：**think / believe / suppose / imagine / expect**。

定语从句翻译？
??
**短定语前置**："……的"——a book that I bought → 我买的书
**长定语后置**：重复先行词，或用"这/该/其"——the plan that was made in 2020 → 2020 年制定**的**计划（或"该计划"）
**非限制性**定语可译成**并列句**——He passed the exam, which surprised us → 他考过了，**这**让我们很惊讶。

被动语态翻译？
??
可译"被"，但更常转**主动**：人们/大家/我们/据……
例句：**It is said that**... 据说……
**He was seen to enter.** 有人看见他进入。
理解：中文习惯用主动句，"被"字太多显得生硬，翻译时常补出泛指主语。

插入语 / 同位语处理？
?
**双逗号、破折号、括号**之间常是插入语。
先跳过，读完主干再补译；同位语可译"**即/也就是/冒号**"。
例句：Many people, **especially the young**, like it. → 很多人——尤其是年轻人——喜欢它。

代词指代？
?
**it / they / this / that / these / those / one / do so** 常回指前文名词、短语或整句。
例句：He said he would come and he **did so**.（did so = came）
翻译时**还原指代对象**，避免"它/这"悬空。

抽象名词转动词？
?
**analysis → 分析；arrival → 到达；growth → 增长；decision → 决定**。
例句：**The arrival of** the train **delayed** us. → 火车"到达"晚点了我们。（arrival 译成动词"到达"更自然）
理解：英语多用名词（静态），中文多用动词（动态），翻译时把名词还原成动词更顺。

写作可迁移句型？
??
倒装：**Not only does** he read, **but** he also writes.
强调：**It is** practice **that** matters.
虚拟：**Were I** you, I would...
非谓语：**Faced with** difficulties, we should stay calm.
从句：**What matters is that**...
理解：这五句是"作文万能骨架"，每种挑 1 句背熟即可。

写作中不要堆砌语法？
?
先保证**主谓一致、时态、单复数、冠词、搭配**正确。
再用**倒装、强调、虚拟、非谓语、从句**各 1—2 处提分即可。
理解：语法点贵在"用得巧"，不贵在"用得多"；堆砌反而暴露错误。
